状态色铁律：绿 = 通过/正常 ｜ 红系 = 失败/高风险/阻塞（深浅两阶）｜ 橙 = 警告/进行中 ｜ 灰 = 未执行/待评审 ｜ 主色蓝（#409EFF）仅用于主按钮、链接与选中态，不表达任何状态。所有状态均以「颜色 + 形状 + 文案」三重编码，不单靠颜色区分。

04按钮体系（主 / 次 / 文字 / 危险）

主按钮实底蓝 + 白字（hover 加深）；次按钮白底描边；文字按钮透明；危险按钮与状态红同源。圆角 6px、高 32px。

hover：主钮 #409eff → #337ecc；次钮描边加深 + 浅灰底
