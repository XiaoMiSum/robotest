状态色铁律：绿 = 通过 / 正常 / 缺陷「轻微」｜ 红系 = 失败 / 高风险 / 缺陷「致命」/阻塞（深浅两阶）｜ 橙 = 警告 / 进行中 / 缺陷「严重」｜ 灰 = 未执行 / 待评审 / 停用 / 缺陷「一般」｜ 主色蓝（#409EFF）仅用于主按钮、链接与选中态，不表达任何状态。所有状态均以「颜色 + 形状 + 文案」三重编码，不单靠颜色区分。

01色彩体系

白 / 灰 / 黑构成 90% 以上的画面；辅助色取自 Element Plus 功能色，仅在语义处出现。色值以 web/src/assets/styles/variables.scss 为单一事实源；本页实际渲染引用的是演示令牌同值短名（--n-* ↔ --color-neutral-*、--brand-* ↔ --color-primary-*、--st-* / --priority-* / --bug-* ↔ 各状态变量），移植到正式实现时以长名为准。

02字体与排版

系统无衬线字体栈（--font-family：-apple-system / Segoe UI / PingFang SC / Microsoft YaHei …），等宽用 --font-mono；不依赖外部字体，靠留白与字重建立层级。

--font-size-3xl · 24px / 650执行结果总览
--font-size-2xl · 20px / 650 · 页面标题测试计划详情
--font-size-lg · 16px / 600 · 卡片/弹窗标题执行记录
--font-size-base · 14px / 400 · 正文用于日常操作与表格内容，保证长时间阅读不疲劳。
--font-size-sm · 13px / 500 · 表头/菜单状态 · 优先级 · 通过率
--font-size-xs · 12px / 400 · 辅助说明最后执行于 2026-09-20 14:32 · 由 张明 触发
--font-size-2xs · 10px / 400 · 角标NEW · 仅用于极小角标，正文不使用
--font-mono · 标识符/路径/编号GET /api/v1/orders/{id}

03留白与间距

06按钮体系（主 / 次 / 文字 / 危险）

主按钮实底蓝 + 白字（hover 加深）；次按钮白底描边；文字按钮透明；危险按钮与状态红同源。圆角 6px、高 32px。

hover：主钮 #409eff → #337ecc；次钮描边加深 + 浅灰底

07表单控件

聚焦态 1px 蓝描边 + 3px 淡蓝光圈；错误态红描边 + 行下红字提示。演示 base.css 的光圈取 rgba(51,112,255,.14)，正式实现（variables.scss EP 桥接层）为 rgba(64,158,255,.1)，同为极低透明度蓝光圈。
