函数管理

项目内可复用的自定义函数，内置函数由平台统一提供

  • uuid 内置
    生成随机 UUID（去连字符）
  • random 内置
    生成指定区间的随机整数
  • timestamp 内置
    当前时间戳，默认毫秒；可指定秒或日期格式
  • json_read 内置
    从 JSON 文本中按 JsonPath 提取值
  • signParams 自定义 项目 已启用
    按业务规则生成签名参数
    删除
  • genOrderNo 自定义 空间 已启用
    生成雪花订单号
    删除
  • legacyFmt 自定义 项目 已停用
    旧版报文格式化（已停用）
    删除
