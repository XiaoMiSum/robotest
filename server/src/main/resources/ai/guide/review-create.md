## 如何发起测试评审

1. 进入「功能测试 → 评审」页（路由 `/workspace/projects/reviews`）。
2. 点击「发起评审」，填写评审标题、选择评审类型，并在用例规划中选择要评审的用例文档。
3. 选择参与人（空间成员），发起后系统生成评审快照（冻结当前用例版本）。
4. 发起人以外的参与人可进入评审详情逐用例提交评审记录（通过/不通过/阻塞）；发起人汇总后可点击「完成评审」。
5. 评审进度与通过率在评审列表实时可见。

## 角色说明

- 发起人：创建评审、调整规划用例、完成评审、删除评审。
- 参与人：查看快照、提交个人评审记录。
