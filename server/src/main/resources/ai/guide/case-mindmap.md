## 如何编辑用例脑图

1. 进入「功能测试」页（路由 `/workspace/projects/functional-testing`），选择目标项目。
2. 页面为用例脑图编辑区：目录 → 文档 → 用例节点三层结构，支持拖拽调整层级与顺序。
3. 点击节点可编辑标题、类型、优先级，或在节点面板维护用例内容（前置条件、步骤、预期结果）。
4. 支持用例节点复制、移动、删除；变更自动同步保存，多人在线协同实时可见。

## 用例类型与优先级

- 类型：功能、接口、性能、安全、兼容性等。
- 优先级：P0（最高）/ P1 / P2 / P3，P0 为关键路径必须覆盖。
