## 如何执行测试计划

1. 从计划列表进入计划详情页（路由模板 `/workspace/projects/plans/{planId}`）。
2. 左侧选择文档，点击用例节点查看执行快照（用例步骤与预期）。
3. 点击「提交记录」选择执行结论：通过 / 失败 / 阻塞，失败或阻塞需填写说明。
4. 已提交记录可再次覆盖；执行进度与通过率实时统计。

## 执行结论含义

- 通过：实际结果符合预期。
- 失败：实际结果与预期不符，一般应同步创建缺陷。
- 阻塞：前置条件或环境未就绪，无法执行。
