## 如何提交缺陷

1. 进入「缺陷管理」页（路由 `/workspace/projects/bugs`）。
2. 点击「新建缺陷」或直接「创建缺陷」（路由 `/workspace/projects/bugs/create`），填写标题、严重等级、优先级、缺陷类型。
3. 建议填写复现步骤（reproSteps），便于处理人定位；可关联相关用例、计划或模块。
4. 提交后缺陷状态为「激活」（active），系统默认指派给提交人，可再指派给其他成员。
5. 提交人在处理人解决前可先「确认」缺陷为有效缺陷。

## 严重等级

fatal（致命）/ serious（严重）/ general（一般）/ minor（轻微）。
