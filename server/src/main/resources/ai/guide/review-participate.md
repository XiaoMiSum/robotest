## 如何参与测试评审

1. 从评审列表进入对应评审详情页（路由模板 `/workspace/projects/reviews/{reviewId}`）。
2. 左侧选择文档，点击用例节点查看评审快照（用例内容、前置条件、步骤、预期）。
3. 点击「提交记录」选择评审结论：通过 / 不通过 / 阻塞，可附文字说明。
4. 已提交的记录可再次修改覆盖，以最后一次为准；发起人可汇总所有人记录后完成评审。

## 评审结论含义

- 通过：该用例符合预期。
- 不通过：存在缺陷或与预期不符，需记录原因。
- 阻塞：前置条件未满足或依赖未就绪，暂时无法评审。
