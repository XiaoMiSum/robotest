## 如何管理空间成员与项目

1. 空间管理员进入「成员」页（路由 `/workspace/members`）管理空间成员：邀请新成员、调整成员角色（管理员/成员）、移除成员。
2. 空间管理员进入「项目」页（路由 `/workspace/projects`）创建项目、编辑项目信息、归档/删除项目。
3. 空间成员默认可见空间内全部项目并可进入协作，编辑/删除等写操作受角色权限约束。

## 角色说明

- 管理员：空间内全部业务权限（含成员与项目管理）。
- 成员：除删除/归档项目、管理成员、编辑空间信息外的常规权限。
