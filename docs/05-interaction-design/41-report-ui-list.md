### 2.1 报告列表页

**路由**：`/workspace/projects/api-testing?tab=reports`

```
┌──────────────────────────────────────────────────────────────┐
│  测试报告                                            │
├──────────────────────────────────────────────────────────────┤
│  [报告类型 ▾] [状态筛选 ▾] [场景] [执行方式 ▾] [日期范围] [搜索] │
├──────────────────────────────────────────────────────────────┤
│  ☑ │ 报告名称      │ 类型 │ 状态 │ 通过率 │ 耗时 │ 创建时间│操作│
│  ☑ │ 每日回归-08-17│ 套件 │ 失败 │ 12/15  │ 15.8s│ 08-17 │…  │
│  ☑ │ 登录流程-08-17│ 场景 │ 通过 │ 100%   │ 1.2s │ 08-17 │…  │
│  ☑ │ 下单流程-08-17│ 场景 │ 失败 │ 66.7%  │ 2.1s │ 08-17 │…  │
│    │（行内操作：查看 / 删除）                              │
├──────────────────────────────────────────────────────────────┤
│  已选 2 项  [批量删除]              < 第1页/共5页 >      │
└──────────────────────────────────────────────────────────────┘
```

| 列 | 内容 |
| ---- | ---- |
| 报告名称 | 场景报告：场景名 + 执行时间戳；套件报告：任务名 + 执行时间戳，点击进入详情 |
| 类型 | 报告粒度徽标：场景（青）/ 套件（蓝） |
| 状态 | 状态徽标：通过（绿）/ 失败（红）/ 部分通过（黄） |
| 通过率 | 场景报告：通过步骤数 / 总步骤数百分比；套件报告：通过场景数 / 总场景数 |
| 耗时 | 总耗时 |
| 创建时间 | 执行完成时间 |
| 操作 | 行内按钮：查看 / 删除 |

**交互说明**：

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 进入页面 | 侧边栏点击「测试报告」 | 拉取报告列表，表格骨架屏加载 |
| 筛选 | 报告类型 / 状态 / 场景 / 执行方式 / 日期范围 | 筛选条件叠加生效，日期范围默认最近 30 天；场景为关键字输入，匹配报告名称或套件内场景名 |
| 查看报告 | 点击报告名称 | 跳转报告详情页（按类型渲染场景/套件详情） |
| 删除 | 行内 [删除] 或勾选后 [批量删除] | 二次确认（红色警示）「删除后不可恢复」 |

**状态分支**：

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 表格展示报告列表，筛选可用 |
| 空态 | 无报告：居中插画 + 「暂无测试报告」+ 说明「执行测试场景后生成报告」；筛选无结果时显示「无匹配结果」+ [清除筛选] |
| 加载态 | 首次进入表格骨架屏；筛选时顶部细进度条 |
| 错误态 | 拉取失败：错误提示 + [重试] |
