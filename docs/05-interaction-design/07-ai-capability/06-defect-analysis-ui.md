# 软件测试平台——AI 缺陷分析

**文档版本**：V1.0  
**日期**：2026-10-03  
**状态**：起草中

---

## 1. 概述

缺陷分析面向缺陷管理模块提供新建缺陷 AI 建议，其中一并给出重复缺陷检测（`docs/01-requirements/07-ai-capability/05-srs-ai-defect-analysis.md`）。承载形态为提交缺陷页内的 AI 建议结果弹窗：任务完成后默认采纳提案并将有效建议覆盖写入表单，弹窗展示原填写值与产物值对照。建议入口对项目成员常驻可见，不按权限码过滤；建议与检测范围限于当前项目。视觉遵循《视觉设计》（`docs/05-interaction-design/03-visual-design.md`）。

## 2. 页面设计

### 2.2 新建缺陷建议审核弹窗

| 组件 | 交互 |
| ---- | ---- |
| 「AI 建议」入口按钮 | 挂在提交缺陷页标题输入框尾部（append，图标 + 「AI 建议」）：AI 未启用时不渲染挂载内容、输入组按无 append 形态收口；标题为空时禁用置灰，填入标题后启用并以呼吸光晕 + 魔棒微晃作闪烁提示；点击直接按标题 / 已填重现步骤 / 所属模块提交 `bug_draft_suggest` AI 任务并打开结果弹窗；任务请求使用通用 AI 任务资源的短等待快路径，未在等待期内完成时转为轮询任务详情直到终态；同一页面再次打开仅回显上次结果，不重复发起任务 |
| SuggestionReviewPanel | 弹窗内按产物分组展示优化后标题、重现步骤、缺陷类型、严重等级、优先级、所属模块、关联用例、关键词的建议值与理由；任务完成后默认采纳，有效建议覆盖写入对应表单字段，每项以「原填写值 / AI 产物值」两列对照展示；不再提供逐项采纳操作，不调用人工提案确认接口 |
| DuplicateSuggestList | 弹窗内展示同一建议提案返回的疑似重复缺陷（短 ID、标题、状态、相似依据，按相似度排序），点击短 ID 跳转查看；无命中或向量未就绪时不渲染列表、不作提示；检测结果仅作建议，不自动合并、不改状态 |

### 2.3 状态分支

- **提交中 / 运行中**：弹窗展示加载态，轮询期间不阻塞表单填写；
- **建议就绪**：覆盖回填表单并展示字段原值与建议值对照、疑似重复缺陷；`duplicates` 为空时不渲染列表、不作提示，字段建议照常展示；
- **任务失败 / 终止**：弹窗内提示失败或终止原因，可关闭弹窗后再次点击「AI 建议」重新提交任务；不自动重试，不影响表单其余填写与提交；
- **AI 未启用 / 无可用模型 / 输入非法**：提交前或提交时按通用错误提示处理，弹窗内显示可理解错误信息，用户可修正后重试；
- **AI 未启用**：入口隐藏（总册 4.5）。

## 3. 核心交互流程

### 3.1 新建缺陷建议（含重复缺陷检测）

```mermaid
sequenceDiagram
  participant U as 用户
  participant F as 新建缺陷表单
  participant D as AI 建议审核弹窗
  participant T as AI 任务资源
  U->>F: 填写标题后点击「AI 建议」
  F->>D: 打开结果弹窗
  D->>T: POST /api/ai/tasks（type=bug_draft_suggest, waitSeconds=10）
  alt 等待期内 closed
    T-->>D: 任务详情（含默认采纳的建议提案）
  else 仍在 running
    loop 轮询
      D->>T: GET /api/ai/tasks/{taskId}
      T-->>D: 任务详情
    end
  end
  alt 建议生成成功
    D->>F: 覆盖写入有效建议到对应表单字段
    D-->>U: 弹窗展示原填写值与 AI 产物值对照、疑似重复缺陷
    Note over D: 同一页面重开仅回显上次结果，不重复发起任务
  else 任务失败 / 终止 / 请求错误
    T-->>D: 错误或 aborted
    D-->>U: 弹窗内提示原因，可关闭后再次点击重试
  end
  Note over D: 默认采纳只写 AI 任务域表与当前表单，不写缺陷业务数据
```

## 4. 视觉与状态要求

- 结果弹窗使用统一弹窗容器，产物按字段分组展示，原填写值与 AI 产物值以两列对照、理由作为辅助信息；
- 任务完成后立即反馈已自动填入状态，不展示逐项采纳按钮；
- 疑似重复列表用 `--color-neutral-*` 边框分隔条目，高相似项前置并以 `--color-warning` 图标标注（不单靠颜色表意）；
- 相似度仅作排序信号，百分比展示不对外承诺阈值。

## 5. 状态管理

- 新建表单建议与重复检测结果同属一次建议结果，存提交缺陷页本地状态；同一页面仅发起一次任务，关闭弹窗后再次打开仅回显上次结果，不重复请求，页面提交或离开后释放；
- 建议结果来自 AI 任务提案，弹窗按任务详情加载；任务完成后按提交人默认写入采纳记录并覆盖写入表单，原填写值仅用于对照展示，不再参与优先级判定。
