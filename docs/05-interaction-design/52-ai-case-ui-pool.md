## 1. 轻量需求池（US-AI-004）

### 1.1 需求池管理页

**路由**：`/project/requirements`（项目工作区侧边菜单入口）

> 视觉与结构对齐验收基准 `web/demos/project/requirements.html`（页头 + 单卡片：toolbar / 表格 / 分页一体）。基准裁剪与保留口径见 1.1.1 末尾。

#### 1.1.1 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  需求池                                    [+ 新建需求]      │
│  沉淀需求条目，作为用例设计与评审的输入                        │
├─────────────────────────────────────────────────────────────┤
│  [启用|已归档] [🔍 需求标题…] [查询] [重置]    [+ AI 拆分]     │
│                                              按更新时间排序   │
├─────────────────────────────────────────────────────────────┤
│  标题（含来源副行）    │ 状态  │ 更新人 │ 更新时间  │ 操作      │
│  [AI] 登录改版需求     │ ●启用 │ 张三  │ 07-30    │编辑 删除 归档│
│    └ prd.internal/1523                                       │
│  支付流程v2           │ ●启用 │ 李四  │ 07-28    │编辑 删除 归档│
│    └ 内部提出                                                 │
│  旧版需求X            │●已归档│ 王五  │ 07-01    │删除 取消归档 │
├─────────────────────────────────────────────────────────────┤
│  共 63 条 · 每页 20 条                      ‹  1  2  3  ›   │
└─────────────────────────────────────────────────────────────┘
```

- **页头**：标题「需求池」+ 描述「沉淀需求条目，作为用例设计与评审的输入」，右侧动作区 [+ 新建需求]（原工具栏新建入口上移至页头）。
- **分段切换**：启用 / 已归档 两段承载归档维筛选，两态互斥即全集（原「全部」选项取消），默认启用；可与关键字组合查询。
- **工具栏右区**：[AI 拆分]（仅条目创建人或具备项目管理权限的成员可见）+ 「按更新时间排序」说明文案（列表按更新时间倒序，文案属实）。
- **标题列**：AI 徽标 + 标题 + **副行承载来源**——有来源 URL 显示短链接（取 host + path，可点击新窗口打开），无来源 URL 显示「内部提出」；基准的独立「来源 URL」列因数据同源并入副行，表格为 5 列。
- **状态列**：圆点 + 文案，启用为成功色、已归档为中性色。
- **分页**：左侧「共 N 条 · 每页 20 条」，分页器为 上一页 / 页码 / 下一页。
- 新建/编辑抽屉：标题 + 内容（Markdown 编辑器复用）+ 来源URL（可选）
- 已归档条目：状态列显示「已归档」，操作列隐藏 [编辑]，仅保留 [删除] 与 [取消归档]
- AI 拆分条目：标题前展示「AI」徽标（复用 AI 标识规范），其余操作与手工条目一致

**基准裁剪与保留口径**：

| 基准内容 | 处理 | 原因 |
| ---- | ---- | ---- |
| 状态列「待分析/分析中/已实现」与分析状态下拉 | 不引入 | 需求池状态仅 active/archived 两态（需求规格 3.2.4），归档维由分段切换承载 |
| 分段计数「启用（63）/已归档（17）」 | 不展示 | 后端列表接口无分面计数，仅返回当前筛选总数 |
| 操作列 [详情] [转用例] [查看用例] | 不引入 | 操作列保留现有能力：编辑 / 删除 / 归档·取消归档（权限与归档只读规则见 1.1.2）；无需求详情页与需求-用例关联数据 |
| 副行版本号与「已拆 N 条用例」 | 不展示 | 无对应数据字段 |
| 搜索占位「需求标题 / 来源」 | 取「需求标题」 | 条目检索仅按标题关键字匹配（需求规格 1.4），避免误导 |
| [查询] [重置] | 保留 | 现有查询能力，基准未画 |

#### 1.1.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 搜索 | 输入标题关键字后回车或点击 [查询]（带 Search 图标） | 列表刷新 |
| 归档维筛选 | 分段切换 启用 / 已归档（默认启用），可配合关键字组合查询 | 列表刷新 |
| 新建条目 | 点击页头 [+ 新建需求] | 右侧抽屉：标题（必填）+ Markdown 内容 + 来源 URL（仅作出处展示，平台不抓取）；创建后状态为「启用」 |
| 编辑条目 | 点击 [编辑] | 抽屉回显；仅条目创建人或具备项目管理权限的成员可见编辑/删除/归档操作；**已归档条目无 [编辑] 入口** |
| 删除条目 | 点击 [删除] | 二次确认：「删除不影响已生成的用例，文档关联将解除」→ 执行后列表刷新；已归档条目仍可删除 |
| 归档条目 | 点击 [归档] | 二次确认：「归档后条目不可编辑，且不再被 AI 功能选用」→ 执行后状态变「已归档」，刷新列表 |
| 取消归档 | 点击 [取消归档]（已归档条目） | 二次确认：「恢复为启用状态，重新参与 AI 选用」→ 执行后状态变「启用」，刷新列表 |
| 内容超限 | 内容长度超过系统配置上限 | 编辑器下方红字提示，禁用保存 |
| AI 拆分 | 点击 [+ AI 拆分]（US-AI-019） | 打开拆分对话框（见 1.1.3）；仅条目创建人或具备项目管理权限的成员可见（与编辑权限一致） |

#### 1.1.3 AI 文档拆分对话框（US-AI-019）

```
┌──────────────────────────────────────────────────────────────┐
│  AI 拆分需求文档                                      [×]     │
├──────────────────────────────────────────────────────────────┤
│  ① 输入                                                      │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  粘贴整份需求文档（Markdown，上限 20000 字符）            │  │
│  │  …                                                      │  │
│  └────────────────────────────────────────────────────────┘  │
│  [AI 拆分]                                                    │
│  ───────────────────────────────────────────────────────────  │
│  ② 预览（流式填充，模块分组）            [全选]               │
│  ┌─ 用户管理 ────────────────────────────────────────────┐  │
│  │  ☑ 用户管理·新增用户    [编辑] [删除]                   │  │
│  │  ☑ 用户管理·编辑用户    [编辑] [删除]                   │  │
│  │  ☑ 用户管理·删除用户    [编辑] [删除]                   │  │
│  │  ☑ 用户管理·查询用户    [编辑] [删除]                   │  │
│  └───────────────────────────────────────────────────────┘  │
│  ┌─ 权限管理 ────────────────────────────────────────────┐  │
│  │  ☑ 权限管理·分配角色      [编辑] [删除]                 │  │
│  └───────────────────────────────────────────────────────┘  │
│  已选 5 / 5 条                                     [批量入库] │
└──────────────────────────────────────────────────────────────┘
```

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 拆分 | 粘贴文档后点击 [AI 拆分] | SSE 流式：预览区按模块分组逐条填充（行内进度占位 + [停止] 按钮）；拆分为「模块 → 需求点[]」，一个需求点 = 一个可测试功能行为（固定细粒度）；文档超限时截断并红字提示 |
| 编辑预览条目 | 点击条目 [编辑] | 行内展开标题 + 内容（Markdown）编辑框，保存后更新预览 |
| 删除预览条目 | 点击条目 [删除] | 该条从预览移除，不再参与入库 |
| 全选 | 点击 [全选] | 全部条目勾选/取消；单个勾选实时更新「已选 n / 总数」计数 |
| 批量入库 | 点击 [批量入库] | 仅勾选条目入库；标题 = 模块名 + 「·」 + 需求点标题（模块名并入标题前缀）；条目 `ai_generated = true`，列表展示「AI」徽标；完成后对话框关闭、列表刷新并提示「已入库 n 条」 |
| 关闭 | 点击 [×] / 遮罩 | 未入库的预览结果丢弃，不产生任何数据 |

### 1.2 需求条目选取器（各 AI 入口复用）

供「AI 生成用例」「AI 补全步骤」「遗漏测试点分析」「用例规划智能推荐」调用的弹窗组件，**仅展示 active（启用）条目**，已归档条目不出现：

```
┌────────────────────────────────────┐
│  选择需求                           │
│  [🔍 关键字过滤…]                   │
│  ☑ 登录改版需求      07-30          │
│  ☐ 支付流程v2        07-28          │
│  ─────────────────────────────      │
│  [取消] [确定]                      │
└────────────────────────────────────┘
```

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 多选条目 | 勾选 | 底部显示已选数量 |
| 确定 | 点击 [确定] | 选中需求回填调用方入口，以标签展示 |

### 1.3 文档关联需求条目

- 脑图文档设置区提供「关联需求条目」入口，复用选取器多选（仅 active 条目可选）；
- 已关联条目在 AI 生成/补全时自动带入为默认上下文，入口内可临时改选；
- 关联随条目删除自动解除，界面无残留；条目归档后其历史关联不再展示（关联记录保留，取消归档后重新可见）。
