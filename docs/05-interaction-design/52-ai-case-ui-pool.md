## 1. 需求工作流（US-AI-004 / US-AI-020 / US-AI-021）

> 概念：一条需求 = 一条测试工作流实例——阶段驱动、证据推进、AI 阶段作业产出提案、采纳写入数据并沉淀血缘（需求规格 3.4.4–3.4.6）。本文档定义需求工作流页（阶段看板 + 列表）与条目工作台（阶段时间线 + 提案队列 + 血缘视图）的交互。

**路由**：`/project/requirements`（项目工作区功能测试侧边菜单入口，**不受 AI 开关控制**）

- **卡片**：AI 徽标（AI 拆分条目）+ 标题 + 来源副行（有来源 URL 显示短链接可点击新窗口打开，无则「内部提出」）+ **待处置提案数角标**（pending + expired 计数，有值时显示）+ **stale 提醒**（内容已变更、下游存在过期提案时卡片标 ⚠）；点卡片进入条目工作台（1.3）。
- **列表视图**：列 = 标题（含来源副行）/ 阶段 / 状态 / 待处置提案数 / 更新人 / 更新时间 / 操作（编辑 删除 归档·取消归档），行点击进入工作台；分页「共 N 条 · 每页 20 条」+ 上一页 / 页码 / 下一页；列表按更新时间倒序。
- **状态分支**：空态（无条目：插画 + [+ 新建需求] [+ AI 拆分] 引导）；筛选无结果（「无匹配条目，调整筛选条件」+ [重置]）；首次加载骨架屏、刷新顶部进度条；接口错误 Toast + [重试]；无编辑权限用户隐藏新建/编辑/删除/归档/拆分/开关（只读浏览），无权限接口 403 由后端兜底。

**列表视图与验收基准的口径**（基准 `web/demos/project/requirements.html` 仅约束列表视图）：

| 操作列 [详情] [转用例] [查看用例] | 不设，由行点击承载 | 详情 = 条目工作台（阶段/提案/血缘齐备），转用例 = 工作台提案采纳链路 |

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 搜索 / 筛选 | 关键字回车或 [查询]；阶段下拉、启用/已归档分段切换 | 看板与列表同步刷新（保持当前视图） |

| 编辑条目 | 列表 [编辑]（抽屉复用） | 回显保存；仅条目创建人或项目管理权限成员可见；已归档条目无 [编辑]；内容变更后本阶段及下游未采纳提案标记「已过期」，「自动推进」开启时后台自动重跑当前阶段作业（Toast 提示「内容已变更，已自动重新发起作业」） |
| 删除条目 | [删除] | 二次确认「删除不影响已生成的用例、评审与计划，血缘关联将清除」→ 执行刷新 |
| 归档 / 取消归档 | [归档] / [取消归档] | 二次确认后执行；归档后条目不可编辑、不可阶段操作，取消归档恢复 |

| 自动推进开关 | 切换页头开关（项目管理权限） | 即时保存，Toast「自动推进已开启/关闭」；关闭时已发起作业不受影响 |

### 1.2 核心交互流程

```mermaid
flowchart TD
    A[条目处于某阶段] --> B[查看阶段状态<br/>stage-status 预检]
    B --> C{出口证据齐备?}
    C -->|否| D[推进按钮置灰<br/>列出缺失清单<br/>（手动关联 / 处置提案 / 完成评审计划）]
    C -->|是| E[点击 [推进]]
    E --> F[阶段变更 + 发起进入阶段的推进作业<br/>AI 不可用时仅提示，阶段照常成功]
    D --> D1[在提案队列处置 / 血缘面板关联 / 完成评审计划]
    D1 --> B
    F --> G[作业进行中 2 秒轮询进度<br/>可 [取消] [重试]]
    G --> H[作业成功 → 提案进入队列<br/>旧未处置提案被替代]
    H --> I[逐条/批量处置<br/>采纳（可编辑后接受）/ 驳回 / gap 三选一]
    I --> C
    B -.人工关口.-> E2[跳过（必填原因，免证据）<br/>回退（必填原因）]
    E2 --> F
```

- **人工关口**：提案采纳、阶段确认（推进/跳过/回退）、创建评审与计划实例**永不自动执行**；
- **半自动默认**：推进/跳过/回退即发起进入阶段的推进作业；「自动推进」开关仅增加内容变更后的自动重跑（去抖、增量）。

#### 1.3.2 阶段时间线（左栏）

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 查看阶段状态 | 进入工作台 / 阶段变更后 | 调 `stage-status`：当前阶段高亮、下一阶段可推进性、缺失证据清单、当前阶段作业、自动推进开关状态 |
| 推进 | 点击主按钮 **[推进]** | 证据齐备时亮起；点击后阶段节点动画推进、时间线新增事件、按 1.2 发起阶段作业；证据不齐时按钮置灰，点击范围展开**缺失清单**（如「尚未关联任何用例」「存在 3 条未处置提案」「无通过的关联评审」），每项给出补通道指引 |
| 跳过 | 点击 [跳过] | 弹窗必填原因（≤500 字，缺失内联红字）→ 确认后免证据推进，时间线留痕「跳过 · 原因」 |
| 回退 | 点击 [回退] | 弹窗必填原因 → 回退单步；「沉淀」阶段回退按钮隐藏；「验收」阶段可回退到「计划执行」 |
| 阶段作业卡 | 自动出现 | 展示作业类型名（用例设计生成 / 覆盖确认分析 / 评审规划 / 计划规划）+ 进行中进度条（2 秒轮询，终态停止）/ 失败原因 + [重试] / 进行中 [取消]；无作业时显示 [运行作业]（AI 关闭时禁用并提示「AI 不可用」；阶段无作业类型时不显示） |
| 作业发起结果 | 推进/跳过后 | `job` 为空且 `jobSkipReason = ai_disabled` → Toast「AI 不可用，作业未发起」；`duplicate_in_flight` → 沿用进行中作业卡；`no_job_for_stage` → 静默 |
| 事件留痕 | 下方时间线列表 | 逆序展示阶段操作事件：动作（推进/跳过/回退）+ 阶段迁移 + 操作人 + 时间 + 原因/豁免说明 |
| 归档条目 | status = archived | 阶段操作与作业入口隐藏，时间线与事件只读展示 |

#### 1.3.3 提案队列（中栏）

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 加载提案 | 进入工作台 / 作业完成 | 按 kind 分组展示当前阶段提案（用例 / 结构 / 遗漏点 / 澄清 / 评审方案 / 计划方案）；作业进行中顶部展示进度条；每 2 秒轮询任务状态，终态停止并刷新列表 |
| 批量勾选 | 勾选框 | 底部显示「选中 n / N」；[批量采纳]（仅用例提案）/ [批量驳回] |
| 采纳（单条） | 点击 [采纳] | 打开**提案预览弹窗**（脑图形式只读渲染用例树，勾选取舍；结构/评审方案/计划方案以表单渲染可编辑后接受）；用例/结构提案确认后跳转目标文档脑图页执行挂载，挂载成功回执采纳（《AI 生成用例》2）；评审方案/计划方案在弹窗内编辑（标题/描述/参与人/用例范围/时间）→ 确认即由后端创建实例并写血缘，Toast「已创建评审/计划」+ 结果跳转链接 |
| 批量采纳 | [批量采纳] | 弹出汇总预览（逐条勾选）→ 确认后跳转文档脑图页一次性挂载，回执整批采纳 |
| 驳回 | 点击 [驳回] | 弹窗原因可选（≤500）→ 置已驳回；同内容再次产出被指纹抑制（不再出现） |
| 遗漏点三选一 | gap 提案行内 [转为用例] [标记不覆盖] [忽略] | **转为用例**：弹落位选择（AI 自主 / 指定文档，同 1.5.1）+ 可编辑拼接文本 → 发起用例设计作业，提案置已采纳；**标记不覆盖**：必填理由 → 置已驳回留痕；**忽略**：本地隐藏（会话内），提案保持待处置、仍阻塞出口证据，区块顶部提示「已忽略 n 条（仍待处理）· [显示]」，确需通过时经 [跳过] 留痕 |
| 过期提案 | 内容变更后 | 折叠分组「已过期提案（n）」，仍可采纳/驳回；计入出口证据未处置数 |
| 作业失败 / 未发起 | 状态展示 | 失败展示原因 + [重试]；无作业显示 [运行作业]（重跑 = 覆盖式新建） |
| 空态 | 无提案 | 「本阶段暂无 AI 提案」+ [运行作业] 按钮 + 说明文案（作业成功仅产出提案，采纳才写入数据） |

#### 1.3.4 血缘视图（右栏）

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 查看血缘 | 进入工作台 | 按 用例 → 文档 → 评审 → 计划 → 缺陷 分组折叠展示，每行展示名称 + 所属位置 + 来源徽标（[AI] 生成 / 手动） |
| 跳转对象 | 点击行 / [跳转] | 路由跳转到对象详情（脑图文档、用例所在文档定位、评审、计划、缺陷），新窗口或当前页沿用平台既有跳转习惯 |
| 关联条目 | [+ 关联条目] | 打开对象选择（按类型分段：文档/评审/计划/缺陷/用例），选中即写入手动血缘，行内即时新增 |
| 解除关联 | 行内 [解除] | 仅 **source = 手动** 的血缘显示该按钮（生成血缘无按钮并悬浮提示「由提案采纳生成，随条目删除清除」）；二次确认后解除 |
| 空态 | 无血缘 | 「尚无关联对象——采纳提案或手动关联后在此沉淀血缘」 |

#### 1.3.5 状态分支

- **权限不足**：非条目创建人且无项目管理权限 → 隐藏编辑/删除/归档/阶段操作/提案处置/血缘手动关联，全栏只读；目标对象无编辑权限时对应处置按钮隐藏或置灰提示；
- **AI 不可用**：作业卡与 [运行作业] 呈禁用态并提示「AI 不可用」，阶段操作、提案浏览与采纳（已有提案）、血缘照常可用；作业类型按钮随 `aiEnabled` 显隐；
- **并发变更**：他人已处置同一批提案 → 提交返回提案状态非法 Toast，自动刷新队列；阶段被他人推进 → 时间线与阶段卡即时刷新并提示「条目阶段已更新」；
- **加载**：三栏分别骨架屏；提案列表刷新期间保留旧数据 + 顶部进度条。

#### 1.4.1 需求条目选取器（各 AI 入口复用）

供「AI 补全步骤」「用例规划智能推荐」「文档关联需求」等入口调用的弹窗组件，**仅展示 active（启用）条目**，已归档条目不出现：

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 多选条目 | 勾选 | 底部显示已选数量 |
| 确定 | 点击 [确定] | 选中需求回填调用方入口，以标签展示 |
| 查看明细 | 点击条目行内 [明细] | 就近冒泡展示该条目 Markdown 正文（仅正文）；点击右上角 [×]、再次点击 [明细]、点击空白或按 ESC 关闭，不联动勾选 |

标签回填收敛规则：标题超 5 字保留前 5 字并以「...」截断、悬浮提示完整标题；已选超 4 条仅平铺前 4 条并追加「+N」溢出指示（点击打开选取器）；标签可单个移除，[清空] 一键移除全部。

#### 1.4.2 文档关联需求条目

- 脑图文档工具条 [关联需求] 提供入口，复用选取器多选（仅 active 条目可选）；
- 已关联条目在 AI 补全等入口自动带入为默认上下文，入口内可临时改选；
- 关联底层即血缘（artifact_type = document、source = 手动）：关联随条目删除自动解除，界面无残留；条目归档后其历史关联不再展示（关联记录保留，取消归档后重新可见）。

## 2. AI 文档拆分对话框（US-AI-019）

入口在需求工作流页工具栏 [+ AI 拆分]（仅条目创建人或具备项目管理权限的成员可见，与编辑权限一致）：

```
┌──────────────────────────────────────────────────────────────┐
│  AI 拆分需求文档                                      [×]     │
├──────────────────────────────────────────────────────────────┤
│  ① 输入                                                      │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  粘贴整份需求文档（Markdown，上限 20000 字符）            │  │
│  │  …                                                      │  │
│  └────────────────────────────────────────────────────────┘  │
│  [AI 拆分]                                                    │
│  ───────────────────────────────────────────────────────────  │
│  ② 预览（流式填充，模块分组）            [全选]               │
│  ┌─ 用户管理 ────────────────────────────────────────────┐  │
│  │  ☑ 用户管理·新增用户    [编辑] [删除]                   │  │
│  │  ☑ 用户管理·编辑用户    [编辑] [删除]                   │  │
│  │  ☑ 用户管理·删除用户    [编辑] [删除]                   │  │
│  │  ☑ 用户管理·查询用户    [编辑] [删除]                   │  │
│  └───────────────────────────────────────────────────────┘  │
│  ┌─ 权限管理 ────────────────────────────────────────────┐  │
│  │  ☑ 权限管理·分配角色      [编辑] [删除]                 │  │
│  └───────────────────────────────────────────────────────┘  │
│  已选 5 / 5 条                                     [批量入库] │
└──────────────────────────────────────────────────────────────┘
```

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 拆分 | 粘贴文档后点击 [AI 拆分] | SSE 流式：预览区按模块分组逐条填充（行内进度占位 + [停止] 按钮）；拆分为「模块 → 需求点[]」，一个需求点 = 一个可测试功能行为（固定细粒度）；文档超限时截断并红字提示 |
| 编辑预览条目 | 点击条目 [编辑] | 行内展开标题 + 内容（Markdown）编辑框，保存后更新预览 |
| 删除预览条目 | 点击条目 [删除] | 该条从预览移除，不再参与入库 |
| 全选 | 点击 [全选] | 全部条目勾选/取消；单个勾选实时更新「已选 n / 总数」计数 |
| 批量入库 | 点击 [批量入库] | 仅勾选条目入库；标题 = 模块名 + 「·」 + 需求点标题（模块名并入标题前缀）；条目 `ai_generated = true`，列表展示「AI」徽标；入库后全部处于「沉淀 intake」阶段；完成后对话框关闭、列表刷新并提示「已入库 n 条」 |
| 关闭 | 点击 [×] / 遮罩 | 未入库的预览结果丢弃，不产生任何数据 |
