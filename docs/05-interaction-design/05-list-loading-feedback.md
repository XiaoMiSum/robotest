# 软件测试平台——列表加载反馈口径

**文档版本**：V1.0  
**日期**：2026-11-17  
**状态**：起草中

## 1. 概述

本文定义标准列表页统一的**加载反馈**状态模型、表现方式与遮罩范围，供各列表页交互设计引用，避免逐页重复定义或各自演化出不一致的加载行为。

适用范围与 `docs/05-interaction-design/04-table-column-settings.md` 一致：`docs/06-implementation-plan/07-list-page-standardization-plan.md` 登记的 12 个标准列表页。专用布局页、编辑器、详情/分享页、用例脑图工作区与 `DebugPage` 调试工作台可参照执行，但不作为本文强制范围。

本文是 `docs/00-spec/50-ui/01-frontend-design.md` UI-DS-04「状态必须完整」与 UI-DS-05「反馈及时且可解释」在标准列表页上的落地口径，不重复定义通用状态原则。承载组件为 `web/src/components/common/ListWorkspace.vue`（布局与表体遮罩）与 `web/src/components/common/ListLoadFeedback.vue`（反馈文案与占位）。

## 2. 状态模型

标准列表页的数据加载划分为 6 种互斥状态，页面在任一时刻只呈现其中一种加载/反馈表现：

| 状态 | 触发条件 | 承载形式 |
| --- | --- | --- |
| 首屏加载 | 首次进入、`hasLoaded=false` 且无错误 | 表格区骨架屏 |
| 刷新加载 | 已有数据后筛选、搜索、翻页、视图/模块切换触发请求 | 表体遮罩，保留当前数据 |
| 首屏失败 | 首次加载请求失败且无已加载数据 | 错误反馈 + 重试，不展示空态 |
| 刷新失败 | 已有数据后刷新请求失败 | 页内错误反馈 + 重试，保留当前数据 |
| 普通空态 | 请求成功但无数据且无筛选条件 | 空态占位 + 创建入口（有权限时） |
| 筛选空态 | 请求成功但无数据且带筛选条件 | 空态占位 + 重置筛选 |

骨架屏与遮罩互斥：首屏只显示骨架，数据到达后 `hasLoaded=true`，后续刷新才使用遮罩，避免在骨架之上叠加遮罩层。

## 3. 统一口径

### 3.1 首屏加载

- 表格区显示骨架屏（约 6 行、`animated`），筛选工具栏与页头常驻可见、可交互。
- 骨架屏仅替换数据区，不改变卡片高度链与分页条位置，避免首屏布局跳动。
- 页面容器设置 `aria-busy=true`，骨架屏以 `role=status` 提供加载中播报。

### 3.2 刷新加载

- 仅在表体范围显示遮罩（对应 `ListWorkspace__body`），工具栏、反馈条与分页条不遮罩，用户仍可中断输入或翻页。
- 刷新期间保留当前已加载数据与分页信息，不清空表格、不回退页码。
- 刷新为幂等覆盖：请求携带序号保护，后发先到的旧响应不得覆盖新数据；卸载或离开页面后失效在途请求。

### 3.3 首屏失败

- 显示错误提示与 [重试]，不展示空态占位，避免"暂无数据"误导用户以为无权限或无数据。
- 重试沿用当前筛选条件与页码，请求成功后按首屏加载转为数据展示。
- 不修改 URL 或上下文；错误文案由调用方提供，包含可执行的下一步说明。

### 3.4 刷新失败

- 保留当前已加载数据、分页信息与筛选条件，在表体上方显示页内错误反馈条与 [重试]。
- 错误反馈条为可见常驻，不依赖一闪而过的消息提示；同时以统一消息提示知会。
- 重试沿用当前筛选条件与页码，成功后清除错误反馈条并刷新数据。

### 3.5 空态与筛选空态

- 普通空态：展示空态占位，具备创建权限时提供 [新建] 入口。
- 筛选空态：展示空态占位与 [重置筛选]，重置后回到无筛选条件的第一页。
- 两种空态均不展示错误提示，文案区分"暂无数据"与"无匹配结果"。

## 4. 遮罩范围

遮罩边界是本章的核心口径，用于消除各页"整卡遮罩 / 内容区遮罩 / 仅表体遮罩"的差异：

| 区域 | 首屏加载 | 刷新加载 |
| --- | --- | --- |
| 页头与筛选工具栏 | 常驻可见 | 常驻可见、可交互，不遮罩 |
| 表格数据区 | 骨架屏 | 表体遮罩 |
| 分页条 | 常驻可见 | 常驻可见、可交互，不遮罩 |

刷新只遮罩表体，是样板页 `ListWorkspace` 的默认行为，作为标准列表页的统一口径。整卡遮罩（覆盖含工具栏与分页的整张卡片）会阻断用户在刷新期间的其它操作，不作为新页面与迁移目标。

## 5. 可访问性

- 加载容器设置 `aria-busy`，加载/错误/空态以 `role=status` 或等价语义提供状态播报。
- [重试]、[重置筛选]、[新建] 等反馈入口可通过键盘聚焦与触发，焦点样式清晰。
- 状态不得仅以颜色区分，加载、错误、空态均配文案或图标。

## 6. 迁移约定

- 新页面与标准列表页重构必须遵循本文口径。
- 存量页按此口径渐进迁移；当前与本文不一致的实现登记为待迁移项，随触及页面的迭代一并收敛，不强制一次性全量改造。
- 已知待迁移项：需求列表页（`web/src/pages/project/requirement/RequirementListPage.vue`）刷新使用整卡遮罩（见 `docs/05-interaction-design/03-function-testing/07-requirement-ui.md` §2.1.3），需迁移为表体遮罩并同步更新该页交互设计。
