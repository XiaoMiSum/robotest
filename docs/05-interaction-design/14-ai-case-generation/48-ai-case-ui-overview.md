## 1. 总体布局

### 1.1 脑图编辑页 AI 入口分布

AI 入口落位于用例脑图编辑页（CaseMindMap），随 `aiEnabled` 显隐：

```
┌────────────────────────────────────────────────────────────┐
│ 工具栏（单行）: [历史][节点结构][布局][类型标记][优先级] …… 命令组（行末右侧）[🔗] ← 纯图标 + 悬浮提示 │
├────────────────────────────────────────────────────────────┤
│                                                            │
│                    脑图画布                                │
│          （case 节点右键菜单含「✨AI 补全步骤」）           │
│                                                            │
│                          ┌────────────────────────┐        │
│                          │  AI 补全抽屉（右侧滑出）│        │
│                          └────────────────────────┘        │
└────────────────────────────────────────────────────────────┘
```

- 工具栏为顶部**单行**流式胶囊：左侧为核心编辑操作（历史/节点结构/布局/类型标记/优先级），行末右侧命令组为 [关联需求]（纯图标 + 悬浮提示「关联需求」，常规业务、不随 `aiEnabled` 显隐）；工具条**所有按钮一律带悬浮提示**（图标型给出功能名与快捷键，文字型给出操作语义）；内容过宽时整行换行、不与画布重叠；
- **生成与分析的入口在需求工作流条目工作台**：用例生成由用例设计阶段推进（含 [运行作业]）发起，遗漏点分析由覆盖确认阶段作业发起，提案处置在工作台队列完成（`docs/05-interaction-design/14-ai-case-generation/52-ai-case-ui-pool.md` 1.3、`docs/05-interaction-design/14-ai-case-generation/49-ai-case-ui-generation.md`、`docs/05-interaction-design/15-ai-review/56-ai-review-ui-missing.md`）；
- 右键菜单仅在 **case 类型节点**上显示「AI 补全步骤」项（置于标记域之后的动作区），随 `aiEnabled` 显隐；
- 需求工作流为项目工作区侧边菜单入口（1.2），**不受 AI 开关控制**（进入后 AI 相关的阶段作业与提案入口才随 `aiEnabled` 显隐）。

> **零影响约束（通用规范 2.7）**：AI 入口在工具栏内以弹性间隔右对齐追加，不改变既有标记组、优先级组的位置与操作；`aiEnabled = false` 时 AI 入口整体隐藏，核心工具栏与右键菜单回退到 V1.0 形态，脑图编辑、协同、撤销等既有能力不受任何影响。

### 1.2 项目工作区侧边菜单增量

功能测试侧边栏菜单新增「需求工作流」项：

```
┌──────────────┐
│ 用例管理     │
│ 测试评审     │
│ 测试计划     │
│ 需求工作流   │  ← 新增（常规业务功能，不随 AI 开关隐藏）
└──────────────┘
```

## 2. AI 标识徽标

- AI 生成/补全/对话式编辑新增的节点统一携带「AI」徽标，位置与既有类型徽标并列（复用 badges.ts 徽标体系）；
- 徽标随节点复制/剪切粘贴保留到副本，随评审/计划快照继承；
- **移除**：右键菜单标记域仅在 `aiGenerated = true` 的节点上显示「移除 AI 标识」芯片，点击即移除；移除后不可重新添加（撤销回退除外），任何入口不提供手动添加；
- AI 标识不影响任何业务规则（评审、计划、执行照常）。

## 3. 通用交互模式总结

### 3.1 弹窗类型

| 类型 | 使用场景 |
| ---- | ---- |
| 抽屉 | AI 补全面板（默认 640px、左缘可拖拽，右侧滑出、透明遮罩不压暗画布、点击空白或 Esc 关闭）、需求条目新建/编辑、提案队列内的评审/计划方案编辑 |
| 居中弹窗 | 提案采纳预览弹窗（脑图形式，宽 70% × 高 80%（视口），两窗并存时置顶）、阶段作业发起弹窗 |
| 确认弹窗 | 条目删除、挂载目标重选、阶段跳过/回退（必填原因）、血缘解除 |
| 选择弹窗 | 需求条目选取器、挂载位置节点选择器、落位文档选择器 |

### 3.2 加载状态

- 流式生成（补全、AI 拆分）：操作行内进度条占位（flex:1、与 [停止] 按钮同行左侧，旁显阶段文案与已耗时）+ [停止] 按钮；超 10 秒提示可取消重试（通用规范 2.3）。
- 阶段作业（生成、遗漏分析、评审/计划规划）：作业卡真实进度条 + **2 秒轮询**至终态，离开页面不中断，返回后依据任务状态恢复展示。
- 同步推荐：按钮 loading，不阻塞脑图编辑。
- 需求工作流看板：首次骨架屏，刷新顶部进度条；提案队列刷新期间保留旧数据 + 顶部进度条。

### 3.3 与协同编辑的关系

- 生成、预览期间文档保持可编辑，协同帧照常收发；
- 挂载经既有编辑内核与协同通道，协同用户实时可见；
- 一切 AI 引发的脑图变更均为单条撤销历史，Ctrl+Z 一次回退。
