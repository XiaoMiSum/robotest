## 1. 总体布局

AI 入口分布在三个既有页面，均随 `aiEnabled` 显隐：

| 页面 | 新增入口 | 可见角色 |
| ---- | ---- | ---- |
| 评审详情页（ReviewMindMap） | [✨AI 一键检查] 侧面板、[✨AI 生成摘要] | 仅评审发起人 |
| 用例模块页 | [✨遗漏测试点分析] 抽屉入口 | 全部业务用户 |
| 计划详情页（PlanMindMap） | [✨执行顺序推荐] 标签页 | 仅计划负责人 / 执行人 |
| 评审详情页 / 计划详情页「调整用例」流程 | [✨AI 推荐用例] 抽屉入口 | 全部业务用户（属覆盖度分析，SRS 附录 B；最终带入关联仍受既有评审/计划编辑权限约束） |

> **零影响约束（通用规范 2.7）**：检查/摘要面板、顺序推荐标签页均为既有页面的附加区域，不改变评审详情、计划详情既有布局与操作流程；`aiEnabled = false` 或无权限时对应入口隐藏，评审、计划、用例模块的既有功能完全不受影响。

## 2. 通用交互模式总结

### 2.1 弹窗类型

| 类型 | 使用场景 |
| ---- | ---- |
| 抽屉 | AI 检查（评审详情页）、遗漏测试点分析、用例规划智能推荐（统一规格见 `docs/05-interaction-design/01-readme.md` 2.9） |
| 弹窗 | 取消任务确认、重新生成确认 |

### 2.2 加载状态

- 异步任务（检查）：进度条 + 2 秒轮询 + 可取消，离开页面可恢复；
- 流式生成（摘要）：统计即时渲染 + 文字流式渲染；
- 同步长调用（遗漏分析 / 用例规划推荐）：70 秒超时的持续加载态 + [取消] 按钮。

### 2.3 权限显隐

- 检查 / 摘要入口：前端按「当前用户 = 评审发起人」判断显隐，后端强校验兜底；
- 顺序推荐入口：仅计划负责人 / 执行人可见；用例规划推荐入口不限角色（带入关联受既有评审/计划编辑权限约束）；
- 权限不足的用户完全不可见入口，不做置灰。
