### 5.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 查看模板 | 悬停卡片右上角 [编辑]，或直接点击卡片 | 抽屉展示当前生效模板（自定义或内置默认），来源以标签标注 |
| 编辑角色指令段 | 文本域直接编辑 | 实时字数统计，保存时校验非空 |
| 编辑格式约束段 | 打开高级开关 | 二次确认弹窗：说明修改可能导致结构化校验失败的风险，确认后文本域解锁 |
| 保存自定义 | 点击 [保存] | 落库覆盖记录，列表卡片状态变更为「已自定义」，Toast 成功 |
| 恢复默认 | 悬停卡片右上角 [恢复默认] | 二次确认 → 删除自定义记录，回退内置模板，抽屉内容刷新 |
| 关闭抽屉（有未保存修改） | 点击 [取消] 或遮罩 | 离开确认弹窗：「有未保存的修改，确定离开？」 |

- 卡片标题栏仅在已自定义时展示状态标签「已自定义」，默认模板不展示标签；图标底色按「默认 / 已自定义」区分；编辑操作默认隐藏，卡片悬停时浮现，避免视觉干扰；
- 自定义、恢复默认及高级开关变更均记录审计日志（界面无需额外操作，静默记录）；
- 抽屉内不提供删除智能体操作（模板位与功能枚举一一对应，只可覆盖或恢复）。
