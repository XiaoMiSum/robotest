## 1. 语义查重（US-AI-009）

### 1.1 触发规则

| 规则 | 说明 |
| ---- | ---- |
| 触发方式 | **随 [AI 建议] 按钮触发**：点击 [AI 建议] 时与建议请求并发发起查重，无独立自动触发 |
| 最小长度 | 标题少于 5 字符不发起查重（仅展示建议） |
| 并发处理 | 连续点击时以最后一次请求为准，过期响应丢弃 |
| 不阻塞 | 查重请求进行中不阻塞输入与提交 |

### 1.2 查重卡片列表

随 [AI 建议] 点击后在 AI 结果面板内嵌展示（无结果时不占位）：

```
┌─ 疑似重复缺陷（2）──────────────────────────┐
│ ⚠ 当前为关键词匹配结果（语义检索暂不可用）   │ ← 降级提示条（按需）
│ ┌────────────────────────────────────────┐  │
│ │ [92%] 登录页白屏无响应   active   张三  │  │
│ │ [85%] 登录后页面卡死     resolved 李四  │  │
│ └────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
```

每条卡片右侧提供 [忽略] 按钮：点击后该条从列表移除（本次结果内忽略，不参与提交确认）。

### 1.3 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 查看疑似重复 | 点击 [AI 建议] 且查重返回命中 | 卡片列表展示：相似度徽标 + 标题 + 状态 + 处理人（按相似度降序） |
| 忽略疑似重复 | 卡片内点击 [忽略] | 该条从列表移除，本次结果内不再参与提交确认；再次点击 [AI 建议] 重新查重时按最新数据重新出现 |
| 查看缺陷详情 | 点击卡片 | 打开对应缺陷详情抽屉（不离开表单，表单内容保留） |
| 确认重复放弃提交 | 用户自行判断 | 关闭表单即可；或继续提交，后续流转中标记「重复缺陷」（复用既有 resolution 机制） |
| 语义降级 | 响应携带降级标志 | 列表顶部提示条明示关键词匹配模式 |
| 无疑似重复 | 检索结果为空 | 列表区不展示（不打扰） |

- 查重范围：当前项目内**未关闭**缺陷（active/resolved/rejected），已关闭缺陷不参与；
- 查重不阻断提交，仅提示。
