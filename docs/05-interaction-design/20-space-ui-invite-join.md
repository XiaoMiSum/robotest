## 6. 邀请加入页面（公开）

**路由**：`/join?token=xxx`

### 6.1 页面布局

邀请流程分为两步，第一步输入邮箱，第二步根据用户是否存在展示不同表单。

**第一步 - 输入邮箱**：

```
┌──────────────────────────────────────────────────┐
│                                                  │
│            🔗 加入工作空间                        │
│                                                  │
│        您将被加入「电商平台测试」工作空间           │
│                                                  │
│       邮箱: [________________]                   │
│                                                  │
│              [下一步]                             │
│                                                  │
└──────────────────────────────────────────────────┘
```

**第二步 - 已有用户**：

```
┌──────────────────────────────────────────────────┐
│                                                  │
│            🔗 加入工作空间                        │
│                                                  │
│        您将被加入「电商平台测试」工作空间           │
│                                                  │
│       邮箱: user@example.com                     │
│       密码: [________________]                   │
│       (8-64字符)                                 │
│                                                  │
│            [加入并登录]                           │
│                                                  │
└──────────────────────────────────────────────────┘
```

**第二步 - 新用户**：

```
┌──────────────────────────────────────────────────┐
│                                                  │
│            🔗 加入工作空间                        │
│                                                  │
│        您将被加入「电商平台测试」工作空间           │
│                                                  │
│       邮箱: user@example.com                     │
│       姓名: [________________]                   │
│                                                  │
│            [创建并加入]                           │
│                                                  │
└──────────────────────────────────────────────────┘
```

### 6.2 交互说明

| 操作     | 触发方式           | 反馈                                                                         |
| ------ | -------------- | -------------------------------------------------------------------------- |
| 验证链接   | 页面加载           | 调用验证接口 → 无效则展示错误提示及原因                                                      |
| 下一步    | 第一步点击[下一步]     | 校验邮箱格式 → 调用用户查询接口 → 已注册：展示密码输入框；未注册：展示姓名输入框                                 |
| 加入并登录  | 第二步点击[加入并登录]   | 前端校验 → 调用加入接口 → 成功：存储Token，设置活跃空间，跳转空间内部；失败：显示具体错误                        |
| 创建并加入  | 第二步点击[创建并加入]   | 前端校验 → 调用注册并加入接口 → 成功：存储Token，设置活跃空间，展示欢迎提示，跳转空间内部；失败：显示具体错误               |
| 密码校验   | 实时              | 校验密码格式（8-64字符）                                                            |
| 防重复    | 提交后             | 按钮置灰显示loading，防止重复提交                                                       |
