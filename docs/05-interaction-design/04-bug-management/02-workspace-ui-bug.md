## 1. 缺陷管理

**路由**：`/workspace/projects/bugs`

缺陷管理采用独立功能面板，包含看板和列表两种视图，支持新增缺陷和查看缺陷详情。

### 1.1 缺陷看板/列表页

看板列包含「激活」「已解决」「已关闭」三列（已拒绝缺陷仅在列表视图查看）；列表包含缩略 ID 列、解决人、解决时间、解决方案、关闭人、关闭时间列。标签配色（状态/严重等级/优先级）列表与详情页统一对齐。

快捷过滤栏提供「未修复」「由我创建」「指派给我」等快速选项；更多筛选弹层内选择条件后保活不收起。

#### 1.1.1 看板视图（四列）

```
┌──────────────────────────────────────────────────────┐
│  缺陷管理       [看板] [列表]       [+ 提交缺陷]       │
├──────────┬──────────────────┬──────────┬────────────┤
│ 激活(3)  │    已解决(2)     │ 已关闭(2)│            │
│ ┌──────┐ │ ┌────────────┐ │ ┌──────┐│            │
│ │登录   │ │ │支付        │ │ │首页  ││            │
│ │致命🔴 │ │ │严重🟠      │ │ │轻微🟢││            │
│ └──────┘ │ └────────────┘ │ └──────┘│            │
└──────────┴──────────────────┴──────────┴────────────┘
```

**交互**：卡片拖拽至目标列更新状态；点击卡片跳转详情页；筛选栏滚动时粘性悬浮于顶部；看板列采用 DynamicSizeList 虚拟化；支持按状态/等级/优先级/处理人/报告人/解决人/关闭人筛选。

#### 1.1.2 列表视图

表格形式：缩略 ID、标题（超 13 字符截断）、严重等级、优先级、状态、处理人、解决人、解决方案、解决时间、关闭人、关闭时间、创建时间、操作。时间列格式统一为 `MM-dd HH:mm`。支持多条件筛选和分页。

**操作列**：详情始终显示；按状态直出解决（active）/关闭（resolved/rejected）/激活（closed）；非 closed 行收「更多」下拉（确认、拒绝、激活、指派、复制）。

**行操作说明**：

- **复制**：跳转创建页经 query 回填源缺陷信息（处理人不复制，由提交人重新指派）。
- **解决**：弹 BugResolveDialog（选择 resolution + 备注说明），解决后处理人自动回设为创建人。
- **拒绝**：弹说明输入框，拒绝后处理人回设为创建人。
- **关闭**：弹说明输入框。
- **激活（重开）**：弹说明输入框，已解决→回设给解决人，已拒绝→回设给拒绝人。

### 1.2 新增缺陷页

**路由**：`/workspace/projects/bugs/create`

#### 1.2.1 页面布局

```
┌──────────────────────────────────────────────────┐
│  缺陷管理 › 提交缺陷           [取消] [提交缺陷]   │
├──────────────────────────────────────────────────┤
│                                                  │
│  [__________________________________] [AI 建议]   │
│  ##### 执行步骤                                   │
│  ##### 实际结果                                   │
│  ##### 期望结果                                   │
│  (默认模板，未修改不提交)                          │
│  附件       [将文件拖到此处，或点击选择]            │
│            (紧凑高度，无卡片)                      │
│                                                  │
│  严重等级   [致命|严重|一般|轻微] (选中按等级色)     │
│  优先级     [高|中|低] (选中按优先级色)              │
│  处理人     [▼ 选择成员]                          │
│  关联用例   未关联                [选择]              │
│  关联计划   [选择] (已选: 功能测试计划)             │
└──────────────────────────────────────────────────┘
```

#### 1.2.2 交互说明

| 操作     | 触发方式       | 反馈                            |
| ------ | ---------- | ----------------------------- |
| 选择处理人  | 点击下拉框展开    | 显示当前工作空间所有成员，支持搜索过滤           |
| 选择关联用例 | 点击[选择]按钮   | 打开CaseSelector弹窗（单选）；左侧展示状态：未关联 / 已选用例，[选择]为右对齐 link 按钮，再次选择直接替换已选用例 |
| 选择关联计划 | 点击[选择]按钮   | 打开计划选择器弹窗，已选计划显示名称，可清除        |
| 选择附件   | 点击[+ 选择文件] | 本地暂存文件列表（单文件不超过 10MB），可移除；提交成功后逐个上传 |
| 粘贴正文图片 | 在重现步骤编辑区内 Ctrl/⌘+V 粘贴、拖入或点击工具栏[上传] | 立即上传并在正文插入图片引用；单张 >10MB 或类型不符时提示并忽略，正文其余内容保留 |
| 分段按钮   | 点击严重等级/优先级单选项 | 分段按钮直接切换，选中态底色/边框按等级色 `--color-bug-*` 与优先级色着色，变更即触发表单校验 |
| 获取 AI 建议 | 点击标题输入框尾部[AI 建议] | AI 未启用不显示；标题为空禁用置灰，填入后启用并闪烁提示；点击按标题/重现步骤/所属模块生成行内建议，徽标点击采纳 |
| 表单校验   | 失焦时触发      | 标题必填，红色边框+错误提示                |
| 提交     | 点击右上角[提交缺陷] | 前端校验→调用创建接口→成功跳转缺陷列表页         |
| 取消     | 点击右上角[取消]或面包屑「缺陷管理」 | 不保存离开（有修改时二次确认）               |

### 1.3 缺陷详情页

**路由**：`/workspace/projects/bugs/:bugId`

**布局特点**：两级面包屑「缺陷管理 › 缺陷详情」，同行右对齐状态 tag、「激活 N 次」与 [提交缺陷]，缩略 ID 与标题占第二行；状态/严重等级/优先级标签配色与列表视图对齐；重现步骤编辑器无卡片包裹，附件为独立无 header 边框卡片（[上传附件] 为右对齐 link 按钮，卡片紧凑内边距）；右栏为 border-card 页签（属性 / 解决信息 / 操作记录），无父容器包裹，页签高度按窗口剩余空间动态固定、内容超出在页签内滚动；仅 active / rejected 可编辑，resolved / closed 全部只读；操作按钮为底部粘性悬浮，透明背景居中。

#### 1.3.1 页面布局（active / rejected，可编辑）

```
┌──────────────────────────────────────────────────┐
│  缺陷管理 › 缺陷详情                              │
│                [激活中] [激活 0 次] [提交缺陷]     │
│  #A1B2C3  [登录页面崩溃________________]          │
├──────────────────────────────┬───────────────────┤
│  [重现步骤 Markdown 编辑器]   │属性│解决│操作记录 │
│  (无卡片包裹；内容显示不全时   │┌───────────────┐ │
│   [完整显示]撑至内容高度,      ││ 缺陷类型 [功能▼]│ │
│   底部拖拽手柄调高)           ││ 所属模块  [▼]  │ │
│  ┌────────────────────────┐  ││ 严重等级 [致命▼]│ │
│  │             [上传附件]  │  ││ 优先级   [高▼] │ │

│  │     [下载] [删除]       │  ││ 关键词   [___] │ │
```

**编辑方式**：active / rejected 状态下标题、重现步骤、附件与右栏属性表单原位直接可编辑（无独立编辑态切换），底部 [保存] 提交；resolved / closed 全部只读。状态不属于可编辑字段，只能通过状态流转按钮变更。

**关联用例展开**：关联用例气泡仅展示前置条件/步骤/预期三种标记节点，UI 徽标风格与文档视图一致；悬停展示关联用例的完整明细（前置条件↔步骤↔预期），支持 [跳转所在文档] 链接直接定位到脑图文档中的对应用例。

#### 1.3.3 交互说明

| 操作     | 触发方式       | 反馈                                                   |
| ------ | ---------- | ---------------------------------------------------- |
| 页面加载   | 进入页面时      | 调用 `GET /api/project/bugs/:bugId` 获取缺陷详情、操作日志与附件列表      |
| 编辑字段   | active / rejected 直接修改表单控件 | 标题、重现步骤、附件与属性原位可编辑（无独立编辑态切换）；支持修改关联用例与关联计划；状态只能通过状态流转按钮变更；标题必填，保存时校验失败红框提示 |
| 更新状态   | 点击底部操作栏按钮  | 按四态状态机流转；解决弹 BugResolveDialog（选 resolution + 备注说明，处理人自动回设创建人）；拒绝弹说明输入框（处理人自动回设创建人）；关闭/重开弹说明输入框 |
| 关联用例悬停 | 鼠标悬浮关联用例区域 | 弹出卡片展示完整明细（前置条件↔步骤↔预期），提供[跳转所在文档]链接 |
| 关联用例选择 | 编辑时点击[选择]  | 打开 CaseSelector 弹窗（单选模式）；未关联时左侧显示「未关联」，[选择]为右对齐 link 按钮；已关联可[更换]/[清除]，清除经保存生效 |
| 上传附件   | 点击[上传附件]   | active / rejected 可用，link 按钮右对齐，单文件不超过 10MB，上传成功后列表刷新并写操作日志        |
| 正文图片渲染 | 进入详情页、编辑态正文变更 | 重现步骤内嵌图片换取临时签名地址显示（15 分钟内有效）；过期或加载失败显示占位提示，不改动正文 |
| 粘贴正文图片 | 编辑态在重现步骤内粘贴、拖入或经工具栏上传图片 | 同新增缺陷页：上传成功后正文插入图片，超限或类型不符提示并忽略 |
| 下载附件   | 点击附件行[下载]  | 浏览器保存原始文件名文件，任意状态可用                              |
| 删除附件   | 点击附件行[删除]  | active / rejected 可用，二次确认后删除并写操作日志                          |
| 保存     | 点击底部[保存] | 调用 `PUT /api/project/bugs/:bugId` → 操作日志刷新 → Toast 提示 |
| 离开页面   | 点击面包屑「缺陷管理」 | 返回缺陷列表页                                                 |
| 查看操作记录 | 切换右栏「操作记录」页签 | 按时间倒序展示所有操作历史，无记录显示「暂无操作记录」空态            |
| 查看解决信息 | 切换右栏「解决信息」页签 | 展示解决方案、重复缺陷跳转、解决人（含时间）、关闭人（仅 closed）；active / rejected 显示「暂无解决信息」空态 |
| 侧栏滚动   | 右栏页签内容超出高度 | 页签高度按窗口剩余空间动态固定、不随内容变化，内容在页签内滚动                |
| 编辑器完整显示 | 重现步骤编辑区内容显示不全时底部出现[完整显示] | 点击后编辑器高度撑至内容完整展示、按钮变[收起]，再次点击恢复默认高度；展开状态下内容继续增长时高度自动跟随 |
| 编辑器拖拽调高 | 拖动重现步骤编辑器底部的拖拽手柄 | 上下拖动调整编辑器高度（最小 200px、最大视口高度）；拖动结束后本次停留期间窗口缩放不再覆盖，刷新或离开页面恢复默认；与[完整显示]/[收起]并存（展开态手柄隐藏）；resolved / closed 只读态不显示 |
| 非可编辑状态限制 | 状态为 resolved 或 closed | 属性、重现步骤与标题全部只读，不显示[保存]与附件上传/删除；resolved 保留[关闭][激活]，closed 保留[激活]；附件下载与重现步骤正文图片只读渲染保留 |

**状态流转规则**（四态状态机）：

```
active → resolved（解决）/ rejected（拒绝）→ closed（关闭）→ active（重开）
```

- **解决**：resolution 必填 + 备注说明；resolution=duplicate 需指定原始缺陷；处理人自动回设为创建人。
- **拒绝**：说明必填；处理人回设为创建人；记录拒绝人。
- **关闭**：说明必填。
- **重开（激活）**：说明必填；处理人流转：已解决→回设给解决人，已拒绝→回设给拒绝人。
- 关闭状态下除重新打开外不可再修改任何信息。

## 2. 关联用例选择器（评审/计划/缺陷复用）

> 缺陷关联用例为**单选模式**：已选用例直接显示在表单中，点击[选择]打开 CaseSelector 弹窗进行单选切换。

### 2.1 弹窗布局

```
┌──────────────────────────────────────┐
│  选择关联用例                  [✕]   │
├──────────┬───────────────────────────┤
│ 模块树   │  当前选中 (1)             │
│ 📁功能   │  · 登录-邮箱登录 ✓       │
│  📁登录  │                           │
│   📄用例集│                           │
│  📁支付  │                           │
│   📄流程 │                           │
├──────────┴───────────────────────────┤
│            [取消]  [确定关联]         │
└──────────────────────────────────────┘
```

### 2.2 交互说明

| 操作     | 触发方式      | 反馈                    |
| ------ | --------- | --------------------- |
| 选择/切换用例 | 点击用例节点   | 选中即替换已选项，仅用例节点可勾选     |
| 移除已选   | 点击已选区域✕  | 清空当前选中                |
| 搜索     | 输入框键入     | 高亮匹配节点                |
| 确定     | 点击[确定关联]  | 关闭弹窗，已选用例回填至发起表单     |

> **缺陷关联用例冒泡**：在详情页中，关联用例气泡仅展示前置条件/步骤/预期三种标记节点，UI 徽标风格与文档视图一致；悬停展示完整明细（前置↔步骤↔预期），支持[跳转所在文档]链接直接跳转至脑图文档中的对应用例。用例选择器支持完整文档树与精简视图两种模式切换。
