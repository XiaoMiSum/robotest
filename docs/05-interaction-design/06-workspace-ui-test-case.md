## 1. 测试用例子模块

选中“测试用例”菜单后，右侧进一步分为左右结构：左侧模块树 + 右侧脑图编辑器。

### 1.2 交互说明

**顶部工具条**：单行排布、不换行，左对齐，常驻于脑图编辑区上方，不随画布滚动；功能组之间以竖分隔线分隔（撤销/重做｜节点操作：下级、同级、编辑、删除｜排版模板与恢复排版｜节点类型与清除标记｜优先级：AI 推荐 + P0–P3），命令组（[🔗 关联需求]｜[✨ AI 生成用例]｜[🔍 AI查漏]——三枚均为纯图标按钮）经弹性占位居于行末右侧，与核心组始终同一行；按钮总量超出容器宽度时工具条自身横向滚动（细滚动条）。排版模板入口只显示图标与下拉箭头，不回显布局名称文本，当前模板由悬浮提示给出；**工具条所有按钮一律带悬浮提示**：图标型给出功能名与快捷键，纯图标入口以悬浮提示替代文字（「关联需求」「AI 生成用例」「AI查漏」），文字型按钮（类型标记、P0–P3）给出操作语义，删除按钮悬浮提示转为警示色。

**模块树交互**：展开/折叠点击箭头；选中文档点击节点加载脑图；新建右键或[+新建]输入名称；重命名双击或右键；拖拽移动节点；删除右键或Delete键二次确认。

**脑图编辑器**：添加子节点Tab；添加兄弟节点Enter；编辑文本双击；移动拖拽；删除Delete；标记用例/优先级顶部工具条或右键菜单；缩放Ctrl+=/-/0或工具栏按钮；抓手模式工具栏切换或按H键。

**AI 功能面板**：AI 生成用例（工具条入口）、AI 补全步骤与移除 AI 标识（画布右键菜单，节点带 AI 徽标）、遗漏测试点分析（工具条入口）统一为右侧滑出抽屉——默认 640px、左缘可拖拽调宽（480px–90vw）、透明遮罩不压暗画布、点击空白或 ✕ 或 Esc 关闭，头部仅图标与标题（调用进行中标题旁显示转圈徽标「生成中/分析中」），骨架为头部 → 内容区（输入/配置区 → 结果/输出区，整体滚动）→ 底部常驻操作行（sticky 不随内容滚动；左侧 4px 纤细进度条 + 阶段文案与已耗时秒表，右侧对话模型选择器与主操作，结果阶段操作同排常驻右下）；调用中关闭抽屉 toast 提示「在后台继续，重新打开可查看结果」，会话在抽屉关闭后保留，重新打开恢复现场并显示「已恢复上次会话」（生成抽屉附 [新会话] 重置，遗漏分析以 [重新分析] 重发）；打开聚焦首个输入、关闭归还焦点、选取器关闭回焦 [选择需求]，`Ctrl/Cmd + Enter` 触发主操作。按钮随任务阶段切换样式与状态：发起态为主按钮（✨ 开始生成/开始补全，generate 模式文本与需求条目皆空时需求输入下方内联红字「请输入需求描述或选择需求条目」且不切换阶段），流式态进度条与阶段耗时同排、换小号「停止」且文本域与需求选择禁用，超时未见首帧出现慢响应提示，完成态为次要「重新生成」+ 主按钮「查看预览」并显示完成提示、结果摘要清单与截断警告，空结果回退发起态并提示；遗漏分析底部操作行含对话模型选择器（45 2.8），主按钮转 loading 并禁用输入与需求选择，取消中止后保留上次结果；完成态输入组（关键词/需求文本/需求池）自动折叠、可 [展开输入]/[收起输入] 手动展开，底部操作行同排为链接样式「重新分析」+ 主按钮「转用例生成（N）」，勾选清零时「转用例生成」禁用，结果列表超长时仅列表内部滚动、抽屉不整体滚动。需求文本域右下实时显示 `n/20000`，需求池 bar 显示「已选 N 条」并可 [清空]，挂载目标路径超长省略并悬浮完整路径。生成/补全结果在独立预览弹窗（70%×80% 视口、置顶于抽屉之上）中按用例勾选、内部结构随用例级联，确认后挂载/追加到脑图；遗漏分析结果逐条勾选后经「转用例生成」将勾选内容拼接为需求文本预填「AI 生成用例」抽屉并 toast「已带入勾选内容（N 条）」。需求池条目统一经「选择需求」选取器弹窗维护（关键字过滤、多选、已选计数），工具条 [关联需求] 复用同一选取器维护文档关联（`docs/05-interaction-design/52-ai-case-ui-pool.md` 1.2 / 1.3），关联条目在打开抽屉时自动带入，选取器行内 [明细] 就近冒泡展示条目 Markdown 正文（仅正文，不联动勾选）。抽屉统一规格与对话模型选择器见 `docs/05-interaction-design/45-ai-infra-ui-overview.md` 2.9 / 2.8，分册交互见 `docs/05-interaction-design/49-ai-case-ui-generation.md`、`docs/05-interaction-design/56-ai-review-ui-missing.md`。

**脑图组件详细设计**参见《脑图组件实现设计文档》。
