## 1. 测试用例子模块

选中“测试用例”菜单后，右侧进一步分为左右结构：左侧模块树 + 右侧脑图编辑器。

### 1.1 页面布局

```
┌──────────┬───────────────────────────────────────┐
│ 模块树   │  [↶][↷]│[＋下级][＋同级][✎][🗑]│[☰右侧分布▾][✨]  │
│          │  [●用例][●前置][●步骤][●预期][⊗]│[✨推荐][P0-P3]⋯[🔗关联需求]│[✨AI生成用例][✨遗漏] │
│ 📁功能   │  ┌──────────────────────────────┐     │
│  📁登录  │  │        脑图编辑区              │     │
```

### 1.2 交互说明

**顶部工具条**：单行排布、左对齐，常驻于脑图编辑区上方，不随画布滚动；功能组之间以竖分隔线分隔（撤销/重做｜节点操作：下级、同级、编辑、删除｜排版模板与恢复排版｜节点类型与清除标记｜优先级：AI 推荐 + P0–P3），命令组（关联需求｜AI 生成用例、遗漏测试点）经弹性占位居于行末右侧；空间不足时整行换行。图标型按钮以悬浮提示给出功能名与快捷键，删除按钮悬浮提示转为警示色。

**模块树交互**：展开/折叠点击箭头；选中文档点击节点加载脑图；新建右键或[+新建]输入名称；重命名双击或右键；拖拽移动节点；删除右键或Delete键二次确认。

**脑图编辑器**：添加子节点Tab；添加兄弟节点Enter；编辑文本双击；移动拖拽；删除Delete；标记用例/优先级顶部工具条或右键菜单；缩放Ctrl+=/-/0或工具栏按钮；抓手模式工具栏切换或按H键。

**脑图组件详细设计**参见《脑图组件实现设计文档》。
