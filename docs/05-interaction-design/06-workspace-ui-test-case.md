### 1.2 交互说明

**顶部工具条**：单行排布、不换行，左对齐，常驻于脑图编辑区上方，不随画布滚动；功能组之间以竖分隔线分隔（撤销/重做｜节点操作：下级、同级、编辑、删除｜排版模板与恢复排版｜节点类型与清除标记｜优先级：AI 推荐 + P0–P3），命令组（关联需求｜AI 生成用例、遗漏测试点）经弹性占位居于行末右侧，与核心组始终同一行；按钮总量超出容器宽度时工具条自身横向滚动（细滚动条）。排版模板入口只显示图标与下拉箭头，不回显布局名称文本，当前模板由悬浮提示给出；其余图标型按钮以悬浮提示给出功能名与快捷键，删除按钮悬浮提示转为警示色。

**模块树交互**：展开/折叠点击箭头；选中文档点击节点加载脑图；新建右键或[+新建]输入名称；重命名双击或右键；拖拽移动节点；删除右键或Delete键二次确认。

**脑图编辑器**：添加子节点Tab；添加兄弟节点Enter；编辑文本双击；移动拖拽；删除Delete；标记用例/优先级顶部工具条或右键菜单；缩放Ctrl+=/-/0或工具栏按钮；抓手模式工具栏切换或按H键。

**AI 功能面板**：AI 生成用例（工具条入口）、AI 补全步骤与移除 AI 标识（画布右键菜单，节点带 AI 徽标）、遗漏测试点分析（工具条入口）统一为右侧滑出抽屉——640px、透明遮罩不压暗画布、点击空白或 ✕ 关闭，头部仅图标与标题，骨架为输入/配置区 → 操作行（进度条居最左、其余控件右对齐，调用中显示 4px 纤细进度条）→ 结果/输出区；会话在抽屉关闭后保留，重新打开恢复现场。按钮随任务阶段切换样式与状态：发起态为主按钮（✨ 开始生成/开始补全，generate 模式文本与需求条目皆空时点击给出警示且不切换阶段），流式态进度条同行、换小号「停止」且文本域与需求选择禁用，超时未见首帧出现慢响应提示，完成态为次要「重新生成」+ 主按钮「查看预览」并显示完成提示与截断警告，空结果回退发起态并提示；遗漏分析操作行含对话模型选择器（45 2.8），主按钮转 loading 并禁用输入与需求选择，取消中止后保留上次结果；完成态输入组（关键词/需求文本/需求池）自动折叠、可 [展开输入]/[收起输入] 手动展开，操作行同排为链接样式「重新分析」+ 主按钮「转用例生成（N）」（位于结果列表上方），勾选清零时「转用例生成」禁用，结果列表超长时仅列表内部滚动、抽屉不整体滚动。生成/补全结果在独立预览弹窗（70%×80% 视口、置顶于抽屉之上）中按用例勾选、内部结构随用例级联，确认后挂载/追加到脑图；遗漏分析结果逐条勾选后经「转用例生成」将勾选内容拼接为需求文本预填「AI 生成用例」抽屉。抽屉统一规格与对话模型选择器见 `docs/05-interaction-design/45-ai-infra-ui-overview.md` 2.9 / 2.8，分册交互见 `docs/05-interaction-design/49-ai-case-ui-generation.md`、`docs/05-interaction-design/56-ai-review-ui-missing.md`。

**脑图组件详细设计**参见《脑图组件实现设计文档》。
