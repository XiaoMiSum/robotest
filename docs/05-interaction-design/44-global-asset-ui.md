# 软件测试平台——公共组件交互设计

**文档版本**：V1.0  
**日期**：2026-09-23  
**状态**：起草中

> 本文档为接口测试域交互设计分册：公共组件管理（项目级可复用组件资产库）的前端交互设计。
> 导航框架与色彩体系见 `docs/05-interaction-design/02-global-navigation.md`、`docs/05-interaction-design/03-visual-design.md`。

## 1. 概述

接口测试域新增公共组件能力。本文档覆盖公共组件管理页的交互设计：

1. **公共组件管理页**——项目级可复用组件资产库的管理（前置/后置处理器、验证器、提取器，承接 SRS 3.7.2）。

### 1.1 菜单与路由

**项目模式**（接口测试侧边栏）在末尾「项目设置」分组（平台级，按业务域过滤）下提供「公共组件」入口：

```
┌──────────────────────────────────┐
│  接口测试（顶部菜单入口）          │
│  ─────────────────────────       │
│  快速调试     /workspace/projects/api-testing?tab=debug
│  接口管理     /workspace/projects/api-testing?tab=interfaces
│  Mock 服务    /workspace/projects/api-testing?tab=mocks
│  测试场景     /workspace/projects/api-testing?tab=scenes
│  接口测试报告 /workspace/projects/api-testing?tab=reports
│  定时任务     /workspace/projects/api-testing?tab=schedules
│  ═════════════════════════════
│  项目设置（平台级 · 按业务域过滤）
│   ├ 环境管理           /workspace/projects/settings/environments
│   └ 公共组件           /workspace/projects/settings/assets  ← 本文档
└──────────────────────────────────┘
```

| 页面 | 路由 | 模式 | 权限 |
| ---- | ---- | ---- | ---- |
| 公共组件管理页 | `/workspace/projects/settings/assets` | 项目模式 | 项目成员查看；项目维护者维护 |

> 上表路由为前端路由示意，与后端 API 路径相互独立。

### 1.2 权限边界

- 公共组件归属项目，按项目隔离；维护（新建/编辑/删除/启停）为项目维护者权限，项目成员可浏览与复制引入。

### 1.3 权限点映射

「项目设置」分组各入口及页面内维护操作按权限点控制（与后端 `@PreAuthorize` 对齐）：

| 模块（侧边导航入口） | 查看权限点 | 维护权限点 |
| ---- | ---- | ---- |
| 环境管理 | `api-env:view` | `api-env:edit` |
| 函数管理 | `api-func:view` | `api-func:edit` / `api-func:edit-space` / `api-func:edit-global` |
| 公共组件 | `api-component:view` | `api-component:edit` / `api-component:edit-space` / `api-component:edit-global` |

- 顶部菜单「接口测试」入口对任一模块查看权限点开放；侧边导航仅展示已持有对应「查看权限点」的入口。
- 未持有任何接口测试域查看权限点时，内容区展示「暂无可用功能模块」空态。
- 页面内维护按钮（新建/编辑/删除等）按「维护权限点」禁用，后端 `@PreAuthorize` 兜底校验。

## 2. 公共组件管理页

**路由**：`/admin/global-assets`（管理模式，仅系统管理员可见）

### 2.1 页面布局

页面采用「左列表 / 右详情」结构，与环境管理页、函数管理页一致：

```
┌──────────────────────────────────────────────────────────┐
│  公共组件                                                 │
│  项目级可复用组件资产库，供快速调试与测试场景复制引入        │
├───────────────────┬───────────────────────────────────────┤
│ [搜索资产_______]  │ ☑ 登录获取 Token 启用   [编辑][复制][删除] │
│ [+ 新建资产]       │ ── 基本信息 ───────────────────────── │
│ [全部][前置处理器]  │ 类型 前置处理器   作用域 项目             │
│ [后置处理器][验证器] │ 更新时间 2026-08-17 10:30                  │
│ [提取器]           │ 描述 登录后提取 token 供后续步骤使用      │
│ ─────────────────  │ ── 配置（随类型切换）─────────────────  │
│ ● 登录获取 Token   │ 处理器类型 [发送 HTTP 请求 ▾]            │
│   [项目] [已启用]   │ 请求方法 [POST ▾]  ref [http_1 ▾]      │
│   前置处理器 · 提取 token│ 路径 [/auth/token]                   │
│ ● 清理测试数据      │ [ 与平台内同类型组件一致的配置表单 ]      │
│   [公共] [已停用]   │ ── 提取器（可选）───────────────────  │
│   后置处理器 · 清理造数│ [ + 添加提取器 ] [从公共组件获取]        │
│  …（滚动）         │                                       │
└───────────────────┴───────────────────────────────────────┘
```

- **左栏（列表区）**：首行为搜索框与 `[+ 新建资产]`，其下为类型页签（全部 / 前置 / 后置 / 验证器 / 提取器，分段控件形态，视觉基准 `web/demos/project/api-components.html`）与组件项列表；列表滚动展示，项内显示组件名、作用域标签与状态标签（已启用 / 已停用），描述行以「类型 · 描述」呈现；停用项降透明度显示。
- **左栏分页与滚动加载**：列表按每页 20 条服务端分页，滚动至底部自动加载下一页追加、滚动至顶部自动加载上一页前插，不显示分页器；窗口最多保留 5 页（100 条），超出时丢弃距视口最远的一页，再次滚回该方向时重新请求，追加与前插均保持滚动位置不跳变。列表首尾各设固定高度的加载提示位：加载中显示「加载中…」，失败显示错误行 + [重试]，提示位出现与消失不改变列表可视区高度。
- **右栏（详情区）**：卡片头部展示组件名、类型与作用域标签、「启用」勾选及编辑/复制/删除操作；进入页面默认选中列表第一条并展示其只读详情，此后跟随最近选中组件；未选中时（列表为空或无匹配结果且无缓存）展示未选中空态，选中项不在列表时右栏保持其缓存详情（见 2.3）。

### 2.2 详情与编辑

新建与编辑在右侧详情区内切换为编辑面板完成（与环境管理页、函数管理页一致），字段与 `docs/04-detailed-design/25-api-test-infra-common-component.md` 第 3 节一致：

```
┌────────────────────────────────────────────────────┐
│  登录获取 Token                      [取消] [保存]  │
│  ── 基本信息 ────────────────────────────────────  │
│  名称      [登录获取 Token                ]         │
│  类型      [前置处理器 ▾]   编辑态置灰不可改         │
│  作用域    [项目 ▾]         仅新建时显示            │
│  描述      [登录后提取 token 供后续步骤使用]         │
│  ── 配置（随类型切换）───────────────────────────  │
│  处理器类型 [发送 HTTP 请求 ▾]                      │
│  [ 与平台内同类型组件一致的配置表单 ]                 │
│  ── 提取器（可选）───────────────────────────────  │
│  [ + 添加提取器 ] [从公共组件获取]                   │
└────────────────────────────────────────────────────┘
```

- 新建态标题为「新建资产」，类型默认「前置处理器」、作用域默认「项目」、启用默认勾选；编辑态标题为组件名，类型与作用域不可修改。编辑面板不提供启停字段，保存时保留组件原启用状态，启停只在查看态卡片头部的「启用」勾选处进行。
- 保存：校验通过后提交并刷新列表与详情，Toast「已创建 / 已更新」；校验失败在字段下方红字定位首个错误项。
- 取消：退出编辑态回到查看态，丢弃未保存改动。

### 2.3 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 进入页面 | 项目模式菜单点击「公共组件」 | 拉取当前项目组件列表（每页 20 条），默认展示全部类型并选中第一条，右栏展示其只读详情 |
| 选中资产 | 点击左栏列表项 | 右栏展示该资产的只读详情 |
| 滚动加载 | 左栏列表滚动至底部 / 顶部 | 底部自动请求下一页追加、顶部自动请求上一页前插，首尾提示位显示「加载中…」，失败显示错误行 + [重试]，无更多数据后不再触发 |
| 选中项滑出窗口 | 其所在页被窗口丢弃或筛选刷新后不在列表中 | 右栏保持显示该资产的缓存详情，该页重新加载后左栏回显高亮 |
| 搜索/筛选 | 左栏搜索框 / 类型页签 | 按名称模糊搜索，类型页签切换过滤，均回到第 1 页重新加载 |
| 新建资产 | 点击 `[+ 新建资产]` | 右栏切换为空白编辑面板，类型默认「前置处理器」 |
| 编辑资产 | 详情区 [编辑] | 右栏切换为编辑面板，回显配置（类型与作用域不可改） |
| 复制资产 | 详情区 [复制] | 右栏切换为新建面板并回填源资产配置，名称追加「 (副本)」且可修改，保存后生成同作用域独立副本（默认启用） |
| 启用/停用 | 详情区卡片头部「启用」勾选 | 勾选设为启用、取消勾选设为禁用，即时切换并同步列表状态标签；停用后项目内不可再引入，已引入副本不受影响，失败时给出错误提示 |
| 删除资产 | 详情区 [删除] | 二次确认（红色警示）「删除后不可恢复，已引入副本不受影响」 |

### 2.4 项目内引入（复制引入）

公共组件在项目内通过「引入选择器」复制引入，入口位于快速调试面板与测试场景的处理器/验证器/提取器配置处：

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 打开引入选择器 | 配置区 [从资产库引入] | 弹窗展示可用资产列表（仅启用状态），支持类型筛选与搜索 |
| 引入资产 | 勾选后点击 [引入] | 生成独立副本并回填到当前配置区，Toast「已引入」；副本与源资产无关联 |
| 查看已停用资产 | 引入选择器内 | 停用资产不展示，不提供引入入口 |

### 2.5 状态分支

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 左栏列表 + 右栏详情，类型页签高亮当前筛选 |
| 空态 | 无资产：左栏空态「暂无公共组件」（新建入口常驻首行）；关键词或类型页签筛选无结果时显示「无匹配结果」+ [清除筛选]（同时清除两者） |
| 加载态 | 首次进入列表与详情骨架屏；滚动加载中列表首尾提示位显示「加载中…」；保存按钮 loading |
| 错误态 | 拉取失败：错误提示 + [重试]；保存失败：编辑面板内红字定位首个错误项 |
| 权限不足 | 非项目维护者访问该路由：403 页面「无权限访问」；项目成员不展示新建/编辑/删除操作，详情区头部不展示「启用」勾选 |

## 3. 通用交互模式

本页涉及的通用交互模式遵循 `docs/05-interaction-design/01-readme.md` 第 3 章的约定：

- **弹窗类型**：确认弹窗用于删除公共组件；新建/编辑使用右栏编辑面板（与环境管理页、函数管理页一致）；选择弹窗用于公共组件引入选择器；
- **加载与错误状态**：列表与详情首次进入骨架屏；表单提交按钮 loading + 禁用；加载失败展示错误区 + [重试]；空态统一为插画 + 主文案 + 主操作按钮，筛选无结果时提供 [清除筛选]；
- **状态徽标色彩**：统一使用 `docs/05-interaction-design/03-visual-design.md` 定义的语义色；
- **响应式处理**：小屏幕下左栏列表收起、仅展示详情区，通过返回操作回到列表。
