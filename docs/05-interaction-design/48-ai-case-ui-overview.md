## 1. 总体布局

### 1.1 脑图编辑页 AI 入口分布

AI 入口落位于用例脑图编辑页（CaseMindMap），随 `aiEnabled` 显隐：

```
┌────────────────────────────────────────────────────────────┐
│ 核心工具栏: [历史] [节点结构] [布局] [类型标记] [优先级] [关联需求]│
│ AI 入口行（右侧）: [✨AI 生成用例] [✨遗漏测试点]               │
├────────────────────────────────────────────────────────────┤
│                                                            │
│                    脑图画布                                │
│          （case 节点右键菜单含「✨AI 补全步骤」）           │
│                                                            │
│                          ┌────────────────────────┐        │
│                          │  AI 生成抽屉（右侧滑出）│        │
│                          └────────────────────────┘        │
└────────────────────────────────────────────────────────────┘
```

- 工具栏为顶部两行流式胶囊：**第一行**为核心编辑操作（历史/节点结构/布局/类型标记/优先级/关联需求），**第二行（右侧）**为 AI 入口 [AI 生成用例] [遗漏测试点]，带 AI 统一视觉标识；两行均随内容换行不重叠；
- 右键菜单仅在 **case 类型节点**上显示「AI 补全步骤」项（置于标记域之后的动作区）；
- 需求池为项目工作区侧边菜单新增入口（1.2），**不受 AI 开关控制**。

> **零影响约束（通用规范 2.7）**：AI 入口独占一行、追加在核心工具栏下方，不改变既有标记组、优先级组的位置与操作；`aiEnabled = false` 时 AI 入口行整体隐藏，核心工具栏与右键菜单回退到 V1.0 形态，脑图编辑、协同、撤销等既有能力不受任何影响。

### 1.2 项目工作区侧边菜单增量

功能测试侧边栏菜单新增「需求池」项：

```
┌──────────┐
│ 用例管理 │
│ 测试评审 │
│ 测试计划 │
│ 需求池   │  ← 新增（常规业务功能，不随 AI 开关隐藏）
└──────────┘
```

## 2. AI 标识徽标

- AI 生成/补全/对话式编辑新增的节点统一携带「AI」徽标，位置与既有类型徽标并列（复用 badges.ts 徽标体系）；
- 徽标随节点复制/剪切粘贴保留到副本，随评审/计划快照继承；
- **移除**：右键菜单标记域仅在 `aiGenerated = true` 的节点上显示「移除 AI 标识」芯片，点击即移除；移除后不可重新添加（撤销回退除外），任何入口不提供手动添加；
- AI 标识不影响任何业务规则（评审、计划、执行照常）。

## 3. 通用交互模式总结

### 3.1 弹窗类型

| 类型 | 使用场景 |
| ---- | ---- |
| 抽屉 | AI 生成/补全面板（640px，右侧滑出、透明遮罩不压暗画布、点击空白关闭）、需求条目新建/编辑 |
| 居中弹窗 | AI 生成用例预览弹窗（脑图形式，宽 70% × 高 80%（视口），两窗并存时置顶） |
| 确认弹窗 | 条目删除、挂载目标重选 |
| 选择弹窗 | 需求条目选取器、挂载位置节点选择器 |

### 3.2 加载状态

- 流式生成：操作行内进度条占位（flex:1、与 [停止] 按钮同行左侧）+ [停止] 按钮；超 10 秒提示可取消重试（通用规范 2.3）。
- 同步推荐：按钮 loading，不阻塞脑图编辑。
- 需求池列表：首次骨架屏，刷新顶部进度条。

### 3.3 与协同编辑的关系

- 生成、预览期间文档保持可编辑，协同帧照常收发；
- 挂载经既有编辑内核与协同通道，协同用户实时可见；
- 一切 AI 引发的脑图变更均为单条撤销历史，Ctrl+Z 一次回退。
