3. 最近评审/计划列表点击可跳转至对应详情。

### 7.2 交互说明

| 操作    | 触发方式             | 反馈                   |
| ----- | ---------------- | -------------------- |
| 搜索/筛选 | 输入关键词或选择状态       | 列表自动刷新               |
| 进入项目  | 点击[进入]或卡片        | 设置活跃项目ID → 跳转至项目工作台  |
| 设为默认  | 点击[设为默认]         | 调用接口 → 卡片标注⭐，Toast提示 |
| 归档/启封 | 点击[归档]/[启封]（管理员） | 二次确认 → 执行            |
| 删除    | 点击[删除]（管理员）      | 二次确认 → 检查项目是否为空 → 执行 |
