## 5. 执行顺序推荐（US-AI-017）

**入口**：计划详情页新增 [执行顺序推荐] 标签页，仅计划负责人 / 执行人可发起与查看。

### 5.1 推荐视图布局

```
┌──────────────────────────────────────────────────────┐
│  [执行记录] [执行顺序推荐✨]              [重新计算]  │
├──────────────────────────────────────────────────────┤
│  ⚠ 计划快照已重新同步，推荐结果已失效，请重新计算    │  ← stale 提示条（按需）
├──────────────────────────────────────────────────────┤
│  #1 │ 支付-余额不足   │ 指数 92 │ P0 │ ▸ 因子明细    │
│  #2 │ 登录-密码错误   │ 指数 87 │ P0 │ ▸ 因子明细    │
│  #3 │ 订单-超时取消   │ 指数 74 │ P1 │ ▸ 因子明细    │
│  …（按推荐执行指数降序）                             │
└──────────────────────────────────────────────────────┘
```

### 5.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 首次进入（无结果） | 打开 [执行顺序推荐] 标签页 | 空态说明 + [开始计算] 按钮 |
| 发起计算 | 点击 [开始计算] / [重新计算] | 确定性加权计算（非 LLM），完成后渲染排序列表 |
| 展开因子明细 | 点击行内 [▸ 因子明细] | 展开显示三项因子得分（历史关联缺陷数 / 优先级权重 / 模块缺陷密度） |
| 查看推荐理由 | 明细内点击 [生成理由] | 按需发起 LLM 调用生成理由文本（行内 loading），已生成则直接展示 |
| 列表定位脑图 | 点击列表行 | 计划脑图滚动定位到对应节点并高亮 |
| 脑图徽标联动 | 脑图节点渲染 #序号 徽标 | 点击徽标反向滚动列表至对应行（双向联动） |
| 快照重新同步 | 同步快照后进入标签页 | 顶部 stale 提示条：推荐已失效需重算 |
| 语义降级 | semanticDegraded | 顶部提示条呈现（同通用规范 2.6） |

- 推荐仅供参考，不改变计划执行流程与执行记录规则。
