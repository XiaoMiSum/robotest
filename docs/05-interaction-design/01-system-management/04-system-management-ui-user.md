#### 1.1.2 交互说明

| 操作    | 触发方式            | 反馈                  |
| ----- | --------------- | ------------------- |
| 搜索    | 输入关键词后回车或点击[查询] | 表格刷新，显示匹配结果         |

| 查看详情  | 点击用户名或[查看]      | 跳转至详情页              |

### 1.2 状态扩展「锁定」

用户列表其余交互（搜索、筛选、批量操作、重置密码、分页等）见 1.1.1、1.1.2，保持不变；以下描述状态「锁定」相关设计。

#### 1.2.1 状态取值与筛选

- 用户状态三态：`active` 启用 / `disabled` 禁用 / `locked` 锁定。
- 状态筛选下拉新增「锁定」选项（启用 / 禁用 / 锁定）。

#### 1.2.2 状态列展示

| 状态值 | 文案 | 点标样式 |
| ------ | ---- | -------- |
| active | 启用 | success 绿点 |
| disabled | 禁用 | neutral 灰点 |
| locked | 锁定 | danger 红点 |

状态列采用验收基准的**点标**样式（圆点 + 文案），点标色义与原标签 success/info/danger 一一对应（info → neutral 灰）。

#### 1.2.3 行操作按钮

均需二次确认（沿用 2.2 全局交互规范的「危险操作二次确认」）：

| 当前状态 | 可用操作 |
| -------- | -------- |
| 启用 | 禁用、锁定 |
| 禁用 | 启用、锁定 |
| 锁定 | 启用、禁用 |

- 操作列宽由 200 调整为 240，容纳新增按钮。
- 批量操作维持「批量启用 / 批量禁用」，**不支持批量锁定**。

#### 1.2.4 登录限制

- 禁用与锁定状态均无法登录；登录失败提示**不区分**禁用/锁定（沿用既有「账户已被禁用或登录凭证失效」，避免账号枚举）。
- 新建用户默认 `active`，不变。

### 1.3 用户创建/编辑页

**路由**：`/admin/users/create`、`/admin/users/:id`

#### 1.3.1 页面布局

> 布局基准：`web/demos/admin/user-form.html`。演示稿中的「确认密码、状态单选、激活邮件提示、底部[返回列表][保存并创建]」无对应后端能力或按约定不实现；按钮功能集保持原状（保存/取消/修改密码），仅位置随基准移至页头。

```
┌───────────────────────────────────────────────────┐
│ 用户管理 › 新建用户 / 编辑用户                      │
├───────────────────────────────────────────────────┤
│ 新建用户 / 编辑用户                 [取消] [保存]   │
│ 创建平台账号并分配系统级角色                         │
├───────────────────────────────────────────────────┤
│ ┌─────────────────────┐ ┌─────────────────────┐   │
│ │ 基本信息            │ │ 系统角色            │   │
│ │                     │ │ 决定全局管理权限     │   │
│ ├─────────────────────┤ ├─────────────────────┤   │
│ │ 用户名 *            │ │ ☐ 系统管理员        │   │
│ │ [______________]    │ │ ☐ 空间管理员        │   │
│ │ 3-30 字母数字/-_     │ │ （竖排复选框）       │   │
│ │ 姓名 *              │ │ （允许为空）         │   │
│ │ [______________]    │ │                     │   │
│ │ 邮箱 *              │ │                     │   │
│ │ [______________]    │ │                     │   │
│ │ 密码 *（新建）       │ │                     │   │
│ │ [______________]    │ │                     │   │
│ │ 8-64 + 强度条       │ │                     │   │
│ │ 编辑时:修改密码链接   │ │                     │   │
│ └─────────────────────┘ └─────────────────────┘   │
└───────────────────────────────────────────────────┘
```

#### 1.3.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ------ | ------------- | ------------------------------------------------ |
| 角色选择 | 点击复选框勾选/取消 | 显示全部系统角色（竖排复选框，角色名来自接口）。**允许为空**，保存时 roleIds 可为空数组 |
| 表单校验 | 失焦时触发 | 红色边框 + 错误提示文字 |
| 保存 | 点击页头[保存] | 前端校验 → 提交 → 成功跳转列表页；失败弹出错误消息 |
| 取消 | 点击页头[取消]或面包屑「用户管理」 | 不保存直接返回列表页（无二次确认） |
| 密码输入 | 创建时显示密码框（含强度条），编辑时隐藏 | 编辑页基本信息卡内显示"修改密码"链接，点击弹出修改密码对话框 |
| 编辑模式 | 打开编辑页 | 用户名只读不可修改，姓名/邮箱/系统角色可编辑 |
| 加载中 | 编辑页拉取用户详情 | 页面区域 loading 遮罩，失败弹出错误消息 |
