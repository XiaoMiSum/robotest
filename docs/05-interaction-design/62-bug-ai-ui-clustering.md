## 4. 缺陷聚类分析（US-AI-010）

**入口**：缺陷看板页 [AI 分析] 按钮，从右侧滑出聚类分析抽屉。

### 4.1 聚类分析抽屉布局（报告式主题卡片）

报告内容以**可读报告**而非紧凑仪表盘呈现：顶部汇总条 + 单列主题卡片（首个默认展开）+ 底部分布图。容器为右侧抽屉：宽度约 560px、**无遮罩**（`:modal=false`，不阻断缺陷列表操作）、ESC 或 X 关闭；报告内容不挤压看板主内容区，可边看报告边操作列表。**（对通用规范 2.9 统一 640px 抽屉规格的例外：本抽屉为报告式阅读型，刻意以 560px + 无遮罩换取"边看报告边操作列表"的双任务体验，其余规格仍遵循 2.9。）**

**字号阶梯**（解决结果区过小问题，视觉规范 `--font-size-*`）：

| 元素 | 字号 | 说明 |
| ---- | ---- | ---- |
| 主题名 | `--font-size-lg`（16px）加粗 | 核心阅读对象 |
| 根因正文 | `--font-size-base`（14px） | 最多 3 行省略，点击展开全文 |
| 展开明细标题 | `--font-size-base`（14px） | 缺陷标题为主信息 |
| 序号/计数徽章、生成时间、汇总、分布图 | `--font-size-xs`（12px）起 | 辅助信息不低于 12px，禁用 `--font-size-2xs` |

### 4.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 打开抽屉（有结果） | 点击 [AI 分析] | 右侧滑出抽屉，读取最近一次结果快照渲染，显示生成时间与汇总条 |
| 打开抽屉（无结果无任务） | 同上 | 空态插画 + 说明 + [开始分析] 按钮 |
| 开始/刷新分析 | 点击 [开始分析] / [刷新] | 创建异步任务，进度条 + 2 秒轮询；同一项目同时只允许一个进行中任务 |
| 关闭抽屉 | 点击 ✕ / 按 ESC / 再次点击 [AI 分析] | 抽屉收起，进行中的任务与轮询不中断（离开页面任务同样不中断） |
| 展开/收起主题 | 点击主题卡片头部 [▸/▾] | 首次打开默认展开第一个主题；点击其他主题仅切换自身展开态，互不联动 |
| 查看根因全文 | 根因超 3 行时点击 | 展开该主题根因全文（与缺陷清单独立展开） |
| 查看缺陷明细 | 主题已展开 | 每行 = 严重度色点 + 缺陷标题 + 状态标签 + 短 ID（标题来自快照 `bugs` 字段）；点击行跳转缺陷详情，抽屉随路由离开自动收起 |
| 取消任务 | 点击 [取消任务] | 任务置已取消，抽屉回退到上一次结果（如有） |
| 任务失败 | 轮询返回 failed | 抽屉展示失败原因 + [重试] 按钮 |
| 语义降级 | `semanticSearch` 非 available | 抽屉顶部降级提示条 |
| 标签生成失败 | 快照 `labeled = false`（LLM 归纳失败/超限） | 主题名前置 ⚠ 标识并标注「标签生成失败」，根因行显示「未生成主题名与根因」，与正常归纳结果明确区分 |

- 分析范围：当前项目全部未关闭缺陷；结果为只读洞察，不修改任何缺陷数据；
- **降级模式**：`semanticSearch` 非 available 时聚类降级为关键词归纳（详细设计 4.3 降级模式），抽屉顶部降级提示条明示，主题卡片、分布图等展示形态与语义模式完全一致；
- 快照 `clusters[].bugs` 携带缺陷标题（详细设计 2.3 变更），明细行直接渲染标题，无需展开后再查详情；
- 分布图不引入图表库，CSS/SVG 轻量自绘：按模块的水平条形分布（宽度比例 + 数量 + 百分比标签）与按严重等级的分段色条，配色沿用视觉设计语义色。
