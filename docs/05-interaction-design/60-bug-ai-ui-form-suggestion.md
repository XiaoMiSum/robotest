## 2. 标题优化与等级建议（US-AI-008）

### 2.1 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 发起建议 | 点击 [AI 建议] 按钮（标题为空时禁用） | 按钮 loading（同步调用）；**并发**发起建议与查重两个请求，各区域独立 loading；上下文仅取当前标题 + 重现步骤 |
| 查看建议 | 调用成功 | 面板内展示建议区：优化标题 + 严重等级建议 + 优先级建议 |
| 收起/展开面板 | 点击面板头部 [收起/展开] | 面板整体折叠为仅标题行（结果保留、不重新请求），再点展开恢复全部内容 |
| 采纳标题 | 卡片内点击 [一键替换] | 表单标题输入框内容替换为优化标题，卡片该项置为已采纳态 |
| 忽略标题 | 卡片内点击 [忽略] | 该建议项收起，标题保持不变 |
| 采纳等级/优先级 | 点击建议值 | 对应下拉框回填该值（建议值必映射平台既有枚举） |
| 调用失败 | 网络/模型错误 | 仅 Toast 轻提示，不影响表单任何操作 |

- 建议仅回填表单待用户确认，提交前可任意修改，不产生任何自动提交行为；
- 建议请求进行中不阻塞输入与提交（非侵入原则，通用规范 2.5）；
- 建议与查重为两个独立请求：任一成功即展示对应区域，任一失败仅轻提示，互不阻断。
