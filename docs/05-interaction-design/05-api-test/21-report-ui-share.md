**交互说明**：

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 访问分享页 | 打开分享链接 | 免登录加载报告只读内容；token 无效或过期：403 提示「分享链接无效或已过期」 |
| 折叠/展开 | 点击场景卡、处理器卡、步骤卡头部 | 与详情页一致（只读，含「全部展开/收起」） |
| 查看套件分享 | 打开套件报告分享链接 | 免登录展示套件只读内容：Hero + 统计卡 + 环境处理器 + 场景卡列表 |

**状态分支**：

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | Hero + 统计卡 + 场景卡的只读展示 |
| 加载态 | 详情骨架屏 |
| 错误态 | token 无效或过期：403 提示「分享链接无效或已过期」；报告已删除：提示「报告不存在或已被删除」 |

> 分享访问页仅提供只读查看，不展示分享/删除等操作入口。
