## 1. 环境管理页

**路由**：`/workspace/projects/settings/environments`

> 环境管理归入侧边栏「项目设置」分组（平台级项目配置入口，见 `docs/05-interaction-design/99-common/02-global-navigation.md` 3.5）。

### 1.1 页面布局

```
┌──────────────────────────┬───────────────────────────────────┐
│  搜索环境名称...   [+ 新增 ▾]│  [HTTP(2)] [变量] [数据源] [处理器]│
│  测试环境  [默认]           │  内部 API       https://staging…  │
│   · 2H 5V 2D 1P          │  第三方支付     https://pay…      │
│  [上移][编辑][复制][删除]    │  [+ 新建配置]   [连接测试]          │
│  预发环境  [设为默认]         │  ────────────────────────────────  │
│   · 8V                    │  名称    [内部 API          ]     │
│  （默认环境置顶）           │  引用名  [internal-api      ]     │
│  （行内操作仅悬浮显示）       │  Base URL [https://staging… ]     │
│                          │  请求头  [+ 添加]                  │
│                          │  （变更计入未保存，随【保存全部】提交） │
│                          │  （数据源连接测试见「数据源」标签页） │
│                          │                                   │
└──────────────────────────┴───────────────────────────────────┘
```

> 页面级说明承载于页头描述（含默认环境说明：场景执行未指定环境时使用列表置顶的默认环境）；详情面板的标签页不设面板标题，面板内仅保留必要的操作按钮行，数据源的新增入口位于列表底部，与 HTTP 一致。新建与复制不弹窗，右侧面板进入**新建态**（见 1.6），其吸顶区为 [名称] [描述] [设为默认] + [取消]/[创建]。

### 1.2 环境列表交互

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 进入页面 | 侧边栏点击「环境管理」 | 左侧加载环境列表（默认环境置顶，其余按排序），骨架屏加载 |
| 搜索 | 左侧搜索框输入 | 防抖 300ms 过滤列表 |
| 选中环境 | 点击列表项 | 列表项高亮，右侧加载环境详情（HTTP、变量、数据源、处理器）；当前处于新建态时先确认放弃（有改动才询问），确认后切换 |
| 新建环境 | 点击搜索框右侧 [+ 新增 ▾] 主按钮 | 右侧面板进入**新建态**（见 1.6）：吸顶区填写名称、描述与「设为默认」，标签页照常编辑，[取消]/[创建] 就地提交；创建后排到列表末尾并选中 |
| 导入/导出 | [+ 新增 ▾] 右侧下拉 [导入环境] / [导出当前环境] | 导入：JSON 文件 + 重名处理开关；导出：下载当前选中环境 JSON |
| 设为默认 | 列表行内（悬浮）[设为默认]（非默认环境显示，默认环境显示「默认」标签；按钮仅悬浮/聚焦行时展示） | 二次确认 → 默认标记转移至该环境（项目内唯一），列表排序刷新 |
| 调整排序 | 列表行内（悬浮）[上移]/[下移] | 相邻互换排序，列表顺序即时更新并保存 |
| 编辑环境 | 列表行内（悬浮）[编辑] | 弹出「编辑环境」弹窗（名称、描述、设为默认），确认后保存并刷新列表，不切换右侧面板编辑态 |

> 列表行内操作（上移/下移/编辑/复制/删除）默认隐藏，鼠标悬浮或键盘聚焦该行时展示；行元信息展示 HTTP / 变量 / 数据源 / 处理器数量。

### 1.3 环境详情编辑

环境详情右侧面板含四个标签页（详情态吸顶区展示环境名称与「默认」标记，名称/描述/设为默认在「编辑环境」弹窗维护；**新建态**（新建与复制共用，见 1.5）在吸顶区就地编辑名称、描述与「设为默认」开关，右侧 [取消]/[创建] 就地提交；标签页不设面板标题，面板内仅保留必要的操作按钮行）：

| 标签页 | 内容与交互 |
| ---- | ---- |
| HTTP | HTTP 配置列表（标签页显示数量），支持多个：每个配置含名称、引用名（必填）、Base URL（必填）、请求头（键值对编辑器）+「设为默认」开关。缺省方法为 GET、跟随重定向、响应/连接超时与 SSL 校验为固定值（见 `docs/04-detailed-design/01-readme.md`）；[+ 新建配置] 新增（新增即创建，默认非默认）、[删除配置] 移除（二次确认）；变更计入未保存，统一由头部【保存全部】提交（见 1.6）；行内 [连接测试] 验证连通性（见 1.5）。设为默认：同一环境内至多一个默认，设为默认时其余 HTTP 配置自动取消默认，默认配置在列表中置顶 |
| 变量 | 环境变量编辑器，完整交互见第 3 章 |
| 数据源 | 数据源列表（名称、驱动、URL），交互同「HTTP」：左侧列表 + 右侧内联表单（名称、引用名称（必填）、驱动下拉（必填；内置常见数据库驱动，切换后自动填充对应 URL 示例，用户名密码写入 URL；Redis 驱动显示 '-' 仅占位满足后端必填，连接按 redis:// 协议识别）、「设为默认」开关、连接 URL（多行文本、独占一行））、[+ 新增数据源]（入口位于列表底部，同「HTTP」）新增并选中（新增即创建，默认非默认）、[删除数据源] 移除（二次确认）；变更计入未保存，统一由头部【保存全部】提交（见 1.6）；行内 [连接测试] 验证连接（见 1.5）。设为默认：同一环境内至多一个默认，设为默认时其余数据源自动取消默认，默认数据源在列表中置顶 |
| 处理器 | 全局前置/后置处理器两个独立标签页，仅作用于该环境下的所有请求；列表为**平铺展开式**：每行展示序号、类型标签、名称与说明，行内（悬浮）操作 [上移]/[下移]/[编辑]/[复制]/[删除]；点击行 → 该行下方展开**只读明细**（再次点击收起），点击行内 [编辑] → 该行下方展开**编辑表单**；[＋ 添加处理器]（面板操作按钮行，同「HTTP」）在列表末尾展开**新增表单**；表单（编辑/新增）展开期间，该行的悬浮操作替换为**常显**的 [取消]/[保存]，且不显示表单标题；同一时刻仅展开一处，[保存] 仅回写列表并计入未保存标记（见 1.6），[取消] 则还原。只读明细与表单的结构、样式同公共组件的前置/后置处理器（见 `docs/05-interaction-design/05-api-test/22-global-asset-ui.md` 2.2）：明细含名称与类型标签、基本信息（更新时间、描述）、配置摘要与提取器只读表格；表单含名称（必填）、类型、描述与配置（HTTP/JDBC 分段、方法与路径、Query/请求体/请求头/提取器页签），不设作用域、环境引用与启用字段。[从公共组件引入] 位于面板操作按钮行，引入为复制、得到独立副本 |

### 1.4 环境类型区分

环境类型仅在数据层区分，列表不展示类型徽标。

- **项目环境**（全部环境均为项目级）：环境归属项目，仅当前项目成员可见可用。
- **全局环境**（预留扩展）：平台级环境，由系统管理员在管理端维护，对所有项目共享。当前不提供维护入口，切换逻辑与展示位待全局环境能力落地后补充。

### 1.5 复制、导入导出与删除

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 复制环境 | 行内（悬浮）[复制] | 右侧面板进入**新建态**并以源环境整体预填：名称预填「原名称（副本）」，HTTP 配置、变量（含取值）、数据源与处理器全部随副本，默认标记不抢占；确认后走创建接口，副本排到列表末尾并选中（数据源凭据内嵌于 URL，仅在项目内复制，不越项目边界；导出/导入仍排除数据源段） |
| 导入环境 | [+ 新建 ▾] 下拉 → [导入环境] | 弹窗选择 JSON 文件 + 「重名处理」开关（开启覆盖 / 关闭跳过）；导入结果弹窗展示新增/覆盖/跳过数量 |
| 导出环境 | [+ 新建 ▾] 下拉 → [导出当前环境] | 下载当前选中环境的 JSON 配置文件，敏感字段脱敏（见需求 3.5） |
| 测试数据源连接 | 行内 [连接测试] | 按钮 loading → 真实建立 JDBC 连接；成功 Toast「连接成功」+ 数据库版本；失败明确提示原因（错误码 1000017403）；新建态无环境 ID，按钮置灰并提示「创建环境后可测试连接」 |
| 测试 HTTP 配置连接 | HTTP 配置行内 [连接测试] | 按钮 loading → 向配置的 base_url 发送 GET 请求验证连通性；成功 Toast「连接成功」+ 状态码与耗时；失败明确提示原因；新建态同数据源，按钮置灰 |
| 删除环境 | 行内（悬浮）[删除] | 二次确认弹窗；若环境被场景引用，**禁止删除**，弹窗列出引用场景清单并提示「请先在场景中解除引用」（错误码 1000017402）；被定时任务绑定同理（错误码 1000017404） |

### 1.6 页面状态

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 左侧列表 + 右侧详情；列表行内操作默认隐藏，鼠标悬浮/聚焦行时展示；默认环境显示「默认」标签，非默认环境悬浮显示 [设为默认]；HTTP、变量、数据源、前置/后置处理器任一标签页存在变更时，头部【保存全部】左侧显示琥珀色「未保存」标记，点击【保存全部】统一提交，成功 Toast「已保存」并清除标记 |
| 新建态 | 右侧面板吸顶区显示名称（必填）、描述与「设为默认」，右侧 [取消]/[创建] 替换 [保存全部]；标签页照常编辑，连接测试按钮置灰并提示「创建环境后可测试连接」；[取消]、点击列表其他项、[编辑]/[删除] 及再次 [新建]/[复制] 均先离开新建态，有改动时确认放弃；[创建] 校验名称（空/重复提示）后排到列表末尾并选中，Toast「环境已创建」 |
| 空态 | 无任何环境：左侧空态插图 + 「暂无环境，点击新建」；搜索无结果：「无匹配环境」+ [清除搜索] |
| 加载态 | 列表与详情首次加载骨架屏；数据源连接测试按钮 loading；导入文件解析中弹窗进度提示 |
| 错误态 | 列表拉取失败：占位 + [重试]；详情拉取失败：右侧面板错误占位 + [重试]；保存失败：Toast 明确原因（如环境名称重复，错误码 1000017401） |
