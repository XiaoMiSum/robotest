## 1. 遗漏测试点分析（US-AI-007）

**入口**：用例模块页操作区 [遗漏测试点分析]，点击展开右侧抽屉。

### 1.1 分析抽屉布局

分析抽屉为右侧滑出抽屉（默认 640px、左缘可拖拽调宽，透明遮罩不压暗画布、点击空白或 Esc 关闭，统一规格见 `docs/05-interaction-design/01-readme.md` 2.9）：

```
┌───────────────────────────────────────┐
│  ✨ 遗漏测试点分析   ⣾ 分析中        ✕  │ ← 进行中徽标（分析中）
├───────────────────────────────────────┤
│  [展开输入 ▾]  ← 分析完成后输入组折叠  │
│  需求输入（三选一，可组合）           │
│  ○ 关键词  [登录, 支付, 短信…]        │
│  ○ 需求文本 [粘贴文本域…    128/20000]│
│  ○ 需求池 [已选 2 条] [清空] [+ 选择需求]│
│  已恢复上次会话                       │ ← 仅重开已有会话时
├───────────────────────────────────────┤ ┐
│  分析结果                             │ │
│  ☑ 未覆盖：验证码过期场景  → 登录模块 │ │ 列表
│  ☑ 未覆盖：并发支付幂等    → 支付模块 │ │ 内部
│  ☐ 未覆盖：…                          │ │ 滚动
│            （超长时仅列表内部滚动）   │ │
├───────────────────────────────────────┤ ┘
│ ▓▓▓▓░░ 分析中… 12s [模型 ▼] [取消] [开始分析]│ ← 底部操作行·分析中
│         [模型 ▼] [重新分析] [转用例生成（2）]│ ← 完成态（同排替换）
└───────────────────────────────────────┘
```

- **底部操作行** sticky 常驻抽屉底部、位于结果列表下方、不随内容滚动：分析中左侧进度条居最左占满左侧余量并旁显阶段文案与已耗时（「正在连接模型…」→「分析中… Ns」），右侧依次为模型选择器、[取消]、[开始分析]；完成态同排替换为 [重新分析]（链接样式）与 [转用例生成（N）]（主按钮，位于 [重新分析] 右侧），结果列表下方不再放置操作按钮；
- 分析完成后需求输入组（关键词/需求文本/需求池）自动折叠，仅保留 [展开输入 ▾] 开关；手动切换 [展开输入]/[收起输入]，重新分析期间保持当前折叠状态，每次分析完成再次折叠；
- 结果列表超出可视区时仅列表内部滚动，抽屉整体不滚动。

### 1.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 输入需求 | 关键词 / 粘贴文本 / 选取需求（复用选取器） | 三态输入可组合；需求池区与文本输入框形态同「AI 生成用例」（见 `docs/05-interaction-design/01-readme.md` 2.1）；需求池 bar 显示「已选 N 条」并可 [清空]，文本域右下实时显示 `n/20000`；**打开抽屉时自动带入当前文档已关联的需求条目**（同该文档 5.3 文档关联需求条目），可再调整 |
| 开始分析 | 点击 [开始分析] 或 `Ctrl/Cmd + Enter` | 同步长调用（前端超时 70s）：底部操作行持续加载态 + [取消]，旁显阶段文案与已耗时 |
| 选择模型 | 操作行对话模型选择器（`AiModelSelect`，通用规范见 `docs/05-interaction-design/45-ai-infra-ui-overview.md` 2.8） | 作用于本次及后续分析；本地记忆，记忆失效时静默回退系统默认 |
| 取消分析 | 点击 [取消] | 中断请求（abort），恢复输入态 |
| 查看结果 | 分析完成 | 遗漏测试点清单（含建议归属模块），逐条可勾选；输入组同时自动折叠 |
| 折叠输入 | 分析完成自动折叠；点击 [展开输入]/[收起输入] | 仅收纳关键词/需求文本/需求池三组输入，底部操作行与结果保留；重新分析期间保持当前折叠状态 |
| 重新分析 | 完成态点击 [重新分析]（链接样式，底部操作行、[转用例生成] 左侧） | 重新发起分析，回到加载态 + [取消]，完成态操作同排替换 |
| 语义降级 | 结果携带降级标志 | 顶部提示条「当前为关键词匹配结果」（通用规范 2.6） |
| 转用例生成 | 勾选若干条 → 点击 [转用例生成]（底部操作行，位于 [重新分析] 右侧） | 弹出目标文档选择 → 路由跳转至该文档脑图页，勾选内容拼接为需求文本预填「AI 生成用例」抽屉，抽屉打开后 toast「已带入勾选内容（N 条），可直接开始生成」 |
| 点击空白关闭 | 点击抽屉外空白区域或按 Esc | 抽屉自动关闭；**分析中不中断请求（abort）**，请求在后台继续直至完成，结果保留；分析中关闭额外 toast 提示「分析在后台继续，重新打开可查看结果」 |
| 重新打开抽屉 | 关闭后再次点击 [遗漏测试点分析] | 恢复上次会话：输入（关键词/文本/需求条目）、分析结果与勾选态原样呈现，抽屉顶部显示「已恢复上次会话」（重新发起以 [重新分析] 为准）；未执行过分析则为初始空态 |
| 终止分析 | 分析中点击 [取消] | 中断请求（abort），恢复输入态（仅显式 [取消] 才中断） |
| 切换文档 | 用例模块页切换至另一文档 | **中断进行中的分析并重置会话**（输入、结果、勾选态清空） |

- 抽屉以透明遮罩承载，点击抽屉外任意空白处或按 Esc 自动关闭，不压暗画布；打开期间页面被遮罩拦截不可交互，需关闭抽屉后再操作；打开时焦点落在关键词输入，关闭后焦点归还触发按钮，调用进行中头部显示进行中徽标（转圈 +「分析中」）；
- **会话保持**：关闭分析抽屉仅隐藏，不中断进行中的分析请求、不丢弃结果；同一文档内重新打开即恢复上次会话；仅切换文档（docId 变化）或显式 [取消] 才中断并重置（会话绑定文档生命周期）；
- 分析范围限定当前项目；建议不自动创建任何用例，清单可整体忽略。
