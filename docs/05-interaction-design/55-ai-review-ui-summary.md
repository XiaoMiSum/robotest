## 3. AI 生成评审摘要（US-AI-006）

**入口**：评审详情页 [AI 生成摘要]，仅评审发起人可见，且仅评审状态为「已完成」时可点击。

### 3.1 摘要视图布局

摘要视图为右侧滑出抽屉（640px，透明遮罩不压暗画布、点击空白关闭，统一规格见 `docs/05-interaction-design/01-readme.md` 2.9）；操作行位于统计卡片上方（右侧对齐，同各 AI 抽屉）：

```
┌──────────────────────────────────────────────┐
│  ✨ 评审摘要                              ✕  │
├──────────────────────────────────────────────┤
│  [模型: DeepSeek-V3 ▼]  [复制]  [✨ 生成摘要]│  ← 操作行（右侧对齐）
├──────────────────────────────────────────────┤
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐│
│  │通过率  │ │不通过率│ │待评审数│ │问题分布││  ← 统计卡片（系统精确计算）
│  │  86%   │ │  10%   │ │   4    │ │ 图/表  ││
│  └────────┘ └────────┘ └────────┘ └────────┘│
├──────────────────────────────────────────────┤
│  文字总结（流式 Markdown 渲染）              │
│  ## 主要问题归纳                             │
│  1. …▌                                       │
└──────────────────────────────────────────────┘
```

### 3.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 生成摘要 | 点击 [AI 生成摘要] | 统计卡片区**即时渲染**（不依赖 LLM）；文字总结区 SSE 流式渲染 Markdown |
| 切换对话模型 | 标题栏模型选择器（`AiModelSelect`，通用规范见 `docs/05-interaction-design/01-readme.md` 2.8） | 作用于本次及后续生成；选择本地记忆，失效静默回退系统默认；仅一个可用模型时不渲染。评审检查、顺序推荐等其余功能固定用系统默认模型，无选择器 |
| 中途取消 | 流式期间点击 [停止] | 断开 SSE，已渲染文字不保留 |
| 复制 | 点击 [复制] | 完整 Markdown 复制到剪贴板，Toast 成功 |
| 重新生成 | 点击 [重新生成] | 二次确认「将覆盖上一份摘要」→ 重新走流式生成 |
| 再次进入页面 | 已有摘要快照 | 直接读取持久化结果渲染，无需重新生成 |

- 摘要不回写评审记录，不影响快照冻结状态。
