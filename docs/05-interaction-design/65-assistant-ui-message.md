## 4. 消息交互

### 4.1 消息发送与流式回复

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 发送消息 | 输入 + 回车 / [发送] | 用户消息即时上屏；助手回复 SSE 流式逐字渲染 |
| 切换对话模型 | 输入区工具条模型选择器（`AiModelSelect`，通用规范见 `docs/05-interaction-design/01-readme.md` 2.8） | 即时生效于后续消息（历史消息不受影响）；选择本地记忆，失效静默回退系统默认；仅一个可用模型时不渲染 |
| 流式期间 | 回复进行中 | **输入框禁用** + [发送] 变为 [停止] 按钮 |
| 停止回复 | 点击 [停止] | 断开 SSE（服务端联动取消上游），已渲染内容保留为最终消息 |
| 超时提示 | 首帧超 10 秒 | 消息气泡内提示「响应较慢，可停止重试」（通用规范 2.3） |

### 4.2 消息渲染规则

- 助手消息以 Markdown 渲染，**链接白名单过滤**：仅渲染站内相对路径（`/` 开头且匹配已注册路由前缀），外部 URL 一律降级为纯文本；
- 查询结果以列表 / 数字 / 站内链接形式呈现，点击链接跳转对应业务页面；
- 查询不到的数据，助手明确回复「查询不到」，不虚构。

### 4.3 工具过程卡片

助手调用只读工具（查询评审 / 计划 / 缺陷 / 用例）时，消息流内插入过程卡片：

```
┌────────────────────────────┐
│ 🔧 正在查询：我参与的评审   │  ← 执行中：loading 态
│ ✓ 查询完成（5 条结果）      │  ← 完成：结果概要
└────────────────────────────┘
```

- 过程卡片默认折叠为一行，可展开查看调用摘要；用户无权限的数据不返回、不展示。
- 过程卡片视觉规格（底色/圆角/状态图标/徽标）见 9.4。
