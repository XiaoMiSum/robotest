## 1. 项目列表页

**路由**：`/workspace/projects`

页面布局以 `web/demos/workspace/projects.html` 的视觉层次为基准，并采用与“我的空间”一致的卡片网格。使用当前工作空间的真实项目数据；空间无项目时在当前路由内展示引导态，不新增独立 onboarding 或 select 路由。

### 1.1 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 项目列表                                      [新建项目]     │
│ 质量中台空间下的全部项目                                      │
├──────────────────────────────────────────────────────────────┤
│ [活跃（N）] [已归档（N）] [搜索项目名称 / 描述]  按最近更新排序 │
├──────────────────────────────────────────────────────────────┤
│ ┌──────────────────┐ ┌──────────────────┐ ┌──────────────────┐ │
│ │ 电商核心系统      │ │ 开放平台          │ │ 数据服务          │ │
│ │ 描述……            │ │ 描述……            │ │ 描述……            │ │
│ │ 开始 / 结束时间    │ │ 开始 / 结束时间    │ │ 开始 / 结束时间    │ │
│ │ 进入 设为默认      │ │ 进入 编辑          │ │ 进入 归档          │ │
│ └──────────────────┘ └──────────────────┘ └──────────────────┘ │
│ ┌ - - - - - - - - -┐                                         │
│ │        ＋         │                                         │
│ │     新建项目      │                                         │
│ └ - - - - - - - - -┘                                         │
│                         继续向下滚动加载更多                 │
└──────────────────────────────────────────────────────────────┘
```

- 页头展示当前工作空间名称和项目列表说明。
- “新建项目”按钮和卡片网格末尾的创建卡片仅对拥有 `project:create` 权限的用户显示。
- 工具栏提供“活跃”和“已归档”两个状态分段，不提供“全部”分段。
- 搜索同时匹配项目名称和描述；输入采用 300ms 防抖，Enter 立即查询，清空立即查询。
- 列表固定按最近更新时间排序；后端无更新时间时按 ID 稳定排序。
- 卡片网格使用 `repeat(auto-fill, minmax(300px, 1fr))`，窄屏自动减少列数。

### 1.2 分页与滚动加载

- 首次进入默认请求第 1 页，`pageSize=20`。
- 页面滚动到列表底部附近时，通过 `IntersectionObserver` 自动请求下一页并追加到现有卡片列表。
- 追加请求必须避免重复触发；筛选切换、搜索和 CRUD 刷新会取消旧请求的过期响应。
- 追加请求失败时保留已加载卡片，显示错误提示和重试入口。
- 加载完毕后显示“没有更多项目”；仍存在下一页时显示继续滚动提示；不额外展示“共 N 个项目”汇总文案。
- 状态数量由 `GET /api/workspace/projects/counts` 独立返回，应用关键词但忽略当前状态；列表接口继续使用标准 `PageResult<ProjectRespDTO>`。

### 1.3 项目卡片与操作

| 操作 | 触发方式 | 反馈 |
| ---- | -------- | ---- |
| 进入项目 | 点击卡片或“进入” | 设置活跃项目，跳转项目工作台 |
| 设为默认 | 点击“设为默认” | 调用默认项目接口，刷新当前列表并显示默认标识 |
| 编辑 | 管理员或项目创建者点击“编辑” | 打开预填表单，保存后刷新列表和数量 |
| 归档 | 空间管理员点击“归档” | 二次确认；成功后切换为“已归档”，并清除相关个人默认项目 |
| 启封 | 空间管理员点击“启封” | 二次确认；成功后切换为“活跃” |
| 删除 | 空间管理员点击“删除” | 二次确认；成功后从列表移除，并清除相关个人默认项目 |

- 活跃卡片可点击进入；已归档卡片只读，不响应卡片点击，不显示“进入”“设为默认”“编辑”。
- “设为默认”表示设为当前用户的个人默认项目，不表示立即进入项目。
- 只有活跃且尚未设为默认的项目显示“设为默认”。
- 默认项目标识由后端根据 `workspace_user.default_project_id` 计算，前端不自行推断。
- 项目创建者信息缺失时显示“未知创建人”，不得因空对象导致列表渲染失败。

### 1.4 创建与编辑

1. 点击“新建项目”打开表单弹窗。
2. 填写名称、描述、开始时间和结束时间；名称必填且在工作空间内唯一。
3. 点击“确定”后校验并提交，按钮显示 loading 并阻止重复提交。
4. 创建或编辑成功后关闭弹窗，清空并刷新第 1 页列表与状态数量。
5. 失败时保留表单内容并显示后端错误信息。

### 1.5 进入项目与默认项目

```mermaid
sequenceDiagram
  actor U as 用户
  participant P as 项目列表页
  participant A as 项目接口
  participant S as 全局状态
  U->>P: 点击活跃项目卡片
  P->>S: 设置 activeProject
  P-->>U: 跳转项目工作台
  U->>P: 点击“设为默认”
  P->>A: PUT /api/workspace/default-project
  A-->>P: 返回当前空间上下文
  P->>P: 刷新第 1 页列表与状态数量
```

- 设为默认不会改变当前活跃项目，也不会触发页面跳转。
- 归档或删除项目后，后端清除所有空间成员对该项目的默认项目引用，列表刷新后默认标识立即消失。
- 从工作空间列表进入空间时，仍遵循“有默认项目进入工作台、无默认项目进入项目列表”的既有规则。

### 1.6 状态与异常

| 状态 | 页面反馈 |
| ---- | -------- |
| 首次加载 | 卡片骨架，筛选控件禁用 |
| 刷新 | 保留当前卡片并显示刷新反馈，忽略过期响应 |
| 加载更多 | 底部显示加载状态，阻止重复请求 |
| 空间无项目 | 展示创建第一个项目的引导态 |
| 筛选无结果 | 展示未找到匹配的项目，提供清除筛选操作 |
| 列表或数量加载失败 | 显示错误提示并提供重试 |
| 已归档项目 | 只读卡片，不显示进入、设为默认、编辑操作 |
| 归档/启封/删除失败 | 保留原列表并显示后端错误信息 |
| 设为默认失败 | 保留原列表并显示后端错误信息 |

### 1.7 响应式与可访问性

- 卡片网格在中等宽度两列、窄屏单列；卡片内容不因操作按钮数量变化而溢出。
- 活跃卡片支持鼠标点击、Enter 和 Space；操作按钮阻止事件冒泡。
- 状态分段使用 `aria-pressed`，搜索框提供明确标签。
- 状态、默认标记和只读信息同时使用文字表达，不仅依赖颜色。
- 所有可操作元素保留清晰焦点态，动画尊重 `prefers-reduced-motion`。
