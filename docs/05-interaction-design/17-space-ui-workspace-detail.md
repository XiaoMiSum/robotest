## 3. 工作空间详情页

**路由**：`/workspaces/:workspaceId/detail`

通过顶部动态菜单“空间信息”进入。展示当前工作空间基本信息，管理员可编辑。

### 3.1 页面布局

```
┌──────────────────────────────────────────────────┐
│  空间信息                                        │
├──────────────────────────────────────────────────┤
│  ┌─── 基本信息 ──────────────────────────┐       │
│  │  名称: [电商平台测试___]  (管理员可编辑)│       │
│  │  描述: [负责电商相关测试_________]    │       │
│  │  成员数: 15    项目数: 5              │       │
│  │  [保存修改] (仅管理员可见)            │       │
│  └──────────────────────────────────────┘       │
│                                                  │
│  ┌─── 个人设置 ──────────────────────────┐       │
│  │  默认项目: [▼ 核心功能测试]           │       │
│  │  切换空间后自动进入该项目              │       │
│  │  (选择即保存，无需额外确认)            │       │
│  └──────────────────────────────────────┘       │
└──────────────────────────────────────────────────┘
```

### 3.2 交互说明

| 操作     | 触发方式              | 反馈                    |
| ------ | ----------------- | --------------------- |
| 编辑信息   | 管理员修改名称/描述 → [保存] | 校验唯一性 → Toast提示       |
| 设置默认项目 | 下拉选择项目（或选择“无”）    | 自动保存，Toast提示“默认项目已更新” |
