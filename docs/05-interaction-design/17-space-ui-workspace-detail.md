## 1. 空间信息页面

**路由**：`/workspace/:workspaceId`

通过业务端顶部动态菜单[空间信息]进入。页面展示当前活跃工作空间的基础资料与已有统计信息，具备 `ws-info:edit` 权限的用户可编辑名称和描述。

> 视觉布局基准：`web/demos/workspace/info.html`。成员数、项目数卡片可进入对应业务页面，基础信息展示创建人。Demo 中现有接口未提供的编辑模式、放弃修改、用例数、未关闭缺陷及趋势数据均不实现，不使用占位数据。

### 1.1 页面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 空间信息                                                    │
│ 空间基础资料与运行统计                                      │
├──────────────────────────────┬───────────────────────────────┤
│ [成员]                      │ [项目]                         │
│ 24 人                       │ 6 个                           │
├──────────────────────────────┴───────────────────────────────┤
│ 基础信息                                                     │
│ 名称 [质量中台________________]  空间 ID [ws_…____________]  │
│ 描述 [核心业务线质量保障与用例资产沉淀___________________]  │
│ 创建人 张三                    创建时间 2026-09-18 10:24    │
├──────────────────────────────────────────────────────────────┤
│                                      [保存修改]              │
└──────────────────────────────────────────────────────────────┘
```

- 页头标题、说明、间距和字号与演示稿一致。
- 成员、项目采用 KPI 卡片；数据分别来自 `memberCount`、`projectCount`。
- 成员卡片跳转到 `/workspace/members`，项目卡片跳转到 `/workspace/projects`。
- 卡片使用语义化链接，支持鼠标、键盘、悬停和焦点反馈。
- 基础信息使用单张全宽卡片；名称与空间 ID 桌面端双列、窄屏单列。
- 空间 ID 只读并使用等宽字体；描述使用多行输入框。
- 创建人优先显示用户姓名，姓名为空时回退用户名；历史数据无创建人时显示 `—`。
- 创建时间沿用统一时间格式化工具展示。
- 保留现有[保存修改]按钮及其权限、校验和反馈逻辑。

### 1.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 查看成员 | 点击[成员]卡片 | 跳转至当前活跃空间的成员管理页 |
| 查看项目 | 点击[项目]卡片 | 跳转至当前活跃空间的项目列表页 |
| 编辑信息 | 具备 `ws-info:edit` 权限的用户修改名称或描述 | 输入项可编辑；无权限时保持禁用 |
| 保存 | 点击[保存修改] | 执行现有表单校验与保存接口，成功/失败沿用 Toast 反馈 |
| 加载 | 进入页面 | 保留现有加载遮罩 |
| 加载失败 | 空间信息请求失败 | 保留现有错误提示 |

### 1.3 视觉与状态要求

- 使用全局设计变量中的中性色、品牌色、阴影、圆角和间距，不硬编码主题色。
- KPI 卡片与基础信息卡均使用 1px Neutral-200 描边、低对比阴影和 8px 圆角。
- 可点击 KPI 卡片悬停时仅提升阴影，焦点态必须清晰可见，不造成布局位移。
- 页面标题 20px/650，说明文字 13px；KPI 数值使用 30px/650 和等宽数字。
- 输入框、按钮、禁用态沿用 Element Plus 现有行为，仅调整信息层级和布局。
- 窄屏下 KPI 卡片、创建信息与表单双列区域降为单列，操作按钮允许换行。
- 尊重 `prefers-reduced-motion`，不在本页引入 JavaScript 滚动控制。

### 1.4 功能边界

- 空间上下文接口增加只读字段 `createdByName`，不新增独立创建人查询接口。
- 不新增“编辑模式”状态及“放弃修改”操作。
- 不新增用例数、缺陷数或趋势统计。
- 不修改工作空间上下文初始化、编辑权限、表单规则或保存流程。
- 卡片跳转不携带工作空间 ID；继续使用当前活跃空间及 `X-Active-Workspace` 请求头。
- 不修改数据库结构。
