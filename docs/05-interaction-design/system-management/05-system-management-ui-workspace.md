## 1. 工作空间管理

### 1.1 工作空间列表页

**路由**：`/admin/workspaces`

#### 1.1.1 页面布局

> 布局基准：`web/demos/admin/workspaces.html`。已按确认口径调整：segment 显示「活跃 / 归档」（后端状态值仍为 `dissolved`，仅前端展示称归档）；无按状态计数接口故不显示计数；归档与重新启用操作均在详情页完成；操作列保持[查看详情]；按要求保留[查询][重置]。

```
┌───────────────────────────────────────────────────┐
│ 空间管理                                          │
│ 平台内全部工作空间及其规模                [新建空间]  │

│ 空间名称 │ 描述   │ 状态  │ 成员 │ 项目 │ 创建时间 │ 操作 │
```

#### 1.1.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ----------- | ------------- |
| 状态筛选 | 点击 segment「活跃 / 归档」 | 立即按所选状态查询（默认「活跃」） |
| 搜索 | 输入名称 + 回车或点击[查询] | 表格刷新（keyword 仅匹配空间名称） |
| 重置 | 点击[重置] | 清空关键词、回到「活跃」segment 并刷新 |
| 新建 | 点击页头[新建空间] | 弹出创建弹窗（名称+描述） |
| 查看详情 | 点击名称链接、行内任意位置或[查看详情] | 跳转至详情页 |
| 创建时间列 | — | 以 `formatDateTime` 展示至分钟 |

**路由**：`/admin/workspaces/:id`

#### 1.2.1 页面布局

> 布局基准：`web/demos/admin/workspace-detail.html`。已按确认口径裁剪：不实现成员/项目/用例/未关闭缺陷 4 张 KPI 卡片与页头[编辑信息]按钮；归档入口移至页头，无独立危险操作卡；创建人保持可移除（后端仅拦「唯一管理员」），不显示「不可移除」。

#### 1.2.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---------------- | ------------------------------------ |
| 编辑信息 | 修改空间名称/描述 → 点击[保存修改] | 校验 → 成功提示；[重置]回填最近一次加载值 |
| 创建人 | — | 只读展示，历史数据无创建人显示 — |
| 添加成员 | 点击[添加用户] | 弹窗：搜索用户 + 为每人选择角色 + 确认 |
| 更新角色 | 点击[改角色] → 行内切换下拉选择 | 选择即提交；失败还原并提示 |
| 移除成员 | 点击[移除] | 二次确认；移除唯一管理员由后端阻止并提示 |
| 归档空间 | 点击页头[归档空间] | 输入空间名确认 → 状态转为归档（不校验项目/成员，成员保留）→ 跳转列表 |
| 归档态 | — | 详情页只读：隐藏[归档空间][重置][保存修改][添加用户]与操作列（改角色/移除），输入禁用；页头显示[重新启用]；后端同步拒绝更新与成员维护 |
| 重新启用 | 点击页头[重新启用] | 归档空间恢复为活跃（成员原样保留），刷新状态与操作入口 |
