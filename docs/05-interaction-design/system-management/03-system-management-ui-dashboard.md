### 3.2 KPI 卡片（4 张）

| 卡片 | 主值 | 单位 | 脚注文案（模板） |
| ---- | ---- | ---- | ------------ |
| 用户总数 | 用户总数 | 人 | `较上周 +{近7日新增用户} · 启用 {启用数}` |
| 工作空间 | 工作空间 | 个 | `活跃 {活跃数} · 已解散 {已解散数}` |
| 项目总数 | 项目总数 | 个 | `近 7 日新增 +{近7日新增项目}` |
| 今日活跃 | 今日登录人次 | 人次 | 无脚注（示例「接口调用 · 失败」按需求裁剪） |

**交互与文案规则**：

1. KPI 卡片为**纯展示**，不可点击、无跳转（新版取消旧版统计卡的点击跳转，示例未提供入口）。
2. 正增量以绿色上标呈现（示例 `kpi__delta--up`）；增量为 0 时显示 `+0` 且用中性灰。
3. 统计口径（含「今日活跃」的定义）见 `docs/04-detailed-design/01-readme.md` §3.2。
4. 工作空间脚注中，示例文案「已归档」适配为本页实际文案**「已解散」**（状态机为 active/dissolved；空间管理列表页对同一状态值展示为「归档」，两页为既有展示用词差异，均以实际实现为准）。

### 3.3 近 14 日活跃用户（面积折线图，占 2 列）

- 纯 SVG 实现（不引入图表库），高度 210，含 4 条水平网格线（基线 1 条加深、3 条浅色）。
- 数据：连续 14 个自然日（含当日），按日**去重**登录用户数；折线 + 半透明面积填充，末点高亮圆点并标注数值。
- 图例：「活跃用户」（单序列）。
- X 轴标签：首日、中间日、末日三个日期，格式 `MM-dd`。
- 空数据：14 个 0，折线贴基线，末点标注 `0`。

### 3.4 用户状态分布（环图）

- 三段环（环宽 14，半径 46），颜色与文案：

  | 状态 | 颜色 | 图例文案 |
  | ---- | ---- | ---- |
  | 启用 | `#67c23a`（成功绿） | `启用 {n}` |
  | 停用 | `#909399`（信息灰） | `停用 {n}` |
  | 锁定 | `#f56c6c`（危险红） | `锁定 {n}` |

- 环心：用户总数 + 「全部用户」。
- 用词约定：环图按示例使用「**停用**」；用户管理列表沿用既有「**禁用**」，二者为同一状态值 `disabled`。
- 空数据：灰底环 + 环心 `0`，图例各项为 0。

### 3.5 最近创建的空间（表格卡片）

- 卡片头：标题「最近创建的空间」+ 右侧链接「查看全部 →」→ `/admin/workspaces`。
- 列：空间名称 / 创建人 / 成员 / 项目 / 状态 / 创建时间。
  - 创建人：空间创建者姓名；历史数据无创建人时显示 `—`。
  - 状态：`活跃`（success 绿点）/ `已解散`（neutral 灰点），本页沿用「已解散」文案（空间管理列表页展示为「归档」，同为状态值 `dissolved`）。
  - 时间：`formatDateTime` 本地时区格式 `YYYY-MM-DD HH:mm`。
- 数据：复用空间列表接口，创建时间倒序，**每页 8 条**；页脚「共 {总数} 个空间」+ 页码按钮（总数 ≤ 每页条数时仅显示总数）。
- 行不可点击（示例未提供行内链接）；仅「查看全部」跳转。

### 3.6 页面头操作

| 操作 | 触发 | 行为 |
| ---- | ---- | ---- |
| 刷新 | 点击「刷新」按钮 | 重新拉取统计接口与空间表格第 1 页，按钮与页面进入 loading |
| 导出报表 | — | **不实现**（示例按钮按需求裁剪） |

### 3.7 状态分支

| 状态 | 表现 |
| ---- | ---- |
| 加载中 | 页面 `v-loading` 遮罩；数值与图表在数据到达前不渲染（初始 0 / 空态） |
| 正常 | 按 3.2–3.5 渲染；副标题展示「数据截至 {generatedAt}」 |
| 接口失败 | 顶部 Toast 报错（如「加载数据概览失败」）；已成功的区块保留展示，未加载区块维持空态 |
| 空数据 | KPI 显示 0；折线图贴基线、环图灰底 0；表格显示空态「暂无工作空间」 |
| 权限 | 菜单项对所有可进入 `/admin` 的用户可见（数据概览不设独立权限点）；路由守卫沿用既有 `requiresAdmin` |
| 未登录 | 沿用全局路由守卫跳转 `/login` |

### 3.8 状态管理

- 页面本地状态（ref），不入 Pinia；进入页面（`onMounted`）自动加载。
- 切换菜单后再次进入页面重新加载，不做跨页缓存。
