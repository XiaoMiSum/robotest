## 1. 角色与权限管理

**路由**：`/admin/roles`

### 1.1 整体布局

页面采用左右分栏结构：

- **左侧**：角色类型树，宽度约260px，可调整。
- **右侧**：选中角色的详情面板，包含“权限配置”和“关联用户”两个Tab页。

```
┌──────────────────────────────────────────────────┐
│  角色管理                                        │
├─────────────┬────────────────────────────────────┤
│ 角色树      │  角色详情（tabs）                   │
│             │  [权限配置] [关联用户]              │
│ 📁 系统角色 │  ┌───────────────────────────┐     │
│  ├ 系统管理员│  │ 操作对象 │ 权限点(复选框) │     │
│  ├ 用户管理 │  │ 用户管理 │ ☑查看 ☑创建   │     │
│  └ 空间查看 │  │          │ ☐编辑 ☐禁用   │     │
│             │  │ 工作空间 │ ☑查看 ☐创建   │     │
│ [+添加]    │  │ ...     │ ...           │     │
│             │  └───────────────────────────┘     │
│             │  [撤销修改] [保存权限]             │
└─────────────┴────────────────────────────────────┘
```

### 1.2 左侧角色树交互

#### 1.2.1 树节点结构

- 根节点按角色类型分组（如“系统角色”），类型节点不可编辑、不可删除。
- 根节点下挂载具体角色节点，显示角色名称，支持内联操作。

#### 1.2.2 添加角色

- 点击根节点（如“系统角色”）右侧的 **[+]** 按钮，在对应类型下新增一个可编辑节点。
- 新增节点默认名称为空，输入框自动聚焦，用户输入角色名称。
- 输入框失去焦点后，前端校验名称是否为空及唯一性，校验通过则调用创建角色接口，提交 `name` 和 `type='system'`，`permissions` 初始为空数组。
- 创建成功后节点保留在树中，选中新节点可继续编辑权限。

#### 1.2.3 编辑角色名称

- 双击树节点，节点名称变为可编辑输入框。
- 修改文本后，输入框失去焦点，自动调用更新角色接口，提交新名称。
- 若名称校验失败（重复或为空），输入框重新聚焦并提示错误。

#### 1.2.4 删除角色

- 右键点击角色节点或选中后点击树工具栏的删除按钮，弹出二次确认。
- 系统预置角色（isSystem=true）不可删除，隐藏删除入口。
- 若角色被用户引用，弹出提示列出引用用户，阻止删除。
- 删除成功后，右侧清空详情，树节点移除。

#### 1.2.5 选择角色

- **单击**树节点，右侧加载该角色的详情面板，默认显示“权限配置”Tab。

### 1.3 右侧角色详情面板

#### 1.3.1 权限配置Tab

- 以**表格**形式展示权限点，表格包含三列：
  - **一级模块**：权限点所属的功能域，例如“用户管理”“工作空间管理”等。
  - **二级模块**：一级模块下的具体功能模块。
  - **权限点**：该模块下所有的具体权限点，每个权限点名称后带有一个复选框。复选框勾选表示拥有该权限。
- 权限表格根据角色类型（system/workspace）过滤对应作用域（global/workspace）的权限点。
- **全量权限角色**（full_access=true）：权限配置面板锁定，所有复选框禁用，显示"该角色拥有全量权限"提示，[保存权限]按钮禁用。
- **非全量权限角色**：用户可正常勾选/取消复选框。
- 表格示例如下：

| 操作对象   | 权限点                                                |
| ------ | -------------------------------------------------- |
| 用户管理   | ☑ 查看用户   ☑ 创建用户   ☐ 编辑用户   ☐ 禁用/启用用户   ☐ 重置密码      |
| 工作空间管理 | ☑ 查看工作空间   ☐ 创建工作空间   ☐ 编辑工作空间   ☐ 解散工作空间   ☐ 管理成员 |
| 角色管理   | ☑ 查看角色   ☐ 创建角色   ☐ 编辑角色   ☐ 删除角色                  |

- **勾选规则**：
  - 每个权限点独立控制，点击复选框即可切换选中/取消状态。
  - 系统预置角色（如“系统管理员”）的已有权限对应的复选框为禁用状态（灰显，不可取消勾选），以保持核心权限不被误移除。新增的权限点可正常勾选。
- **撤销修改**：在未点击“保存权限”按钮前，可点击[撤销修改]按钮，将权限配置恢复到上次保存时的状态。本次所有未保存的修改会被丢弃。
- **保存权限**：点击[保存权限]按钮，收集所有选中的权限点code，调用更新角色接口。保存成功后Toast提示“权限已保存”，并更新权限快照。
- 权限表格与关联用户表格保持相同样式；表头固定，权限点较多时仅表格内容区内部滚动，外层不显示纵向滚动条。

#### 1.3.2 关联用户Tab

- 展示拥有当前角色的用户列表：系统角色显示用户名、姓名、邮箱、状态、授权时间、操作；工作空间角色显示用户名、姓名、归属空间、授权时间、操作。
- 两类关联用户均采用服务端分页，默认每页 20 条，支持切换 20 / 50 / 100 条；分页条固定在表格底部，切换角色时回到第 1 页。
- 表格样式与权限点表格一致：表头固定、内容区内部滚动，不出现外层纵向滚动条。
- 授权时间：系统角色取角色与用户的关联更新时间；工作空间角色存在多个归属空间时取最近一次关联更新时间。
- **添加用户**：点击[添加用户]按钮，弹出多选搜索弹窗，可搜索平台用户（仅显示启用状态的用户），选择后批量插入 `user_role` 关联。
- **移除用户**：每行用户有[移除]按钮，点击后二次确认，解除该用户与当前角色的关联。
- 操作完成后列表自动刷新。

### 1.4 页面级滚动与布局验收

本页采用“左右分栏 + 右侧标签页 + 表格内部滚动”的布局。通用规则遵循 `docs/00-spec/13-scroll-container.md` 的 UI-SC-01～UI-SC-09，本节只定义角色管理页的页面行为。

```text
AdminLayout 内容区
└── RolePage（桌面端固定高度）
    ├── RoleTreePanel
    │   └── 角色树：原生 overflow-y: auto，隐藏纵向滚动条
    └── RoleDetail
        ├── 权限点 Tab
        │   └── PermissionTable：el-table 内部滚动，隐藏纵向滚动条
        └── 关联用户 Tab
            └── RoleUsersTable：el-table 内部滚动，分页固定底部
```

页面级要求：

1. `RolePage` 建立完整高度链路并保持左右栏等高，不新增外层纵向滚动。
2. `RoleTreePanel` 只负责角色树区域的原生纵向滚动；桌面端可隐藏视觉滚动条，但保留滚轮、触摸和键盘滚动能力。
3. `PermissionTable`、`RoleUsersTable` 保留 `el-table` 固定表头和内部滚动，不在外层增加第二层滚动。
4. 关联用户分页条固定在表格底部；切换角色或分页筛选后回到第 1 页。
5. 桌面端隐藏纵向滚动条；响应式布局高度变化时恢复页面级滚动。
6. 横向滚动条默认保留，窄屏下仍可访问全部表格列。
7. 角色树和表格区域提供可见焦点、边界或悬停反馈，不能仅依赖隐藏的滚动条提示内容剩余。
