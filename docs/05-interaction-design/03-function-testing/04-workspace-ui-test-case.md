### 1.2 交互说明

**顶部工具条**：单行排布、不换行，左对齐，常驻于脑图编辑区上方，不随画布滚动；功能组之间以竖分隔线分隔（撤销/重做｜节点操作：下级、同级、编辑、删除｜排版模板与恢复排版｜节点类型与清除标记｜优先级：P0–P3），命令组（[🔗 关联需求]——纯图标按钮）经弹性占位居于行末右侧，与核心组始终同一行；按钮总量超出容器宽度时工具条自身横向滚动（细滚动条）。排版模板入口只显示图标与下拉箭头，不回显布局名称文本，当前模板由悬浮提示给出；**工具条所有按钮一律带悬浮提示**：图标型给出功能名与快捷键，纯图标入口以悬浮提示替代文字（「关联需求」），文字型按钮（类型标记、P0–P3）给出操作语义，删除按钮悬浮提示转为警示色。

**模块树交互**：展开/折叠点击箭头；选中文档点击节点加载脑图；新建右键或[+新建]输入名称；重命名双击或右键；拖拽移动节点；删除右键或Delete键二次确认。

**脑图编辑器**：添加子节点Tab；添加兄弟节点Enter；编辑文本双击；移动拖拽；删除Delete；标记用例/优先级顶部工具条或右键菜单；缩放Ctrl+=/-/0或工具栏按钮；抓手模式工具栏切换或按H键。

**关联需求**：需求条目统一经「选择需求」选取器弹窗维护（关键字过滤、多选、已选计数），工具条 [关联需求] 复用同一选取器维护文档关联，选取器行内 [明细] 就近冒泡展示条目 Markdown 正文（仅正文，不联动勾选）。

**脑图组件详细设计**参见《脑图组件实现设计文档》。
