## 1. 测试计划子模块

选中“测试计划”菜单后，右侧展示计划列表或计划详情。

### 1.1 计划列表页

> 视觉与结构对齐验收基准 `web/demos/project/plans.html`（页头 + 单卡片：toolbar / 表格 / 分页一体）。基准裁剪与保留口径见本节末尾。

```
┌──────────────────────────────────────────────────────────────────┐
│  测试计划                                        [+ 新建计划]     │
│  计划维度组织用例执行与通过率统计                                  │
├──────────────────────────────────────────────────────────────────┤
│  [🔍 计划名称…] [状态: 全部 ▼] [查询] [重置]      共 18 个计划     │
├──────────────────────────────────────────────────────────────────┤
│  名称（含关联用例副行）│负责人│起止时间 │环境     │状态  │进度│通过率│操作│
│  V1.4.2 回归测试      │张明 │09-20 ~ 09-24│staging│●执行中│[58%]│94.6%│…│
│    └ 关联用例 47 条                                               │
│  支付网关专项         │李华 │09-19 ~ 09-23│staging│●已阻塞│[31%]│87.2%│…│
│  营销活动冒烟         │王芳 │09-22 09:00  │production│●未开始│[0%]│  — │…│
│  履约链路回归         │周敏 │09-10 ~ 09-16│staging│●已完成│[100%]│96.5%│…│
├──────────────────────────────────────────────────────────────────┤
│  共 18 个计划 · 每页 20 条                          ‹  1  2  3  › │
└──────────────────────────────────────────────────────────────────┘
```

- **页头**：标题「测试计划」+ 描述「计划维度组织用例执行与通过率统计」，右侧动作区 [+ 新建计划]（原工具栏创建入口上移至页头）；点击弹出创建表单：名称、负责人、起止时间、执行环境、关联用例，提交后跳转至计划详情页。
- **状态文案**（列表、详情页与工作台共用一份口径）：未开始（new）/ 执行中（in_progress）/ 已完成（completed）/ 已阻塞（blocked）/ 已关闭（closed）。
- **状态列**：圆点 + 文案——未开始中性、执行中橙、已完成绿、已阻塞红、已关闭中性。
- **名称列**：主行为计划名称（点击进详情），副行展示「关联用例 N 条」；**环境**列以 chip 展示，无环境显示 `-`。
- **起止时间**：双值 `MM-DD ~ MM-DD`，单值 `MM-DD HH:mm`，均无则 `-`。
- **进度列**：百分比，按状态配色（执行中橙、已阻塞红，其余默认）。
- **通过率列**：未开始显示 `—`，已完成绿色加粗，其余常规显示。
- **操作列**（保留现有能力）：[进入执行]/[查看详情]（执行中为「进入执行」）、[完成]（未开始/执行中可见，确认后直接完成，不校验未执行用例）、[恢复]（仅已阻塞，确认后回到执行中）、[删除]（二次确认，仅负责人，后端校验）。
- **计数与分页**：工具栏右侧「共 N 个计划」，分页左侧「共 N 个计划 · 每页 20 条」。

**基准裁剪与保留口径**：

| 基准内容 | 处理 | 原因 |
| ---- | ---- | ---- |
| 环境筛选下拉（全部环境/staging/production） | 不引入 | 计划列表接口无环境过滤参数，本次不扩展查询参数；环境列仅展示 |
| 搜索占位「计划名称 / 负责人」 | 取「计划名称」 | 关键字仅按名称模糊匹配，避免误导 |
| 操作列 [详情] [执行] [报告] | 映射为现有操作 | [详情]/[执行] 即 [查看详情]/[进入执行]；[报告] 不引入（无独立计划报告页） |
| 状态下拉「已阻塞」 | 引入 | 本次新增 blocked 状态与 [恢复]（见 1.2），其余四态沿用 |
| [查询] [重置] | 保留 | 现有查询能力，基准未画 |

### 1.2 计划详情页

```
┌──────────────────────────────────────────────────┐
│ 测试计划 › 功能测试计划                             │
│ 功能测试计划 [执行中] [━进度━] 通过n 失败n 阻塞n 待执行n │
│          [调整用例][同步用例][完成执行][阻塞]          │
├──────────┬───────────────────────────────────────┤
│ 快照文档树│   快照脑图                              │
│ (多文档   │   节点右侧徽标回显执行结果：             │
│  点击切换) │   ✓通过 ✕失败 ⚠阻塞（待执行不显示）    │
└──────────┴───────────────────────────────────────┘
```

**详情页交互**（与评审详情页保持一致）：

- 标题行单行承载：名称 + 状态标签 + 进度与分色统计 + 操作按钮（未开始/执行中：调整用例/同步用例/完成执行/阻塞；已阻塞：恢复）；标记成功后进度实时刷新。
- 不再提供单独的“开始执行”操作：未开始计划首次标记执行结果后自动转入执行中；[完成执行]二次确认后状态置已完成，不可再标记执行结果。
- 左侧快照文档树点击切换多文档；[调整用例]在计划未结束（未开始/执行中）时可用，回显当前规划并差量更新快照。
- **阻塞与恢复**（均仅负责人，二次确认后执行）：[阻塞] 将未开始/执行中的计划置为已阻塞，期间不可标记执行结果、调整用例、同步或完成；[恢复] 将已阻塞计划置回执行中，恢复后能力与执行中一致。
- 执行标记四态：通过/失败/阻塞/待执行（重置），结果以彩色徽标回显在节点右侧。
- 点面包屑「测试计划」回到功能测试页并自动激活“测试计划”子模块（`?tab=plans`）。

**移除已选用例**（计划未结束时可用）：

- **入口**（两处）：
  1. **标记结果组件（脑图工具栏）**：[移除用例] 按钮，位于执行结果按钮组右侧；
  2. **右键菜单**：选中用例节点右键，「从计划中移除」菜单项。
- **触发条件**：
  - 仅当选中节点为 `case` 类型时可用；
  - 计划状态为「已完成/已关闭/已阻塞」时入口隐藏，与 [调整用例] 权限一致；后端强校验兜底。
- **交互流程**：
  1. 脑图中选中一个已关联的用例节点；
  2. 点击工具栏 [移除用例] 或右键菜单「从计划中移除」；
  3. 二次确认弹窗「确定从该计划中移除用例『用例标题』吗？移除后该用例及其执行结果将不再展示，历史执行记录保留作审计。」；
  4. 确认后调用规划用例更新接口（全量覆盖式）：从当前规划中剔除该用例，若所属文档无剩余用例则整文档移除；
  5. 成功 Toast「已移除用例」→ 脑图重载、进度条与统计实时刷新；
  6. 取消或失败：关闭弹窗 / 错误 Toast，界面不变。
- **边界与约束**：
  - 移除仅删除快照节点，执行记录保留作审计（与调整用例行为一致）；
  - 移除后快照树同步重载：若整文档被移除，左侧文档树对应条目消失，当前选中文档回退到首个文档；
  - 移除后计划快照视为已变更，执行顺序推荐结果失效（stale 提示规则沿用既有同步机制）。

详情页复用脑图组件（`mode='plan'`），工具栏切换为执行操作按钮。
