## 1. 测试评审子模块

选中“测试评审”菜单后，右侧展示评审列表或评审详情。

### 1.1 评审列表页

> 视觉与结构对齐验收基准 `web/demos/project/reviews.html`（页头 + 单卡片：toolbar / 表格 / 分页一体）。基准裁剪与保留口径：基准无 [查询][重置]、无 [删除]，两者为现状能力故保留（删除入口仅存在于列表）；基准无 [完成]，完成评审统一由详情页承载；基准的「驳回」入口不存在，新增至详情页页头（见 1.2）。

```
┌────────────────────────────────────────────────────────────────┐
│  测试评审                                        [+ 发起评审]   │
│  用例评审与评审结论跟踪                                          │
├────────────────────────────────────────────────────────────────┤
│ [搜索标题][状态: 全部/待评审/进行中/已通过/已驳回 ▼][查询][重置] 共 N 场评审 │
│ 标题(副行:关联用例 N 条)│发起人│状态│进度│通过率│参与者│创建时间│操作 │
│ 下单模块用例评审        │ 张明 │●进行中│[━━] 18/30│40% │头像堆│…│[进入]│
│ 履约配送用例评审        │ 周敏 │●已驳回│[━━] 35/35│62.9%│头像堆│…│[查看][重新发起]│
└────────────────────────────────────────────────────────────────┘
```

**状态展示映射**（接口状态值 → 展示文案，点标圆点配色随文案；列表与详情页共用）：

| 状态值 | 展示文案 | 点标 |
| --- | --- | --- |
| `new` | 待评审 | 中性灰 |
| `in_progress` | 进行中 | 橙色（含光晕） |
| `completed` | 已通过 | 绿色 |
| `rejected` | 已驳回 | 红色 |

> 详情页基准 `web/demos/project/review-detail.html` 中该状态写作「评审中」，与列表基准文案冲突，统一取列表基准「进行中」；需求文档中的「评审已完成（completed）」表述对应展示文案「已通过」。

查询区：标题关键字输入框（回车即查）+ 状态下拉（全部/待评审/进行中/已通过/已驳回）+ [查询]/[重置]按钮，重置清空条件并回到首页；工具栏右侧计数「共 N 场评审」，分页区左侧「共 N 场 · 每页 20 条」。

列表列与口径：

- **标题**：主行标题 + 副行「关联用例 N 条」（`totalAssociated`），点击进入详情；
- **进度**：进度条 + `已评审/关联总数`（`reviewed`/`totalAssociated`）；进行中橙色、已驳回红色、其余默认色；
- **通过率**：待评审显示 `—`；进行中常规展示、已通过绿色加粗、已驳回红色；
- **参与者**：头像堆（最多展示 3 个 + 「+N」），取头像图或姓名首字，发起人在列内时用品牌色；无参与者显示 `—`；
- **操作**：[进入]（`new`/`in_progress`）、[查看]（`completed`/`rejected`）、[重新发起]（仅 `rejected`，二次确认后回到 `in_progress`）、[删除]（保留项，二次确认，仅发起人，后端校验）。

点击[发起评审]弹出创建表单：标题、描述、参与者（多选成员）、关联用例（打开CaseSelector弹窗）。提交后跳转至评审详情页，新建评审默认待评审状态，首次标记后自动转入进行中。

### 1.2 评审详情页

```
┌──────────────────────────────────────────────────┐
│ ← 返回 登录模块评审 [进行中]  [━进度━] 通过n 不通过n 待评审n │
│            [调整用例][同步用例][驳回][完成评审]        │
├──────────┬───────────────────────────────────────┤
│ 快照文档树│   快照脑图 (只读)                      │
│ (多文档   │   节点右侧徽标回显评审标记 ✓通过/✕不通过 │
│  点击切换) │   工具栏：通过/不通过/待评审/评论          │
└──────────┴───────────────────────────────────────┘
```

**详情页交互**：

- 标题行单行承载全部信息：标题 + 状态标签（按 1.1 状态展示映射：待评审/进行中/已通过/已驳回）；右侧为进度条与分色统计（通过绿/不通过红/待评审橙）及操作按钮（带图标；主操作实心、次要操作 plain）；标记成功后进度实时刷新。
- 左侧为快照文档树（目录/文档层级），点击文档切换右侧对应文档的快照脑图，支持多文档评审；默认选中首个文档。
- [调整用例]（评审未完成可用）：打开 CaseSelector 弹窗并回显当前规划的用例，确认后差量更新快照（可增删文档与用例）。
- [同步用例]：同步成功后自动重载快照树与脑图。
- [完成评审]：仅当待评审与不通过均为 0（全部通过）时可用，否则置灰并 tooltip 提示；确认后状态变更为已通过（`completed`）。
- [驳回]（新增，仅 `new`/`in_progress` 可见，仅发起人，后端强校验）：二次确认后状态变更为已驳回（`rejected`），快照冻结、标记/调整/同步入口收起。
- [重新发起]（仅 `rejected` 可见，仅发起人）：二次确认后状态回到进行中（`in_progress`），既有标记与评论保留，参与者可继续评审；再次完成仍需全部通过。
- 评审标记三态：通过/不通过/待评审（重置），结果以彩色徽标回显在节点右侧；选中节点点[评论]打开“评审记录”抽屉（头像气泡列表 + 底部固定输入区，Enter 发送）。
- 点[← 返回]回到功能测试页并自动激活“测试评审”子模块（`?tab=reviews`）。

**移除已选用例**（评审未完成时可用）：

- **入口**（两处）：
  1. **标记结果组件（脑图工具栏）**：[移除用例] 按钮，位于 [评论] 按钮右侧；
  2. **右键菜单**：选中用例节点右键，「从评审中移除」菜单项，位于「添加评论」下方，以分隔线隔开。
- **触发条件**：
  - 仅当选中节点为 `case` 类型时可用（步骤/前置条件/文档/目录节点不可移除，入口置灰或提示）；
  - 评审进入终态（`completed` 已通过 / `rejected` 已驳回）时入口隐藏，与 [调整用例] 权限一致；后端强校验兜底（终态抛业务异常）。
- **交互流程**：
  1. 脑图中选中一个已关联的用例节点；
  2. 点击工具栏 [移除用例] 或右键菜单「从评审中移除」；
  3. 二次确认弹窗「确定从该评审中移除用例『用例标题』吗？移除后该用例及其评审标记将不再展示，历史标记记录保留作审计。」；
  4. 确认后调用规划用例更新接口（全量覆盖式）：从当前规划中剔除该用例，若所属文档无剩余用例则整文档移除；
  5. 成功 Toast「已移除用例」→ 脑图重载（该文档快照刷新）、进度条与统计实时刷新；
  6. 取消或失败：关闭弹窗 / 错误 Toast，界面不变。
- **边界与约束**：
  - 移除仅删除快照节点，评审标记/评论记录保留作审计（与调整用例行为一致）；
  - 移除后快照树同步重载：若整文档被移除，左侧文档树对应条目消失，当前选中文档回退到首个文档；
  - 移除入口的可用状态（是否选中 case 节点）由脑图选中态实时驱动，无选中或选中非 case 节点时置灰。

详情页复用脑图组件（`mode='review'`），工具栏切换为评审操作按钮。
