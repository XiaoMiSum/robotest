## 1. 项目工作台

**路由**：`/workspace/projects/dashboard`

### 1.1 页面布局

页面沿用现有统计卡片和最近评审/计划区域，增加页头、快捷入口和最近动态区域；不增加导出、发起执行或未明确的图表功能。

```text
┌──────────────────────────────────────────────────────────────┐
│ 项目工作台                                                    │
│ 电商核心系统 · 活跃 · 2026-06-01 ~ 2026-12-31               │
├──────────────────────────────┬───────────────────────────────┤
│ 快捷入口                     │ 项目统计                      │
│ ┌──────────┐ ┌──────────┐     │ ┌──────────┐ ┌──────────┐     │
│ │ 编写用例 │ │ 新建计划 │     │ │ 用例总数 │ │ 进行评审 │     │
│ └──────────┘ └──────────┘     │ └──────────┘ └──────────┘     │
│ ┌──────────┐ ┌──────────┐     │ ┌──────────┐ ┌──────────┐     │
│ │ 提交缺陷 │ │ 接口调试 │     │ │ 进行计划 │ │ 未关闭数 │     │
│ └──────────┘ └──────────┘     │ └──────────┘ └──────────┘     │
├──────────────────────────────┴───────────────────────────────┤
│ 最近动态                                                    │
└──────────────────────────────────────────────────────────────┘
```

- 页头展示当前项目名称、状态和起止时间；时间使用统一格式化工具，空时间显示 `-`。
- 快捷入口仅跳转到已有页面：编写测试用例、新建测试计划、提交缺陷、接口调试。
- 最近动态来自后端 `recentActivities`，按时间倒序展示；不在前端拼接业务数据。
- 原有统计卡片、最近评审和最近计划继续保留。
- “进行中评审”和“进行中计划”统计卡片与“用例总数”进入同一个功能测试页面，分别使用 `?tab=reviews` 和 `?tab=plans` 激活对应子模块。
- 快捷入口和项目统计分别置于左右两个等宽父卡片中，两个父卡片及其内部卡片保持宽高一致；小屏幕下改为上下排列。

### 1.2 快捷入口

| 入口 | 目标路由 | 说明 |
| ---- | -------- | ---- |
| 编写测试用例 | `/workspace/projects/functional-testing` | 进入脑图/表格用例模块 |
| 新建测试计划 | `/workspace/projects/functional-testing?tab=plans` | 进入功能测试页面的测试计划模块 |
| 提交缺陷 | `/workspace/projects/bugs/create` | 进入缺陷创建页 |
| 接口调试 | `/workspace/projects/api-testing` | 进入接口测试模块 |

快捷入口不创建数据、不增加新的接口；权限和路由校验沿用现有项目上下文及路由守卫。

### 1.3 最近动态

- 动态类型来自项目语义事件表，包含项目、用例、评审、计划、缺陷等关键操作。
- 每条动态展示操作摘要、操作人、类型和时间；可跳转时跳转已有详情页。
- 自动保存、轮询、读取、排序和筛选不产生动态。
- 动态为空时显示空态，不影响统计卡片和快捷入口使用。

### 1.4 交互说明

1. 进入项目时调用 `GET /api/project/dashboard`，同时加载页头、统计数据和最近动态。
2. 统计卡片、快捷入口和最近动态分别跳转到已有页面；评审/计划统计卡片和测试计划快捷入口统一进入功能测试页面并激活对应子模块。
3. 动态记录由后端业务服务在操作成功后写入，前端不负责推断或拼接动态。
