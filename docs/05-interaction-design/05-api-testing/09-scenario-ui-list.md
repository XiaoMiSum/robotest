## 1. 场景管理列表页

**路由**：`/workspace/projects/api-testing?tab=scenes`

### 1.1 页面布局

```
┌──────────────────────────────────────────────────────────────┐
│ [全部场景] │ 下单成功主链路 × │ 支付回调重放 × [+] │
├──────────────────────────────────────────────────────────────┤
│  [搜索场景名称...        ] [执行状态 ▾] [发布状态 ▾] [模块 ▾] [刷新 ↺] │
├──────────────────────────────────────────────────────────────┤
│  场景名称      │描述       │步骤数│状态   │最近执行状态│最近执行时间│操作│
│  ☐ 登录流程测试 │登录并提取…│  5  │[草稿] │ [成功]    │08-17 10:30 │…  │
│  ☐ 下单流程回归 │下单全链路…│  3  │[已发布]│ [失败]    │08-16 09:12 │…  │
│  ☐ 支付回调测试 │支付回调验…│  8  │[已发布]│ [执行中]  │08-16 15:40 │…  │
├──────────────────────────────────────────────────────────────┤
│  [移动] [删除]                                                 │
│              < 第1页/共2页 · 共18条 >                          │
└──────────────────────────────────────────────────────────────┘
```

- 页面首行为**工作区页签条**：**默认型页签**（不使用 card / border-card 卡片型，选中项以下划线标识）；首个固定为「全部场景」列表页签，其后为已打开的场景编排页签（可关闭），**最后一个页签之后紧跟虚线 [+] 新建入口**（仅图标、无文字，`title` 提示「新建场景」）（见 `docs/05-interaction-design/05-api-testing/10-scenario-ui-orchestration.md`）。页面不设独立标题行——标题与左侧栏当前项重复，页面级动作已由页签条承载，[+] 为弱样式入口，不与编排页 [运行] / [保存] / [发布] 争主色。
- 平台原生场景名称无附加徽标；GitLab 导入场景名称旁跟随 **[GitLab] 来源徽标**与**源状态徽标**（见 1.2）。`gitlab_ci` 导入场景行内 [编辑] 同样进入编排页，页面以只读形态呈现（见 `docs/05-interaction-design/05-api-testing/10-scenario-ui-orchestration.md` 1.9）。
- 所属仓库存在源更新时（源探查发现默认分支有新提交），列表顶部显示**单条仓库级信息条**「所属仓库有更新，导入或同步后生效」，点击跳转 GitLab 集成页；仅一条、不逐场景标注，导入或同步成功后自动消失。

行内操作菜单（点击行尾 […] 展开）：编辑 / 执行 / 复制 / 查看报告 / 创建定时任务 / 删除。勾选列（列表首列）支持行勾选与表头全选，选中后展示批量操作工具条，其中「移动」「删除」为 link 形态按钮（「移动」主色、「删除」危险色）。「移动」将所选场景移动到目标场景模块，「删除」对被定时任务引用的场景整体拒绝。

### 1.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 进入页面 | 侧边栏点击「测试场景」 | 拉取场景列表（默认按更新时间倒序），表格骨架屏加载 |
| 搜索 | 输入框输入关键词 | 防抖 300ms 刷新列表，按场景名称模糊匹配 |
| 筛选 | [执行状态] 下拉选择 | 按最近执行结果过滤：全部/成功/失败/执行中/未执行；切换即时刷新 |
| 筛选 | [发布状态] 下拉选择 | 按场景发布状态过滤：全部/草稿/已发布；切换即时刷新 |
| 查看来源 | 场景名称旁 [GitLab] 徽标 | hover 展示仓库名与项目路径，点击跳转 GitLab 集成页并落到「导入」页签；平台原生场景无徽标 |
| 查看源状态 | 场景名称旁源状态徽标 | 取值：源码已退化 / 来源已移除 / 仓库不可达，配色引用 `docs/05-interaction-design/03-visual-design.md`；点击跳转 GitLab 集成页；仓库级「源有更新」不逐场景标注（见 1.1 顶部信息条） |
| 筛选 | [来源] 下拉选择 | 按来源过滤：全部 / 平台原生 / GitLab 导入；切换即时刷新 |
| 查看状态 | 列表「状态」列 | 场景发布状态徽标：草稿（中性色）/ 已发布（主色） |
| 筛选 | [模块] 下拉选择 | 按场景归属模块树筛选；选项来自项目级统一模块树（project_module，详见《项目模块与文档管理详细设计说明书》） |
| 新建场景 | 点击页签末尾虚线 [+]（无文字） | 打开新建弹窗（场景名称必填、模块选择、描述），确认后创建并**跳转场景编排页** |
| 编辑 | 行内 [编辑] | 跳转场景编排页 `/workspace/projects/scenes/:sceneId/edit` |
| 执行 | 行内 [执行] | 直接触发执行（环境缺省回退项目默认环境），Toast「场景「×」执行已启动」后刷新列表，无执行确认弹窗；行内徽标转「执行中」并轮询执行状态至终态 |
| GitLab 流水线场景执行 | `gitlab_ci` 场景行内 [执行] | 直接触发流水线（无环境选择、无确认弹窗），Toast「场景「×」流水线执行已启动」，行内徽标转「执行中」并轮询执行状态至终态 |
| 复制 | 行内 [复制] | 打开新建态场景编辑器并预填源场景全部内容（名称默认「原名称（副本）」，可修改），保存后生成独立副本并返回列表刷新 |
| 查看报告 | 行内 [查看报告] | 跳转接口测试报告列表（按该场景筛选），见报告交互设计 |
| 创建定时任务 | 行内 [创建定时任务] | 跳转定时任务页并预填该场景，见定时任务交互设计 |
| 删除 | 行内 [删除] | 二次确认弹窗（红色警示）；被定时任务引用的场景删除被拒并提示原因 |

### 1.3 批量操作

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 勾选 | 点击行首勾选框 / 表头全选 | 选中行高亮；底部批量操作工具条展示 [移动] [删除]（不展示已选数量）；勾选状态跨分页保持 |
| 移动 | 点击 [移动]（link 形态） | 打开场景模块树选择弹窗（复用项目级统一模块树，单选）；确认后将所选场景移至目标模块，Toast 提示「已移动 N 个场景」并刷新列表；涉及模块权限不足时失败并提示 |
| 删除 | 点击 [删除]（link 形态，危险色） | 二次确认弹窗（红色警示）；任一场景被定时任务引用则整体拒绝并提示失败清单 |

### 1.4 页面状态

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 表格展示场景列表；默认环境场景名称旁显示默认环境名标签 |
| 空态 | 无任何场景时展示引导插图 + 文案「暂无场景，创建第一个测试场景」+ [新建场景] 主按钮；有筛选条件时展示「无匹配结果」+ [清除筛选] |
| 加载态 | 首次进入骨架屏；筛选/刷新时表格上方细进度条；翻页采用表格局部 loading |
| 错误态 | 列表拉取失败：占位区展示失败原因 + [重试] 按钮；执行环境列表拉取失败：弹窗内提示 + [重试]，不阻断浏览列表 |
