## 1. 接口管理列表页

**路由**：`/workspace/projects/api-testing?tab=interfaces`

### 1.1 页面布局

```
┌──────────────────────────────────────────────────────────────────┐
│ [全部接口] │ 创建订单 × │ 查询订单详情 × [+]              [导入] │
├──────────────┬───────────────────────────────────────────────────┤
```

- 页面首行为**工作区页签条**：首个固定为「全部接口」列表页签，其后为已打开的接口编辑页签（可关闭、未保存圆点）；**最后一个页签之后紧跟虚线 [+] 新建入口**（仅图标、无文字，`title` 提示「新建接口」），页签条**最右端**为 [导入]（见 `docs/05-interaction-design/05-api-testing/04-interface-ui-editor.md`）。页面不设独立标题行——标题与左侧栏当前项重复，页面级动作已由页签条承载：[+] 为弱样式入口，[导入] 为主色调链接按钮，均不与编辑器 [保存] 争一级主色。
- 左侧为**项目统一模块树**（project_module，多级嵌套，支持拖拽排序与右键菜单；详见《项目模块与文档管理详细设计说明书》）；右侧为**接口列表**（按选中模块过滤）。
- **表格高度**：表格为固定高度，高度沿页面高度链路取窗口剩余可用空间（`height="100%"`，随窗口缩放动态变化），数据超出时仅在表体内部滚动，搜索卡、表头与分页条固定不动；纵向视觉滚动条按 `UI-SC-05` 组件级策略隐藏，横向视觉滚动条保留显示，滚轮与横向滚动能力保留。
- **模块树滚动**：左侧模块树与 [批量移动到模块] 弹窗内的模块树数据超出时仅树内纵向滚动，视觉滚动条按 `UI-SC-03` 隐藏，滚轮与键盘滚动能力保留。
- 行内操作菜单（点击行尾 […] 展开）：编辑 / 调试 / 复制 / 关注 / 查看引用 / 删除。接口名称列支持超长截断，悬浮或键盘聚焦时可查看完整名称，点击名称可打开编辑。

### 1.2 模块树操作

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 新建模块 | 点击 [+ 新建模块] 或树节点右键 [新建子模块] | 行内输入框（默认「新建模块」），回车确认、Esc 取消；名称 ≤100 字符，同级重名校验 |
| 重命名模块 | 树节点右键 [重命名] | 行内变为输入态，回车保存、Esc 取消 |
| 删除模块 | 树节点右键 [删除] | 二次确认弹窗：提示「模块下 N 个接口将移至未分组」；确认后模块删除、接口保留并归入 [未分组] |
| 排序 | 拖拽树节点 | 同级与跨级拖拽均支持；拖拽中节点浮起，松开触发排序保存；跨级拖拽时目标位置高亮 |
| 搜索过滤 | 左侧搜索框输入 | 防抖 300ms，按模块名与接口名称/路径模糊匹配；命中节点高亮，无命中显示「无匹配结果」 |
| 节点名称可达性 | 悬停或键盘聚焦树节点名称 | 名称按列宽截断时悬停与键盘聚焦均可查看全文（可聚焦标识与 `el-tooltip` hover/focus 触发，焦点态清晰）；点击节点仍按既有规则展开目录或选中过滤，重命名、删除、拖拽等行为不变 |
| 展开/折叠 | 点击节点箭头 | 展开态记忆于本地（浏览器缓存），刷新后保留 |
| 新建接口到模块 | 树节点右键 [新建接口] | 打开接口定义编辑器（内联，见第 3 章）并预填所属模块 |

### 1.3 列表操作

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 进入页面 | 侧边栏点击「接口管理」 | 加载模块树与接口列表（默认选中根节点，按更新时间倒序），骨架屏加载 |
| 搜索 | 输入框输入关键词 | 防抖 300ms 刷新列表，按接口名称/路径模糊匹配 |
| 筛选方法 | [方法 ▾] 下拉 | 全部/GET/POST/PUT/PATCH/DELETE，切换即时刷新 |
| 筛选状态 | [状态 ▾] 下拉 | 全部/启用/停用，切换即时刷新 |
| 新建接口 | 点击页签末尾虚线 [+]（无文字） | 打开接口定义编辑器（内联，见第 3 章），默认归属当前选中模块 |
| 导入 | 点击页签条最右端 [导入]（主色调链接按钮） | 先切换回列表 Tab，再打开导入弹窗（导入功能见 `docs/05-interaction-design/01-readme.md` 第 3 章） |
| 编辑 | 行内 [编辑] | 打开接口定义编辑器（内联，见第 3 章） |
| 调试 | 行内 [调试] | 跳转快速调试页并携带该接口的请求参数（方法、路径、请求头、请求体、Query、认证） |
| 复制 | 行内 [复制] | 打开接口定义编辑器（内联，见第 3 章）新建态并回填源接口全部定义，名称默认「原名称（副本）」可修改，保存后生成独立副本 |
| 关注/取消关注 | 行内 [关注] | 图标即时切换；关注列表在视图切换「我关注的」中可见 |
| 查看引用 | 行内 [查看引用] | 打开引用关系弹窗：展示引用该接口的场景与 Mock 清单（名称 + 跳转链接），无引用时提示「未被引用」 |
| 删除 | 行内 [删除] | 二次确认弹窗（红色警示）；被场景/Mock 引用时**禁止删除**，弹窗列出引用方清单并提示「请先解除引用」（错误码 1000017103） |

### 1.4 批量操作

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 勾选 | 表头全选或行首勾选 | 页面底部居中浮现浮动批量条：「已选 N 项 [批量移动] [批量删除] [清空]」，取消全部勾选或点击 [清空] 后隐藏 |
| 批量移动 | 点击 [批量移动] | 打开模块选择弹窗（模块树单选），确认后所选接口移至目标模块，Toast 成功并刷新 |
| 批量删除 | 点击 [批量删除] | 二次确认弹窗（红色警示，列出数量）；含被引用接口时整体拒绝并列出引用清单，提示先解除引用 |

### 1.5 页面状态

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 模块树 + 接口表格正常渲染；方法徽标按语义色区分（GET 绿 / POST 蓝 / PUT 橙 / DELETE 红）；被引用接口名称旁显示引用计数标签 |
| 空态 | 项目无任何接口：右侧列表区展示空态引导与新建/导入入口（按页面能力提供）；有搜索、视图、状态或模块筛选条件且无结果时展示「无匹配结果」+ [清除筛选]；模块树无模块时展示「暂无模块」+ [新建模块] |
| 加载态 | 首屏加载显示加载占位；筛选、搜索、视图切换、模块切换或翻页刷新时保留当前已加载内容并显示加载反馈；模块树与右侧列表并行加载 |
| 错误态 | 右侧列表首屏加载失败：展示错误提示 + [重试]，不展示误导空态；筛选、搜索、视图切换、模块切换或翻页刷新失败：保留当前已加载数据与分页信息，展示错误提示与 [重试]，重试沿用当前条件；模块树拉取失败：左侧错误占位 + [重试]，右侧列表仍可浏览；删除被引用接口被拒：弹窗内明确提示引用方清单 |
