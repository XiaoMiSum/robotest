## 1. 总体布局

### 1.1 脑图编辑页 AI 入口分布

AI 入口落位于用例脑图编辑页（CaseMindMap），随 `aiEnabled` 显隐：

```
┌────────────────────────────────────────────────────────────┐
│ 工具栏: [节点类型标记组] [优先级组] … │ [✨AI生成用例] [✨AI指令] │
├────────────────────────────────────────────────────────────┤
│                                                            │
│                    脑图画布                                │
│          （case 节点右键菜单含「✨AI 补全步骤」）           │
│                                                            │
│                          ┌────────────────────────┐        │
│                          │  AI 生成抽屉（右侧滑出）│        │
│                          └────────────────────────┘        │
└────────────────────────────────────────────────────────────┘
```

- 工具栏新增 [AI 生成用例] [AI 指令] 两个按钮，置于既有按钮组右侧，带 AI 统一视觉标识；
- 右键菜单仅在 **case 类型节点**上显示「AI 补全步骤」项（置于标记域之后的动作区）；
- 需求池为项目工作区侧边菜单新增入口（1.2），**不受 AI 开关控制**。

> **零影响约束（通用规范 2.7）**：AI 按钮仅追加在既有工具栏/右键菜单末尾，不改变既有标记组、优先级组的位置与操作；`aiEnabled = false` 时上述 AI 入口整体隐藏，工具栏与右键菜单回退到 V1.0 形态，脑图编辑、协同、撤销等既有能力不受任何影响。

### 1.2 项目工作区侧边菜单增量

功能测试侧边栏菜单新增「需求池」项：

```
┌──────────┐
│ 用例管理 │
│ 测试评审 │
│ 测试计划 │
│ 需求池   │  ← 新增（常规业务功能，不随 AI 开关隐藏）
└──────────┘
```

## 2. AI 生成用例（US-AI-001）

**入口**：脑图工具栏 [AI 生成用例]，生成结果挂载到当前选中节点下（未选中时默认根节点）。

### 2.1 生成抽屉布局

```
┌───────────────────────────────────────┐
│  ✨ AI 生成用例                    ✕  │
├───────────────────────────────────────┤
│  挂载目标：登录模块 > 密码登录        │
├───────────────────────────────────────┤
│  需求输入                             │
│  [需求描述文本域…              ]      │
│  [＋ 从需求池选取]  已选条目：2 条 ✕  │
│                            [✨ 生成]  │
├───────────────────────────────────────┤
│  输出区                               │
│  ┌─────────────────────────────────┐  │
│  │ (生成中: 流式文本逐字渲染)      │  │
│  │ (完成后: 切换为结构化预览树)    │  │
│  │ ☑ 用例A [P1]                    │  │
│  │   ☑ 前置条件… ☑ 步骤… ☑ 预期…  │  │
│  │ ☑ 用例B [P0]                    │  │
│  └─────────────────────────────────┘  │
│  (生成中)[停止] / (完成)[重新生成] [确认挂载]│
└───────────────────────────────────────┘
```

### 2.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 打开抽屉 | 点击工具栏 [AI 生成用例] | 抽屉滑出，显示挂载目标节点路径；文档已关联需求池条目时自动带入并可改选 |
| 选取需求条目 | 点击 [从需求池选取] | 打开条目选取器弹窗（见 6.2），多选后以标签形式回显，可单个移除 |
| 发起生成 | 点击 [生成] | 建立 SSE，输出区流式渲染原始文本；超时与取消遵循通用规范 2.3 |
| 生成完成 | done 帧到达 | 输出区切换为结构化预览树，默认全选；上下文被裁剪时顶部显示截断警告 |
| 勾选取舍 | 预览树勾选框 | 级联规则：取消父节点则子孙一并排除；case 节点取消时其前置/步骤/预期子节点整组排除 |
| 确认挂载 | 点击 [确认挂载] | 校验目标节点仍存在 → 经编辑内核批量创建（单条撤销历史）→ 脑图定位到新子树，Toast 成功 |
| 目标节点已被协同删除 | 确认挂载时校验失败 | 提示「挂载目标已被删除，请重新选择」→ 弹出节点选择器重选，**不丢弃预览结果** |
| 中途取消 | 点击 [停止] | 断开 SSE，已输出内容不保留，可重新生成 |

- 预览-确认阶段抽屉保持打开，用户可切换到脑图继续编辑，生成过程中文档照常可编辑；
- 挂载的节点自动完成类型标记（用例/前置条件/执行步骤/预期结果）与优先级标记，并携带 AI 徽标（见第 7 章），无需逐个手工标记；
- 挂载走既有编辑通道：协同用户实时可见，支持整体撤销。

### 2.3 预览树呈现规则

- 节点渲染为圆角芯片，case 节点带 P0–P3 优先级徽标，类型徽标沿用既有配色（用例紫 / 前置蓝 / 步骤绿 / 预期橙）；
- 所有节点默认平铺展开、默认全选，勾选采用父子级联。

## 3. AI 补全步骤（US-AI-002）

**入口**：case 节点右键菜单「AI 补全步骤」。

### 3.1 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 发起补全 | 右键 case 节点 → 点击「AI 补全步骤」 | 打开生成抽屉（复用 2.1，标题变为「AI 补全步骤」），自动带入节点上下文与关联需求条目，可临时粘贴补充文本 |
| 生成与预览 | 同 2.2 | 预览树仅含新增的执行步骤/预期结果节点；已有步骤/预期结果保留不覆盖 |
| 确认追加 | 点击 [确认挂载] | 追加为该 case 节点子节点，自动完成类型标记并带 AI 徽标 |
| 原 case 节点已被协同删除 | 确认时校验失败 | 提示「节点已被删除，无法挂载」——补全目标只能是原节点，**不提供重选** |

## 4. AI 指令（US-AI-015 / US-AI-016）

**入口**：脑图工具栏 [AI 指令]，点击后在工具栏下方展开输入区，双模式共用。

### 4.1 输入区布局

```
┌────────────────────────────────────────────────────────┐
│ ✨ [指令模式] ⇄  [输入自然语言指令或粘贴外部文本…] [执行]│
└────────────────────────────────────────────────────────┘
```

### 4.2 双模式切换

| 规则 | 说明 |
| ---- | ---- |
| 默认模式 | 指令翻译模式（自然语言 → 批量操作） |
| 自动切换 | 文本超过 200 字符，或含制表符/多行 → 自动切为「导入模式」 |
| 模式徽标 | 当前模式以徽标显式展示在输入区左侧；自动判定有误时一键切回，已输入文本保留 |

### 4.3 批量指令模式交互（US-AI-015）

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 提交指令 | 输入自然语言 → 点击 [执行] | 同步调用 DSL 翻译，按钮 loading |
| 翻译成功 | 返回指令集 | 弹出**命中预览确认弹窗**（见 4.4） |
| 翻译歧义/失败 | LLM 声明歧义或校验失败 | 输入区下方提示「指令无法可靠理解，请改写」，不做模糊执行 |
| 确认执行 | 预览弹窗点击 [确认执行] | 前端确定性代码批量执行，整批单条撤销历史；弹窗关闭并聚焦首个受影响节点 |
| 取消 | 预览弹窗点击 [取消] | 关闭弹窗，不产生任何变更 |

- 支持的动作：标记类型、标记优先级、高亮、文档内移动、新增子节点；首期仅限当前文档内，跨文档操作提示不支持；
- DSL 批量标记类型不触发优先级推荐（避免批量请求）。

### 4.4 命中预览确认弹窗

```
┌────────────────────────────────────┐
│  将对 12 个节点 执行：标记为 P2    │  ← 命中数量醒目展示
│  ▸ 命中节点清单（默认折叠可展开）  │
│  ▸ 将跳过 2 个节点（含跳过原因）   │
│              [取消] [确认执行]     │
└────────────────────────────────────┘
```

### 4.5 外部文本导入模式交互（US-AI-016）

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 粘贴文本 | 粘贴自由文本 / Markdown / 制表符表格 | 自动切导入模式并显示模式徽标 |
| 发起解析 | 点击 [执行] | SSE 流式解析 → 预览树 → 勾选 → 挂载，链路与 2.2 完全一致 |
| 无法解析 | done 帧返回空节点 + warning | 提示「未能解析出用例结构，请调整文本格式」 |
| 超长文本 | 超过系统配置上限 | 提交前红字提示，禁用 [执行] |

- 表格文本按「一行一用例」解析，自由文本按语义分组；插入的节点自动完成类型与优先级标记并携带 AI 徽标。

## 5. 优先级智能推荐（US-AI-003）

**触发**：节点被**手工单节点**标记为用例类型时（含既有节点重标记）；AI 生成节点已带优先级不触发，DSL 批量标记不触发，撤销/重做重放不触发。

### 5.1 呈现位置

标记面板（右键菜单标记域 / 工具栏优先级组）优先级按钮区上方显示推荐标签：

```
┌──────────────────────────────┐
│  ✨ 推荐 P0（点击采纳）       │  ← 非侵入推荐标签
│  [P0] [P1] [P2] [P3]         │  ← 优先级按钮区
└──────────────────────────────┘
```

> 取消标记按钮（⊗）属节点类型标记组（重置类型并清除优先级），不在优先级按钮区，此处不重复描述。

### 5.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 关键词规则命中 | 标记为用例类型瞬间 | 即时显示推荐标签（无 LLM 调用延迟） |
| 规则未命中 | 同上 | 后台发起 LLM 推荐，到达后再显示标签；请求进行中不阻塞任何操作 |
| 采纳推荐 | 点击推荐标签 | 直接完成优先级标记，标签消失 |
| 忽略 | 不操作 / 手工另选 | 用户已手工选择后到达的 LLM 结果直接丢弃 |
| 无推荐 | 规则未命中且 LLM 失败/超时 | 不显示任何标签（预期行为，无错误提示） |

## 6. 轻量需求池（US-AI-004）

### 6.1 需求池管理页

**路由**：`/project/requirements`（项目工作区侧边菜单入口）

#### 6.1.1 页面布局

```
┌──────────────────────────────────────────────────────┐
│  需求池                                              │
├──────────────────────────────────────────────────────┤
│  [🔍 搜索条目标题…] [查询]            [+ 新建条目]   │
├──────────────────────────────────────────────────────┤
│  标题        │ 来源URL │ 更新人 │ 更新时间 │ 操作    │
│  登录改版需求│ http…  │ 张三   │ 07-30    │编辑 删除│
│  支付流程v2  │   —    │ 李四   │ 07-28    │编辑 删除│
├──────────────────────────────────────────────────────┤
│                                        第1页/共3页   │
└──────────────────────────────────────────────────────┘

新建/编辑抽屉：标题 + 内容（Markdown 编辑器复用）+ 来源URL（可选）
```

#### 6.1.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 搜索 | 输入标题关键字后回车或点击 [查询]（带 Search 图标） | 列表刷新 |
| 新建条目 | 点击 [+ 新建条目] | 右侧抽屉：标题（必填）+ Markdown 内容 + 来源 URL（仅作出处展示，平台不抓取） |
| 编辑条目 | 点击 [编辑] | 抽屉回显；仅条目创建人或具备项目管理权限的成员可见编辑/删除操作 |
| 删除条目 | 点击 [删除] | 二次确认：「删除不影响已生成的用例，文档关联将解除」→ 执行后列表刷新 |
| 内容超限 | 内容长度超过系统配置上限 | 编辑器下方红字提示，禁用保存 |

### 6.2 需求条目选取器（各 AI 入口复用）

供「AI 生成用例」「AI 补全步骤」「遗漏测试点分析」「回归子集推荐」调用的弹窗组件：

```
┌────────────────────────────────────┐
│  选择需求条目                       │
│  [🔍 关键字过滤…]                   │
│  ☑ 登录改版需求      07-30          │
│  ☐ 支付流程v2        07-28          │
│  ─────────────────────────────      │
│  [保存为需求池条目]  [取消] [确定]  │
└────────────────────────────────────┘
```

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 多选条目 | 勾选 | 底部显示已选数量 |
| 临时文本入池 | AI 入口粘贴了临时文本时点击 [保存为需求池条目] | 弹出精简表单（标题预填文本首行）→ 保存后自动勾选该新条目 |
| 确定 | 点击 [确定] | 选中条目回填调用方入口，以标签展示 |

### 6.3 文档关联需求条目

- 脑图文档设置区提供「关联需求条目」入口，复用选取器多选；
- 已关联条目在 AI 生成/补全时自动带入为默认上下文，入口内可临时改选；
- 关联随条目删除自动解除，界面无残留。

## 7. AI 标识徽标

- AI 生成/补全/导入/对话式编辑新增的节点统一携带「AI」徽标，位置与既有类型徽标并列（复用 badges.ts 徽标体系）；
- 徽标随节点复制/剪切粘贴保留到副本，随评审/计划快照继承；
- **移除**：右键菜单标记域仅在 `aiGenerated = true` 的节点上显示「移除 AI 标识」芯片，点击即移除；移除后不可重新添加（撤销回退除外），任何入口不提供手动添加；
- AI 标识不影响任何业务规则（评审、计划、执行照常）。

## 8. 通用交互模式总结

### 8.1 弹窗类型

| 类型 | 使用场景 |
| ---- | ---- |
| 抽屉 | AI 生成/补全面板、需求条目新建/编辑 |
| 确认弹窗 | DSL 命中预览、条目删除、挂载目标重选 |
| 选择弹窗 | 需求条目选取器、挂载位置节点选择器 |

### 8.2 加载状态

- 流式生成：输出区逐字渲染 + [停止] 按钮；超 10 秒提示可取消重试（通用规范 2.3）。
- 同步翻译/推荐：按钮 loading，不阻塞脑图编辑。
- 需求池列表：首次骨架屏，刷新顶部进度条。

### 8.3 与协同编辑的关系

- 生成、预览期间文档保持可编辑，协同帧照常收发；
- 挂载/批量执行经既有编辑内核与协同通道，协同用户实时可见；
- 一切 AI 引发的脑图变更均为单条撤销历史，Ctrl+Z 一次回退。
