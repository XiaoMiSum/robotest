## 1. 总体布局

### 1.1 脑图编辑页 AI 入口分布

AI 入口落位于用例脑图编辑页（CaseMindMap），随 `aiEnabled` 显隐：

```
┌────────────────────────────────────────────────────────────┐
│ 核心工具栏: [历史] [节点结构] [布局] [类型标记] [优先级] [关联需求]│
│ AI 入口行（右侧）: [✨AI 生成用例] [✨遗漏测试点]               │
├────────────────────────────────────────────────────────────┤
│                                                            │
│                    脑图画布                                │
│          （case 节点右键菜单含「✨AI 补全步骤」）           │
│                                                            │
│                          ┌────────────────────────┐        │
│                          │  AI 生成抽屉（右侧滑出）│        │
│                          └────────────────────────┘        │
└────────────────────────────────────────────────────────────┘
```

- 工具栏为顶部两行流式胶囊：**第一行**为核心编辑操作（历史/节点结构/布局/类型标记/优先级/关联需求），**第二行（右侧）**为 AI 入口 [AI 生成用例] [遗漏测试点]，带 AI 统一视觉标识；两行均随内容换行不重叠；
- 右键菜单仅在 **case 类型节点**上显示「AI 补全步骤」项（置于标记域之后的动作区）；
- 需求池为项目工作区侧边菜单新增入口（1.2），**不受 AI 开关控制**。

> **零影响约束（通用规范 2.7）**：AI 入口独占一行、追加在核心工具栏下方，不改变既有标记组、优先级组的位置与操作；`aiEnabled = false` 时 AI 入口行整体隐藏，核心工具栏与右键菜单回退到 V1.0 形态，脑图编辑、协同、撤销等既有能力不受任何影响。

### 1.2 项目工作区侧边菜单增量

功能测试侧边栏菜单新增「需求池」项：

```
┌──────────┐
│ 用例管理 │
│ 测试评审 │
│ 测试计划 │
│ 需求池   │  ← 新增（常规业务功能，不随 AI 开关隐藏）
└──────────┘
```

## 2. AI 生成用例（US-AI-001）

**入口**：脑图工具栏 [AI 生成用例]，生成结果挂载到当前选中节点下（未选中时默认根节点）。

### 2.1 生成弹窗与预览弹窗布局

生成完成后，预览在**独立弹窗**中展示（两窗并存、预览置顶）；生成弹窗内不再内嵌预览。

**生成弹窗**（居中模态，压暗画布，尺寸约 720px）：

```
┌───────────────────────────────────────────┐
│  ✨ AI 生成用例                        ✕  │
├───────────────────────────────────────────┤
│  挂载目标：登录模块 > 密码登录             │
├───────────────────────────────────────────┤
│  需求输入                                 │
│  [需求描述文本域…                  ]       │
│  [＋ 从需求池选取]  已选条目：2 条 ✕      │
│  [模型: DeepSeek-V3 ▼]     [✨ 生成]      │
├───────────────────────────────────────────┤
│  输出区（生成中：流式文本逐字渲染）         │
│  (生成中)[停止] / (完成)[重新生成] [查看预览]│
└───────────────────────────────────────────┘
```

**预览弹窗**（完成并点击 [查看预览] 后打开，居中模态、置顶于生成弹窗之上，宽度 70% × 高度 80%（视口）：

```
┌────────────────────────────────────────────────┐
│  ✨ AI 生成用例预览                        ✕   │
├────────────────────────────────────────────────┤
│  挂载目标：登录模块 > 密码登录                   │
├────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────┐  │
│  │  脑图（仅本次生成节点树，只读渲染）        │  │
│  │  ☑ 用例B [P0] [AI]                       │  │
│  │    前置条件… 步骤… 预期…（随用例级联）     │  │
│  │  ☑ 用例C [P1] [AI]                       │  │
│  └──────────────────────────────────────────┘  │
│  已勾选 2/2 个用例      [关闭] [确认挂载]       │
└────────────────────────────────────────────────┘
```

> 生成弹窗打开期间画布被遮罩拦截不可编辑；预览弹窗打开后，生成弹窗保留在下一层（仍处于「完成」态，可随时关闭预览弹窗后点 [查看预览] 重新打开）。两窗关闭后画布恢复可编辑。

### 2.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 打开弹窗 | 点击工具栏 [AI 生成用例] | 生成弹窗打开，显示挂载目标节点路径；文档已关联需求池条目时自动带入并可改选 |
| 选取需求条目 | 点击 [从需求池选取] | 打开条目选取器弹窗（见 6.2），多选后以标签形式回显，可单个移除 |
| 切换对话模型 | [生成] 旁模型选择器（`AiModelSelect`，通用规范见《AI基础设施与管理端页面交互设计》2.8） | 作用于本次及后续生成；选择本地记忆，失效静默回退系统默认；仅一个可用模型时不渲染 |
| 发起生成 | 点击 [生成] | 建立 SSE，输出区流式渲染原始文本；超时与取消遵循通用规范 2.3 |
| 生成完成 | done 帧到达 | 输出区保留最后一段流式文本；底部按钮变为 [重新生成] [查看预览]；上下文被裁剪时输出区上方显示截断警告 |
| 打开预览 | 点击 [查看预览] | 打开独立预览弹窗（脑图文档形式，见 2.3），**不关闭生成弹窗** |
| 勾选取舍 | 预览弹窗内点击用例节点 | 仅用例节点带勾选框（☑ 默认勾选，点击切换）；前置/步骤/预期等非用例节点无勾选框、点击无效，其挂载随所属用例节点级联（取消用例则其整棵内部结构一并排除，恢复勾选时整组恢复） |
| 确认挂载 | 预览弹窗点击 [确认挂载] | 校验目标节点仍存在 → 经编辑内核批量创建（单条撤销历史）→ 脑图定位到新子树，Toast 成功 → **关闭预览弹窗与生成弹窗（全部弹窗）** |
| 目标节点已被协同删除 | 确认挂载时校验失败 | 提示「挂载目标已被删除，请重新选择」→ 弹出节点选择器重选，**不丢弃预览结果** |
| 中途取消 | 点击 [停止] | 断开 SSE，已输出内容不保留，可重新生成 |
| 关闭预览弹窗 | 点击预览弹窗遮罩或关闭按钮 | **仅关闭预览弹窗**，生成弹窗保留在「完成」态（预览快照保留，可再次 [查看预览]）；画布仍被生成弹窗遮罩拦截 |
| 关闭生成弹窗 | 点击生成弹窗遮罩或关闭按钮 | 关闭生成弹窗（预览弹窗若打开则一并关闭）；生成中关闭即断开 SSE（已输出内容不保留） |

> **纯预览约束**：预览树为**前端本地快照组装**（仅本次生成结果，文档既有数据不并入预览），仅用于展示与勾选，**不写入编辑内核、不产生撤销历史、不广播协同帧、不落库**；勾选状态（aiSelected）仅存在于预览实例内存，关闭预览弹窗即丢弃；只有点击 [确认挂载] 后才经既有编辑通道批量插入节点；
> 挂载的节点自动完成类型标记（用例/前置条件/执行步骤/预期结果）与优先级标记，并携带 AI 徽标（见第 7 章），无需逐个手工标记；
> 挂载走既有编辑通道：协同用户实时可见，支持整体撤销。

### 2.3 预览弹窗呈现规则

- 预览弹窗以**脑图形式**渲染**本次生成节点树**（复用 kityminder 只读实例，前端从生成结果组装，纯本地展示不落库）：仅展示生成节点，文档既有数据不再并入预览；节点样式沿用既有类型/优先级徽标配色（用例紫 / 前置蓝 / 步骤绿 / 预期橙），生成节点带青色「AI」徽标（`aiBadge`）；
- **仅用例节点可勾选**：用例节点左侧带勾选框（☑ 默认勾选，点击切换勾选状态：勾选=青色对勾，取消=灰色空框）；前置/步骤/预期等非用例节点无勾选框、点击无效，其挂载随所属用例节点级联（取消用例则其整棵内部结构一并排除，恢复勾选时整组恢复）；
- 预览弹窗底部显示「已勾选 N/M 个用例」，随勾选实时更新，N/M 仅统计用例节点。

## 3. AI 补全步骤（US-AI-002）

**入口**：case 节点右键菜单「AI 补全步骤」。

### 3.1 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 发起补全 | 右键 case 节点 → 点击「AI 补全步骤」 | 打开生成抽屉（复用 2.1，标题变为「AI 补全步骤」），自动带入节点上下文与关联需求条目，可临时粘贴补充文本 |
| 生成与预览 | 同 2.2 | 预览树仅含新增的执行步骤/预期结果节点；已有步骤/预期结果保留不覆盖 |
| 确认追加 | 点击 [确认挂载] | 追加为该 case 节点子节点，自动完成类型标记并带 AI 徽标 |
| 原 case 节点已被协同删除 | 确认时校验失败 | 提示「节点已被删除，无法挂载」——补全目标只能是原节点，**不提供重选** |

## 5. 优先级智能推荐（US-AI-003）

**触发**：节点被**手工单节点**标记为用例类型时（含既有节点重标记）；AI 生成节点已带优先级不触发，撤销/重做重放不触发。

### 5.1 呈现位置

标记面板（右键菜单标记域 / 工具栏优先级组）优先级按钮区上方显示推荐标签：

```
┌──────────────────────────────┐
│  ✨ 推荐 P0（点击采纳）       │  ← 非侵入推荐标签
│  [P0] [P1] [P2] [P3]         │  ← 优先级按钮区
└──────────────────────────────┘
```

> 取消标记按钮（⊗）属节点类型标记组（重置类型并清除优先级），不在优先级按钮区，此处不重复描述。

### 5.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 关键词规则命中 | 标记为用例类型瞬间 | 即时显示推荐标签（无 LLM 调用延迟） |
| 规则未命中 | 同上 | 后台发起 LLM 推荐，到达后再显示标签；请求进行中不阻塞任何操作 |
| 采纳推荐 | 点击推荐标签 | 直接完成优先级标记，标签消失 |
| 忽略 | 不操作 / 手工另选 | 用户已手工选择后到达的 LLM 结果直接丢弃 |
| 无推荐 | 规则未命中且 LLM 失败/超时 | 不显示任何标签（预期行为，无错误提示） |

## 6. 轻量需求池（US-AI-004）

### 6.1 需求池管理页

**路由**：`/project/requirements`（项目工作区侧边菜单入口）

#### 6.1.1 页面布局

```
┌──────────────────────────────────────────────────────┐
│  需求池                                              │
├──────────────────────────────────────────────────────┤
│  [🔍 搜索条目标题…] [查询]            [+ 新建条目]   │
├──────────────────────────────────────────────────────┤
│  标题        │ 来源URL │ 更新人 │ 更新时间 │ 操作    │
```

#### 6.1.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 搜索 | 输入标题关键字后回车或点击 [查询]（带 Search 图标） | 列表刷新 |

| 编辑条目 | 点击 [编辑] | 抽屉回显；仅条目创建人或具备项目管理权限的成员可见编辑/删除操作 |

### 6.3 文档关联需求条目

- 脑图文档设置区提供「关联需求条目」入口，复用选取器多选；
- 已关联条目在 AI 生成/补全时自动带入为默认上下文，入口内可临时改选；
- 关联随条目删除自动解除，界面无残留。

## 7. AI 标识徽标

- AI 生成/补全/对话式编辑新增的节点统一携带「AI」徽标，位置与既有类型徽标并列（复用 badges.ts 徽标体系）；
- 徽标随节点复制/剪切粘贴保留到副本，随评审/计划快照继承；
- **移除**：右键菜单标记域仅在 `aiGenerated = true` 的节点上显示「移除 AI 标识」芯片，点击即移除；移除后不可重新添加（撤销回退除外），任何入口不提供手动添加；
- AI 标识不影响任何业务规则（评审、计划、执行照常）。

## 8. 通用交互模式总结

### 8.1 弹窗类型

| 类型 | 使用场景 |
| ---- | ---- |
| 居中弹窗 | AI 生成/补全面板（约 720px）、AI 生成用例预览弹窗（脑图形式，宽 70% × 高 80%（视口），两窗并存时置顶）、需求条目新建/编辑 |
| 确认弹窗 | 条目删除、挂载目标重选 |
| 选择弹窗 | 需求条目选取器、挂载位置节点选择器 |

### 8.2 加载状态

- 流式生成：输出区逐字渲染 + [停止] 按钮；超 10 秒提示可取消重试（通用规范 2.3）。
- 同步推荐：按钮 loading，不阻塞脑图编辑。
- 需求池列表：首次骨架屏，刷新顶部进度条。

### 8.3 与协同编辑的关系

- 生成、预览期间文档保持可编辑，协同帧照常收发；
- 挂载经既有编辑内核与协同通道，协同用户实时可见；
- 一切 AI 引发的脑图变更均为单条撤销历史，Ctrl+Z 一次回退。
