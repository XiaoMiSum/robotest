## 1. 总体布局

### 1.1 脑图编辑页 AI 入口分布

AI 入口落位于用例脑图编辑页（CaseMindMap），随 `aiEnabled` 显隐：

```
┌────────────────────────────────────────────────────────────┐
│ 核心工具栏: [历史] [节点结构] [布局] [类型标记] [优先级] [关联需求]│
│ AI 入口行（右侧）: [✨AI 生成用例] [✨遗漏测试点]               │
├────────────────────────────────────────────────────────────┤
│                                                            │
│                    脑图画布                                │
│          （case 节点右键菜单含「✨AI 补全步骤」）           │
│                                                            │
│                          ┌────────────────────────┐        │
│                          │  AI 生成抽屉（右侧滑出）│        │
│                          └────────────────────────┘        │
└────────────────────────────────────────────────────────────┘
```

- 工具栏为顶部两行流式胶囊：**第一行**为核心编辑操作（历史/节点结构/布局/类型标记/优先级/关联需求），**第二行（右侧）**为 AI 入口 [AI 生成用例] [遗漏测试点]，带 AI 统一视觉标识；两行均随内容换行不重叠；
- 右键菜单仅在 **case 类型节点**上显示「AI 补全步骤」项（置于标记域之后的动作区）；
- 需求池为项目工作区侧边菜单新增入口（1.2），**不受 AI 开关控制**。

> **零影响约束（通用规范 2.7）**：AI 入口独占一行、追加在核心工具栏下方，不改变既有标记组、优先级组的位置与操作；`aiEnabled = false` 时 AI 入口行整体隐藏，核心工具栏与右键菜单回退到 V1.0 形态，脑图编辑、协同、撤销等既有能力不受任何影响。

### 1.2 项目工作区侧边菜单增量

功能测试侧边栏菜单新增「需求池」项：

```
┌──────────┐
│ 用例管理 │
│ 测试评审 │
│ 测试计划 │
│ 需求池   │  ← 新增（常规业务功能，不随 AI 开关隐藏）
└──────────┘
```

## 2. AI 生成用例（US-AI-001）

**入口**：脑图工具栏 [AI 生成用例]，生成结果固定挂载到文档根节点下。

### 2.1 生成抽屉与预览弹窗布局

生成完成后，预览在**独立弹窗**中展示（两窗并存、预览置顶）；生成抽屉内不再内嵌预览。

**生成抽屉**（右侧滑出，透明遮罩不压暗画布，尺寸统一 640px，点击抽屉外空白处自动关闭）：

```
┌───────────────────────────────────────────┐
│  ✨ AI 生成用例                        ✕  │
├───────────────────────────────────────────┤
│  挂载目标：登录模块（根节点）               │
├───────────────────────────────────────────┤
│  需求输入                                 │
│  [需求描述文本域…                  ]       │
│  [+ 选择需求]  已选条目：2 条 ✕          │
│  [模型: DeepSeek-V3 ▼] [进度条] [停止]    │
├───────────────────────────────────────────┤
│  输出区（生成中：空白；完成：提示文字）     │
│  (完成)[重新生成] [查看预览]               │
└───────────────────────────────────────────┘
```

**预览弹窗**（完成并点击 [查看预览] 后打开，居中模态、置顶于生成抽屉之上，宽度 70% × 高度 80%（视口）：

```
┌────────────────────────────────────────────────┐
│  ✨ AI 生成用例预览                        ✕   │
├────────────────────────────────────────────────┤
│  挂载目标：登录模块（根节点）                     │
├────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────┐  │
│  │  脑图（仅本次生成节点树，只读渲染）        │  │
│  │  ☑ 用例B [P0] [AI]                       │  │
│  │    前置条件… 步骤… 预期…（随用例级联）     │  │
│  │  ☑ 用例C [P1] [AI]                       │  │
│  └──────────────────────────────────────────┘  │
│  已勾选 2/2 个用例      [关闭] [确认挂载]       │
└────────────────────────────────────────────────┘
```

> 生成抽屉打开期间页面被透明遮罩拦截不可交互（画布可见但不压暗）；预览弹窗打开后，生成抽屉保留在下一层（仍处于「完成」态，可随时关闭预览弹窗后点 [查看预览] 重新打开）。全部关闭后画布恢复可编辑。
> **会话保持**：关闭生成抽屉仅隐藏面板，**不中断进行中的 SSE、不丢弃已完成的结果**；同一文档内重新打开即恢复上次会话（见 2.2）。仅当**切换文档**时断开并重置（会话绑定文档生命周期）。

### 2.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 打开抽屉 | 点击工具栏 [AI 生成用例] | 生成抽屉右侧滑出，显示挂载目标节点路径（固定为文档根节点）；文档已关联需求池条目时自动带入并可改选 |
| 选取需求池条目 | 点击 [+ 选择需求] | 打开条目选取器弹窗（见 6.2），多选后以标签形式回显，可单个移除 |
| 切换对话模型 | [开始生成] 旁模型选择器（`AiModelSelect`，通用规范见《AI基础设施与管理端页面交互设计》2.8） | 作用于本次及后续生成；选择本地记忆，失效静默回退系统默认；仅一个可用模型时不渲染 |
| 发起生成 | 点击 [开始生成] | 建立 SSE，操作行内进度条（flex:1 占位、与按钮同行左侧）转滚动态；超时与取消遵循通用规范 2.3 |
| 生成完成 | done 帧到达 | 进度条消失（**不显示完成态进度条**），输出区显示完成提示文字与结果；底部按钮变为 [重新生成]（次要按钮样式，无主按钮底色）[查看预览]（主按钮，位于 [重新生成] 右侧）；上下文被裁剪时输出区上方显示截断警告 |
| 打开预览 | 点击 [查看预览] | 打开独立预览弹窗（脑图文档形式，见 2.3），**不关闭生成抽屉** |
| 勾选取舍 | 预览弹窗内点击可勾选节点 | **生成模式**：仅用例节点带勾选框（☑ 默认勾选，点击切换），前置/步骤/预期等非用例节点无勾选框、点击无效，其挂载随所属用例节点级联（取消用例则其整棵内部结构一并排除，恢复勾选时整组恢复）；**补全模式**：全部生成节点（前置/步骤/预期）带勾选框且默认勾选，可逐项独立取舍（无级联） |
| 确认挂载 | 预览弹窗点击 [确认挂载] | 校验目标节点仍存在 → 经编辑内核批量创建（单条撤销历史）→ 脑图定位到新子树，Toast 成功 → **关闭预览弹窗与生成抽屉** |
| 文档根节点已被协同删除 | 确认挂载时校验失败 | 提示「挂载目标已被删除，请重新选择」→ 弹出节点选择器重选，**不丢弃预览结果** |
| 中途取消 | 点击 [停止] | 断开 SSE，已输出内容不保留，可重新生成 |
| 关闭预览弹窗 | 点击预览弹窗遮罩或关闭按钮 | **仅关闭预览弹窗**，生成抽屉保留在「完成」态（预览快照保留，可再次 [查看预览]）；画布仍被生成抽屉遮罩拦截 |
| 关闭生成抽屉 | 点击抽屉外空白处或标题栏关闭按钮 | 仅隐藏抽屉（预览弹窗若打开则一并关闭）；**生成中不断开 SSE**，后台继续直至完成，会话结果（输入文本、预览、完成态）保留 |
| 重新打开抽屉 | 关闭后再次点击工具栏 [AI 生成用例] | 恢复上次会话：输入文本、需求条目、生成结果（含「完成」态预览）原样呈现；未执行过生成则为初始空态 |
| 切换文档 | 脑图切换至另一文档（docId 变化） | **断开 SSE 并重置会话**（输入、预览、完成态全部清空）；切回原文档亦不复原 |

> **纯预览约束**：预览树为**前端本地快照组装**（仅本次生成结果，文档既有数据不并入预览），仅用于展示与勾选，**不写入编辑内核、不产生撤销历史、不广播协同帧、不落库**；勾选状态（aiSelected）仅存在于预览实例内存，关闭预览弹窗即丢弃；只有点击 [确认挂载] 后才经既有编辑通道批量插入节点；
> 挂载的节点自动完成类型标记（用例/前置条件/执行步骤/预期结果）与优先级标记，并携带 AI 徽标（见第 7 章），无需逐个手工标记；
> 挂载走既有编辑通道：协同用户实时可见，支持整体撤销。

### 2.3 预览弹窗呈现规则

- 预览弹窗以**脑图形式**渲染**本次生成节点树**（复用 kityminder 只读实例，前端从生成结果组装，纯本地展示不落库）：仅展示生成节点，文档既有数据不再并入预览；节点样式沿用既有类型/优先级徽标配色（用例紫 / 前置蓝 / 步骤绿 / 预期橙），生成节点带青色「AI」徽标（`aiBadge`）；
- **可勾选节点按模式区分**：**生成模式**仅用例节点左侧带勾选框（☑ 默认勾选，点击切换勾选状态：勾选=青色对勾，取消=灰色空框），前置/步骤/预期等非用例节点无勾选框、点击无效，其挂载随所属用例节点级联（取消用例则其整棵内部结构一并排除，恢复勾选时整组恢复）；**补全模式**全部生成节点带勾选框（默认勾选），可逐项独立取舍（无级联）；
- 预览弹窗底部显示「已勾选 N/M 个用例」（补全模式为「已勾选 N/M 项」），随勾选实时更新，N/M 仅统计可勾选节点。

## 3. AI 补全步骤（US-AI-002）

**入口**：case 节点右键菜单「AI 补全步骤」。

### 3.1 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 发起补全 | 右键 case 节点 → 点击「AI 补全步骤」 | 打开生成抽屉（复用 2.1，标题变为「AI 补全用例」），自动带入节点上下文与关联需求条目，可临时粘贴补充文本；操作行主按钮为 [开始补全]（完成态按钮移至底部），与「AI 生成用例」面板的 [开始生成] 区分 |
| 生成与预览 | 点击 [查看预览]（底部） | 预览树仅含新增的前置条件/执行步骤/预期结果节点；**全部节点默认勾选、可逐项取舍**（与生成模式的用例级联勾选不同，见 2.2 勾选取舍）；已有的前置/步骤/预期保留不覆盖（仅补缺失项） |
| 确认追加 | 点击 [确认追加] | 追加为该 case 节点子节点，自动完成类型标记并带 AI 徽标 |
| 原 case 节点已被协同删除 | 确认时校验失败 | 提示「节点已被删除，无法挂载」——补全目标只能是原节点，**不提供重选** |
| 关闭抽屉后重开 | 关闭后再右键**同一 case 节点** → 点「AI 补全步骤」 | 恢复上次会话：补充文本、需求条目、补全结果（含「完成」态预览）原样呈现 |
| 目标节点更换 | 右键**另一 case 节点** → 点「AI 补全步骤」 | **重置为初始状态**：断开进行中的 SSE、清空补充文本与结果，按新节点重新加载关联需求条目 |
| 切换文档 | 脑图切换至另一文档（docId 变化） | **断开 SSE 并重置会话**（同 2.2） |

## 5. 优先级智能推荐（US-AI-003）

**触发**：节点被**手工单节点**标记为用例类型时（含既有节点重标记）；AI 生成节点已带优先级不触发，撤销/重做重放不触发。

### 5.1 呈现位置

标记面板（右键菜单标记域 / 工具栏优先级组）优先级按钮区上方显示推荐标签：

```
┌──────────────────────────────┐
│  ✨ 推荐 P0（点击采纳）       │  ← 非侵入推荐标签
│  [P0] [P1] [P2] [P3]         │  ← 优先级按钮区
└──────────────────────────────┘
```

> 取消标记按钮（⊗）属节点类型标记组（重置类型并清除优先级），不在优先级按钮区，此处不重复描述。

### 5.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 关键词规则命中 | 标记为用例类型瞬间 | 即时显示推荐标签（无 LLM 调用延迟） |
| 规则未命中 | 同上 | 后台发起 LLM 推荐，到达后再显示标签；请求进行中不阻塞任何操作 |
| 采纳推荐 | 点击推荐标签 | 直接完成优先级标记，标签消失 |
| 忽略 | 不操作 / 手工另选 | 用户已手工选择后到达的 LLM 结果直接丢弃 |
| 无推荐 | 规则未命中且 LLM 失败/超时 | 不显示任何标签（预期行为，无错误提示） |

│                              [+ AI 拆分] [+ 新建条目]      │
├──────────────────────────────────────────────────────────┤
│  标题        │ 来源URL │ 状态 │ 更新人 │ 更新时间 │ 操作    │
│  登录改版需求│ http…  │ 启用 │ 张三   │ 07-30    │编辑 删除 归档│

AI 拆分条目：标题前展示「AI」徽标（复用 AI 标识规范），其余操作与手工条目一致
```

#### 6.1.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 搜索 | 输入标题关键字后回车或点击 [查询]（带 Search 图标） | 列表刷新 |
| 状态筛选 | 下拉选择 全部 / 启用（active）/ 已归档（archived），可配合关键字组合查询 | 列表刷新；「全部」为默认 |
| 新建条目 | 点击 [+ 新建条目] | 右侧抽屉：标题（必填）+ Markdown 内容 + 来源 URL（仅作出处展示，平台不抓取）；创建后状态为「启用」 |
| 编辑条目 | 点击 [编辑] | 抽屉回显；仅条目创建人或具备项目管理权限的成员可见编辑/删除/归档操作；**已归档条目无 [编辑] 入口** |
| 删除条目 | 点击 [删除] | 二次确认：「删除不影响已生成的用例，文档关联将解除」→ 执行后列表刷新；已归档条目仍可删除 |
| 归档条目 | 点击 [归档] | 二次确认：「归档后条目不可编辑，且不再被 AI 功能选用」→ 执行后状态变「已归档」，刷新列表 |
| 取消归档 | 点击 [取消归档]（已归档条目） | 二次确认：「恢复为启用状态，重新参与 AI 选用」→ 执行后状态变「启用」 |
| 内容超限 | 内容长度超过系统配置上限 | 编辑器下方红字提示，禁用保存 |
| AI 拆分 | 点击 [+ AI 拆分]（US-AI-019） | 打开拆分对话框（见 6.1.3）；仅条目创建人或具备项目管理权限的成员可见（与编辑权限一致） |

│  │  ☑ 用户管理·编辑用户    [编辑] [删除]                   │  │

│  │  ☑ 用户管理·查询用户    [编辑] [删除]                   │  │
│  └───────────────────────────────────────────────────────┘  │

└──────────────────────────────────────────────────────────────┘
```

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 拆分 | 粘贴文档后点击 [AI 拆分] | SSE 流式：预览区按模块分组逐条填充（行内进度占位 + [停止] 按钮）；拆分为「模块 → 需求点[]」，一个需求点 = 一个可测试功能行为（固定细粒度）；文档超限时截断并红字提示 |
| 编辑预览条目 | 点击条目 [编辑] | 行内展开标题 + 内容（Markdown）编辑框，保存后更新预览 |
| 删除预览条目 | 点击条目 [删除] | 该条从预览移除，不再参与入库 |
| 全选 | 点击 [全选] | 全部条目勾选/取消；单个勾选实时更新「已选 n / 总数」计数 |
| 批量入库 | 点击 [批量入库] | 仅勾选条目入库；标题 = 模块名 + 「·」 + 需求点标题（模块名并入标题前缀）；条目 `ai_generated = true`，列表展示「AI」徽标；完成后对话框关闭、列表刷新并提示「已入库 n 条」 |
| 关闭 | 点击 [×] / 遮罩 | 未入库的预览结果丢弃，不产生任何数据 |

### 6.2 需求条目选取器（各 AI 入口复用）

供「AI 生成用例」「AI 补全步骤」「遗漏测试点分析」「用例规划智能推荐」调用的弹窗组件，**仅展示 active（启用）条目**，已归档条目不出现：

| ---- | ---- | ---- |
| 多选条目 | 勾选 | 底部显示已选数量 |
| 确定 | 点击 [确定] | 选中需求回填调用方入口，以标签展示 |

### 6.3 文档关联需求条目

- 脑图文档设置区提供「关联需求条目」入口，复用选取器多选（仅 active 条目可选）；
- 已关联条目在 AI 生成/补全时自动带入为默认上下文，入口内可临时改选；
- 关联随条目删除自动解除，界面无残留；条目归档后其历史关联不再展示（关联记录保留，取消归档后重新可见）。

## 7. AI 标识徽标

- AI 生成/补全/对话式编辑新增的节点统一携带「AI」徽标，位置与既有类型徽标并列（复用 badges.ts 徽标体系）；
- 徽标随节点复制/剪切粘贴保留到副本，随评审/计划快照继承；
- **移除**：右键菜单标记域仅在 `aiGenerated = true` 的节点上显示「移除 AI 标识」芯片，点击即移除；移除后不可重新添加（撤销回退除外），任何入口不提供手动添加；
- AI 标识不影响任何业务规则（评审、计划、执行照常）。

## 8. 通用交互模式总结

### 8.1 弹窗类型

| 类型 | 使用场景 |
| ---- | ---- |
| 抽屉 | AI 生成/补全面板（640px，右侧滑出、透明遮罩不压暗画布、点击空白关闭）、需求条目新建/编辑 |
| 居中弹窗 | AI 生成用例预览弹窗（脑图形式，宽 70% × 高 80%（视口），两窗并存时置顶） |
| 确认弹窗 | 条目删除、挂载目标重选 |
| 选择弹窗 | 需求条目选取器、挂载位置节点选择器 |

### 8.2 加载状态

- 流式生成：操作行内进度条占位（flex:1、与 [停止] 按钮同行左侧）+ [停止] 按钮；超 10 秒提示可取消重试（通用规范 2.3）。
- 同步推荐：按钮 loading，不阻塞脑图编辑。
- 需求池列表：首次骨架屏，刷新顶部进度条。

### 8.3 与协同编辑的关系

- 生成、预览期间文档保持可编辑，协同帧照常收发；
- 挂载经既有编辑内核与协同通道，协同用户实时可见；
- 一切 AI 引发的脑图变更均为单条撤销历史，Ctrl+Z 一次回退。
