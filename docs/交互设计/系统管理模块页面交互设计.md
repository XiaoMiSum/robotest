## 1. 引言

### 1.1 编写目的

本文档为 V1.2 迭代的系统管理模块页面交互设计**增量文档**，描述「数据概览」页按示例 `web/demos/admin/dashboard.html` 的整体重构，以及用户管理页因用户状态扩展「锁定」产生的交互变更，为前后端实现提供交互依据。

### 1.2 与基线的关系

- 上一基线：`docs/archive/v1.1/交互设计/系统管理模块页面交互设计.md`（V1.0/V1.1，已归档）。
- 本文档只写**新增/变更**内容：数据概览页整体替换基线第 2 章「仪表盘页」设计；用户管理仅描述状态「锁定」增量（基线第 3.1 节其余交互沿用）。
- 工作空间管理、角色管理页面沿用基线，本文档不重复描述。
- 本迭代明确**不提供**「导出报表」功能（示例中含该按钮，按需求裁剪）。
- 示例 KPI 脚注「接口调用 12.4k · 失败 0.3%」**不实现**（按需求裁剪，今日活跃卡片只展示主值与单位）。

### 1.3 定义与缩写

| 术语 | 定义 |
| ---- | ---- |
| 数据截至 | 统计接口返回的 `generatedAt`（统计生成时间），展示于页面副标题 |
| 登录人次 | 一次成功登录记 1 人次；同一用户当日多次登录累加（用于「今日活跃」KPI） |
| 活跃用户 | 某自然日内按用户去重的登录用户数（用于 14 日趋势图） |
| 锁定 | 用户状态 `locked`，由管理员设置，与「禁用」一样阻止登录 |

## 2. 数据概览页（V1.2 重构）

**路由**：`/admin/dashboard`
**菜单名**：数据概览（侧栏既有命名；基线中的「仪表盘」命名随之废弃）
**设计基准**：`web/demos/admin/dashboard.html`

### 2.1 页面布局

```
┌──────────────────────────────────────────────────────────┐
│ 数据概览                                  [刷新]          │ ← page-head（无「导出报表」）
│ 平台整体运行状态 · 数据截至 2026-09-23 09:00               │
├──────────────────────────────────────────────────────────┤
│ ┌用户总数───┐ ┌工作空间──┐ ┌项目总数──┐ ┌今日活跃──┐      │
│ │ 128 人    │ │ 16 个    │ │ 54 个    │ │ 63 人次   │      │
│ │较上周 +6  │ │活跃14    │ │近7日 +3  │ │（无脚注）  │      │
│ │· 启用 108 │ │·已解散 2 │ │          │ │          │      │
│ └───────────┘ └──────────┘ └──────────┘ └───────────┘      │

│ │  SVG 面积折线图 + 末点数值标签   │ │  环图 + 竖排图例 │    │

│ └──────────────────────────────────────────────┘            │
└──────────────────────────────────────────────────────────┘
```

### 2.2 KPI 卡片（4 张）

| 卡片 | 主值 | 单位 | 脚注文案（模板） |
| ---- | ---- | ---- | ------------ |
| 用户总数 | 用户总数 | 人 | `较上周 +{近7日新增用户} · 启用 {启用数}` |
| 工作空间 | 工作空间 | 个 | `活跃 {活跃数} · 已解散 {已解散数}` |
| 项目总数 | 项目总数 | 个 | `近 7 日新增 +{近7日新增项目}` |
| 今日活跃 | 今日登录人次 | 人次 | 无脚注（示例「接口调用 · 失败」按需求裁剪） |

**交互与文案规则**：

1. KPI 卡片为**纯展示**，不可点击、无跳转（与基线「统计卡点击跳转」不同，示例未提供入口）。
2. 正增量以绿色上标呈现（示例 `kpi__delta--up`）；增量为 0 时显示 `+0` 且用中性灰。
3. 统计口径（含「今日活跃」的定义）见 `docs/详细设计/系统管理模块详细设计说明书.md` §3.2。
4. 工作空间脚注中，示例文案「已归档」适配为平台实际状态**「已解散」**（平台空间无归档态，状态机为 active/dissolved）。

### 2.3 近 14 日活跃用户（面积折线图，占 2 列）

- 纯 SVG 实现（不引入图表库），高度 210，含 4 条水平网格线（基线 1 条加深、3 条浅色）。
- 数据：连续 14 个自然日（含当日），按日**去重**登录用户数；折线 + 半透明面积填充，末点高亮圆点并标注数值。
- 图例：「活跃用户」（单序列）。
- X 轴标签：首日、中间日、末日三个日期，格式 `MM-dd`。
- 空数据：14 个 0，折线贴基线，末点标注 `0`。

### 2.4 用户状态分布（环图）

- 三段环（环宽 14，半径 46），颜色与文案：

  | 状态 | 颜色 | 图例文案 |
  | ---- | ---- | ---- |
  | 启用 | `#67c23a`（成功绿） | `启用 {n}` |
  | 停用 | `#909399`（信息灰） | `停用 {n}` |
  | 锁定 | `#f56c6c`（危险红） | `锁定 {n}` |

- 环心：用户总数 + 「全部用户」。
- 用词约定：环图按示例使用「**停用**」；用户管理列表沿用既有「**禁用**」，二者为同一状态值 `disabled`。
- 空数据：灰底环 + 环心 `0`，图例各项为 0。

### 2.5 最近创建的空间（表格卡片）

- 卡片头：标题「最近创建的空间」+ 右侧链接「查看全部 →」→ `/admin/workspaces`。
- 列：空间名称 / 创建人 / 成员 / 项目 / 状态 / 创建时间。
  - 创建人：空间创建者姓名；历史数据无创建人时显示 `—`。
  - 状态：`活跃`（success 绿点）/ `已解散`（neutral 灰点），与空间管理列表用词一致。
  - 时间：`formatDateTime` 本地时区格式 `YYYY-MM-DD HH:mm`。
- 数据：复用空间列表接口，创建时间倒序，**每页 8 条**；页脚「共 {总数} 个空间」+ 页码按钮（总数 ≤ 每页条数时仅显示总数）。
- 行不可点击（示例未提供行内链接）；仅「查看全部」跳转。

### 2.6 页面头操作

| 操作 | 触发 | 行为 |
| ---- | ---- | ---- |
| 刷新 | 点击「刷新」按钮 | 重新拉取统计接口与空间表格第 1 页，按钮与页面进入 loading |
| 导出报表 | — | **不实现**（示例按钮按需求裁剪） |

### 2.7 状态分支

| 状态 | 表现 |
| ---- | ---- |
| 加载中 | 页面 `v-loading` 遮罩；数值与图表在数据到达前不渲染（初始 0 / 空态） |
| 正常 | 按 2.2–2.5 渲染；副标题展示「数据截至 {generatedAt}」 |
| 接口失败 | 顶部 Toast 报错（如「加载数据概览失败」）；已成功的区块保留展示，未加载区块维持空态 |
| 空数据 | KPI 显示 0；折线图贴基线、环图灰底 0；表格显示空态「暂无工作空间」 |
| 权限 | 菜单项对所有可进入 `/admin` 的用户可见（数据概览不设独立权限点）；路由守卫沿用既有 `requiresAdmin` |
| 未登录 | 沿用全局路由守卫跳转 `/login` |

### 2.8 状态管理

- 页面本地状态（ref），不入 Pinia；进入页面（`onMounted`）自动加载。
- 切换菜单后再次进入页面重新加载，不做跨页缓存。

## 3. 用户管理——状态扩展「锁定」（V1.2 增量）

> 基线第 3.1 节其余交互（搜索、批量、重置密码、分页等）不变，以下仅描述增量。

### 3.1 状态取值与筛选

- 用户状态三态：`active` 启用 / `disabled` 禁用 / `locked` 锁定。
- 状态筛选下拉新增「锁定」选项（启用 / 禁用 / 锁定）。

### 3.2 状态列展示

| 状态值 | 标签文案 | 标签类型 |
| ------ | -------- | -------- |
| active | 启用 | success |
| disabled | 禁用 | info |
| locked | 锁定 | danger |

### 3.3 行操作按钮

均需二次确认（沿用基线 1.2「危险操作二次确认」）：

| 当前状态 | 可用操作 |
| -------- | -------- |
| 启用 | 禁用、锁定 |
| 禁用 | 启用、锁定 |
| 锁定 | 启用、禁用 |

- 操作列宽由 200 调整为 240，容纳新增按钮。
- 批量操作维持「批量启用 / 批量禁用」，**不支持批量锁定**。

### 3.4 登录限制

- 禁用与锁定状态均无法登录；登录失败提示**不区分**禁用/锁定（沿用既有「账户已被禁用或登录凭证失效」，避免账号枚举）。
- 新建用户默认 `active`，不变。
