**文档版本**：V1.0  
**日期**：2026-09-23  
**状态**：起草中

---

## 1. 引言

### 1.1 编写目的

本文档为系统管理模块页面交互设计的完整文档，为前后端实现提供交互依据，涵盖管理端总体布局与全局交互规范（第 2 章）、数据概览页（第 3 章）、用户管理（第 4 章）、工作空间管理（第 5 章）、角色与权限管理（第 6 章）与通用交互模式总结（第 7 章）。

本版本范围约定：

- **数据概览页**为新版设计，按示例 `web/demos/admin/dashboard.html` 实现，整体替代原「仪表盘」页设计；该页不提供「导出报表」功能（示例中含该按钮，按需求裁剪），KPI 卡片亦不展示示例中的「接口调用 12.4k · 失败 0.3%」脚注，详见 3.2、3.6。
- **用户管理**在既有交互基础上扩展用户状态「**锁定**」：状态取值、展示、行操作与登录限制见 4.2；其余交互（搜索、批量操作、重置密码、分页等）保持不变。
- 工作空间管理、角色与权限管理的页面设计分别见第 5、6 章。

### 1.2 定义与缩写

| 术语 | 定义 |
| ---- | ---- |
| 数据截至 | 统计接口返回的 `generatedAt`（统计生成时间），展示于页面副标题 |
| 登录人次 | 一次成功登录记 1 人次；同一用户当日多次登录累加（用于「今日活跃」KPI） |
| 活跃用户 | 某自然日内按用户去重的登录用户数（用于 14 日趋势图） |
| 锁定 | 用户状态 `locked`，由管理员设置，与「禁用」一样阻止登录 |

## 2. 总体布局

### 2.1 管理端整体框架

管理端采用“左右结构”布局：

- **左侧**：固定宽度（180px）深色侧边栏，包含 Logo 和垂直导航菜单。
- **右侧**：自适应宽度内容区，分为顶部导航栏和主工作区。

```
┌──────────────────────────────────────────────────┐
│  Logo         管理端标题          [管理员] [退出] │ ← 顶部栏
├──────────┬───────────────────────────────────────┤
│ 数据概览 │                                       │
│ 用户管理 │         主工作区                       │
│ 工作空间 │      (根据路由切换内容)                │
│ 角色管理 │                                       │
│          │                                       │
├──────────┴───────────────────────────────────────┤
```

### 2.2 全局交互规范

- **表格操作**：危险操作（禁用、删除、解散）均需二次确认弹窗。
- **批量操作**：表格支持多选，选中后底部浮现操作栏。
- **消息反馈**：成功/失败操作使用 Toast 提示（顶部居中，3秒自动消失）。
- **表单校验**：前端实时校验并提示错误信息，提交时再次全量校验。
- **加载状态**：数据请求时表格显示骨架屏，按钮显示 loading 状态。

### 3.2 KPI 卡片（4 张）

| 卡片 | 主值 | 单位 | 脚注文案（模板） |
| ---- | ---- | ---- | ------------ |
| 用户总数 | 用户总数 | 人 | `较上周 +{近7日新增用户} · 启用 {启用数}` |
| 工作空间 | 工作空间 | 个 | `活跃 {活跃数} · 已解散 {已解散数}` |
| 项目总数 | 项目总数 | 个 | `近 7 日新增 +{近7日新增项目}` |
| 今日活跃 | 今日登录人次 | 人次 | 无脚注（示例「接口调用 · 失败」按需求裁剪） |

**交互与文案规则**：

1. KPI 卡片为**纯展示**，不可点击、无跳转（新版取消旧版统计卡的点击跳转，示例未提供入口）。
2. 正增量以绿色上标呈现（示例 `kpi__delta--up`）；增量为 0 时显示 `+0` 且用中性灰。
3. 统计口径（含「今日活跃」的定义）见 `docs/详细设计/系统管理模块详细设计说明书.md` §3.2。
4. 工作空间脚注中，示例文案「已归档」适配为平台实际状态**「已解散」**（平台空间无归档态，状态机为 active/dissolved）。

### 3.3 近 14 日活跃用户（面积折线图，占 2 列）

- 纯 SVG 实现（不引入图表库），高度 210，含 4 条水平网格线（基线 1 条加深、3 条浅色）。
- 数据：连续 14 个自然日（含当日），按日**去重**登录用户数；折线 + 半透明面积填充，末点高亮圆点并标注数值。
- 图例：「活跃用户」（单序列）。
- X 轴标签：首日、中间日、末日三个日期，格式 `MM-dd`。
- 空数据：14 个 0，折线贴基线，末点标注 `0`。

### 3.4 用户状态分布（环图）

- 三段环（环宽 14，半径 46），颜色与文案：

  | 状态 | 颜色 | 图例文案 |
  | ---- | ---- | ---- |
  | 启用 | `#67c23a`（成功绿） | `启用 {n}` |
  | 停用 | `#909399`（信息灰） | `停用 {n}` |
  | 锁定 | `#f56c6c`（危险红） | `锁定 {n}` |

- 环心：用户总数 + 「全部用户」。
- 用词约定：环图按示例使用「**停用**」；用户管理列表沿用既有「**禁用**」，二者为同一状态值 `disabled`。
- 空数据：灰底环 + 环心 `0`，图例各项为 0。

### 3.5 最近创建的空间（表格卡片）

- 卡片头：标题「最近创建的空间」+ 右侧链接「查看全部 →」→ `/admin/workspaces`。
- 列：空间名称 / 创建人 / 成员 / 项目 / 状态 / 创建时间。
  - 创建人：空间创建者姓名；历史数据无创建人时显示 `—`。
  - 状态：`活跃`（success 绿点）/ `已解散`（neutral 灰点），与空间管理列表用词一致。
  - 时间：`formatDateTime` 本地时区格式 `YYYY-MM-DD HH:mm`。
- 数据：复用空间列表接口，创建时间倒序，**每页 8 条**；页脚「共 {总数} 个空间」+ 页码按钮（总数 ≤ 每页条数时仅显示总数）。
- 行不可点击（示例未提供行内链接）；仅「查看全部」跳转。

### 3.6 页面头操作

| 操作 | 触发 | 行为 |
| ---- | ---- | ---- |
| 刷新 | 点击「刷新」按钮 | 重新拉取统计接口与空间表格第 1 页，按钮与页面进入 loading |
| 导出报表 | — | **不实现**（示例按钮按需求裁剪） |

### 3.7 状态分支

| 状态 | 表现 |
| ---- | ---- |
| 加载中 | 页面 `v-loading` 遮罩；数值与图表在数据到达前不渲染（初始 0 / 空态） |
| 正常 | 按 3.2–3.5 渲染；副标题展示「数据截至 {generatedAt}」 |
| 接口失败 | 顶部 Toast 报错（如「加载数据概览失败」）；已成功的区块保留展示，未加载区块维持空态 |
| 空数据 | KPI 显示 0；折线图贴基线、环图灰底 0；表格显示空态「暂无工作空间」 |
| 权限 | 菜单项对所有可进入 `/admin` 的用户可见（数据概览不设独立权限点）；路由守卫沿用既有 `requiresAdmin` |
| 未登录 | 沿用全局路由守卫跳转 `/login` |

### 3.8 状态管理

- 页面本地状态（ref），不入 Pinia；进入页面（`onMounted`）自动加载。
- 切换菜单后再次进入页面重新加载，不做跨页缓存。

### 4.2 状态扩展「锁定」

用户列表其余交互（搜索、筛选、批量操作、重置密码、分页等）见 4.1.1、4.1.2，保持不变；以下描述状态「锁定」相关设计。

#### 4.2.1 状态取值与筛选

- 用户状态三态：`active` 启用 / `disabled` 禁用 / `locked` 锁定。
- 状态筛选下拉新增「锁定」选项（启用 / 禁用 / 锁定）。

#### 4.2.2 状态列展示

| 状态值 | 文案 | 点标样式 |
| ------ | ---- | -------- |
| active | 启用 | success 绿点 |
| disabled | 禁用 | neutral 灰点 |
| locked | 锁定 | danger 红点 |

状态列采用验收基准的**点标**样式（圆点 + 文案），点标色义与原标签 success/info/danger 一一对应（info → neutral 灰）。

#### 4.2.3 行操作按钮

均需二次确认（沿用 2.2 全局交互规范的「危险操作二次确认」）：

| 当前状态 | 可用操作 |
| -------- | -------- |
| 启用 | 禁用、锁定 |
| 禁用 | 启用、锁定 |
| 锁定 | 启用、禁用 |

- 操作列宽由 200 调整为 240，容纳新增按钮。
- 批量操作维持「批量启用 / 批量禁用」，**不支持批量锁定**。

#### 4.2.4 登录限制

- 禁用与锁定状态均无法登录；登录失败提示**不区分**禁用/锁定（沿用既有「账户已被禁用或登录凭证失效」，避免账号枚举）。
- 新建用户默认 `active`，不变。

| 解散空间 | 点击[解散工作空间]       | 检查无项目 → 输入空间名确认 → 执行后跳转列表            |

## 6. 角色与权限管理

**路由**：`/admin/roles`

### 6.1 整体布局

页面采用左右分栏结构：

- **左侧**：角色类型树，宽度约260px，可调整。
- **右侧**：选中角色的详情面板，包含“权限配置”和“关联用户”两个Tab页。

```
┌──────────────────────────────────────────────────┐
│  角色管理                                        │
├─────────────┬────────────────────────────────────┤
│ 角色树      │  角色详情（tabs）                   │
│             │  [权限配置] [关联用户]              │
│ 📁 系统角色 │  ┌───────────────────────────┐     │
│  ├ 系统管理员│  │ 操作对象 │ 权限点(复选框) │     │
│  ├ 用户管理 │  │ 用户管理 │ ☑查看 ☑创建   │     │
│  └ 空间查看 │  │          │ ☐编辑 ☐禁用   │     │
│             │  │ 工作空间 │ ☑查看 ☐创建   │     │
│ [+添加]    │  │ ...     │ ...           │     │
│             │  └───────────────────────────┘     │
│             │  [撤销修改] [保存权限]             │
└─────────────┴────────────────────────────────────┘
```

### 6.2 左侧角色树交互

#### 6.2.1 树节点结构

- 根节点按角色类型分组（如“系统角色”），类型节点不可编辑、不可删除。
- 根节点下挂载具体角色节点，显示角色名称，支持内联操作。

#### 6.2.2 添加角色

- 点击根节点（如“系统角色”）右侧的 **[+]** 按钮，在对应类型下新增一个可编辑节点。
- 新增节点默认名称为空，输入框自动聚焦，用户输入角色名称。
- 输入框失去焦点后，前端校验名称是否为空及唯一性，校验通过则调用创建角色接口，提交 `name` 和 `type='system'`，`permissions` 初始为空数组。
- 创建成功后节点保留在树中，选中新节点可继续编辑权限。

#### 6.2.3 编辑角色名称

- 双击树节点，节点名称变为可编辑输入框。
- 修改文本后，输入框失去焦点，自动调用更新角色接口，提交新名称。
- 若名称校验失败（重复或为空），输入框重新聚焦并提示错误。

#### 6.2.4 删除角色

- 右键点击角色节点或选中后点击树工具栏的删除按钮，弹出二次确认。
- 系统预置角色（isSystem=true）不可删除，隐藏删除入口。
- 若角色被用户引用，弹出提示列出引用用户，阻止删除。
- 删除成功后，右侧清空详情，树节点移除。

#### 6.2.5 选择角色

- **单击**树节点，右侧加载该角色的详情面板，默认显示“权限配置”Tab。

### 6.3 右侧角色详情面板

#### 6.3.1 权限配置Tab

- 以**表格**形式展示权限点，表格包含两列：
  - **操作对象**：权限点所属的功能模块，例如"用户管理"、"工作空间管理"、"角色管理"等，同一模块的权限点合并为一个单元格。
  - **权限点**：该模块下所有的具体权限点，每个权限点名称后带有一个复选框。复选框勾选表示拥有该权限。
- 权限表格根据角色类型（system/workspace）过滤对应作用域（global/workspace）的权限点。
- **全量权限角色**（full_access=true）：权限配置面板锁定，所有复选框禁用，显示"该角色拥有全量权限"提示，[保存权限]按钮禁用。
- **非全量权限角色**：用户可正常勾选/取消复选框。
- 表格示例如下：

| 操作对象   | 权限点                                                |
| ------ | -------------------------------------------------- |
| 用户管理   | ☑ 查看用户   ☑ 创建用户   ☐ 编辑用户   ☐ 禁用/启用用户   ☐ 重置密码      |
| 工作空间管理 | ☑ 查看工作空间   ☐ 创建工作空间   ☐ 编辑工作空间   ☐ 解散工作空间   ☐ 管理成员 |
| 角色管理   | ☑ 查看角色   ☐ 创建角色   ☐ 编辑角色   ☐ 删除角色                  |

- **勾选规则**：
  - 每个权限点独立控制，点击复选框即可切换选中/取消状态。
  - 系统预置角色（如“系统管理员”）的已有权限对应的复选框为禁用状态（灰显，不可取消勾选），以保持核心权限不被误移除。新增的权限点可正常勾选。
- **撤销修改**：在未点击“保存权限”按钮前，可点击[撤销修改]按钮，将权限配置恢复到上次保存时的状态。本次所有未保存的修改会被丢弃。
- **保存权限**：点击[保存权限]按钮，收集所有选中的权限点code，调用更新角色接口。保存成功后Toast提示“权限已保存”，并更新权限快照。

#### 6.3.2 关联用户Tab

- 展示拥有当前角色的用户列表，分页显示（用户名、邮箱、状态、操作）。
- **添加用户**：点击[添加用户]按钮，弹出多选搜索弹窗，可搜索平台用户（仅显示启用状态的用户），选择后批量插入 `user_role` 关联。
- **移除用户**：每行用户有[移除]按钮，点击后二次确认，解除该用户与当前角色的关联。
- 操作完成后列表自动刷新。

## 7. 通用交互模式总结

### 7.1 弹窗类型

| 类型   | 使用场景               |
| ---- | ------------------ |
| 确认弹窗 | 删除、禁用、解散、移除关联等危险操作 |
| 表单弹窗 | 快速创建（如新建工作空间、添加成员） |
| 选择弹窗 | 多选用户关联角色、选择成员      |

### 7.2 加载状态

- **列表加载**：首次显示骨架屏，刷新显示顶部进度条。
- **表单提交**：按钮loading+禁用，完成恢复。
- **树节点操作**：添加/编辑/删除时节点局部loading或全局提示。

### 7.3 响应式处理

- 侧边栏小屏幕下可折叠为图标模式。
- 角色管理左右分栏在小屏幕下切换为上下布局，树组件可折叠。
