## 1. 总体布局

### 1.1 悬浮按钮与面板

助手悬浮按钮挂载于 BusinessLayout（业务模式：工作空间/项目页面），管理端布局不挂载；随 `aiEnabled` 显隐。

> **零影响约束（通用规范 2.7）**：悬浮按钮固定于右下角浮层，不占用页面内容区、不遮挡既有操作；`aiEnabled = false` 时按钮与面板整体隐藏，业务页面回退 V1.0 形态。助手的写操作与脑图编辑均经预览-确认-执行并复用既有 Service/编辑通道（权限、校验、审计不变），不存在绕过既有规则影响原有功能的路径。

```
┌──────────────────────────────────────────────────────────┐
│  顶部导航栏                                              │
├──────────────────────────────────────┬───────────────────┤
│                                      │  助手对话面板     │
│           业务页面内容区              │ （右侧抽屉滑出）  │
│                                      │                   │
│                                      │                   │
│                                 (✨) │                   │
└──────────────────────────────────────┴───────────────────┘
        右下角悬浮按钮 ↑
```

### 1.2 对话面板结构

```
┌───────────────────────────────────────────┐
│  ✨ 智能助手                      ─  ✕    │
├──────────┬────────────────────────────────┤
│ 会话列表  │  消息流                        │

│ ·…       │  │  🔧 工具过程卡片          │ │
```

## 2. 悬浮按钮

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 打开面板 | 点击悬浮按钮 | 右侧抽屉滑出；恢复最近一次会话（若有） |
| 最小化 | 面板 [─] 按钮 | 面板收起为悬浮按钮，**会话状态保持**（含进行中的流式回复） |
| 关闭 | 面板 [✕] 按钮 | 面板关闭；再次打开时重载会话列表 |
| 空间切换 | 用户切换工作空间 | 面板重置会话列表（会话按空间隔离），当前会话关闭 |

## 3. 会话管理

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 新建会话 | 点击 [＋新会话] | 消息流清空，首条消息发送后会话入列并本地置顶 |
| 切换会话 | 点击会话列表项 | 惰性拉取该会话全量消息渲染；50 条以上启用虚拟滚动 |
| 滚动加载 | 会话列表滚动至底部 | 携带游标拉取下一页追加渲染（加载中显示骨架条）；无更多后不再触发 |
| 发送消息置顶 | 发送消息 / 新建会话 | 对应会话本地置顶，不重拉列表 |
| 清空会话 | 会话项操作菜单 [清空] | 二次确认 → 删除该会话记录 |

- 会话内容仅本人可见；会话按工作空间隔离。

## 4. 消息交互

### 4.1 消息发送与流式回复

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 发送消息 | 输入 + 回车 / [发送] | 用户消息即时上屏；助手回复 SSE 流式逐字渲染 |
| 流式期间 | 回复进行中 | **输入框禁用** + [发送] 变为 [停止] 按钮 |
| 停止回复 | 点击 [停止] | 断开 SSE（服务端联动取消上游），已渲染内容保留为最终消息 |
| 超时提示 | 首帧超 10 秒 | 消息气泡内提示「响应较慢，可停止重试」（通用规范 2.3） |

### 4.2 消息渲染规则

- 助手消息以 Markdown 渲染，**链接白名单过滤**：仅渲染站内相对路径（`/` 开头且匹配已注册路由前缀），外部 URL 一律降级为纯文本；
- 查询结果以列表 / 数字 / 站内链接形式呈现，点击链接跳转对应业务页面；
- 查询不到的数据，助手明确回复「查询不到」，不虚构。

### 4.3 工具过程卡片

助手调用只读工具（查询评审 / 计划 / 缺陷 / 用例）时，消息流内插入过程卡片：

```
┌────────────────────────────┐
│ 🔧 正在查询：我参与的评审   │  ← 执行中：loading 态
│ ✓ 查询完成（5 条结果）      │  ← 完成：结果概要
└────────────────────────────┘
```

- 过程卡片默认折叠为一行，可展开查看调用摘要；用户无权限的数据不返回、不展示。

## 5. 快捷操作执行（US-AI-012）

写操作（白名单制，首期仅创建缺陷、创建计划草稿）强制预览-确认-执行，通过**确认卡片**承载：

### 5.1 确认卡片布局

```
┌──────────────────────────────────────┐
│ 📋 待确认操作：创建缺陷               │
│ ┌──────────────────────────────────┐ │
│ │ 项目     │ 项目X                  │ │
│ │ 标题     │ 登录超时               │ │
│ │ 优先级   │ P1（高）               │ │
│ │ …字段明细表格…                    │ │
│ └──────────────────────────────────┘ │
│ 剩余确认时间 04:32                    │
│              [取消]  [确认执行]       │
└──────────────────────────────────────┘
```

### 5.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 收到确认请求 | 助手判定需执行写操作 | 消息流插入确认卡片（操作明细表格 + 倒计时），流式循环暂停等待 |
| 确认执行 | 点击 [确认执行] | 卡片状态更新为「执行成功」+ 结果跳转链接；助手生成收尾答复 |
| 取消 | 点击 [取消] | 卡片置「已取消」，操作放弃，助手答复确认取消 |
| 确认超时 | 倒计时归零（默认 5 分钟） | 卡片置「已超时」不可操作，操作放弃 |
| 执行失败 | 后端校验失败 | 卡片展示失败原因（与人工操作相同的业务校验与提示） |

- 写操作与人工操作产生完全相同的审计记录与业务校验；任何写操作不得跳过确认。

## 6. 对话式脑图编辑（US-AI-013）

### 6.1 页面上下文桥

- 脑图编辑页挂载时向助手注入上下文：当前项目、当前文档、选中节点；选中变化实时更新；
- 非脑图页仅注入当前项目（若在项目内）；
- 上下文使助手能消歧「当前用例」「这个节点」等指代。

### 6.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 发出编辑指令 | 脑图页内对助手说「为当前用例增加一个步骤…」 | 助手翻译为脑图操作指令，回复「已准备好编辑预览，请确认」 |
| 执行预览 | 消息流内 DSL 预览执行入口 | **复用脑图 AI 指令的命中预览确认弹窗**（命中数量 + 清单 + 跳过项） |
| 确认执行 | 预览弹窗确认 | 前端经编辑内核批量执行，单条撤销历史；新增节点带 AI 徽标；消息流追加本地提示「已执行」 |
| 取消执行 | 预览弹窗取消 | 消息流追加本地提示「已取消」，无任何变更 |
| 已离开文档页 | 编辑指令到达时不在对应文档 | 提示「请回到文档后重试」，指令丢弃不缓存 |
| 无文档上下文 | 非脑图页发出编辑指令 | 助手回复「请在脑图编辑页使用该能力」 |
| 指令歧义 | 翻译置信不足 | 助手以文本追问澄清，不做模糊执行 |
| 无编辑权限 | 权限校验失败 | 助手回复无权限提示 |

## 7. 平台使用指引（US-AI-014）

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 询问使用方法 | 如「如何发起评审？」 | 助手返回步骤指引 + 可点击的页面路由链接 |
| 点击指引链接 | 消息内站内链接 | 跳转对应功能页面（面板保持最小化可回） |
| 知识库外问题 | 无命中知识片段 | 明确回复「该问题超出使用指引范围」，不杜撰功能 |

- 使用指引为纯只读能力，任何角色的业务用户均可使用；指引内容按用户角色过滤（不展示无权使用的功能指引）。

## 8. 通用交互模式总结

### 8.1 卡片类型

| 类型 | 使用场景 |
| ---- | ---- |
| 工具过程卡片 | 只读工具调用过程与结果概要 |
| 确认卡片 | 写操作预览-确认-执行（含倒计时） |
| DSL 预览入口 | 对话式脑图编辑的执行确认 |

### 8.2 加载状态

- 消息回复：流式逐字渲染 + 打字光标；输入框禁用 + [停止] 按钮；
- 会话列表：滚动加载骨架条；
- 消息历史：50 条以上虚拟滚动，保障长会话性能。

### 8.3 状态保持与重置

| 场景 | 行为 |
| ---- | ---- |
| 最小化 | 会话与流式回复保持 |
| 页面路由切换（同空间） | 面板状态保持 |
| 工作空间切换 | 会话列表重置，当前会话关闭 |
| AI 开关关闭 | 悬浮按钮与面板隐藏，进行中回复中断并提示 |
