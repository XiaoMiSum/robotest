## 1. 概述

### 1.1 模块范围

本文档覆盖 V1.2 接口测试业务域（承接 SRS 3.7.1 环境管理）的环境管理能力：

**环境管理**——环境 CRUD、默认配置（http 默认配置）、环境变量、数据源、全局前置/后置处理器、环境导入导出。

### 1.2 侧边栏菜单与路由

V1.2 项目模式顶部菜单在既有「功能测试」「缺陷管理」之外**新增「接口测试」入口**（增量见 `docs/交互设计/全局导航与菜单交互系统设计.md` 3.3）。接口测试页面内部采用侧边栏组织子模块：

### 1.3 场景与环境的业务关系

- **环境**为执行提供变量、Base URL、默认配置、数据源与全局处理器；场景执行时必须选择目标环境（可配置默认环境）。
- **场景**是核心执行单元：由**步骤**（http/jdbc 取样器）按顺序编排而成，步骤可来源于接口定义（复制或链接引用）、公共步骤或自定义请求。场景编排交互见 `docs/交互设计/测试场景交互设计.md`。
- 变量解析优先级（低→高）：**内置函数 < 环境变量 < 场景变量 < 步骤级变量 < 步骤提取器变量 < 运行时覆盖**（见 `docs/详细设计/测试场景详细设计说明书.md` 4.1）。
- 配置合并优先级（低→高）：**环境默认配置 < 场景级配置 < 步骤级配置**，同名配置项以高优先级覆盖。

## 2. 环境管理页

**路由**：`/workspace/projects/settings/environments`

> 环境管理归入侧边栏「项目设置」分组（平台级项目配置入口，见 `docs/交互设计/全局导航与菜单交互系统设计.md` 3.5）。

### 2.1 页面布局

```
┌──────────────────────────┬───────────────────────────────────┐
│  搜索环境名称...   [+ 新增 ▾]│  [HTTP(2)] [变量] [数据源] [处理器]│
│  测试环境  [默认] [项目]     │  ── HTTP 配置列表 ────────────────  │
│   · 2H 5V 2D 1P          │  内部 API       https://staging…  │
│  [上移][编辑][复制][删除]    │  第三方支付     https://pay…      │
│  预发环境  [设为默认] [项目]  │  [+ 新建配置]   [连接测试]          │
│   · 8V                    │  ────────────────────────────────  │
│  （默认环境置顶）           │  名称    [内部 API          ]     │
│  （行内操作仅悬浮显示）       │  引用名  [internal-api      ]     │
│                          │  Base URL [https://staging… ]     │
│                          │  请求头  [+ 添加]                  │
│                          │  （逐条即时保存：新增/编辑/删除）    │
│                          │  （数据源连接测试见「数据源」标签页） │
├──────────────────────────┴───────────────────────────────────┤
│  默认环境说明：场景执行未指定环境时使用默认环境                 │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 环境列表交互

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 进入页面 | 侧边栏点击「环境管理」 | 左侧加载环境列表（默认环境置顶，其余按排序），骨架屏加载 |
| 搜索 | 左侧搜索框输入 | 防抖 300ms 过滤列表 |
| 选中环境 | 点击列表项 | 列表项高亮，右侧加载环境详情（HTTP、变量、数据源、处理器） |
| 新建环境 | 点击搜索框右侧 [+ 新增 ▾] 主按钮 | 新增弹窗（名称、描述、是否设为默认），确认后创建并自动选中 |
| 导入/导出 | [+ 新增 ▾] 右侧下拉 [导入环境] / [导出当前环境] | 导入：JSON 文件 + 重名处理开关；导出：下载当前选中环境 JSON |
| 设为默认 | 列表行内（悬浮）[设为默认]（非默认环境显示，默认环境显示「默认」标签；按钮仅悬浮/聚焦行时展示） | 二次确认 → 默认标记转移至该环境（项目内唯一），列表排序刷新 |
| 调整排序 | 列表行内（悬浮）[上移]/[下移] | 相邻互换排序，列表顺序即时更新并保存 |
| 编辑环境 | 列表行内（悬浮）[编辑] | 弹出「编辑环境」弹窗（名称、描述、设为默认），确认后保存并刷新列表，不切换右侧面板编辑态 |

> 列表行内操作（上移/下移/编辑/复制/删除）默认隐藏，鼠标悬浮或键盘聚焦该行时展示；行元信息展示 HTTP / 变量 / 数据源 / 处理器数量。

### 2.3 环境详情编辑

环境详情右侧面板含四个标签页（面板不展示环境名称与描述，环境名称/描述仅在新增与编辑弹窗维护）：

| 标签页 | 内容与交互 |
| ---- | ---- |
| HTTP | HTTP 配置列表（标签页显示数量），支持多个：每个配置含名称、引用名（ref_name）、Base URL、请求头（键值对编辑器）。缺省方法为 GET、跟随重定向、响应/连接超时与 SSL 校验为固定值（见 `docs/详细设计/环境管理详细设计说明书.md`），无默认 HTTP 配置概念；[+ 新建配置] 新增（新增即创建）、行内编辑 [保存修改] 生效、[删除配置] 移除（二次确认），无全局【保存】按钮与未保存标记；行内 [连接测试] 验证连通性（见 2.5） |
| 变量 | 环境变量编辑器，完整交互见第 3 章 |
| 数据源 | 数据源列表（名称、驱动、URL），交互同「HTTP」：左侧列表 + 右侧内联表单（名称、引用名称（ref_name）、驱动下拉（内置常见数据库驱动，切换后自动填充对应 URL 示例，用户名密码写入 URL；Redis 驱动显示 '-' 仅占位满足后端必填，连接按 redis:// 协议识别）、连接 URL、连接池上限）；[+ 新增数据源] 新增并选中（新增即创建）、行内编辑 [保存修改] 生效、[删除数据源] 移除（二次确认）；行内 [连接测试] 验证连接（见 2.5） |
| 处理器 | 全局前置/后置处理器列表，交互同 `docs/交互设计/测试场景交互设计.md` 3.5 场景级处理器，仅作用于该环境下的所有请求 |

### 2.4 环境类型区分

- **项目环境**（V1.2 全部环境均为项目级）：环境归属项目，仅当前项目成员可见可用；列表类型徽标显示「项目」。
- **全局环境**（预留扩展）：平台级环境，由系统管理员在管理端维护，对所有项目共享。V1.2 不提供维护入口，界面为类型徽标预留「全局」样式与展示位，切换逻辑待全局环境能力落地后补充。

### 2.5 复制、导入导出与删除

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 复制环境 | 行内（悬浮）[复制] | 弹窗输入副本名称（默认「原名称（副本）」）；复制内容含 HTTP 配置、变量与处理器（数据源不复制，需重新配置）；确认后创建并选中 |
| 导入环境 | [+ 新建 ▾] 下拉 → [导入环境] | 弹窗选择 JSON 文件 + 「重名处理」开关（开启覆盖 / 关闭跳过）；导入结果弹窗展示新增/覆盖/跳过数量 |
| 导出环境 | [+ 新建 ▾] 下拉 → [导出当前环境] | 下载当前选中环境的 JSON 配置文件，敏感字段脱敏（见需求 3.5） |
| 测试数据源连接 | 行内 [连接测试] | 按钮 loading → 真实建立 JDBC 连接；成功 Toast「连接成功」+ 数据库版本；失败明确提示原因（错误码 7403） |
| 测试 HTTP 配置连接 | HTTP 配置行内 [连接测试] | 按钮 loading → 向配置的 base_url 发送 GET 请求验证连通性；成功 Toast「连接成功」+ 状态码与耗时；失败明确提示原因 |
| 删除环境 | 行内（悬浮）[删除] | 二次确认弹窗；若环境被场景引用，**禁止删除**，弹窗列出引用场景清单并提示「请先在场景中解除引用」（错误码 7402）；被定时任务绑定同理（错误码 7404） |

### 2.6 页面状态

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 左侧列表 + 右侧详情；列表行内操作默认隐藏，鼠标悬浮/聚焦行时展示；默认环境显示「默认」标签，非默认环境悬浮显示 [设为默认]；详情面板 HTTP/数据源逐条即时保存，无全局【保存】按钮与「未保存」标记 |
| 空态 | 无任何环境：左侧空态插图 + 「暂无环境，点击新建」；搜索无结果：「无匹配环境」+ [清除搜索] |
| 加载态 | 列表与详情首次加载骨架屏；数据源连接测试按钮 loading；导入文件解析中弹窗进度提示 |
| 错误态 | 列表拉取失败：占位 + [重试]；详情拉取失败：右侧面板错误占位 + [重试]；保存失败：Toast 明确原因（如环境名称重复，错误码 7401） |

## 3. 环境变量编辑器

**位置**：环境管理页详情面板「变量」标签页（复用组件，场景编排页「场景参数」标签使用同结构组件，作用域不同）。

### 3.1 页面布局

```
┌──────────────────────────────────────────────────────────────┐
│  环境变量                                [导入] [导出] [+ 新增变量]│
├──────────────────────────────────────────────────────────────┤
│  变量名     │值            │描述    │操作                     │
│  BASE_URL  │https://…     │默认地址│编辑│删除                │
│  TEST_PASS │123456        │测试密码│编辑│删除                │
│  userId    │1001          │用户 ID │编辑│删除                │
│  orderNo   │SO-20260817   │单号    │编辑│删除                │
├──────────────────────────────────────────────────────────────┤
│  引用语法：${变量名}，如 ${BASE_URL}；支持内置函数，如         │
│  ${random(1,100)}、${timestamp()}。点击 [函数帮助] 查看函数列表│
└──────────────────────────────────────────────────────────────┘
```

### 3.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 新增变量 | 点击右上角 [+ 新增变量] | 表格末尾追加空行进入编辑态（变量名、值、描述），行内 [完成] 即时保存；变量名校验：仅字母/数字/下划线，不得与既有变量重名 |
| 编辑变量 | 行内 [编辑] | 行内变为输入态，[完成] 点击即校验并保存（无底部保存按钮）；取值明文展示与编辑 |
| 删除变量 | 行内 [删除] | 直接移除该行并即时落库 |
| 批量导入 JSON | 点击右上方 [导入] | 打开文本编辑弹窗，粘贴 `[{name,value,description}]`；解析后预览新增/冲突清单，冲突行提示重名，可取消冲突行后导入 |
| 导出变量 | 点击右上方 [导出] | 下载 JSON 文件（变量值明文导出） |
| 编辑保存 | 行内 [完成] | 全量校验（名称必填且唯一）→ 提交；成功 Toast + 刷新行列表；保存失败行内红字提示 |

### 3.4 变量引用与快捷使用

- 变量引用统一 `${变量名}` 语法，引用不存在变量时执行保留字面量并在执行日志警告（不阻断执行，见需求 3.10）；
- 变量名输入/表达式编辑输入框（步骤 URL、参数值、断言期望值、处理器配置等）在输入 `$` 或 `${` 时弹出**变量自动补全**下拉：列出当前环境变量、场景变量、步骤级变量、步骤提取器变量，标注来源层级（环境/场景/步骤/提取器）；
- [函数帮助] 弹窗展示内置函数列表（分组：数据生成、日期时间、数据处理、安全加密），每条含函数签名、参数说明、示例与 [插入] 按钮，点击后插入当前光标位置（见需求 3.10）；
- 从执行结果快速添加：单步骤调试结果浮层或报告详情中，选中响应提取片段 → 右键/操作菜单「添加为环境变量」→ 预填变量名与值，确认后写入当前环境变量表。

### 3.5 页面状态

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 表格展示变量；变量名按字母序排列（同环境内）；行数超过 10 条时分页展示 |
| 空态 | 无变量：表格区展示「暂无变量，点击右上角新增」；右上角 [导入] [新增变量] 可用 |
| 加载态 | 变量列表随环境详情骨架屏加载；批量导入解析中弹窗 loading |
| 错误态 | 变量保存失败：行内红字提示原因（重名/格式非法）；批量导入解析失败：弹窗内错误清单与原因，[重试] |
