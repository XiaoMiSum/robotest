# 软件测试平台——视觉设计

**文档版本**：V1.0  
**日期**：2026-09-22  
**状态**：已发布  

---

## 1. 设计目标

为软件测试平台定义统一的视觉体系，确保：

- 色彩与 **Element Plus 官方色板**同源（精确色值以 Element Plus `var.scss` 为准），自研样式与组件库颜色一致，降低维护成本。
- 导航摆脱 element-admin 既视感：**浅色白底顶栏 + 悬浮卡片侧栏 + 悬浮白卡内容区**。
- 状态标识（通过、失败、阻塞、未执行等）语义明确，一律**颜色 + 形状 + 文案三重编码**，不单靠颜色区分。
- 字体使用系统字体栈（不引外部字体），图标线条扁平化，阴影收敛低对比。
- 符合企业级产品的专业、稳重、高效定位。

**修订说明**（V1.0 原位修订）：原「专业蓝 + 管理端蓝灰 / 业务端蓝绿双色相」体系整体替换为 Element Plus 官方色板；深色侧栏改为浅色悬浮壳层，内容区布局采用方案 B（见 6）；缺陷「一般」由黄色改为信息灰、「轻微」由灰改绿（见 4.1 / 4.3）。视觉验收基准为演示稿 `web/demos/`（纯静态资源，不参与前端构建）。

## 2. 色彩体系总览

### 2.1 主色——Element Plus Primary

品牌主色采用 Element Plus primary 蓝，**仅用于交互**：主按钮、链接、选中态、焦点提示；**不表达任何状态**（状态一律使用第 4 节语义色）。

| 色阶            | 色值        | EP 对应   | 用途            |
| ------------- | --------- | ------- | ------------- |
| Primary-50    | `#ECF5FF` | light-9 | 选中态浅底、浅色背景   |
| Primary-100   | `#C6E2FF` | light-7 | 图表辅助、渐变端点    |
| Primary-200   | `#A0CFFF` | light-5 | 图表辅助         |
| Primary-300   | `#8CC5FF` | light-4 | 图表辅助         |
| Primary-400   | `#79BBFF` | light-3 | 图表辅助         |
| Primary-500   | `#409EFF` | base    | **主色**：主按钮、链接、选中态 |
| Primary-600   | `#337ECC` | dark-2  | 按钮悬停态        |
| Primary-700   | `#337ECC` | dark-2  | 按钮按下态（EP 最深阶，同值复用） |

> Element Plus 无 Primary-800/900 更深阶，旧版对应色阶废除。

### 2.2 状态功能色——Element Plus 四功能色

| 名称      | 色值        | 强调档（dark-2） | 浅底（light-9） | 语义范围            |
| ------- | --------- | ----------- | ----------- | --------------- |
| Success | `#67C23A` | `#529B2E`   | `#F0F9EB`   | 通过 / 正常 / 轻微    |
| Warning | `#E6A23C` | `#B88230`   | `#FDF6EC`   | 警告 / 进行中 / 严重    |
| Danger  | `#F56C6C` | `#C45656`   | `#FEF0F0`   | 失败 / 致命 / 高风险；dark-2 兼作**阻塞**档 |
| Info    | `#909399` | —           | `#F4F4F5`   | 未执行 / 一般等中性信息   |

### 2.3 模式色相说明

旧版「管理端蓝灰 / 业务端蓝绿」独立色相**废除**：管理模式、空间模式、项目模式统一使用本文色板，模式差异由导航结构表达（见 6.3），不再引入独立色相。

## 4. 语义色体系

### 4.1 状态色

**三重编码原则**：状态一律「颜色 + 形状 + 文案」同时呈现（如彩色圆点 / 图标 + 色块 + “通过”字样），禁止仅靠颜色区分；蓝色不表达任何状态。

| 语义                  | 色值        | 浅底        | 边框色       | 典型状态                       |
| ------------------- | --------- | --------- | --------- | -------------------------- |
| 通过 / 正常 / 轻微        | `#67C23A` | `#F0F9EB` | `#C2E7B0` | 用例通过、账号启用、缺陷轻微            |
| 失败 / 致命 / 高风险        | `#F56C6C` | `#FEF0F0` | `#FBC4C4` | 用例失败、致命缺陷、P0              |
| 阻塞（danger dark-2 深档） | `#C45656` | `#F9EEEE` | `#E7BBBB` | 用例阻塞（与失败同相、以深浅区分）          |
| 警告 / 进行中 / 严重        | `#E6A23C` | `#FDF6EC` | `#F5DAB1` | 警告、执行中、严重缺陷、P1            |
| 未执行 / 待评审 / 停用 / 一般  | `#909399` | `#F4F4F5` | `#E4E7ED` | 未执行、待评审、账号停用、缺陷一般（信息灰）    |

> 原「暗黄档」废除：缺陷「一般」与「未执行」同用 EP info 灰，依赖文案 + 形状三重编码区分场景。
> 进行中徽标在信息灰与橙之间按语义取橙（进行中 = Warning 相），「未执行」取信息灰。

### 4.2 用例优先级色

| 优先级 | 色值        | 对应功能色   | 说明       |
| --- | --------- | ------- | -------- |
| P0  | `#F56C6C` | danger  | 红色，最高优先级 |
| P1  | `#E6A23C` | warning | 橙色，高优先级  |
| P2  | `#409EFF` | primary | 蓝色，中优先级  |
| P3  | `#909399` | info    | 灰色，低优先级  |

变量：`--color-priority-p0` ~ `--color-priority-p3`。

### 4.3 缺陷等级色

| 等级  | 色值        | 对应功能色  | 说明               |
| --- | --------- | ------ | ---------------- |
| 致命  | `#F56C6C` | danger | 红色               |
| 严重  | `#E6A23C` | warning | 橙色               |
| 一般  | `#909399` | info   | 信息灰（原黄色档废除，按确认改为信息灰） |
| 轻微  | `#67C23A` | success | 绿色（按确认：轻微 = 绿）    |

用于脑图中不同节点类型的视觉区分，以圆角色块徽标渲染在节点文本左侧（与 `badges.ts` 实现及详细设计 4.1 一致）。

| 节点类型       | 色值        | 样式                                   |

## 6. 导航与壳层结构

### 6.1 壳层形态（浅色 + 悬浮卡片）

- **顶栏**：白底、全宽固定，高 52px，底部 `Neutral-200` 描边；承载 logo、面包屑、动态菜单、用户区。
- **侧栏**：**悬浮卡片**，`top/left/bottom` 各留 16px（顶边与内容卡对齐，与内容卡间距 16px），宽 180px；白底、`Neutral-200` 描边、12px 圆角、`--shadow-float` 浮影。
- **内容区（方案 B）**：主体整体为**一张悬浮白卡**，四周 16px 页边距，内边距 32px，与侧栏卡同描边、同圆角、同浮影，形成对称双卡。
- **页面底**：`Neutral-50`（`#F5F7FA`），透过卡片四周留白可见，构成「灰底浮白卡」的层次。
- 双栏页（功能测试 / 接口测试 / 需求 / 计划 / 评审等）：内容容器透明让位，拆分为「模块侧栏卡 + 主内容卡」并排，两张等高悬浮卡片同规格。

```
┌──────────────────────────────────────────────────┐
│ 顶栏（白底 · 52px · 全宽固定 · 底部描边）              │
├───────────────────────────────────────────────────┤
│ 页面底 #F5F7FA（顶栏下留 16px，两卡顶边对齐）             │
│  ┌──────┐  ┌────────────────────────────────────┐  │
│  │ 侧栏  │  │ 内容区（悬浮白卡 · 四周 16px 页边距）    │  │
│  │ 悬浮  │  │  ┌──────────────────────────────┐  │  │
│  │ 卡片  │  │  │ 页头 + 卡片（内边距 32px）        │  │  │
│  │ 180px│  │  └──────────────────────────────┘  │  │
│  └──────┘  └────────────────────────────────────┘  │
└───────────────────────────────────────────────────┘
   两卡均为白底 12px 圆角 + 浮影；顶边同在顶栏下 16px
```

### 6.2 导航元素色

| 元素          | 色值        | 变量                   | 说明          |
| ----------- | --------- | -------------------- | ----------- |
| 顶栏 / 侧栏背景   | `#FFFFFF` | `--shell-bg`         | 白底          |
| 顶栏 / 卡片描边   | `#E4E7ED` | `--shell-border`     | 1px 描边      |
| 导航 / 菜单文字   | `#606266` | `--shell-text`       | 常规项         |
| 强文字（logo 等） | `#303133` | `--shell-text-strong`| 强调          |
| 菜单 hover 底 | `#F5F7FA` | `--shell-item-hover` | 浅灰          |
| 菜单选中底      | `#ECF5FF` | `--shell-item-active`| 浅蓝底 + `#409EFF` 文字 |
| 动态菜单选中     | `#409EFF` | `--color-primary-500` | 蓝色文字 + 底部指示条 |
| 页面底        | `#F5F7FA` | `--color-neutral-50`  | 灰底          |

### 6.3 模式区分（结构而非色相）

三模式导航元素色值完全一致（见 6.2），差异由结构表达：

- **管理模式**：固定悬浮模块侧栏（用户、空间、角色、AI 配置等）+ 内容卡。
- **空间模式**：顶栏动态菜单，无侧栏，内容区为整幅悬浮白卡。
- **项目模式**：顶栏动态菜单 + 双栏页时的模块侧栏卡（需求 / 用例 / 计划 / 评审 / 接口调试等）。
