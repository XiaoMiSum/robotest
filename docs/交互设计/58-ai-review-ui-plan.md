## 6. 用例规划智能推荐（US-AI-018）

**入口**：评审详情页「调整用例」流程与计划详情页「调整用例」流程中的 [✨AI 推荐用例] 按钮，打开抽屉。推荐抽屉为评审/计划共用组件，仅「带入」目标不同。

### 6.1 推荐抽屉布局

推荐抽屉为右侧滑出抽屉（640px，透明遮罩不压暗画布、点击空白关闭，统一规格见 `docs/交互设计/README.md` 2.9）：

```
┌────────────────────────────────────────────┐
│  ✨ AI 推荐用例                         ✕  │
├────────────────────────────────────────────┤
│  需求输入（条目 / 文本至少一项非空）         │
│  需求池                      [+ 选择需求]      │
│  （已选条目标签 / 未选择需求条目）           │
│  需求文本 [粘贴文本域…]                     │
│  ▓▓▓▓░░░░（推荐中虚假进度条）               │
│                              [取消] [开始推荐]│
├────────────────────────────────────────────┤
│  推荐清单（已自动排除当前评审/计划中用例）   │
│  ☑ 登录 > 密码登录 > 密码错误   理由：…     │
│  ☑ 支付 > 收银台 > 余额不足     理由：…     │
│  ☐ …                                        │
│                             [加入评审（5）]  │
│                             [加入计划（5）]  │
└────────────────────────────────────────────┘
```

### 6.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 输入需求 | 选取需求池条目（可多选，复用选取器）或粘贴需求文本 | 条目与文本可组合，至少一项非空；形态同 4.2 |
| 开始推荐 | 点击 [开始推荐] | 同步长调用（前端超时 70s）：操作行右侧持续加载态（虚假进度条占位）+ [取消] 按钮 |
| 查看清单 | 推荐完成 | 建议用例清单（含所属模块路径与推荐理由），逐条可勾选，默认全选 |
| 带入评审/计划 | 点击 [加入评审] / [加入计划] | 携带勾选用例进入**既有**「调整用例」关联流程，最终关联由用户在该流程中确认 |
| 语义降级 | 结果携带降级标志 | 提示条「当前为关键词匹配结果」（通用规范 2.6） |

- 按钮三区职责化（统一 AI 抽屉规格 2.9）：需求选取按钮置于需求池行最右侧，已选条目标签或「未选择需求条目」提示独占下一行；[开始推荐] 与 [取消] 置于操作行（右侧对齐，推荐中进度条占位），[加入评审] / [加入计划] 仅置于底部（右侧）且仅在推荐完成后显示；抽屉以透明遮罩承载，点击空白或标题栏 ✕ 关闭；
- 推荐范围限定当前项目；已纳入当前评审/计划的用例由前端在发起推荐时传入排除，不重复推荐；
- 推荐结果不自动写入任何关联，抽屉关闭不保留本次推荐结果。
