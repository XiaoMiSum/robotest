## 1. 概述

### 1.1 模块范围

本文档覆盖 V1.2 接口测试业务域（承接 SRS 3.7 项目设置）的以下内容：

1. **项目设置框架交互**——平台级统一入口在各业务域侧边栏的呈现规则、域归属过滤、权限控制；
2. **安全策略与应用设置页**——报告分享开关、分享链接有效期等配置项的维护交互（承接 SRS 3.7.4）。

环境管理、全局资产、GitLab 仓库配置的页面交互分别见 `docs/交互设计/环境管理交互设计.md`、`docs/交互设计/全局资产交互设计.md`、`docs/交互设计/GitLab集成交互设计.md`，本文档不重复描述。

### 1.2 菜单与路由

「项目设置」分组固定位于接口测试侧边栏末尾（完整侧边栏树见各分册 1.2），以分隔线与业务功能区分隔：

| 页面 | 路由 | 模式 | 权限 |
| ---- | ---- | ---- | ---- |
| 环境管理 | `/workspace/projects/settings/environments` | 项目模式 | 项目成员查看/使用；项目维护者维护 |
| 函数管理 | `/workspace/projects/settings/functions` | 项目模式 | 项目成员查看；项目维护者维护 |
| 全局资产 | `/workspace/projects/settings/assets` | 项目模式 | 项目成员查看/复制引入；项目维护者维护 |
| GitLab 仓库配置 | `/workspace/projects/settings/gitlab-repos` | 项目模式 | 项目成员查看；项目维护者维护 |
| 安全策略与应用设置 | `/workspace/projects/settings/security` | 项目模式 | 项目成员查看；项目维护者维护 |

> 上表路由为前端路由示意，与后端 API 路径相互独立。路由前缀 `/workspace/projects/settings/*` 为平台级统一约定，跨业务域一致。

### 1.3 权限边界

- 项目设置的查看为项目成员权限；维护（开关、有效期、增删改）为项目维护者权限。
- 项目成员进入任何设置页均为只读态：维护控件禁用并提示「需项目维护者」。

## 2. 项目设置框架交互

### 2.1 域归属过滤呈现

| 规则 | 交互表现 |
| ---- | ---- |
| 域过滤 | 侧边栏「项目设置」分组仅展示 `common` 通用项与当前业务域（接口测试域内为 `api_test`）归属的配置项；其他业务域专属项不渲染 |
| 分组分隔 | 分组标题「项目设置」与业务功能区之间以分隔线区隔，视觉弱于业务功能区（字号更小、图标单色） |
| 入口一致 | 用户从功能测试域切换到接口测试域时，「项目设置」分组位置、样式、交互保持一致，仅配置项集合随域变化 |
| 路由直达 | 通过 URL 直达其他业务域专属设置路由时，重定向至当前域设置首页并 Toast 提示「无权访问该业务域配置」 |

### 2.2 权限态

| 角色 | 表现 |
| ---- | ---- |
| 项目维护者 | 各设置页维护控件可用，修改即时保存 |
| 项目成员 | 各设置页维护控件禁用（开关不可切换、下拉不可选、按钮隐藏），页面顶部显示只读提示条「当前为只读模式，修改需项目维护者权限」 |

## 3. 安全策略与应用设置页

**路由**：`/workspace/projects/settings/security`

### 3.1 页面布局

```
┌──────────────────────────────────────────────────────────────┐
│  安全策略与应用设置                                             │
├──────────────────────────────────────────────────────────────┤
│  ── 安全策略 ──────────────────────────────────────────────── │
│  允许分享接口测试报告                        [开关 ●] 默认关闭   │
│    开启后，项目成员可在测试报告页生成分享链接                     │
│  ── 应用设置 ──────────────────────────────────────────────── │
│  分享链接有效期                              [7 天 ▾]           │
│    对新生成的接口测试报告分享链接生效；                           │
│    已生成链接按其生成时的有效期判定，不受后续修改影响              │
├──────────────────────────────────────────────────────────────┤
│  各业务域配置相互独立，此处仅展示通用与接口测试域配置项            │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 进入页面 | 侧边栏点击「安全策略与应用设置」 | 拉取当前项目 `common` + `api_test` 配置；未显式配置的项显示默认值（开关关闭、有效期 7 天）；骨架屏加载 |
| 切换分享开关 | 点击 [开关] | 维护者：二次确认弹窗（文案随方向变化：开启——「开启后项目成员可生成分享链接」；关闭——「关闭后不可再生成新的分享链接，已生成链接在有效期内仍可访问」）→ 确认后保存 → Toast「已保存」，开关状态即时生效；成员：控件禁用 + Tooltip「需项目维护者」 |
| 修改有效期 | 下拉选择（1 / 7 / 30 / 90 天） | 维护者：选择后即时保存 → Toast「已保存」；成员：禁用 |
| 保存失败 | — | 控件回滚至原值，Toast 明确原因（配置项非法 7701 / 配置值非法 7702） |

### 3.3 页面状态

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 展示全部配置项及当前值；底部固定说明文字 |
| 只读态 | 项目成员视角：维护控件禁用 + 顶部只读提示条（见 2.2） |
| 加载态 | 首次进入骨架屏；保存中开关/下拉处于 pending 态防重复操作 |
| 错误态 | 配置拉取失败：占位 + [重试]；保存失败：Toast + 控件回滚 |

## 4. 函数管理页

**路由**：`/workspace/projects/settings/functions`

### 4.1 页面布局

```
┌──────────────────────────────────────────────────────────────┐
│  ┌── 列表区（340px）──┐  ┌── 详情区 ──────────────────────┐  │
│  │ [搜索框________] [新增]│ │  内置函数详情：                 │  │
│  │ [全部][内置][自定义] │  │    签名 / 描述 / 参数 / 示例    │  │
│  │ ─────────────────  │  │                                │  │
│  │ ● random (内置)     │  │  或自定义函数（查看/编辑/新建）：│  │
│  │   uuid (内置)       │  │    签名 / 描述 / 参数 / 示例     │  │
│  │   myFunc (自定义)   │  │    Groovy 脚本（代码编辑器）     │  │
│  │   ...              │  │    [编辑] / [保存] / [取消]     │  │
│  └────────────────────┘  └────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 进入页面 | 侧边栏点击「函数管理」 | 并行加载内置函数目录与自定义函数列表；骨架屏加载 |
| 搜索 | 输入框输入（300ms 防抖） | 按名称和描述过滤，内置/自定义分别筛选 |
| 标签页切换 | 点击 [全部]/[内置]/[自定义] | 切换列表显示范围 |
| 选中函数 | 点击列表项 | 右侧显示对应函数详情卡片 |
| 新增函数 | 点击搜索栏右侧 [新增] | 右侧详情区切换为空白编辑表单（新增模式），字段可编辑，底部 [保存] / [取消] |
| 编辑函数 | 点击详情区 [编辑] | 右侧详情区切换为编辑表单（预填当前值），字段可编辑，底部 [保存] / [取消] |
| 保存/取消 | 编辑/新增模式下点击 | 保存：校验后提交并刷新；取消：退出编辑态、丢弃未保存改动 |
| Groovy 脚本 | 详情查看 / 编辑 | 只读展示：代码块高亮；编辑态：使用 CodeMirror 代码编辑器（Groovy 语法高亮、行号） |
| 启停切换 | 列表项操作区 [启用]/[禁用] | 即时切换，维护者可操作 |
| 删除函数 | 列表项操作区 [删除] | 二次确认弹窗 |

### 4.3 函数助手弹窗

函数助手对标 JMeter 函数助手对话框，为可复用独立组件，可在任意需要输入表达式的位置调用。

```
┌─────────────────────────────────────────────┐
│  函数助手                                [×] │
├─────────────────────────────────────────────┤
│  选择函数：[下拉选择（内置 + 自定义函数）]     │
│                                             │
│  ── 函数说明 ──────────────────────────────  │
│  签名：${random(min, max)}                 │
│  描述：生成指定区间的随机整数                   │
│  参数：                                     │
│    min (必填) - 区间下界                      │
│    max (必填) - 区间上界                      │
│                                             │
│  ── 参数填写 ──────────────────────────────  │
│  min: [____]  max: [____]                   │
│                                             │
│  ── 生成结果 ──────────────────────────────  │
│  ${random(1, 100)}              [复制]     │
│                                             │
│  ── 表达式试算 ────────────────────────────  │
│  [自定义表达式输入框____________________]     │
│  [试算]  结果：42 （3ms）    [复制结果]       │
├─────────────────────────────────────────────┤
│                         [插入表达式] [取消]   │
└─────────────────────────────────────────────┘
```

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 选择函数 | 下拉选择 | 显示函数说明、动态参数表单、生成表达式 |
| 搜索函数 | 下拉输入框过滤 | 按名称/描述实时过滤 |
| 填写参数 | 输入框 | 实时更新生成的表达式 |
| 复制表达式 | 点击 [复制] | 复制到剪贴板，Toast「已复制到剪贴板」 |
| 试算 | 输入表达式 → 点击 [试算] | 调用后端 evaluate 接口，显示结果和耗时 |
| 复制结果 | 点击 [复制结果] | 复制试算结果到剪贴板 |
| 插入表达式 | 点击 [插入表达式] | emit 表达式给父组件（如调试页输入框） |

### 4.4 函数助手复用场景

函数助手组件（`FunctionHelperDialog.vue`）设计为独立可复用组件，以下场景需要集成：

| 场景 | 页面 | 触发方式 | 集成状态 |
| ---- | ---- | ---- | ---- |
| 快速调试 | DebugPage.vue | 输入框旁「函数助手」图标按钮 | 待实现 |
| 接口步骤编辑 | InterfacesPage.vue | 参数/断言输入框旁图标按钮 | 待实现 |
| 场景步骤编辑 | ScenesPage.vue | 变量表达式输入框旁图标按钮 | 待实现 |
| 环境变量值 | EnvironmentDetailPanel.vue | 变量值输入框旁图标按钮 | 待实现 |

> 各场景集成时通过 `v-model` 控制弹窗显隐，通过 `@insert` 事件接收生成的表达式并插入到对应输入框。

### 4.5 页面状态

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 左侧列表 + 右侧详情卡片 |
| 只读态 | 项目成员视角：新增/编辑/删除/启停按钮隐藏或禁用 |
| 加载态 | 骨架屏（列表 8 行） |
| 错误态 | 列表加载失败：占位 + [重试] |
| 空态 | 无自定义函数时显示「暂无自定义函数，点击新增」 |
