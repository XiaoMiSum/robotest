**文档版本**：V1.2  
**日期**：2026-08-17

> 本文档为 V1.2 接口测试域交互设计的第四部分：GitLab 仓库集成、可执行导入与定时任务管理的前端交互设计。
> 导航框架与色彩体系见 `docs/交互设计/全局导航与菜单交互系统设计.md`、`docs/交互设计/视觉设计.md`。

## 1. 概述

### 1.1 模块范围

V1.2 接口测试业务域新增 GitLab 集成与定时任务能力，本文档覆盖五个页面：

1. **GitLab 仓库配置页**——项目级维护 GitLab 仓库配置（地址、分支、访问令牌、测试源码路径），可执行导入与仓库流水线执行均引用此项目级公共配置；
2. **可执行导入页**——从仓库源码解析 `@Test` + `@RyzeTest` 注解测试方法的 resource path yaml，导入为平台可执行场景；
3. **元数据同步页**——扫描源码提取测试类元数据（仅描述，不解析为可执行场景），供仓库流水线执行触发；
4. **流水线触发与状态页**——通过 GitLab API 传递测试类元数据触发仓库 CI 流水线，拉取状态与报告产物；
5. **定时任务管理页**——接口导入与场景执行的统一 Cron 调度、执行记录与状态管理。

### 1.2 项目模式侧边栏

本模块页面位于项目模式侧边栏「接口测试」分组下（项目模式导航框架见 `docs/交互设计/全局导航与菜单交互系统设计.md` 3.3，页面内部采用侧边栏布局组织子模块）：

```
┌──────────────┐
│ 快速调试      │
│ 接口管理      │
│ Mock 服务     │
│ 测试场景      │
│ 环境管理      │
│ 接口测试报告  │
│ ──────────── │
│ GitLab 集成   │
│   ├ 仓库配置  │
│   ├ 可执行导入│
│   ├ 元数据同步│
│   └ 流水线触发│
│ 定时任务      │
└──────────────┘
```

### 1.3 两种导入范式

| 范式 | 产物 | 执行路径 | 用途 |
| ---- | ---- | ---- | ---- |
| 可执行导入（源码导入） | 平台可执行场景 | 平台执行引擎 | 场景级自动化回归 |
| 元数据导入（仅描述） | 仓库测试类元数据 | 仓库 CI 流水线 | 触发仓库侧执行 |

两种执行路径互斥：可执行导入场景为平台可执行场景，走平台内执行；仅元数据导入的场景（仅描述、无可执行内容）走仓库 CI 流水线执行，平台不可直接执行。

### 2.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 进入页面 | 侧边栏点击 | 拉取仓库配置列表，表格骨架屏加载；无配置时展示空态引导 |
| 添加仓库 | 点击 [+ 添加仓库] | 打开弹窗；弹窗内提供「从 GitLab 浏览」入口，按名称搜索项目并选择，选中后自动回填仓库地址与默认分支 |
| 编辑仓库 | 行内 [编辑] | 弹窗回显配置；访问令牌脱敏显示 `****xxxx`（末 4 位），留空表示不修改 |
| 测试连接 | 弹窗内 [测试连接] | 按钮 loading → 真实调用校验；成功展示仓库名、默认分支、提交数；失败 Toast + 明细（地址不可达 / 令牌无效） |
| 保存配置 | 点击 [保存] | 前端校验必填项 → 提交；创建时后端立即校验仓库可达性，失败定位到对应字段并红字提示 |
| 删除配置 | 行内 [删除] | 二次确认（红色警示）；存在绑定的定时任务时提示先删除定时任务，阻止删除 |
| 令牌轮换 | 编辑弹窗内重新填写令牌 | 保存后列表令牌列更新为新的末 4 位 |
| 令牌吊销 | 删除配置 | 删除配置即吊销令牌（令牌仅存服务端，前端无明文） |

### 2.3 状态覆盖

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 列表展示全部仓库配置，状态徽标按最近导入结果着色 |
| 空态 | 无配置时展示引导文案与 [添加仓库] 主按钮 |
| 加载态 | 列表骨架屏；测试连接按钮 loading + 禁用 |
| 错误态 | 连接失败（地址不可达 / 令牌无效）Toast 展示错误码与原因；保存失败定位到字段 |

### 3.3 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |

| 解析预览 | 点击 [下一步] | 触发解析，表格骨架屏；解析完成展示场景清单，失败行展示原因 |

| 模块映射 | 步骤3 模块下拉 | 默认按测试类/资源目录结构映射，可手动调整归属模块 |
| 冲突处理 | 步骤3 单选 | 检测到重复场景时强制选择「覆盖」或「跳过」 |
| 开始导入 | 点击 [开始导入] | 进入步骤4，进度条 + 文件级状态逐条更新 |
| 查看失败清单 | 点击 [查看失败清单] | 弹窗展示失败文件与原因，不阻断整体导入 |
| 完成 | 点击 [完成] | 关闭向导，跳转测试场景列表 |

### 3.4 状态覆盖

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 四步向导逐步推进，每步校验通过才可进入下一步 |
| 空态 | 仓库无匹配文件时文件树展示空态文案；解析无结果时预览表为空 |

### 5.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 选择触发范围 | 单选 | 切换后对应选择器显隐：完整测试无选择器；指定接口/场景测试展示多选选择器 |

| 查看流水线详情 | 点击行展开 | 展开行展示场景执行结果（场景名、状态、报告链接）、GitLab 流水线链接 |
| 刷新状态 | 行内 [刷新] | 手动拉取最新状态；状态未知（拉取失败）时提供 [刷新] 与流水线链接 |
| 拉取报告 | 流水线完成后自动 | 报告产物写入平台报告，历史行展示报告链接 |

### 5.3 状态覆盖

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 触发表单与流水线历史正常展示 |
| 空态 | 无流水线历史时展示空态文案；仓库未配置时表单区提示先配置仓库 |
| 加载态 | 触发按钮 loading；进行中流水线状态徽标为「进行中」并每 5 秒轮询刷新 |
| 错误态 | 触发失败（契约不满足 / 令牌失效 / 元数据缺失）Toast + 表单定位；状态拉取失败标记「状态未知」并给出 GitLab 流水线链接 |

### 6.3 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 新建任务 | 点击 [+ 新建任务] | 打开弹窗；任务类型默认「场景执行」 |

| 选择绑定对象 | 下拉 | 场景执行时校验场景为平台可执行场景（元数据导入场景不可选） |
| 选择目标环境 | 下拉 | 场景执行任务必选；环境被删除后任务执行失败并明确提示 |
| 配置 Cron | 预设下拉或自定义输入 | 预设选中回填表达式；自定义输入实时校验，非法红字提示 |
| 校验表达式 | 点击 [校验] | 调用校验接口，展示表达式描述与下次 5 次执行时间预览 |
| 保存任务 | 点击 [保存] | 前端校验 → 提交；Cron 非法不可保存；成功 Toast + 列表刷新 |
| 立即执行 | 行内 [立即执行] | 二次确认 → 触发；上一次执行未结束时提示并阻止 |
| 启停任务 | 行内 [启停] | 切换启用状态；停用后不再触发，下次执行列显示「-」 |
| 查看执行记录 | 行内 [执行记录] | 展开子表格或抽屉展示历史执行（触发方式、状态、耗时、关联报告/导入结果链接） |

## 7. 通用交互模式

### 7.1 弹窗类型

| 类型 | 使用场景 |
| ---- | ---- |
| 表单弹窗 | 仓库配置添加/编辑、定时任务新建/编辑 |
| 确认弹窗 | 删除仓库配置、删除定时任务、立即执行、开启自动同步、启停任务 |
| 抽屉 | 变更明细查看、执行记录查看 |
| 提示条 | 元数据过期提示、仓库不可达提示 |

### 7.2 加载与错误状态

- **表单提交 / 连接测试**：按钮 loading + 禁用，完成恢复；
- **列表加载**：首次骨架屏，筛选刷新顶部进度条；
- **导入 / 同步 / 流水线**：进度条 + 状态文案；流水线状态每 5 秒轮询；
- **错误提示**：操作类错误 Toast + 错误码；表单类错误定位字段红字提示；失败清单类错误以清单呈现不阻断整体。

### 7.3 状态徽标约定

| 状态 | 徽标 | 语义色 |
| ---- | ---- | ---- |
| 成功 / 已启用 | [成功] [已启用] | `--color-success` |
| 失败 / 已停用 | [失败] [已停用] | `--color-danger` |
| 部分成功 | [部分成功] | `--color-warning` |
| 进行中 / 待处理 | [进行中] [待处理] | `--color-info` |
| 已跳过 / 状态未知 | [已跳过] [状态未知] | `--color-neutral` |

### 7.4 连接测试模式

连接测试为跨页面复用的统一交互模式（GitLab 仓库配置、数据源连接测试等）：

1. 点击 [测试连接] → 按钮 loading + 禁用；
2. 成功：Toast 成功 + 明细（仓库名、默认分支、提交数）；
3. 失败：Toast 失败 + 错误码与原因（地址不可达 / 令牌无效）；
4. 表单内测试以当前填写值测试，列表行内测试以已保存配置测试。
