## 1. 总体布局

AI 能力嵌入缺陷管理既有页面，均随 `aiEnabled` 显隐：

| 页面 | 新增内容 |
| ---- | ---- |
| 缺陷新建/编辑表单 | 表单侧 [✨AI 建议] 按钮与建议卡片；标题输入下方疑似重复缺陷卡片列表 |
| 缺陷看板页 | [✨AI 分析] 聚类面板 |

> **零影响约束（通用规范 2.7）**：AI 建议区、查重卡片、聚类面板均为既有缺陷表单/看板的附加区域；`aiEnabled = false` 时全部隐藏，表单字段布局与看板回退 V1.0 形态。查重/建议为异步非阻塞（不占用提交按钮、不校验其结果），AI 失败或降级时缺陷创建、编辑、流转等既有主流程完全不受影响。

## 2. 标题优化与等级建议（US-AI-008）

### 2.1 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 发起建议 | 点击 [AI 建议] 按钮 | 按钮 loading（同步调用）；上下文仅取当前标题 + 重现步骤 |
| 查看建议 | 调用成功 | 表单侧展示建议卡片：优化标题 + 严重等级建议 + 优先级建议 |
| 采纳标题 | 卡片内点击 [一键替换] | 表单标题输入框内容替换为优化标题，卡片该项置为已采纳态 |
| 忽略标题 | 卡片内点击 [忽略] | 该建议项收起，标题保持不变 |
| 采纳等级/优先级 | 点击建议值 | 对应下拉框回填该值（建议值必映射平台既有枚举） |
| 调用失败 | 网络/模型错误 | 仅 Toast 轻提示，不影响表单任何操作 |

- 建议仅回填表单待用户确认，提交前可任意修改，不产生任何自动提交行为；
- 建议请求进行中不阻塞输入与提交（非侵入原则，通用规范 2.5）。

## 3. 语义查重（US-AI-009）

### 3.1 触发规则

| 规则 | 说明 |
| ---- | ---- |
| 自动触发 | 表单监听标题（及描述）变更，防抖 500ms 发起查重 |
| 最小长度 | 标题少于 5 字符不触发 |
| 并发处理 | 以最后一次请求为准，过期响应丢弃 |
| 限流保护 | 收到 6004（频率超限）后本次表单会话内停止自动查重，仅保留 [手动查重] 按钮 |
| 不阻塞 | 查重请求进行中不阻塞输入与提交 |

### 3.2 查重卡片列表

标题输入框下方内嵌展示（无结果时不占位）：

```
┌─ 疑似重复缺陷（2）──────────────────────────┐
│ ⚠ 当前为关键词匹配结果（语义检索暂不可用）   │ ← 降级提示条（按需）
│ ┌────────────────────────────────────────┐  │
│ │ [92%] 登录页白屏无响应   active   张三  │  │
│ │ [85%] 登录后页面卡死     resolved 李四  │  │
│ └────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
```

### 3.3 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 查看疑似重复 | 输入标题后自动 | 卡片列表渐入展示：相似度徽标 + 标题 + 状态 + 处理人（按相似度降序） |
| 查看缺陷详情 | 点击卡片 | 打开对应缺陷详情抽屉（不离开表单，表单内容保留） |
| 确认重复放弃提交 | 用户自行判断 | 关闭表单即可；或继续提交，后续流转中标记「重复缺陷」（复用既有 resolution 机制） |
| 手动查重 | 点击 [手动查重] 按钮 | 立即发起一次查重（限流停用自动触发后的兜底入口） |
| 语义降级 | 响应携带降级标志 | 列表顶部提示条明示关键词匹配模式 |
| 无疑似重复 | 检索结果为空 | 列表区不展示（不打扰） |

- 查重范围：当前项目内**未关闭**缺陷（active/resolved/rejected），已关闭缺陷不参与；
- 查重不阻断提交，仅提示。

## 4. 缺陷聚类分析（US-AI-010）

**入口**：缺陷看板页 [AI 分析] 按钮，展开聚类面板。

### 4.1 聚类面板布局（报告式主题卡片）

面板以**可读报告**而非紧凑仪表盘呈现：顶部汇总条 + 单列主题卡片（首个默认展开）+ 底部分布图。

```
┌──────────────────────────────────────────────────────────┐
│  ✨ AI 分析      生成时间：07-30 14:22      [刷新] [收起] │
├──────────────────────────────────────────────────────────┤
│  ▓▓▓▓▓▓▓░░░ 分析中…                          [取消任务]  │  ← 进行中：进度条
├──────────────────────────────────────────────────────────┤
│  汇总：共 20 条缺陷 · 3 个聚类主题 · 2 条未聚类           │
├──────────────────────────────────────────────────────────┤
│  ① 登录链路异常                     [8]  ●●●○      ▾    │  ← 首个默认展开
│     根因：会话过期导致 token 失效，集中在登录模块          │
│  ┌────────────────────────────────────────────────────┐  │
│  │ ● 登录页白屏无响应        [严重] [active]  #1a2b3c  │  │  ← 展开明细
│  │ ● 登录接口偶发 401        [严重] [active]  #1a2b3d  │  │
│  └────────────────────────────────────────────────────┘  │
│                                                          │
│  ② 支付超时类                       [5]  ●●○○      ▸    │
│     根因：网关抖动                                        │
│  ③ 未命名主题 3                     [3]  ●○○○      ▸    │
│     根因：未给出根因                                      │
├──────────────────────────────────────────────────────────┤
│  分布图（字号 ≥12px）                                     │
│  按模块:   登录  ████████████  12        (百分比标签)    │
│            支付  ████████      8                         │
│  按等级:   [致命█][严重███][一般██][轻微█] 分段色条+图例  │
└──────────────────────────────────────────────────────────┘
```

**字号阶梯**（解决 V1.1 结果区过小问题，视觉规范 `--font-size-*`）：

| 元素 | 字号 | 说明 |
| ---- | ---- | ---- |
| 主题名 | `--font-size-lg`（16px）加粗 | 核心阅读对象 |
| 根因正文 | `--font-size-base`（14px） | 最多 3 行省略，点击展开全文 |
| 展开明细标题 | `--font-size-base`（14px） | 缺陷标题为主信息 |
| 序号/计数徽章、生成时间、汇总、分布图 | `--font-size-xs`（12px）起 | 辅助信息不低于 12px，禁用 `--font-size-2xs` |

### 4.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 打开面板（有结果） | 点击 [AI 分析] | 读取最近一次结果快照渲染，显示生成时间与汇总条 |
| 打开面板（无结果无任务） | 同上 | 空态插画 + 说明 + [开始分析] 按钮 |
| 开始/刷新分析 | 点击 [开始分析] / [刷新] | 创建异步任务，进度条 + 2 秒轮询；同一项目同时只允许一个进行中任务 |
| 展开/收起主题 | 点击主题卡片头部 [▸/▾] | 首次打开默认展开第一个主题；点击其他主题仅切换自身展开态，互不联动 |
| 查看根因全文 | 根因超 3 行时点击 | 展开该主题根因全文（与缺陷清单独立展开） |
| 查看缺陷明细 | 主题已展开 | 每行 = 严重度色点 + 缺陷标题 + 状态标签 + 短 ID（标题来自快照 `bugs` 字段）；点击行跳转缺陷详情 |
| 取消任务 | 点击 [取消任务] | 任务置已取消，面板回退到上一次结果（如有） |
| 任务失败 | 轮询返回 failed | 面板展示失败原因 + [重试] 按钮 |
| 语义降级 | `semanticSearch` 非 available | 面板顶部降级提示条 |

- 分析范围：当前项目全部未关闭缺陷；结果为只读洞察，不修改任何缺陷数据；
- 快照 `clusters[].bugs` 携带缺陷标题（详细设计 2.3 变更），明细行直接渲染标题，无需展开后再查详情；
- 分布图不引入图表库，CSS/SVG 轻量自绘：按模块的水平条形分布（宽度比例 + 数量 + 百分比标签）与按严重等级的分段色条，配色沿用视觉设计语义色。

## 5. 通用交互模式总结

### 5.1 弹窗类型

| 类型 | 使用场景 |
| ---- | ---- |
| 抽屉 | 疑似重复缺陷的详情查看（不离开表单） |
| 面板 | 聚类分析（看板页内嵌展开） |
| Toast | 建议调用失败轻提示、限流提示 |

### 5.2 加载状态

- 同步建议：按钮 loading，不阻塞表单；
- 自动查重：静默进行，无 loading 遮罩（结果渐入）；
- 异步聚类：进度条 + 轮询，离开页面任务不中断。

### 5.3 非侵入原则

本域全部 AI 能力（建议、查重、聚类）均为建议/洞察性质：不弹模态窗、不阻塞输入与提交、不自动修改数据；失败仅轻提示，缺陷业务主流程完全不受影响。
