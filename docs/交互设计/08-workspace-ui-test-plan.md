### 3.4 测试计划子模块

选中“测试计划”菜单后，右侧展示计划列表或计划详情。

#### 3.4.1 计划列表页

```
┌──────────────────────────────────────────────────┐
│  [搜索名称] [状态: 全部 ▼] [查询] [重置]  [+ 创建计划] │
├──────────────────────────────────────────────────┤
│  名称 │ 负责人 │ 时间 │ 状态 │ 进度 │ 通过率 │ 操作   │
│  功能  │ 赵六   │08-01 │进行中│[━━] │ 60%   │[进入执行][完成][删除]│
└──────────────────────────────────────────────────┘
```

查询区与评审列表一致（关键字按名称模糊匹配）。列表同样提供进度（已执行/关联总数）与通过率（100% 绿色、否则红色）两列；操作列：[进入执行]/[查看详情]、[完成]（未结束可见，确认后直接完成，不校验未执行用例）、[删除]（二次确认，仅负责人，后端校验）。点击[创建计划]弹出创建表单：名称、负责人、起止时间、执行环境、关联用例。提交后跳转至计划详情页。

#### 3.4.2 计划详情页

```
┌──────────────────────────────────────────────────┐
│ ← 返回 功能测试计划 [进行中] [━进度━] 通过n 失败n 阻塞n 待执行n │
│              [调整用例][同步用例][完成执行]          │
├──────────┬───────────────────────────────────────┤
│ 快照文档树│   快照脑图                              │
│ (多文档   │   节点右侧徽标回显执行结果：             │
│  点击切换) │   ✓通过 ✕失败 ⚠阻塞（待执行不显示）    │
└──────────┴───────────────────────────────────────┘
```

**详情页交互**（与评审详情页保持一致）：

- 标题行单行承载：名称 + 状态标签 + 进度与分色统计 + 操作按钮（待开始/进行中：调整用例/同步用例/完成执行）；标记成功后进度实时刷新。
- 不再提供单独的“开始执行”操作：待开始计划首次标记执行结果后自动转入进行中；[完成执行]二次确认后状态置已完成，不可再标记执行结果。
- 左侧快照文档树点击切换多文档；[调整用例]在计划未结束（待开始/进行中）时可用，回显当前规划并差量更新快照。
- 执行标记四态：通过/失败/阻塞/待执行（重置），结果以彩色徽标回显在节点右侧。
- 点[← 返回]回到功能测试页并自动激活“测试计划”子模块（`?tab=plans`）。

**移除已选用例**（计划未结束时可用）：

- **入口**（两处）：
  1. **标记结果组件（脑图工具栏）**：[移除用例] 按钮，位于执行结果按钮组右侧；
  2. **右键菜单**：选中用例节点右键，「从计划中移除」菜单项。
- **触发条件**：
  - 仅当选中节点为 `case` 类型时可用；
  - 计划状态为「已完成/已关闭」时入口隐藏，与 [调整用例] 权限一致；后端强校验兜底。
- **交互流程**：
  1. 脑图中选中一个已关联的用例节点；
  2. 点击工具栏 [移除用例] 或右键菜单「从计划中移除」；
  3. 二次确认弹窗「确定从该计划中移除用例『用例标题』吗？移除后该用例及其执行结果将不再展示，历史执行记录保留作审计。」；
  4. 确认后调用规划用例更新接口（全量覆盖式）：从当前规划中剔除该用例，若所属文档无剩余用例则整文档移除；
  5. 成功 Toast「已移除用例」→ 脑图重载、进度条与统计实时刷新；
  6. 取消或失败：关闭弹窗 / 错误 Toast，界面不变。
- **边界与约束**：
  - 移除仅删除快照节点，执行记录保留作审计（与调整用例行为一致）；
  - 移除后快照树同步重载：若整文档被移除，左侧文档树对应条目消失，当前选中文档回退到首个文档；
  - 移除后计划快照视为已变更，执行顺序推荐结果失效（stale 提示规则沿用既有同步机制）。

详情页复用脑图组件（`mode='plan'`），工具栏切换为执行操作按钮。
