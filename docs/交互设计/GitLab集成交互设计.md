# 软件测试平台——GitLab集成交互设计

**文档版本**：V1.2  
**日期**：2026-08-17  
**状态**：起草中

> 本文档为 V1.2 接口测试域交互设计的组成部分：GitLab 集成能力的前端交互设计。GitLab 集成**不是独立侧边栏模块**——可执行导入、元数据同步、流水线触发为**测试场景模块的子功能**，以弹窗/抽屉形态内嵌于测试场景列表页；仅 GitLab 仓库配置页归入「项目设置」分组。
> 定时任务管理页见 `docs/交互设计/定时任务交互设计.md`；导航框架与色彩体系见 `docs/交互设计/全局导航与菜单交互系统设计.md`、`docs/交互设计/视觉设计.md`。

---

## 1. 概述

### 1.1 模块范围

V1.2 接口测试业务域新增 GitLab 集成能力，本文档覆盖四个功能：

1. **GitLab 仓库配置页**——项目级维护 GitLab 仓库配置（地址、分支、访问令牌、测试源码路径），可执行导入与仓库流水线执行均引用此项目级公共配置；归属「项目设置」分组；
2. **可执行导入向导弹窗**——从仓库源码解析 `@Test` + `@RyzeTest` 注解测试方法的 resource path yaml，导入为平台可执行场景；测试场景列表页 [导入场景] 按钮触发的四步向导弹窗；
3. **元数据同步抽屉**——扫描源码提取测试类元数据（仅描述，不解析为可执行场景），供仓库流水线执行触发；测试场景列表页 [元数据同步] 按钮触发的抽屉；
4. **流水线触发弹窗**——通过 GitLab API 传递测试类元数据触发仓库 CI 流水线；触发后状态与结果由执行历史与测试报告体系承载（含流水线 ID 与链接），不设独立历史页面。

### 1.2 项目模式侧边栏

本组功能无独立侧边栏入口（项目模式导航框架见 `docs/交互设计/全局导航与菜单交互系统设计.md` 3.3）：可执行导入、元数据同步、流水线触发的入口位于**测试场景列表页工具栏**；仓库配置页归入侧边栏末尾「项目设置」分组（平台级）：

```
┌──────────────────────────────────┐
│  接口测试（顶部菜单入口）          │
│  ─────────────────────────       │
│  快速调试     /workspace/projects/api-testing?tab=debug
│  接口管理     /workspace/projects/api-testing?tab=interfaces
│  Mock 服务    /workspace/projects/api-testing?tab=mocks
│  测试场景     /workspace/projects/api-testing?tab=scenes      ← 第 3–5 章弹窗/抽屉宿主页面
│  接口测试报告 /workspace/projects/api-testing?tab=reports
│  定时任务     /workspace/projects/api-testing?tab=schedules
│  ═════════════════════════════
│  项目设置（平台级 · 按业务域过滤）
│   ├ 环境管理           /workspace/projects/settings/environments
│   ├ 全局资产           /workspace/projects/settings/assets
│   └ GitLab 仓库配置    /workspace/projects/settings/gitlab-repos ← 本文档第 2 章
└──────────────────────────────────┘
```

### 1.3 两种导入范式

| 范式 | 产物 | 执行路径 | 用途 |
| ---- | ---- | ---- | ---- |
| 可执行导入（源码导入） | 平台可执行场景 | 平台执行引擎 | 场景级自动化回归 |
| 元数据导入（仅描述） | 仓库测试类元数据 | 仓库 CI 流水线 | 触发仓库侧执行 |

两种执行路径互斥：可执行导入场景为平台可执行场景，走平台内执行；仅元数据导入的场景（仅描述、无可执行内容）走仓库 CI 流水线执行，平台不可直接执行。

### 1.4 入口与形态

| 功能 | 宿主页面 | 形态 | 路由 |
| ---- | ---- | ---- | ---- |
| GitLab 仓库配置 | 项目设置分组 | 独立页面 | `/workspace/projects/settings/gitlab-repos` |
| 可执行导入向导 | 测试场景列表页（[导入场景] 按钮） | 弹窗（960px 四步向导） | 无独立路由，随宿主页面 |
| 元数据同步 | 测试场景列表页（[元数据同步] 按钮） | 抽屉（640px） | 无独立路由，随宿主页面 |
| 流水线触发 | 测试场景列表页（[触发流水线] 按钮） | 弹窗（720px） | 无独立路由，随宿主页面 |

> 流水线触发后的执行状态与结果不设独立历史页面：流水线执行记录进入执行历史（含流水线 ID 与链接），报告产物生成平台报告并在报告中标记来源与流水线链接（见《测试报告交互设计》）。

## 2. GitLab仓库配置页

> 仓库配置页归入侧边栏「项目设置」分组（平台级项目配置入口，见 `docs/交互设计/全局导航与菜单交互系统设计.md` 3.5），页面交互仍在本章描述。

### 2.1 页面布局

```

│  回归仓库 │ https://…│ develop │ ****a2f8 │ [失败] │ 08-16 18:00 │ … │

└──────────────────────────────────────────────┘
```

### 2.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 进入页面 | 侧边栏点击 | 拉取仓库配置列表，表格骨架屏加载；无配置时展示空态引导 |
| 添加仓库 | 点击 [+ 添加仓库] | 打开弹窗；弹窗内提供「从 GitLab 浏览」入口，按名称搜索项目并选择，选中后自动回填仓库地址与默认分支 |
| 编辑仓库 | 行内 [编辑] | 弹窗回显配置；访问令牌脱敏显示 `****xxxx`（末 4 位），留空表示不修改 |
| 测试连接 | 弹窗内 [测试连接] | 按钮 loading → 真实调用校验；成功展示仓库名、默认分支、提交数；失败 Toast + 明细（地址不可达 / 令牌无效） |
| 保存配置 | 点击 [保存] | 前端校验必填项 → 提交；创建时后端立即校验仓库可达性，失败定位到对应字段并红字提示 |
| 删除配置 | 行内 [删除] | 二次确认（红色警示）；存在绑定的定时任务时提示先删除定时任务，阻止删除 |
| 令牌轮换 | 编辑弹窗内重新填写令牌 | 保存后列表令牌列更新为新的末 4 位 |
| 令牌吊销 | 删除配置 | 删除配置即吊销令牌（令牌仅存服务端，前端无明文） |

### 2.3 状态覆盖

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 列表展示全部仓库配置，状态徽标按最近导入结果着色 |
| 空态 | 无配置时展示引导文案与 [添加仓库] 主按钮 |
| 加载态 | 列表骨架屏；测试连接按钮 loading + 禁用 |
| 错误态 | 连接失败（地址不可达 / 令牌无效）Toast 展示错误码与原因；保存失败定位到字段 |

### 3.1 导入向导流程

```mermaid
flowchart LR
    A[步骤1 选择仓库与文件] --> B[步骤2 解析预览]
```

### 3.3 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 打开向导 | 测试场景列表页点击 [导入场景] | 打开弹窗；无仓库配置时步骤1 展示引导文案与「前往项目设置配置仓库」链接 |
| 选择仓库 | 步骤1 仓库下拉 | 切换仓库后重新加载文件树与分支列表 |
| 浏览文件树 | 展开目录节点 | 按需加载子目录；文件按扩展名过滤（.json / .yaml / .yml / .har） |
| 选择文件 | 勾选文件复选框 | 底部已选计数实时更新；支持目录级全选 |
| 解析预览 | 点击 [下一步] | 触发解析，表格骨架屏；解析完成展示场景清单，失败行展示原因 |
| 勾选场景 | 步骤2 表格复选框 | 未勾选任何场景时 [下一步] 禁用并提示 |
| 模块映射 | 步骤3 模块下拉 | 默认按测试类/资源目录结构映射，可手动调整归属模块 |
| 冲突处理 | 步骤3 单选 | 检测到重复场景时强制选择「覆盖」或「跳过」 |
| 开始导入 | 点击 [开始导入] | 进入步骤4，进度条 + 文件级状态逐条更新；导入中不可关闭弹窗（防误操作） |
| 查看失败清单 | 点击 [查看失败清单] | 弹窗展示失败文件与原因，不阻断整体导入 |
| 完成 | 点击 [完成] 或 [×] | 关闭弹窗，刷新测试场景列表 |

### 3.4 状态覆盖

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 四步向导逐步推进，每步校验通过才可进入下一步 |
| 空态 | 仓库无匹配文件时文件树展示空态文案；解析无结果时预览表为空；项目无仓库配置时展示引导链接 |
| 加载态 | 文件树加载、解析中、导入中均展示对应进度反馈 |
| 错误态 | 仓库不可达 / 令牌无效在步骤1 顶部提示条展示；解析失败与导入失败以失败清单呈现，不阻断整体 |

## 4. 元数据同步抽屉

**入口**：测试场景列表页 [元数据同步] 按钮（宿主路由 `/workspace/projects/api-testing?tab=scenes`）。

### 4.1 抽屉布局

```
┌──────────────────────────────────────────────┐
│  元数据同步                              [×] │
│  扫描源码提取测试类元数据，供仓库流水线触发    │
├──────────────────────────────────────────────┤
│  仓库 [主仓库 ▾]   分支 [main ▾]              │

│  └──────────────────────────────────────┘  │

└──────────────────────────────────────────────┘
```

### 4.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 打开抽屉 | 测试场景列表页点击 [元数据同步] | 打开抽屉并加载当前项目仓库的同步范围配置与同步历史；无仓库配置时展示引导链接 |
| 切换仓库 | 仓库下拉 | 重新加载该仓库的同步范围配置与同步历史 |
| 配置同步范围 | 表单直接修改 | 源码路径、注解过滤、是否仅含 resource path 的类 |
| 手动同步 | 点击 [同步元数据] | 按钮 loading → 进度条展示扫描进度 → 完成后刷新变更预览与同步历史，Toast「元数据已同步」 |
| 查看变更明细 | 点击 [明细] | 抽屉内展开新增/修改/移除三类明细（类名、显示名、变更内容） |
| 开启自动同步 | 切换自动同步开关 | 二次确认：说明将按仓库 commit 变化自动刷新元数据；开启后展示最近自动同步时间 |
| 关闭抽屉 | 点击 [×] 或遮罩 | 关闭抽屉，回到测试场景列表 |

### 4.3 状态覆盖

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 变更预览与同步历史正常展示 |
| 空态 | 从未同步时变更预览区展示「尚未同步，点击 [同步元数据] 开始」；项目无仓库配置时展示引导链接 |
| 加载态 | 同步中进度条 + 状态文案；历史表格骨架屏 |
| 错误态 | 同步失败（仓库不可达 / 令牌失效）Toast + 历史行标记失败，可重试 |

## 5. 流水线触发弹窗

**入口**：测试场景列表页 [触发流水线] 按钮（宿主路由 `/workspace/projects/api-testing?tab=scenes`）。流水线执行的状态与结果由执行历史与测试报告体系承载，本弹窗仅负责触发。

### 5.1 弹窗布局

```
┌──────────────────────────────────────────────┐
│  仓库流水线执行                          [×] │
│  通过 GitLab API 传递测试类元数据触发 CI 流水线 │
├──────────────────────────────────────────────┤
│  仓库 [主仓库 ▾]   分支 [main ▾]              │
│  触发范围  ○ 完整测试  ○ 指定接口测试          │
│            ○ 指定场景测试                     │
│  指定场景 [登录接口测试 ▾]（多选，映射来源      │
│            测试类元数据）                      │
│  环境变量  ENV [staging ▾]  + 添加自定义变量   │
│  ── 元数据状态 ─────────────────────────────  │
│  ✓ 元数据已同步（commit a1b2c3d）[去同步]     │
│  ⚠ 元数据已过期，触发时将自动同步后执行        │
├──────────────────────────────────────────────┤
│  流水线在仓库 .gitlab-ci.yml 中定义，平台仅    │

│  [取消] [触发流水线]                          │
└──────────────────────────────────────────────┘
```

### 5.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 打开弹窗 | 测试场景列表页点击 [触发流水线] | 打开弹窗并加载仓库、元数据状态；无仓库配置时展示引导链接 |
| 选择触发范围 | 单选 | 切换后对应选择器显隐：完整测试无选择器；指定接口/场景测试展示多选选择器 |
| 选择场景 | 场景多选 | 仅展示元数据导入（仅描述）场景；可执行导入场景不参与映射 |
| 配置环境变量 | 下拉 + 添加 | ENV 等变量键值对，可添加自定义变量 |
| 去同步 | 点击元数据状态区 [去同步] | 关闭本弹窗并打开元数据同步抽屉（见第 4 章） |
| 触发流水线 | 点击 [触发流水线] | 校验元数据过期状态 → 按钮 loading → 成功 Toast「流水线已触发」+ 关闭弹窗；失败展示原因（契约不满足 / 令牌失效），弹窗内定位 |
| 查看执行结果 | 触发成功后 | 执行历史记录流水线 ID 与链接；报告产物生成平台报告（来源标记「仓库流水线」）；状态拉取失败时执行历史标记「状态未知」并提供 GitLab 流水线链接与 [刷新] |

### 5.3 状态覆盖

| 状态 | 表现 |
| ---- | ---- |
| 正常态 | 触发表单正常展示，元数据状态区显示同步状态 |
| 空态 | 项目无仓库配置或无可触发场景（无元数据导入场景）时展示引导文案 |
| 加载态 | 打开弹窗拉取元数据状态时 loading；触发按钮 loading 防重复 |
| 错误态 | 触发失败（契约不满足 / 令牌失效 / 元数据缺失）Toast + 表单定位；执行侧状态未知在执行历史中标记并提供流水线链接 |
