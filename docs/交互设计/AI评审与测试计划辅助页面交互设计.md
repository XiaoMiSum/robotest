## 1. 总体布局

AI 入口分布在三个既有页面，均随 `aiEnabled` 显隐：

| 页面 | 新增入口 | 可见角色 |
| ---- | ---- | ---- |
| 评审详情页（ReviewMindMap） | [✨AI 一键检查] 侧面板、[✨AI 生成摘要] | 仅评审发起人 |
| 用例模块页 | [✨遗漏测试点分析] 抽屉入口 | 全部业务用户 |
| 计划详情页（PlanMindMap） | [✨执行顺序推荐] 标签页 | 仅计划负责人 / 执行人 |
| 计划详情页 / 计划用例关联流程 | [✨回归子集推荐] 弹窗入口 | 全部业务用户（属覆盖度分析，SRS 附录 B；最终带入关联仍受既有计划编辑权限约束） |

> **零影响约束（通用规范 2.7）**：检查/摘要面板、顺序推荐标签页均为既有页面的附加区域，不改变评审详情、计划详情既有布局与操作流程；`aiEnabled = false` 或无权限时对应入口隐藏，评审、计划、用例模块的既有功能完全不受影响。

## 2. AI 一键检查（US-AI-005）

**入口**：评审详情页操作区 [AI 一键检查]，仅评审发起人可见；评审状态为「待评审」或「评审中」时可发起检查，评审已完成（completed）时点击仅只读查看历史检查结果。

### 2.1 检查面板布局

```
┌────────────────────────────────┐
│  ✨ AI 检查                 ✕  │
├────────────────────────────────┤
│  ▓▓▓▓▓▓░░░░ 3/5 批  [取消任务]│  ← 进行中：进度条
├────────────────────────────────┤
│  维度过滤: [全部▼]             │
│  ┌──────────────────────────┐  │
│  │ ⚠ 缺少前置条件           │  │
│  │   用例：登录-密码错误提示 │  │
│  ├──────────────────────────┤  │
│  │ ⚠ 步骤描述过于笼统       │  │
│  │   用例：支付-余额不足    │  │
│  └──────────────────────────┘  │
└────────────────────────────────┘
```

### 2.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 发起检查 | 待评审/评审中点击 [AI 一键检查] | 创建异步任务，面板展开显示进度条（大快照分批检查，展示批次进度），2 秒轮询 |
| 重复发起 | 已有进行中任务时点击 | 提示「已有检查任务在执行」，同一评审同时只允许一个任务 |
| 查看建议 | 检查完成 | 建议列表按维度分组展示（缺少前置条件 / 步骤笼统 / 预期缺失 / 优先级冲突），支持维度下拉过滤 |
| 定位节点 | 点击建议条目 | 脑图定位并高亮对应快照节点 |
| 取消任务 | 点击 [取消任务] | 二次确认 → 任务标记已取消，已产出的部分结果仍展示 |
| 离开页面 | 任务进行中导航离开 | 任务不中断；返回页面后面板轮询恢复展示 |
| 任务失败 | 轮询返回 failed | 面板展示失败原因 + [重试] 按钮 |
| 评审状态流转 | 评审完成（待评审/评审中 → 已完成） | 进行中任务自动终止并置「已取消」；已产出结果仍可查看 |
| 查看历史结果 | 已完成评审点击 [AI 一键检查] | 面板只读展示最近一次检查结果（含取消/失败时已产出部分结果），无发起/重试按钮；无历史记录时展示「该评审已完成，无历史检查结果」 |

- 检查建议仅供参考，不自动修改任何节点或评审标记；
- 结果仅评审发起人可查看。

## 3. AI 生成评审摘要（US-AI-006）

**入口**：评审详情页 [AI 生成摘要]，仅评审发起人可见，且仅评审状态为「已完成」时可点击。

### 3.1 摘要视图布局

```
┌──────────────────────────────────────────────┐
│  ✨ 评审摘要  [模型: DeepSeek-V3 ▼] [复制] [重新生成]│
├──────────────────────────────────────────────┤
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐│
│  │通过率  │ │不通过率│ │待评审数│ │问题分布││  ← 统计卡片（系统精确计算）
│  │  86%   │ │  10%   │ │   4    │ │ 图/表  ││
│  └────────┘ └────────┘ └────────┘ └────────┘│
├──────────────────────────────────────────────┤
│  文字总结（流式 Markdown 渲染）              │
│  ## 主要问题归纳                             │
│  1. …▌                                       │
└──────────────────────────────────────────────┘
```

### 3.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 生成摘要 | 点击 [AI 生成摘要] | 统计卡片区**即时渲染**（不依赖 LLM）；文字总结区 SSE 流式渲染 Markdown |
| 切换对话模型 | 标题栏模型选择器（`AiModelSelect`，通用规范见《AI基础设施与管理端页面交互设计》2.8） | 作用于本次及后续生成；选择本地记忆，失效静默回退系统默认；仅一个可用模型时不渲染。评审检查、顺序推荐等其余功能固定用系统默认模型，无选择器 |
| 中途取消 | 流式期间点击 [停止] | 断开 SSE，已渲染文字不保留 |
| 复制 | 点击 [复制] | 完整 Markdown 复制到剪贴板，Toast 成功 |
| 重新生成 | 点击 [重新生成] | 二次确认「将覆盖上一份摘要」→ 重新走流式生成 |
| 再次进入页面 | 已有摘要快照 | 直接读取持久化结果渲染，无需重新生成 |

- 摘要不回写评审记录，不影响快照冻结状态。

## 4. 遗漏测试点分析（US-AI-007）

**入口**：用例模块页操作区 [遗漏测试点分析]，点击展开右侧抽屉。

### 4.1 分析抽屉布局

```
┌───────────────────────────────────────┐
│  ✨ 遗漏测试点分析                 ✕  │
├───────────────────────────────────────┤
│  需求输入（三选一，可组合）           │
│  ○ 关键词  [登录, 支付, 短信…]        │
│  ○ 需求文本 [粘贴文本域…]             │
│  ○ 需求条目 [已选 N 条 ▾ 调整]        │
│                        [开始分析]     │
├───────────────────────────────────────┤
│  分析结果                             │
│  ☑ 未覆盖：验证码过期场景  → 登录模块 │
│  ☑ 未覆盖：并发支付幂等    → 支付模块 │
│  ☐ 未覆盖：…                          │
│              [转用例生成（已选 2）]   │
└───────────────────────────────────────┘
```

### 4.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 输入需求 | 关键词 / 粘贴文本 / 选取需求池条目（复用条目选取器） | 三态输入可组合；需求条目区与文本输入框形态同「AI 生成用例」（见《智能用例生成》2.1）；**打开抽屉时自动带入当前文档已关联的需求条目**（同《智能用例生成》6.3 文档关联），可再调整 |
| 开始分析 | 点击 [开始分析] | 同步长调用（前端超时 70s）：面板持续加载态 + [取消] 按钮 |
| 取消分析 | 点击 [取消] | 中断请求（abort），恢复输入态 |
| 查看结果 | 分析完成 | 遗漏测试点清单（含建议归属模块），逐条可勾选 |
| 语义降级 | 结果携带降级标志 | 顶部提示条「当前为关键词匹配结果」（通用规范 2.6） |
| 转用例生成 | 勾选若干条 → 点击 [转用例生成] | 弹出目标文档选择 → 路由跳转至该文档脑图页，勾选内容拼接为需求文本预填「AI 生成用例」抽屉 |
| 点击空白关闭 | 点击抽屉外空白区域 | 抽屉自动关闭；分析中关闭即中断请求（abort） |

- 抽屉以透明遮罩承载，点击抽屉外任意空白处自动关闭，不压暗画布；打开期间页面被遮罩拦截不可交互，需关闭抽屉后再操作；
- 分析范围限定当前项目；建议不自动创建任何用例，清单可整体忽略。

## 5. 执行顺序推荐（US-AI-017）

**入口**：计划详情页新增 [执行顺序推荐] 标签页，仅计划负责人 / 执行人可发起与查看。

### 5.1 推荐视图布局

```
┌──────────────────────────────────────────────────────┐
│  [执行记录] [执行顺序推荐✨]              [重新计算]  │
├──────────────────────────────────────────────────────┤
│  ⚠ 计划快照已重新同步，推荐结果已失效，请重新计算    │  ← stale 提示条（按需）
├──────────────────────────────────────────────────────┤
│  #1 │ 支付-余额不足   │ 指数 92 │ P0 │ ▸ 因子明细    │
│  #2 │ 登录-密码错误   │ 指数 87 │ P0 │ ▸ 因子明细    │
│  #3 │ 订单-超时取消   │ 指数 74 │ P1 │ ▸ 因子明细    │
│  …（按推荐执行指数降序）                             │
└──────────────────────────────────────────────────────┘
```

### 5.2 交互说明

| 操作 | 触发方式 | 反馈 |
| ---- | ---- | ---- |
| 首次进入（无结果） | 打开 [执行顺序推荐] 标签页 | 空态说明 + [开始计算] 按钮 |
| 发起计算 | 点击 [开始计算] / [重新计算] | 确定性加权计算（非 LLM），完成后渲染排序列表 |
| 展开因子明细 | 点击行内 [▸ 因子明细] | 展开显示三项因子得分（历史关联缺陷数 / 优先级权重 / 模块缺陷密度） |
| 查看推荐理由 | 明细内点击 [生成理由] | 按需发起 LLM 调用生成理由文本（行内 loading），已生成则直接展示 |
| 列表定位脑图 | 点击列表行 | 计划脑图滚动定位到对应节点并高亮 |
| 脑图徽标联动 | 脑图节点渲染 #序号 徽标 | 点击徽标反向滚动列表至对应行（双向联动） |
| 快照重新同步 | 同步快照后进入标签页 | 顶部 stale 提示条：推荐已失效需重算 |
| 语义降级 | semanticDegraded | 顶部提示条呈现（同通用规范 2.6） |

- 推荐仅供参考，不改变计划执行流程与执行记录规则。

│  ☑ 登录 > 密码登录 > 密码错误   理由：…    │

| 操作 | 触发方式 | 反馈 |

## 7. 通用交互模式总结

### 7.1 弹窗类型

| 类型 | 使用场景 |
| ---- | ---- |
| 侧面板 | AI 检查结果（评审详情页内嵌） |
| 抽屉 | 遗漏测试点分析 |
| 弹窗 | 回归子集推荐、取消任务确认、重新生成确认 |

### 7.2 加载状态

- 异步任务（检查）：进度条 + 2 秒轮询 + 可取消，离开页面可恢复；
- 流式生成（摘要）：统计即时渲染 + 文字流式渲染；
- 同步长调用（遗漏分析 / 回归推荐）：70 秒超时的持续加载态 + [取消] 按钮。

### 7.3 权限显隐

- 检查 / 摘要入口：前端按「当前用户 = 评审发起人」判断显隐，后端强校验兜底；
- 顺序推荐入口：仅计划负责人 / 执行人可见；回归子集推荐入口不限角色（带入关联受既有计划编辑权限约束）；
- 权限不足的用户完全不可见入口，不做置灰。
