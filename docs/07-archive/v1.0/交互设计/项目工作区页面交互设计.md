## 1. 总体布局

### 1.1 项目工作区整体框架

进入项目后采用“顶部导航 + 内容区”布局。内容区根据功能模块不同采用不同结构：

- **功能测试**：左右分栏（左侧菜单导航 + 右侧工作区）
- **接口测试**：暂未开放，显示占位提示
- **缺陷管理**：独立功能面板

```
┌──────────────────────────────────────────────────────────┐
│  顶部导航栏                                              │
│  [Logo] [功能测试] [接口测试] [缺陷管理]                  │
│  [📁 我的空间] [📂 我的项目] [⚙ 空间管理] [🔧 系统管理] │
├──────────────────────────────────────────────────────────┤
│                                                          │
│                      内容区                               │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 1.2 顶部导航栏

项目工作区顶部导航栏分为两行：

- **第一行**：动态菜单区，包含项目内功能入口
- **第二行**：右侧图标组，与全局导航保持一致

#### 1.2.1 动态菜单

项目模式下动态菜单固定为三个入口：

| 菜单项  | 路由                             | 说明           |
| ---- | ------------------------------ | ------------ |
| 功能测试 | `/workspace/projects/cases`    | 测试用例管理、评审、计划 |
| 接口测试 | `/workspace/projects/api-test` | 暂未开放         |
| 缺陷管理 | `/workspace/projects/bugs`     | 缺陷全生命周期管理    |

当前激活菜单项高亮显示。

#### 1.2.2 默认进入

用户进入项目后，默认跳转至**项目工作台**页面（`/workspace/projects/dashboard`），展示项目概览信息。

#### 1.2.3 我的项目

点击顶部导航栏右侧“📂 我的项目”图标，跳转至我的项目页面。该页面展示当前工作空间下所有活跃项目列表，用户可切换或选择项目。

### 1.3 全局交互规范

- **消息反馈**：成功/失败操作使用 Toast 提示（顶部居中，3秒自动消失）。
- **危险操作**：删除、归档等需二次确认弹窗。
- **加载状态**：数据请求时显示骨架屏，按钮显示 loading 状态。
- **自动保存**：脑图编辑操作实时同步，无需手动保存。
- **实时协作**：编辑脑图时自动建立 WebSocket 连接，断线时顶部显示“正在重连...”横幅。

## 3. 功能测试

功能测试工作区采用**左右分栏**布局：

- **左侧**：菜单导航，展示测试用例、测试评审、测试计划三个子模块入口。
- **右侧**：子模块内容区，根据当前选中菜单项切换内容。

```
┌──────────────────────────────────────────────────┐
│  功能测试                                        │
├──────────┬───────────────────────────────────────┤
│ 菜单导航 │         子模块内容区                    │
│          │                                       │
│ 测试用例 │      (根据菜单切换)                     │
│ 测试评审 │                                       │
│ 测试计划 │                                       │
│          │                                       │
└──────────┴───────────────────────────────────────┘
```

### 3.1 左侧菜单导航

菜单项列表：

| 菜单项  | 图标  | 说明                 |
| ---- | --- | ------------------ |
| 测试用例 | 📋  | 管理测试用例，包含模块树和脑图编辑器 |
| 测试评审 | ✅   | 管理测试评审，包含评审列表和评审详情 |
| 测试计划 | 📝  | 管理测试计划，包含计划列表和执行跟踪 |

- 点击菜单项切换右侧子模块内容。

#### 3.2.1 页面布局

```
┌──────────┬───────────────────────────────────────┐
│ 模块树   │   📄 登录用例集                        │
│          │                                       │
│ 📁功能   │  ┌──────────────────────────────┐     │
│  📁登录  │  │        脑图编辑区              │     │
│   📄用例集│  │                              │     │
│  📁支付  │  │    ┌───┐                      │     │
│   📄流程 │  │    │根节点│                    │     │
│ [+新建]  │  │    └─┬─┘                      │     │
│          │  │  ┌───┴───┐                    │     │
│          │  │  │子节点1 │                    │     │
│          │  │  └───────┘                    │     │
```

#### 3.2.2 交互说明

**模块树交互**：展开/折叠点击箭头；选中文档点击节点加载脑图；新建右键或[+新建]输入名称；重命名双击或右键；拖拽移动节点；删除右键或Delete键二次确认。

**脑图编辑器**：添加子节点Tab；添加兄弟节点Enter；编辑文本双击；移动拖拽；删除Delete；标记用例/优先级工具栏或右键菜单；缩放Ctrl+=/-/0或工具栏按钮；抓手模式工具栏切换或按H键。

**脑图组件详细设计**参见《脑图组件实现设计文档》。

### 3.3 测试评审子模块

选中“测试评审”菜单后，右侧展示评审列表或评审详情。

#### 3.3.1 评审列表页

```
┌──────────────────────────────────────────────────┐
│  [搜索标题] [状态: 全部 ▼] [查询] [重置]  [+ 发起评审] │
├──────────────────────────────────────────────────┤
│  标题 │ 发起人 │ 状态 │ 进度 │ 通过率 │ 创建时间 │ 操作    │
│  登录  │ 张三   │ 评审中│[━━] │ 60%    │06-15    │[进入评审][完成][删除]│
│  支付  │ 李四   │ 已完成│[━━] │ 100%   │06-10    │[查看详情][删除]     │
└──────────────────────────────────────────────────┘
```

查询区：关键字输入框（标题模糊匹配，回车即查）+ 状态下拉（待评审/评审中/已完成）+ [查询]/[重置]按钮，重置清空条件并回到首页。列表新增两列：进度（已评审/关联总数进度条）与通过率（100% 时绿色、否则红色）。操作列：[进入评审]（未完成）/[查看详情]（已完成）；[完成]（未完成可见，确认后直接完成，不做全部通过门槛校验）；[删除]（二次确认，仅发起人，后端校验）。点击[发起评审]弹出创建表单：标题、描述、参与者（多选成员）、关联用例（打开CaseSelector弹窗）。提交后跳转至评审详情页，新建评审默认待评审状态，首次标记后自动转入评审中。

#### 3.3.2 评审详情页

```
┌──────────────────────────────────────────────────┐
│ ← 返回 登录模块评审 [评审中]  [━进度━] 通过n 不通过n 待评审n │
│                    [调整用例][同步用例][完成评审]      │
├──────────┬───────────────────────────────────────┤
│ 快照文档树│   快照脑图 (只读)                      │
│ (多文档   │   节点右侧徽标回显评审标记 ✓通过/✕不通过 │
│  点击切换) │   工具栏：通过/不通过/待评审/评论          │
└──────────┴───────────────────────────────────────┘
```

**详情页交互**：

- 标题行单行承载全部信息：标题 + 状态标签（待评审/评审中/已完成）；右侧为进度条与分色统计（通过绿/不通过红/待评审橙）及操作按钮（带图标；主操作实心、次要操作 plain）；标记成功后进度实时刷新。
- 左侧为快照文档树（目录/文档层级），点击文档切换右侧对应文档的快照脑图，支持多文档评审；默认选中首个文档。
- [调整用例]（评审未完成可用）：打开 CaseSelector 弹窗并回显当前规划的用例，确认后差量更新快照（可增删文档与用例）。
- [同步用例]：同步成功后自动重载快照树与脑图。
- [完成评审]：仅当待评审与不通过均为 0（全部通过）时可用，否则置灰并 tooltip 提示。
- 评审标记三态：通过/不通过/待评审（重置），结果以彩色徽标回显在节点右侧；选中节点点[评论]打开“评审记录”抽屉（头像气泡列表 + 底部固定输入区，Enter 发送）。
- 点[← 返回]回到功能测试页并自动激活“测试评审”子模块（`?tab=reviews`）。

详情页复用脑图组件（`mode='review'`），工具栏切换为评审操作按钮。

选中“测试计划”菜单后，右侧展示计划列表或计划详情。

#### 3.4.1 计划列表页

```

│  [搜索名称] [状态: 全部 ▼] [查询] [重置]  [+ 创建计划] │
├──────────────────────────────────────────────────┤
```

查询区与评审列表一致（关键字按名称模糊匹配）。列表同样提供进度（已执行/关联总数）与通过率（100% 绿色、否则红色）两列；操作列：[进入执行]/[查看详情]、[完成]（未结束可见，确认后直接完成，不校验未执行用例）、[删除]（二次确认，仅负责人，后端校验）。点击[创建计划]弹出创建表单：名称、负责人、起止时间、执行环境、关联用例。提交后跳转至计划详情页。

#### 3.4.2 计划详情页

```
┌──────────────────────────────────────────────────┐
│ ← 返回 功能测试计划 [进行中] [━进度━] 通过n 失败n 阻塞n 待执行n │
│              [调整用例][同步用例][完成执行]          │
├──────────┬───────────────────────────────────────┤
│ 快照文档树│   快照脑图                              │

│  点击切换) │   ✓通过 ✕失败 ⚠阻塞（待执行不显示）    │
└──────────┴───────────────────────────────────────┘
```

**详情页交互**（与评审详情页保持一致）：

- 标题行单行承载：名称 + 状态标签 + 进度与分色统计 + 操作按钮（待开始/进行中：调整用例/同步用例/完成执行）；标记成功后进度实时刷新。
- 不再提供单独的“开始执行”操作：待开始计划首次标记执行结果后自动转入进行中；[完成执行]二次确认后状态置已完成，不可再标记执行结果。
- 左侧快照文档树点击切换多文档；[调整用例]在计划未结束（待开始/进行中）时可用，回显当前规划并差量更新快照。
- 执行标记四态：通过/失败/阻塞/待执行（重置），结果以彩色徽标回显在节点右侧。
- 点[← 返回]回到功能测试页并自动激活“测试计划”子模块（`?tab=plans`）。

详情页复用脑图组件（`mode='plan'`），工具栏切换为执行操作按钮。

## 5. 缺陷管理

**路由**：`/workspace/projects/bugs`

缺陷管理采用独立功能面板，包含看板和列表两种视图，支持新增缺陷和查看缺陷详情。

### 5.1 缺陷看板/列表页

看板列包含「激活」「已解决」「已关闭」三列（已拒绝缺陷仅在列表视图查看）；列表包含缩略 ID 列、解决人、解决时间、解决方案、关闭人、关闭时间列。标签配色（状态/严重等级/优先级）列表与详情页统一对齐。

快捷过滤栏提供「未修复」「由我创建」「指派给我」等快速选项；更多筛选弹层内选择条件后保活不收起。

#### 5.1.1 看板视图（四列）

```
┌──────────────────────────────────────────────────────┐
│  缺陷管理       [看板] [列表]       [+ 提交缺陷]       │
├──────────┬──────────────────┬──────────┬────────────┤
│ 激活(3)  │    已解决(2)     │ 已关闭(2)│            │
│ ┌──────┐ │ ┌────────────┐ │ ┌──────┐│            │
│ │登录   │ │ │支付        │ │ │首页  ││            │
│ │致命🔴 │ │ │严重🟠      │ │ │轻微🟢││            │
│ └──────┘ │ └────────────┘ │ └──────┘│            │
└──────────┴──────────────────┴──────────┴────────────┘
```

**交互**：卡片拖拽至目标列更新状态；点击卡片跳转详情页；筛选栏滚动时粘性悬浮于顶部；看板列采用 DynamicSizeList 虚拟化；支持按状态/等级/优先级/处理人/报告人/解决人/关闭人筛选。

#### 5.1.2 列表视图

表格形式：缩略 ID、标题（超 13 字符截断）、严重等级、优先级、状态、处理人、解决人、解决方案、解决时间、关闭人、关闭时间、创建时间、操作。时间列格式统一为 `MM-dd HH:mm`。支持多条件筛选和分页。

**操作列**：详情始终显示；按状态直出解决（active）/关闭（resolved/rejected）/激活（closed）；非 closed 行收「更多」下拉（确认、拒绝、激活、指派、复制）。

**行操作说明**：

- **复制**：跳转创建页经 query 回填源缺陷信息（处理人不复制，由提交人重新指派）。
- **解决**：弹 BugResolveDialog（选择 resolution + 备注说明），解决后处理人自动回设为创建人。
- **拒绝**：弹说明输入框，拒绝后处理人回设为创建人。
- **关闭**：弹说明输入框。
- **激活（重开）**：弹说明输入框，已解决→回设给解决人，已拒绝→回设给拒绝人。

### 5.2 新增缺陷页

**路由**：`/workspace/projects/bugs/create`

#### 5.2.1 页面布局

```

├──────────────────────────────────────────────────┤
```

#### 5.2.2 交互说明

| 操作     | 触发方式       | 反馈                            |
| ------ | ---------- | ----------------------------- |
| 选择处理人  | 点击下拉框展开    | 显示当前工作空间所有成员，支持搜索过滤           |
| 选择关联用例 | 点击[选择]按钮   | 打开CaseSelector弹窗，已选用例显示名称，可清除 |
| 选择关联计划 | 点击[选择]按钮   | 打开计划选择器弹窗，已选计划显示名称，可清除        |
| 选择附件   | 点击[+ 选择文件] | 本地暂存文件列表（单文件不超过 10MB），可移除；提交成功后逐个上传 |
| 表单校验   | 失焦时触发      | 标题必填，红色边框+错误提示                |
| 提交     | 点击[提交]     | 前端校验→调用创建接口→成功跳转缺陷列表页         |
| 取消     | 点击[取消]或←返回 | 不保存离开（有修改时二次确认）               |

#### 5.3.3 交互说明

| 操作     | 触发方式       | 反馈                                                   |
| ------ | ---------- | ---------------------------------------------------- |
| 页面加载   | 进入页面时      | 调用 `GET /api/project/bugs/:bugId` 获取缺陷详情、操作日志与附件列表      |
| 编辑字段   | 直接修改表单控件   | 非关闭状态下所有字段可编辑；支持修改关联用例与关联计划                        |
| 更新状态   | 点击底部操作栏按钮  | 按四态状态机流转；解决弹 BugResolveDialog（选 resolution + 备注说明，处理人自动回设创建人）；拒绝弹说明输入框（处理人自动回设创建人）；关闭/重开弹说明输入框 |
| 关联用例悬停 | 鼠标悬浮关联用例区域 | 弹出卡片展示完整明细（前置条件↔步骤↔预期），提供[跳转所在文档]链接 |
| 关联用例选择 | 编辑时点击[选择]  | 打开 CaseSelector 弹窗（单选模式），已选用例显示名称，可清除 |
| 上传附件   | 点击[上传附件]   | 非关闭状态可用，单文件不超过 10MB，上传成功后列表刷新并写操作日志        |
| 下载附件   | 点击附件行[下载]  | 浏览器保存原始文件名文件，任意状态可用                              |
| 删除附件   | 点击附件行[删除]  | 非关闭状态可用，二次确认后删除并写操作日志                          |
| 保存     | 点击[保存]     | 调用 `PUT /api/project/bugs/:bugId` → 操作日志刷新 → Toast提示 |
| 取消     | 点击[取消]或←返回 | 不保存离开（有修改时二次确认）                                      |
| 查看操作记录 | 滚动下方列表     | 按时间倒序展示所有操作历史                                        |
| 关闭状态限制 | 状态为"已关闭"时  | 表单控件变为只读文本，不显示[保存][取消]与附件上传/删除，保留[激活]入口与附件下载      |

**状态流转规则**（四态状态机）：

```
active → resolved（解决）/ rejected（拒绝）→ closed（关闭）→ active（重开）
```

- **解决**：resolution 必填 + 备注说明；resolution=duplicate 需指定原始缺陷；处理人自动回设为创建人。
- **拒绝**：说明必填；处理人回设为创建人；记录拒绝人。
- **关闭**：说明必填。
- **重开（激活）**：说明必填；处理人流转：已解决→回设给解决人，已拒绝→回设给拒绝人。
- 关闭状态下除重新打开外不可再修改任何信息。

## 8. 通用交互模式总结

### 8.1 弹窗类型

| 类型    | 使用场景                 |
| ----- | -------------------- |
| 确认弹窗  | 删除节点/文档/模块、关闭计划、完成评审 |
| 表单弹窗  | 发起评审、创建计划、提交缺陷       |
| 选择器弹窗 | 关联用例、选择处理人、选择计划      |

### 8.2 状态标识规范

- **用例优先级**：P0红色、P1橙色、P2蓝色、P3灰色
- **执行结果**：通过🟢、失败🔴、阻塞⚪、未执行🟡
- **缺陷等级**：致命🔴、严重🟠、一般🟡、轻微🟢
- **评审标记**：通过✅、不通过❌

### 8.3 空状态处理

| 场景     | 展示                    |
| ------ | --------------------- |
| 无模块    | “暂无模块，右键或点击[+新建]创建”   |
| 文档无节点  | 显示根节点，提示“Tab添加子节点”    |
| 无评审/计划 | “暂无评审/计划，点击按钮创建”      |
| 无缺陷    | “暂无缺陷，点击[提交缺陷]创建”     |
| 脑图加载   | 文档区域显示骨架屏             |
| 协作断线   | 顶部黄色横幅“连接已断开，正在重连...” |
