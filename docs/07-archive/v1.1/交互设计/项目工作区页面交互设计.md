## 1. 评审详情页变更（3.3.2 增量）

### 1.1 移除已选用例

**入口**：评审详情页脑图（ReviewMindMap）两处，评审未完成（待评审/评审中）时可用：

1. **标记结果组件（脑图工具栏）**：新增 [移除用例] 按钮，位于 [评论] 按钮右侧；
2. **右键菜单**：选中用例节点右键，新增「从评审中移除」菜单项，位于「添加评论」下方，以分隔线隔开。

**触发条件**：

- 仅当选中节点为 `case` 类型时可用（步骤/前置条件/文档/目录节点不可移除，入口置灰或提示）；
- 评审状态为「已完成」（completed）时入口隐藏，与 [调整用例] 权限一致；后端强校验兜底（已完成抛业务异常）。

**交互流程**：

1. 脑图中选中一个已关联的用例节点；
2. 点击工具栏 [移除用例] 或右键菜单「从评审中移除」；
3. 二次确认弹窗「确定从该评审中移除用例『用例标题』吗？移除后该用例及其评审标记将不再展示，历史标记记录保留作审计。」；
4. 确认后调用规划用例更新接口（全量覆盖式）：从当前规划中剔除该用例，若所属文档无剩余用例则整文档移除；
5. 成功 Toast「已移除用例」→ 脑图重载（该文档快照刷新）、进度条与统计实时刷新；
6. 取消或失败：关闭弹窗 / 错误 Toast，界面不变。

**边界与约束**：

- 移除仅删除快照节点，**评审标记/评论记录保留作审计**（与调整用例行为一致）；
- 移除后快照树同步重载：若整文档被移除，左侧文档树对应条目消失，当前选中文档回退到首个文档；
- 移除入口的可用状态（是否选中 case 节点）由脑图选中态实时驱动，无选中或选中非 case 节点时置灰。

## 2. 计划详情页变更（3.4.2 增量）

### 2.1 移除已选用例

**入口**：计划详情页脑图（PlanMindMap）两处，计划未结束（待开始/进行中）时可用：

2. **右键菜单**：选中用例节点右键，新增「从计划中移除」菜单项。

**触发条件**：

- 仅当选中节点为 `case` 类型时可用；
- 计划状态为「已完成/已关闭」时入口隐藏，与 [调整用例] 权限一致；后端强校验兜底。

**交互流程**：

1. 脑图中选中一个已关联的用例节点；
2. 点击工具栏 [移除用例] 或右键菜单「从计划中移除」；
3. 二次确认弹窗「确定从该计划中移除用例『用例标题』吗？移除后该用例及其执行结果将不再展示，历史执行记录保留作审计。」；
4. 确认后调用规划用例更新接口（全量覆盖式）：从当前规划中剔除该用例，若所属文档无剩余用例则整文档移除；
5. 成功 Toast「已移除用例」→ 脑图重载、进度条与统计实时刷新；
6. 取消或失败：关闭弹窗 / 错误 Toast，界面不变。

**边界与约束**：

- 移除仅删除快照节点，**执行记录保留作审计**（与调整用例行为一致）；
- 移除后快照树同步重载：若整文档被移除，左侧文档树对应条目消失，当前选中文档回退到首个文档；
- 移除后计划快照视为已变更，执行顺序推荐结果失效（stale 提示规则沿用既有同步机制）。
