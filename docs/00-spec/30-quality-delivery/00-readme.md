## 1. 用途

本分类维护质量门禁、Git 协作、构建部署和项目发布操作要求。通用规范与具体项目 Runbook 分开维护。

## 2. 文档清单

| 文档 | 职责 | 状态 |
| --- | --- | --- |
| [01-quality](01-quality.md) | 测试、覆盖率、静态检查和质量红线 | 已发布 |
| [02-workflow](02-workflow.md) | 分支、提交、PR、发布和回滚流程 | 已发布 |
| [03-deploy](03-deploy.md) | 构建、环境、部署和回滚原则 | 已发布 |
| [04-deployment-runbook](04-deployment-runbook.md) | 具体项目部署操作和故障排查 | 已发布 |

## 3. 阅读顺序

1. 提交前阅读 `01-quality.md` 和 `02-workflow.md`；
2. 构建发布前阅读 `03-deploy.md`；
3. 执行实际环境操作时查阅 `04-deployment-runbook.md`。

## 4. 维护规则

- 通用门禁和项目操作步骤分开编写。
- 质量阈值、命令和例外必须有验证证据。
- 发布变更必须记录制品、验证和回滚方式。
