# 前端面包屑导航规范

**文档版本**：V1.0
**日期**：2026-09-30
**状态**：起草中

---

## 1. 引言

### 1.1 编写目的

本规范定义前端详情类页面面包屑导航的结构、视觉基准与交互要求，保证回退入口与当前页定位在不同业务模块之间保持一致。

本规范只约束面包屑的结构与视觉表现，不改变页面的数据流、状态管理或业务逻辑。

### 1.2 适用范围

适用于从列表页进入的详情、编辑类页面的内容区顶部导航，重点包括：

- 系统管理域的用户表单、工作空间详情等页面。
- 功能测试域的测试计划详情、测试评审详情等页面。
- 后续新增的「列表 → 详情/编辑」二级页面。
- 不适用于列表页、首页等一级页面；不适用于三级以上多级路径（当前业务未出现，出现时先更新本规范）。

### 1.3 定义与缩写

| 术语 | 定义 |
| ---- | ---- |
| 面包屑 | 内容区顶部由「回退入口 → 分隔符 → 当前页项」组成的定位导航行。 |
| 回退入口 | 面包屑中可点击、指向上一级列表页的链接项。 |
| 当前页项 | 面包屑末项，标识当前页面位置，不可点击。 |
| 演示稿 | `web/demos/` 下的静态示例页面，本规范视觉基准的来源。 |

### 1.4 与现有规范的关系

- 通用视觉、设计令牌使用与组件样式覆盖要求见 `docs/00-spec/50-ui/01-frontend-design.md`（UI-DS-03、UI-DS-09）。
- 页面拆分与状态归属见 `docs/00-spec/50-ui/02-page-development.md`。
- 面包屑在整高 flex 分区滚动页面中的固定行行为见 `docs/00-spec/50-ui/03-scroll-container.md`（UI-SC-06）。
- 页面具体文案、层级与交互流程由对应的需求、设计和交互文档定义；本规范只规定结构与视觉基准，不复制具体项目的色值与业务布局。

### 1.5 规则登记

本文件的规则已在 `docs/00-spec/00-governance/01-overview.md` 登记为 `UI-BC-01` 至 `UI-BC-05`。

## 2. 总体原则

1. **只承担定位与回退。** 面包屑不承载操作、状态标签或装饰。
2. **可点击信号由颜色承担。** 回退入口用全站链接主色，当前页项用最深中性色，两者不互换。
3. **当前页只加深不加粗。** 位置感交给深浅，强调由紧随其下的页面标题承担。
4. **结构固定为两级路径。** 「上一级列表 → 当前页」，不展开多级历史路径。
5. **视觉值统一取自设计令牌与本规范基准。** 颜色、字号、间距禁止页面各自取值。

## 3. 规范条目

### 3.1 UI-BC-01：适用场景与结构

面包屑只出现在从列表页进入的详情、编辑类页面，位于内容区顶部、页头标题区之上；列表页、首页等一级页面不渲染面包屑。

结构固定为「回退入口 → 分隔符 → 当前页项」，语义为两级导航：

```vue
<!-- 结构示意（伪代码）：路由与文案按页面实际上级列表配置 -->
<div class="page__breadcrumb">
  <router-link to="/parent/list">父级列表</router-link>
  <el-icon :size="13"><ArrowRight /></el-icon>
  <span>{{ currentName }}</span>
</div>
```

**要求**：

- 容器为页面根类下的 `<page>__breadcrumb`，样式限定在页面 `scoped` 样式内，禁止新增全局类名。
- 回退入口使用 `router-link` 指向上一级列表页，保留列表页原有上下文参数（如页签 `?tab=plans`）。
- 当前页项为纯文本 `<span>`，不得渲染为链接；回退入口是唯一可点击项。

**禁止**：一级页面顶部放置面包屑；当前页项可点击；为凑层级增加无回退价值的中间项。

### 3.2 UI-BC-02：容器排版基准

容器统一采用以下排版基准：

```scss
.page__breadcrumb {
  display: flex;
  align-items: center;
  gap: 6px;
  margin-bottom: var(--space-sm);
  font-size: var(--font-size-sm);
  color: var(--color-neutral-600);
}
```

**要求**：

- `gap: 6px` 为固定基准值，`margin-bottom` 统一 `var(--space-sm)`，与演示稿基准一致。
- 字号统一 `var(--font-size-sm)`；容器基础文字色 `var(--color-neutral-600)` 作为中间层级的文字回退。
- 面包屑是页面级固定行：页面根容器为整高纵向 flex（`height: 100%` + `flex-direction: column`）时必须声明 `flex-shrink: 0`，防止被相邻内容压缩，关联 UI-SC-06；普通流式页面无需该声明。
- 面包屑行不加背景、边框或内边距，不卡片化，不参与滚动容器的样式改写。

**禁止**：硬编码色值（必须引用 `var(--color-*)`、`var(--font-size-*)`、`var(--space-*)`）；为面包屑新增独立样式文件。

### 3.3 UI-BC-03：回退入口链接色

回退入口沿用全站链接色：颜色本身就是「可点击」信号，与仅作定位的当前页项区分。

```scss
.page__breadcrumb a {
  color: var(--color-primary-500);
  font-weight: 500;
  text-decoration: none;
}

.page__breadcrumb a:hover {
  color: var(--color-primary-600);
}
```

**要求**：

- 链接色 `var(--color-primary-500)`、字重 `500`、无下划线；hover 加深为 `var(--color-primary-600)`。
- 不为回退入口增加外框、背景或箭头图标等额外提示，反馈只依赖颜色加深。

**禁止**：回退入口使用中性灰（与当前页项失去区分，可点击性不可发现）；hover 时添加下划线或背景（与全站链接反馈不一致）。

### 3.4 UI-BC-04：当前页项与文字层级

当前页只加深不加粗：位置感交给深浅，强调由紧随其下的页面标题承担。

```scss
.page__breadcrumb > :last-child {
  color: var(--color-neutral-900);
}
```

**要求**：

- 末项通过 `> :last-child` 命中（结构固定，末项即当前页），颜色 `var(--color-neutral-900)`。
- 当前页项不加粗、不加背景徽标、不包 `router-link`。
- 当前页项文案标识当前对象或页面（数据未就绪时回退到页面占位名），与下方页面标题同源。

**禁止**：当前页项加粗或使用主色（与回退入口混淆）；为当前页项单独新增命名类与重复声明。

### 3.5 UI-BC-05：分隔符图标

分隔符统一使用 Element Plus 全局注册图标，不使用字符或自定义 SVG：

```vue
<el-icon :size="13"><ArrowRight /></el-icon>
```

```scss
.page__breadcrumb .el-icon {
  color: var(--color-neutral-400);
}
```

**要求**：

- 图标为 `ArrowRight`，`:size="13"`，颜色 `var(--color-neutral-400)`；图标已在应用入口全局注册，无需按页导入。
- 颜色声明挂在 `el-icon` 根类上（颜色经继承落到 SVG），不使用 `:deep()` 侵入组件内部结构，符合 UI-DS-09。
- 演示稿分隔符为等价方向图标，实现按 UI-DS-09 优先取 Element Plus 图标组件。

**禁止**：使用字符（`/`、`>`、`»`）或自定义 SVG 作为分隔符；使用 `:deep()` 覆盖 Element Plus 图标内部样式。

## 4. 审查清单

| 编号 | 检查项 | 通过标准 |
| ---- | ---- | -------- |
| UI-BC-01 | 场景与结构 | 详情/编辑页内容区顶部为「链接 → 分隔符 → 纯文本当前页」两级结构；一级页面无面包屑；当前页项非链接。 |
| UI-BC-02 | 容器排版 | flex 布局、`gap: 6px`、底距 `var(--space-sm)`、字号 `var(--font-size-sm)`、基础色 `var(--color-neutral-600)`；整高 flex 页面含 `flex-shrink: 0`；无硬编码色值。 |
| UI-BC-03 | 回退入口 | 主色 `var(--color-primary-500)` + 字重 500、无下划线，hover `var(--color-primary-600)`。 |
| UI-BC-04 | 当前页项 | `> :last-child` 为 `var(--color-neutral-900)`，不加粗、非链接、无命名类。 |
| UI-BC-05 | 分隔符 | `ArrowRight` `:size="13"`、`var(--color-neutral-400)`；无字符/自定义 SVG 分隔符，无 `:deep()` 覆盖。 |
