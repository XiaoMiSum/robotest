# 跨端契约索引

**文档版本**：V1.0
**日期**：2026-09-24
**状态**：已发布

---

## 1. 用途

本分类维护 HTTP、实时通信、响应、分页、错误码和持久化等跨端契约。业务字段和具体业务边界由对应的详细设计补充。

## 2. 文档清单

| 文档 | 职责 | 状态 |
| --- | --- | --- |
| [01-api](01-api.md) | HTTP API、响应、分页、错误码和 OpenAPI | 已发布 |
| [02-database](02-database.md) | 数据类型、表结构、索引和迁移 | 已发布 |
| [03-realtime-protocol](03-realtime-protocol.md) | 通用 WebSocket 连接、帧和生命周期 | 已发布 |

## 3. 阅读顺序

1. 先阅读 `01-api.md` 确认 HTTP 契约；
2. 涉及持久化时阅读 `02-database.md`；
3. 涉及实时连接时阅读 `03-realtime-protocol.md`。

## 4. 维护规则

- 同一契约只能有一个主规范定义。
- 业务事件和资源字段在详细设计中定义，不在本分类复制。
- 契约变更必须同步 OpenAPI、类型和测试。
