## 3. 阅读顺序

安全相关页面、接口、实时连接和部署变更均先阅读 `01-security.md`，再结合对应契约和详细设计执行。

## 4. 维护规则

- 前端体验和路由不能替代服务端授权。
- 密钥、凭证和敏感数据不得进入日志或普通响应。
- 安全例外必须记录范围、原因、负责人和失效条件。
