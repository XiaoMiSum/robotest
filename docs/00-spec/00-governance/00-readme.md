# 规范治理索引

**文档版本**：V1.0

**状态**：已发布

---

## 1. 用途

本分类维护工程规范的治理规则、冲突处理、任务模板和待办记录。规范内容本身以根目录 `docs/00-spec/00-readme.md` 为索引入口。

## 2. 文档清单

| 文档 | 职责 | 状态 |
| --- | --- | --- |
| [01-overview](01-overview.md) | 规则登记、权威边界和冲突处理 | 已发布 |
| [02-task-template](02-task-template.md) | 任务执行和交付检查模板 | 已发布 |
| [03-improvement-backlog](03-improvement-backlog.md) | 未完成事项、优先级和验收标准 | 起草中 |

## 3. 阅读顺序

1. 先阅读根目录总索引和 `01-overview.md`；
2. 执行任务时查阅 `02-task-template.md`；
3. 需要了解未完成工作时查阅 `03-improvement-backlog.md`。

## 4. 维护规则

- 本分类文件使用语义化文件名，分类目录负责排序。
- 新增治理规则时同步更新根索引和规则登记册。
- 待办事项必须包含状态、依赖和完成标准。
