## 1. 用途

本分类维护前端、后端和框架集成相关的工程实现规范。业务语义和具体接口契约不在本分类中重复定义。

## 2. 文档清单

| 文档 | 职责 | 状态 |
| --- | --- | --- |
| [01-frontend](01-frontend.md) | 前端分层、组件、路由、请求和测试边界 | 已发布 |
| [02-backend](02-backend.md) | 后端分层、DTO、数据访问和更新边界 | 已发布 |
| [03-migoo-framework](03-migoo-framework.md) | 框架组件选择、适配和升级要求 | 已发布 |
| [04-migoo-api-reference](04-migoo-api-reference.md) | 框架 API 速查和接入边界 | 已发布 |

## 3. 阅读顺序

1. 先阅读前端或后端主规范；
2. 使用框架能力前阅读 `03-migoo-framework.md`；
3. 需要 API 入口时查阅 `04-migoo-api-reference.md`。

## 4. 维护规则

- 端级实现规则只在本分类维护。
- 跨端契约引用 `docs/00-spec/20-contracts/`。
- 框架 API 以锁定版本和官方文档为准。
