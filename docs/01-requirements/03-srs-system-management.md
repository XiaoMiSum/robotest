### 3.1 系统管理模块（拥有系统权限的用户可访问）

拥有任意系统权限的用户可见系统管理功能入口。无系统权限的用户不显示系统管理入口。

#### 3.1.1 用户管理

**功能描述**：管理平台所有账号的生命周期。  
**功能点**：  

- 创建账号：录入用户名、邮箱、初始密码，选择角色。  
- 编辑账号：修改邮箱、角色、密码重置。  
- 禁用/启用账号：禁用后该用户无法登录，历史数据保留。支持批量操作。  
- 查询与筛选：可按用户名、邮箱、状态、角色等条件检索用户。  

**业务规则**：  

- 用户名必须全局唯一，长度3~30字符。  
- 密码仅需 8~64 字符长度，不再要求包含大写、小写、数字、特殊字符中至少三种。
- 系统管理员不能修改自己的角色或禁用自己。  
- 用户的工作空间归属由「全局工作空间管理」维护，用户管理不涉及工作空间归属的设置。

#### 3.1.2 全局工作空间管理

**功能描述**：管理平台内所有工作空间的创建、解散及成员构成。  
**功能点**：  

- 创建工作空间：输入工作空间名称和描述，名称全局唯一，长度2~50字符。  
- 解散工作空间：仅当工作空间下没有任何项目（含归档项目）时允许解散；解散后自动解除所有成员的该工作空间归属。  
- 添加成员：选择目标工作空间，从平台业务用户中多选加入。一个用户可同时属于多个工作空间。  
- 移除成员：解除指定用户与目标工作空间的关系，不影响该用户在其他工作空间的归属。  

**业务规则**：  

- 系统管理员不能被添加为任何工作空间成员。

#### 3.1.3 角色与权限管理

**功能描述**：定义平台角色及其功能权限，并将角色授予用户。  
**功能点**：  

- 定义角色：可创建自定义系统角色或工作空间角色，预置"系统管理员"角色不可删除。
- 权限作用域：权限点分为 `global`（系统级）和 `workspace`（空间级）两类，角色通过 `scope` 字段限定其权限范围。
- 全量权限（full_access）：角色可设置为全量权限，拥有对应作用域下的所有权限码，运行时自动注入。
- 配置权限：以功能模块为单位，通过权限列表勾选可访问的功能点。系统管理员默认拥有所有全局管理权限且不可更改。
- 分配角色：为用户指定一个或多个系统角色，工作空间角色在空间成员管理中设置。

**业务规则**：  

- 角色名称全局唯一。
- 具有全量权限（full_access）的角色，其权限配置面板锁定，不可手动编辑。
- 权限变更后，已登录用户的下次请求即可生效（工作空间权限通过拦截器实时注入）。

#### 3.1.4 系统初始化

**功能描述**：平台首次部署完成后，系统必须经过初始化才能使用。初始化由安装者在登录页自动引导完成。  
**功能点**：

- 初始化检测：访问登录页时自动调用初始化状态接口，后端检查有无任何用户存在。
- 初始化引导：若系统未初始化，登录页自动跳转至初始化页面。
- 设置管理员密码：输入管理员密码（至少 8 位）并确认，提交后系统创建 admin 账号并分配系统管理员角色。
- 初始化防重：若系统已初始化（存在用户），再次调用初始化设置接口返回错误码，禁止重复初始化。

**业务规则**：

- 初始化接口为公开接口，无需认证即可访问。
- admin 账号为系统初始化时自动创建，用户名固定为 `admin`，显示名称为「系统管理员」。
- 初始化完成后跳转至登录页，用户使用 admin 账号及设置的密码登录。
- 系统管理员角色预置 UUID `b0000000-0000-0000-0000-000000000001`，拥有全部系统权限。
- 初始化后可登录进入系统管理模块创建普通用户，也可先创建工作空间后再创建业务用户。
