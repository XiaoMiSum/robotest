## 1. 智能助手

### 1.1 总体描述

智能助手提供**项目内**对话入口，用户用一句话提出问题或任务，助手解析意图、按需查询平台数据补全省略参数，信息不足时主动澄清，最终以流式回答附来源引用返回。**助手不提供任何数据变更操作**，不创建、修改或删除业务数据，查询范围限于当前活跃项目。

核心交互链路：**一句话 → 对话式任务执行（查询补全与澄清追问）→ 流式回答（附来源引用）**。任务与审计口径见总册 1.5（`docs/01-requirements/07-ai-capability/02-srs-ai-capability.md`）；助手查询遵守项目成员归属与数据范围约束。

**权限**：业务模块免 RBAC 权限码校验，保留项目成员归属校验：助手入口仅在活跃项目上下文内对业务用户可见；查询范围限于当前活跃项目，操作人即当前登录用户。会话仅创建人可见可操作（含历史记录），管理员亦不跨人查看。

### 1.2 助手会话（US-AI-010）

**功能描述**：管理助手对话会话与上下文。  
**功能点**：

- 项目内常驻入口（侧边栏 / 悬浮球），仅在活跃项目上下文内的业务页面可唤起；未进入项目的页面（如「我的空间」列表页、项目列表页及空间相关页面）不显示入口。
- 会话列表：仅展示当前活跃工作空间及当前项目内的历史会话，按时间倒序，支持新建会话、继续既有会话、重命名与删除。
- 上下文自动携带：当前活跃工作空间、当前活跃项目（经请求头传递，为助手唯一目标作用域）与当前页面（如正在查看的脑图文档、计划），助手可据此解析省略的指代；助手内不提供项目二选一，跨项目指代被拒绝并提示切换作用域。
- 多轮对话：信息不足或存在歧义时助手**主动追问澄清**并给出 2~5 个快捷选项，不臆断作答；用户可补充约束（如"只看登录模块的用例"）。
- 查询补全：助手回答前可先查询平台数据（项目、模块与用例文档树、计划、评审、用例清单与进度等）自行补全省略的指代与参数，仅在系统中无据可依时才询问用户。

**业务规则**：

- 会话归属于其创建时所在的工作空间与项目：仅在归属空间及归属项目的会话列表中可见，发送与执行限于归属作用域；不在归属作用域操作该会话时拒绝并提示切换。
- 创建会话须处于项目上下文。
- 切换活跃工作空间或项目后，会话列表按新作用域重载，新任务的执行范围以切换后的上下文为准；跨工作空间 / 项目的指代被拒绝并提示。
- 删除会话仅删除会话与消息，不影响平台业务数据。

### 1.3 只读问答（US-AI-013）

**功能描述**：回答查询与统计类问题，不产生数据变更。  
**功能点**：

- 支持查询当前工作空间内的数据，如"当前计划执行进度""本周新增多少缺陷""某模块的用例数量"；进度查看类问题（评审进度、计划执行进度）直接作答并附对象跳转链接。
- 回答附来源引用，可点击跳转到对应对象（总册 1.3）；来源分平台数据查询结果与知识检索（含平台使用指引）两类。
- 数据超出所属工作空间或项目范围时明确拒绝并说明。

**业务规则**：

- 助手仅提供只读问答，不产生任何数据变更，直接返回答案与来源引用。
- 答案基于平台数据查询或知识检索结果，检索不可用时提示不可用，不编造数据。

### 1.4 消息附图与视觉理解（US-AI-014）

**功能描述**：用户发送消息时可附带图片，由具备视觉能力的模型理解后参与本轮问答与任务执行。  
**功能点**：

- 输入区支持选择图片随消息发送：单条消息 ≤3 张，单张 ≤10MB，支持 png / jpg / jpeg / gif / webp / bmp。
- 消息回显附图缩略图，历史会话可回看。
- 附图在本轮对话中被模型理解，可参与只读问答与澄清追问（如据截图询问用例覆盖情况）。
- 无可用视觉能力模型时发送即明确失败并提示，不静默忽略图片。

**业务规则**：

- 图片仅在发送轮次内被理解，历史消息图片不随上下文回传；跨轮追问需重新附图或以文字承接。
- 图片类型或大小超限即时拒绝并提示；图片与 1.2 的实体附件互为独立校验、互不影响。
- 图片仅存文件引用（落库不存字节），项目成员归属与会话归属口径同 1.2。
