## 1. AI 能力

### 1.1 总体描述

AI 能力是平台级基础能力，三个能力域构建其上：

| 能力域 | 分册 | 一句话定位 |
| ---- | ---- | ---- |
| 智能助手 | `docs/01-requirements/07-ai-capability/04-srs-ai-assistant.md` | 项目内对话式只读问答：查询平台数据、缺参澄清追问、回答附来源引用，不提供数据变更操作 |
| 缺陷分析 | `docs/01-requirements/07-ai-capability/05-srs-ai-defect-analysis.md` | 新建缺陷实时建议（含重复缺陷检测） |
| 辅助功能 | `docs/01-requirements/07-ai-capability/06-srs-ai-assisted-features.md`、`docs/01-requirements/07-ai-capability/07-srs-ai-review.md` | 用例优化（字段补全 + 级别推荐）、测试用例执行顺序推荐、脑图内基于需求生成测试用例、规划用例的 AI 评审 |

**两条全局原则**：

- **AI 自主编排执行**：耗时的 AI 操作一律经 AI Task 框架执行——由 AI 自主规划步骤、在已注册工具白名单范围内调用能力并全程留痕；提交即返回，执行过程（计划、当前步骤、轨迹）实时可见，可随时中止；执行受预算护栏约束，超限自动终止，不阻塞用户当前操作。
- **提案人工采纳**：AI 产出的模块、脑图、用例、分类建议等一律为**提案**，不直接落为正式数据；人工逐项或批量审核采纳（含修改后采纳）后才生效。采纳后 AI 不覆盖人工修改过的内容。

**定义与缩写**：

| 术语 | 定义 |
| ---- | ---- |
| 模型配置 | 对单个大模型接入的登记（地址、密钥、能力声明、启用状态），平台可配置多个，供给方式不锁定，可为云端 API 或私有化部署端点 |
| 向量 API | 将文本转化为向量表示的独立接入配置，可与模型配置来自不同供应商 |
| 提示词 | 针对特定业务场景编排的模型指令模板，可按场景自定义覆盖默认值 |
| AI 任务 | 一次面向明确目标的 AI 工作请求，由平台统一受理并交由 AI 自主编排执行，具有类型、状态与产出提案 |
| 执行轨迹 | 执行过程中 AI 的步骤规划、决策与工具调用的全过程留痕，用户可回看，只增不改 |
| 预算护栏 | 单次执行的资源上限（步数、时长、token、成本），超限自动终止执行 |
| 提案 | AI 执行产出的结构化结果（附证据引用），处于待采纳态，经人工采纳后落库 |
| 待采纳态 | AI 提案未生效的状态，可逐项采纳、修改后采纳、批量采纳或驳回 |
| 向量化 | 将文本等内容转化为向量表示，供相似检索使用 |
| RAG | 检索增强生成：生成前先检索平台内相关业务数据，并在产出中给出来源引用 |
| 多模态 | AI 输入不仅限于文本，还包括图片、文档附件等 |

### 1.2 AI 配置与使用分析（US-AI-001）

**功能描述**：系统管理端提供 AI 能力的全局开关、模型与向量 API 配置、业务场景提示词维护与使用情况分析。  
**功能点**：

- **总开关**：全局开启 / 关闭 AI 功能；关闭后全平台 AI 功能入口不可用并提示「AI 功能已关闭」，已生成的数据与确认记录保留可查。
- **多模型配置**：可配置多个模型条目，每条含名称、能力声明（文本生成 / 多模态解析）、接入地址、密钥与启用状态；可指定默认模型，各能力域（助手、缺陷分析、辅助功能）可分别覆盖默认模型；每条模型提供连通性测试与启用 / 停用。
- **向量 API 配置**：向量化 API 独立配置（接入地址、密钥、模型标识），可与模型配置来自不同供应商；提供连通性测试；未配置时依赖检索的能力（RAG、相似检测）不可用。
- **业务场景提示词配置**：按业务场景维护提示词模板（需求拆解、助手任务执行、缺陷实时建议、用例优化等），支持查看默认提示词、自定义覆盖与恢复默认；场景随能力域扩展，未自定义的场景使用默认提示词。
- **使用情况分析**：按时间范围、模型、能力域统计调用次数、成功 / 失败分布与失败原因、平均响应时延、token 消耗（模型服务上报时）；提供趋势图与异常提示（如失败率突增）；可下钻查看对应的 AI 任务列表。

**业务规则**：

- 配置与使用分析仅系统管理端可见可用，业务用户不可见；全部配置操作记审计。
- 关闭总开关时，进行中的 AI 任务立即终止（原因：AI 功能已关闭），已采纳产出不受影响。
- 密钥保存后不可回显，仅支持替换。
- 未配置任何启用状态的模型或向量 API 时，对应 AI 能力入口可见但不可用，并引导至配置页。
- 提示词自定义仅影响其对应场景的后续 AI 调用，不改变已采纳的产出。
- 模型调用失败（不可用、超时、限流）时，执行终止并给出原因，可再次执行；平台非 AI 功能不受影响。

### 1.3 知识与检索能力（US-AI-002）

**功能描述**：AI 的生成与问答基于平台内业务数据的向量化检索（RAG），并支持多模态输入。  
**功能点**：

- 平台内指定范围的文本类业务数据（需求条目、测试用例、缺陷、评审记录等）可被向量化索引，供相似检索与生成引用。
- AI 产出（提案、回答、建议）必须携带来源引用，引用指向具体业务对象，可点击跳转定位。
- 多模态输入：支持将用户上传的图片与文档附件作为 AI 输入解析（如需求导入的截图、附件中的需求文本）。
- 检索范围严格限定：仅检索当前用户所属工作空间及其项目的数据，范围外数据不得进入 AI 上下文。

**业务规则**：

- 向量索引随业务数据变更同步更新；已归档、逻辑删除的数据不再被检索。
- 检索能力不可用时，依赖检索的 AI 功能提示不可用，不降级为无引用的生成。
- 来源引用缺失的 AI 产出视为不合格产出，不得进入待采纳态供采纳。

### 1.5 AI 任务通用规则（US-AI-004）

**功能描述**：所有能力域的 AI 操作遵循统一的任务执行、提案采纳与审计口径。  
**功能点**：

- AI 任务状态：执行中（可挂起等待人工批准）→ 待采纳 → 已结束；中止、预算耗尽或执行出错时为已终止。任务列表展示当前项目内全部任务并标注发起人，包含标题、类型、执行摘要与发起人；标题在任务提交创建时按「任务类型中文名 - 来源标题」生成，来源标题按任务类型取对应用例 / 评审 / 需求等来源对象标题，存量空标题按任务类型名兜底。任务详情可查看提案产物与审核结果（含待采纳 / 已采纳 / 已驳回状态及驳回原因），回看项以卡片呈现且可展开收起查看产物明细；提案的采纳、编辑后采纳与驳回统一在各业务面板完成，任务详情对所有任务类型均只读、不提供审核操作。
- 执行过程可见：AI 在执行开始给出的步骤计划随任务展示；执行中的决策与工具调用可在轨迹中逐条回看，AI 决策事件可查看该次模型调用的请求摘要（业务上下文与工具声明摘要）与完整模型响应；执行实时可见、可中止，中止后可再次执行（保留原执行记录）。
- 预算护栏：单次执行的步数、时长、token 与成本受上限约束，超限自动终止并给出原因；发起时可在类型默认上限内调低预算。
- 提案采纳操作：各业务面板提供单条采纳、批量采纳、修改后采纳、驳回；驳回可附反馈再次执行（局部重新生成）；业务面板存在多个产物时提供逐条查看产物信息的导航，已处置产物只读。
- 人工编辑保护：已被人工编辑过的产出，AI 仅在用户显式发起重新生成并二次采纳后才可覆盖。
- 审计：每次任务发起、中止、再次执行、采纳、修改、驳回均记录操作人、时间与内容摘要，可在任务详情回看；执行轨迹只增不改。
- 权限：业务模块免 RBAC 权限码校验，保留任务归属与项目成员归属校验；后端任务端点不做权限码校验（工作空间 / 项目上下文经请求头传递），AI 只能调用已注册工具白名单内的能力，不绕过既有业务校验。

**业务规则**：

- 同一批输入存在进行中的同类任务时，重复发起需提示。
- 按输入复用的轻量能力（用例优化、脑图生成用例、AI 评审）重新执行按最近任务状态分叉：`running` 仅回显原任务进度，不新建任务或执行；`aborted` 沿用原任务新建执行实例；`proposals_ready` / `closed` 按原输入新建任务，原任务及其执行、提案与采纳记录保留只读回看，不被覆盖。任务中心与任务详情页对上述能力的「再次执行」动作遵循同一口径。
- 任务列表与进行中计数按项目上下文过滤：附带活跃项目时展示该项目内全部任务（含发起人），无项目上下文时不按提交人过滤。
- 执行中止、执行错误或预算耗尽不产生任何落库数据与提案；已采纳的产出不受后续执行失败影响。
- AI 产出在采纳前不落库；写入业务数据的唯一入口是采纳动作。

### 1.6 非功能需求

- 交互式 AI 建议（用例优化、重复检测等）应在 10 秒内给出首屏反馈；未及时响应时展示进行中状态与中止入口。
- AI 任务的执行过程（计划、当前步骤、轨迹）实时可见且可中止；完成后通知发起人。
- AI 产出的来源引用 100% 可跳转定位。
- 使用云端模型时，出站内容仅限任务必需的上下文，由系统管理员决定是否启用云端接入；密钥不落日志。
- 配置的模型或向量 API 不可用时，平台核心测试功能不受影响，AI 入口降级提示。
- AI 上下文严格限于当前用户所属工作空间及其项目的数据（见 1.3），跨工作空间数据不得进入任何 AI 任务。

### 1.7 数据需求

**功能描述**：定义 AI 能力涉及的数据实体及其关系（实体级，不含表结构）。  
**功能点**：

- **AI 任务**：任务类型、标题（创建时按任务类型中文名与输入来源标题生成）、输入来源（如需求条目集）、生命周期状态、发起人（创建人，任务列表与计数仅按当前用户过滤）、终止原因、产出提案清单。
- **执行与轨迹**：执行的预算上限与实际消耗（步数 / 时长 / token / 成本）、状态与终止原因；轨迹事件的类型、摘要与时序（只增不改）；AI 决策事件的请求摘要（业务上下文与工具声明摘要）与完整模型响应（正文、工具调用、结束原因、token 用量）随事件留存并可在任务详情查看。
- **提案**：结构化内容、证据引用（来源对象与原文引语）、确认状态（待采纳 / 只读）、驳回原因。
- **采纳记录**：所属任务、提案标识、采纳方式（单条 / 批量 / 修改后 / 驳回）、操作人、时间、落库结果引用；任务详情按提案逐条只读回看采纳结果与驳回原因，支持展开卡片查看该提案的完整产物明细。
- **AI 配置**：总开关状态、模型配置（接入信息、能力声明、默认标记、启用状态，可多条）、向量 API 配置、业务场景提示词（默认值与自定义值）。
- **AI 使用统计**：按时间、模型、能力域聚合的调用量、成功 / 失败与失败原因、响应时延、token 消耗。
- **向量索引条目**：来源业务对象标识、所属工作空间、索引状态。
- **AI 助手会话与消息**：定义见智能助手分册。

**业务规则**：

- 所有实体通过所属项目或工作空间归属进行隔离，遵循既有数据隔离约定。
