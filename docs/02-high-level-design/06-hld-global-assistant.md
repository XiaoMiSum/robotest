## 1. 全局助手与工具调用

* **会话模型**：会话（conversation）→ 消息（message）两级，归属用户、按工作空间隔离；上下文窗口取最近 N 轮。
* **工具注册表**：每个工具声明名称、参数 Schema、读/写属性、所需权限码。注册表声明工具全集；写工具的**启用白名单为系统配置项**（首期默认仅开放创建缺陷、创建计划草稿两项低风险操作）。工具实现直接调用既有 Service 层方法，以当前 LoginUser 身份执行——权限校验、数据隔离、业务规则、审计全部复用。
* **执行循环**：用户消息 → LLM（附工具清单）→ 若返回工具调用：只读工具直接执行并回填结果继续循环；**写工具中断循环**，向前端返回操作预览卡片 → 用户确认后执行 → 结果回填 → LLM 生成最终答复。确认请求带一次性令牌与超时，超时/取消则放弃。
* **页面上下文桥**：脑图编辑页将当前文档 ID、选中节点注入助手请求上下文；对话式编辑指令翻译为 DSL 后交前端挂载执行器处理（同 4.8/4.9）。
* **使用指引**：平台操作手册以静态知识片段内置，指引类问题由 LLM 基于知识片段作答并附路由链接；知识外问题明确拒答。
