## 2. 系统总体设计

### 2.1 架构风格

系统采用 **B/S 架构**，**前后端分离**。整体分为三层：

    ┌─────────────────────────────┐
    │        前端（SPA）           │
    │  ┌────────┐  ┌────────────┐ │
    │  │管理端  │  │  业务端    │ │
    │  └────────┘  └────────────┘ │
    └─────────────┬───────────────┘
                  │ HTTP / WS
    ┌─────────────┴───────────────┐
    │       网关层（Gateway）      │
    │  认证、上下文注入、路由转发  │
    └─────────────┬───────────────┘
                  │
    ┌─────────────┴───────────────┐
    │          服务层              │
    │  ┌─────────┐ ┌───────────┐ │
    │  │管理服务 │ │ 业务服务  │ │
    │  └─────────┘ └───────────┘ │
    │  ┌───────────────────────┐ │
    │  │   WebSocket 服务      │ │
    │  └───────────────────────┘ │
    └─────────────┬───────────────┘
                  │
    ┌─────────────┴───────────────┐
    │          数据层              │
    │  ┌──────┐ ┌──────┐ ┌──────┐│
    │  │关系库│ │缓存  │ │文件  ││
    │  └──────┘ └──────┘ └──────┘│
    └─────────────────────────────┘

### 2.2 前后端职责

* **前端**：
  * 管理端：独立路由树，仅拥有系统角色的用户可见。
  * 业务端：根据活跃工作空间动态加载数据，包含工作空间管理、项目管理、脑图编辑器、测试评审、测试计划、缺陷管理界面。
  * 脑图编辑器支持 WebSocket 实时协作。
* **后端**：
  * 提供 RESTful API，分为管理接口（`/api/admin`）和业务接口（`/api/workspace` 和 `/api/project`）。
  * WebSocket 服务负责脑图文档的实时协作消息广播与持久化。
  * 中间件统一处理 JWT 认证、活跃工作空间/项目上下文注入与校验。

### 2.3 系统初始化流程

系统首次部署后需经过初始化才能使用。初始化在认证流程之前，无需登录即可访问。

```
用户首次访问 → 登录页
  ↓
检查初始化状态 GET /api/auth/init/status
  ↓
未初始化 → /init 初始化页面 → 设置管理员密码 → POST /api/auth/init/setup
  ↓
已初始化 → 正常登录流程
```

初始化会创建 admin 账号并分配系统管理员角色（预置 UUID `b0000000-...-001`），用户使用 admin 和设置的密码登录。

### 2.4 技术选型概要

整体技术选型：

| 组件    | 选型方向                                     |
| ----- | ---------------------------------------- |
| 前端框架  | 现代 SPA 框架（React / Vue / Angular）         |
| 脑图编辑器 | 自研或基于开源库扩展，需支持自定义数据模型                    |
| 后端框架  | 主流 Web 框架（Spring Boot / Express / Gin 等） |
| 数据库   | 关系型数据库（MySQL / PostgreSQL）               |
| 缓存    | Redis                                    |
| 实时通信  | WebSocket（Socket.IO 或原生实现）               |

## 3. 模块划分

### 3.1 模块总览

    软件测试平台
    ├── 系统管理模块
    │   ├── 数据概览
    │   ├── 用户管理
    │   ├── 全局工作空间管理
    │   └── 系统角色与权限管理
    └── 业务功能模块
        ├── 我的工作空间
        ├── 工作空间成员管理
        ├── 项目管理
        └── 功能测试
            ├── 测试用例管理（模块树 + 脑图协作编辑）
            ├── 测试评审管理
            ├── 测试计划管理
            └── 缺陷管理

### 3.2 模块职责简述

* **用户管理**：账号生命周期维护（启用/禁用/锁定三态），分配系统角色。
* **数据概览**：平台关键指标（用户、工作空间、项目、登录与活跃趋势）聚合展示，为管理端默认落地页。
* **全局工作空间管理**：工作空间的创建、归档与重新启用，全平台成员分配；归档仅冻结状态，成员归属保留。
* **系统角色与权限管理**：定义系统级角色及其管理端权限，系统管理员可配置。
* **我的空间**：按名称检索用户归属的工作空间，按“全部 / 我管理的 / 已归档”筛选并查看真实规模统计，按最近访问排序；切换活跃空间或编辑基本信息，具备全局创建权限时可在当前页发起创建。
* **工作空间成员管理**：管理当前工作空间内成员，可邀请/移除，并可设置空间管理员。
* **项目管理**：当前工作空间下项目的 CRUD 与归档。
* **测试用例管理**：模块树管理 + 脑图实时协作编辑。
* **测试评审管理**：发起用例评审，基于快照进行节点标记/评论，支持记录、同步与调整规划用例。
* **测试计划管理**：创建计划，基于快照跟踪执行，支持多次执行记录、同步与调整规划用例。
* **缺陷管理**：缺陷全生命周期管理，关联用例与计划。
