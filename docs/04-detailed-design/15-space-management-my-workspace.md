### 3.2 我的空间相关接口（/api/workspaces）

我的空间接口面向当前登录用户，用于管理用户归属的工作空间列表和切换活跃空间，无需携带 `X-Active-Workspace` 头。认证通过 `Authorization: Bearer <token>` 头传递。

#### 3.2.1 获取我的工作空间列表

- **路径**：`GET /api/workspaces`
- **请求参数**：

| 参数       | 类型  | 必填  | 说明                |
| -------- | --- | --- | ----------------- |
| page     | int | 否   | 页码，默认 1           |
| pageSize | int | 否   | 每页数量，默认 20，最大 100 |

- **响应**：
  
  ```json
  {
  "records": [
    {
      "id": 1,
      "name": "电商平台测试",
      "description": "负责电商平台相关测试",
      "workspaceRole": "admin",
      "defaultProjectId": 10,
      "defaultProjectName": "核心功能测试",
      "memberCount": 15,
      "projectCount": 5,
      "status": "active",
      "createdAt": "2026-01-01T00:00:00Z"
    }
  ],
  "total": 5
  }
  ```

- **说明**：`defaultProjectName` 为 `defaultProjectId` 对应的项目名称，未设置默认项目时两者均为 null；`projectCount` 为该工作空间下的**真实项目计数**（而非固定值）。

#### 3.2.2 设置活跃工作空间偏好

- **路径**：`PUT /api/workspaces/active`
- **请求体**：`{ "workspaceId": 2 }`
- **说明**：记录用户最近活跃工作空间，便于下次登录自动默认选中。


### 4.1 工作空间切换流程

工作空间切换为纯前端操作，无需调用后端引导接口：

1. 用户在“我的空间”页面或顶部工作空间切换器中选择目标工作空间。
2. 前端更新全局状态 `activeWorkspaceId`。
  3. 前端根据本地缓存的该空间默认项目信息判断跳转目标：
     - 有默认项目 → 直接进入项目仪表盘（`/workspace/projects/:projectId/dashboard`）。
     - 无默认项目 → 进入项目列表页（`/workspace/projects`，有项目时显示列表，无项目时显示引导创建区域）。
4. 顶部动态菜单切换为工作空间模式（空间信息、成员管理、项目列表）。


### 4.2 个人默认项目设置规则

- 用户**仅可在项目列表页**设置个人默认项目，通过卡片上的“设为默认”按钮操作。
- 默认项目必须是当前工作空间下状态为 active 的项目。
- 用户在同一工作空间最多只能设置一个默认项目。设置新默认项目时自动替换旧默认项目。
- 该设置为用户级别，不同用户在同一工作空间可设置不同默认项目。
- 若默认项目被归档或删除，系统自动清除相关用户的默认项目引用。


#### 5.3.1 我的空间页面

**路由**：`/workspaces`

点击顶部导航栏“📁 我的空间”图标进入，以卡片列表形式展示用户所有归属空间，支持分页。

**页面布局**：

```
┌──────────────────────────────────────────────────┐
│  我的工作空间                                     │
├──────────────────────────────────────────────────┤
│  ┌──────────────────┐ ┌──────────────────┐       │
│  │ ⭐电商平台测试    │ │   数据平台       │       │
│  │ 负责电商相关测试  │ │ 数据平台测试     │       │
│  │ 角色: 管理员      │ │ 角色: 成员       │       │
│  │ 默认项目: 核心功能│ │ 默认项目: 无     │       │
│  │ 成员:15 项目:5   │ │ 成员:8 项目:3    │       │
│  │ [进入工作空间]   │ │ [进入工作空间]   │       │
│  └──────────────────┘ └──────────────────┘       │
├──────────────────────────────────────────────────┤
│                < 第1页/共3页 >                    │
└──────────────────────────────────────────────────┘
```

**交互说明**：

| 操作   | 触发方式          | 反馈                                  |
| ---- | ------------- | ----------------------------------- |
| 翻页   | 点击分页器或键盘方向键   | 卡片列表刷新                              |
| 进入空间 | 点击[进入工作空间]或卡片 | 设置活跃空间ID → 跳转至项目列表页；顶部动态菜单切换为工作空间模式 |
