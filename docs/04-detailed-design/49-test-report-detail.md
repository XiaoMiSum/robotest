### 4.1 报告生成

- 场景报告（`source = 'scene'`）：场景执行完成后由执行引擎生成，`report_type = 'scene'`，`result` 存场景数据集：

1. **步骤级结果收集**：从 Ryze 结果树收集每个步骤的请求/响应快照（Real* 序列化）、验证器结果、提取器结果、耗时。
2. **结果汇总计算**：总步骤数、通过数、失败数、跳过数、总耗时。
3. **报告写入**：`report_type='scene'`、`external_id` = 场景 ID、`name` = 场景名 + 执行时间戳，`result` 填充场景数据集，同时更新 `api_execution_record.report_id`。
4. **Ryze 快照保存**：平台内执行时保存序列化后的完整 Ryze 结果树至 `api_report.ryze_snapshot`。

- 套件报告（`source = 'schedule'`）：测试计划任务（含立即执行）执行多个场景后聚合生成，`report_type = 'suite'`，`result` 存套件数据集：

1. **场景结果收集**：遍历本次执行各场景的最终结果（各场景执行记录已生成）。
2. **套件汇总计算**：场景数、通过/失败场景数、全部场景步骤总数与通过/失败/跳过数、总耗时。
3. **报告写入**：`report_type='suite'`、`external_id` = 任务 ID、`name` = 任务名 + 执行时间戳，`result` 的 `scenes[]` 填充各场景数据集；将该套件报告 ID 回写至本套件内各场景执行记录的 `report_id`（共享）。
4. **Ryze 快照保存**：平台内执行时聚合生成套件树序列化至 `ryze_snapshot`。

**报告状态判定**：
- 场景报告：
  - `success`：所有启用步骤的所有验证器均通过。
  - `failed`：任一验证器失败或引擎异常。
  - `partial`：部分步骤被跳过（disabled），其余通过。
- 套件报告：
  - `success`：全部场景通过。
  - `failed`：任一场景失败。
  - `partial`：有场景部分通过且无失败场景。

**验证器解析失败规则**：验证器表达式解析失败按验证失败处理，该验证器 `result = failed` 并在 `error` 字段记录解析错误信息；报告状态判定不受影响（仍按任一验证器失败计为 `failed`）。


### 4.5 场景执行记录弹窗查看报告

场景页执行记录中的 [报告] 按钮不再跳转报告页，改为在弹窗中直接展示报告明细（`GET /api/project/reports/:id`）：

- 场景页 [运行] 产生的报告（`source = 'scene'`，`report_type = 'scene'`）虽不进报告列表，但可通过执行记录弹窗查看。
- 弹窗内容与场景报告详情一致：Hero 概览、统计卡、场景卡（处理器 Tab + 步骤卡，展开查看请求/响应快照、验证器明细、提取器结果）。
- 定时任务的场景执行记录（共享套件报告）：弹窗展示该记录的步骤明细（从套件数据集 `result.scenes[]` 按 `sceneId` 定位），并提供「查看完整套件报告」跳转套件详情。

### 5.1 报告查看页

- **报告列表**：分页、筛选（状态/报告类型/执行方式/时间范围）、搜索（报告名称关键字）。
  - 列表列：报告名称（场景报告：场景名 + 时间戳；套件报告：任务名 + 时间戳）、报告类型、状态、通过率、耗时、创建时间、操作。
  - 状态列：通过（绿）/ 失败（红）/ 部分通过（黄）。
  - 批量操作：勾选后批量删除（二次确认）。
  - 列表仅展示定时任务报告（scene 报告不进列表，见 3.1）；场景页 [运行] 直接产生的报告通过场景执行记录弹窗查看（见 4.5）。
- **报告详情**（统一由 `ReportResultView.vue` 渲染，接收报告详情与可选 `focusSceneId`，内部复用处理器区组件与步骤卡组件；详情页/分享页/执行记录弹窗三者复用同一套展示）：
  - **顶部概览（Hero）**：渐变淡绿卡片——报告名称 + 状态章（执行成功/失败）+ 来源章（定时任务/平台内执行）；元信息：环境、执行/触发时间、总耗时、场景 ID / Task ID（等宽）。
  - **执行概览（5 项统计卡）**：场景报告与套件定位单场景为步骤口径（总步骤/通过/失败/通过率/总耗时）；套件报告整体为场景口径（场景总数/通过场景/失败场景/通过率/总耗时）。
  - **处理器 Tab**（环境级/场景级复用 `ReportProcessorsTabs.vue`）：前置/后置 Tab（数量角标 + 状态圆点）+ 执行顺序提示链 + 处理器小卡（可折叠，含请求头表、Query/请求体/响应体格式化 code、提取器表）。
  - **步骤卡**（`ReportStepCard.vue`）：序号、名称、方法 chip、状态徽标、耗时、验证器数（失败红）；展开含请求块（方法+URL、请求头表、Query/请求体）、响应块（状态码、HTTP 版本·Content-Type·耗时、响应体、响应头表）、验证器表、提取器表；失败/错误步骤默认展开，提供「全部展开/收起」。
  - **场景输出**：
    - 场景报告：Hero + 统计卡 + 单场景卡（默认折叠：mini 统计 + 场景处理器 Tab + 步骤区）。
    - 套件报告：Hero + 场景口径统计卡 + 环境处理器卡（任务前置/后置）+ 场景卡列表（自上而下平铺，含「查看完整套件 / 返回当前场景」定位）。
  - 组件职责：`ReportResultView.ts` 编排数据，`ReportProcessorsTabs.ts` / `ReportStepCard.ts` 纯展示（颜色语义引用视觉设计 CSS 变量）。
- **分享操作**：[分享] 按钮位于 Hero 右上角（始终可用，权限不足由后端返回 403）。打开弹窗时若报告存在**未过期分享**（详情接口 `share` 非空）→ 直接展示现有记录（分享链接、有效期至、分享人）+ [复制]；复制内容为带描述文本（报告名称/链接/有效期/分享人，见 4.2.3）。无未过期分享 → 弹窗两步式（选有效期，缺省 7 天 → 生成链接），生成后展示并支持复制；[重新生成] 显式覆盖旧分享。
- **刷新操作**：报告行内 [刷新]，按钮 loading → 调用刷新接口（见 3.3）→ 成功后更新状态徽标。


### 5.2 执行记录弹窗查看报告

场景执行记录中的 [报告] 按钮打开弹窗（复用 5.1 `ReportResultView.vue`：Hero + 统计卡 + 场景卡/环境处理器），弹窗内调用报告详情接口（见 4.5）。场景报告展示单场景步骤；套件执行记录弹窗从套件数据集定位该场景展示，并提供「查看完整套件报告」入口。报告详情渲染的通用前端约定见《API 测试基础设施详细设计说明书》5.2。
