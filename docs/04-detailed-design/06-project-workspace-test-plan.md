### 3.5 测试计划管理接口

#### 3.5.1 获取计划列表

- **路径**：`GET /api/project/plans`
- **参数**：`status`（可选）、`keyword`（可选，名称模糊匹配）、`page`、`pageSize`
- **响应**：列表项在计划基本信息外附带进度字段 `totalAssociated`/`passed`/`progressPercent`/`passRate`，口径与 3.4.1 一致（progressPercent 以“已执行（非 untested）”计）。

#### 3.5.2 创建计划

- **路径**：`POST /api/project/plans`

- **请求体**：
  
  ```json
  {
  "name": "功能测试计划",
  "description": "...",
  "executorId": 4,
  "startTime": "2026-08-01T00:00:00Z",
  "endTime": "2026-08-10T00:00:00Z",
  "environment": "staging",
  "selectedNodes": [
    { "documentId": 10, "caseIds": [101, 103] }
  ]
  }
  ```

- **处理**：生成模块和节点快照（完整拷贝用例属性），标记 is_associated，初始化 last_result='untested'。

- **响应**：201。

#### 3.5.3 获取计划快照树

- **路径**：`GET /api/project/plans/:id/modules`
- **参数**：`documentId`（可选）
- **响应**：裁剪后的模块树 + 节点树。节点部分以嵌套的根节点对象形式返回（结构与 3.3.4 一致），每个节点包含完整拷贝属性及 lastResult、associated 等快照特有字段。

#### 3.5.4 提交执行记录

- **路径**：`POST /api/project/plans/:id/records`

- **请求体**：
  
  ```json
  {
  "snapshotNodeId": 6001,
  "result": "pass",
  "note": "正常通过"
  }
  ```

- **校验**：仅 is_associated=true 且 type='case' 的节点可标记执行结果；result 取值限 `pass` / `fail` / `block` / `untested`（untested 即重置回待执行）。不再校验计划状态；待开始（new）计划首次标记后自动转入 in_progress（已取代单独的“开始执行”操作）。执行结果以徽标形式回显在节点右侧。

- **处理**：新增 test_plan_execution_record，更新快照节点的 last_result、last_executor_id、last_executed_at。

#### 3.5.5 获取节点执行记录

- **路径**：`GET /api/project/plans/:id/nodes/:nodeId/records`
- **响应**：该节点的执行历史列表。

#### 3.5.6 同步最新用例

- **路径**：`POST /api/project/plans/:id/sync`
- **权限**：负责人，计划未结束（new/in_progress）；已结束返回错误码 1000011027。
- **处理**：与评审同步逻辑一致，更新快照节点属性，保留执行记录。

#### 3.5.7 关闭计划

- **路径**：`POST /api/project/plans/:id/close`
- **校验**：检查是否存在 is_associated=true 且 last_result='untested' 的节点，提示确认后可关闭。
- **处理**：状态变更为 closed。
- **说明**：接口保留；前端详情页已改用 3.5.11 完成计划（“完成执行”）。

#### 3.5.8 获取模块快照树

- **路径**：`GET /api/project/plans/:id/module-tree`
- **响应**：与 3.4.9 同构，供计划详情页左侧文档树展示与多文档切换。

#### 3.5.9 获取规划用例

- **路径**：`GET /api/project/plans/:id/cases`
- **响应**：与 3.4.10 同构。

#### 3.5.10 调整规划用例

- **路径**：`PUT /api/project/plans/:id/cases`
- **前置**：计划状态为 new 或 in_progress（未结束即可调整）；已结束返回语义化错误码 1000011027（“计划已结束，无法执行该操作”）。
- **请求体与处理**：与 3.4.11 一致；新补节点快照初始 last_result='untested'。

#### 3.5.11 完成计划

- **路径**：`POST /api/project/plans/:id/complete`
- **权限**：仅负责人。
- **处理**：状态变更为 completed；不做未执行用例门槛校验（前端二次确认，完成后不可再标记执行结果）。

#### 3.5.12 删除计划

- **路径**：`DELETE /api/project/plans/:id`
- **权限**：仅负责人，任意状态可删。
- **处理**：无物理外键，事务中显式级联删除执行记录、节点快照、模块快照后删除计划本体。


### 4.5 同步最新用例

触发后批量对比原始节点与当前节点，更新快照属性；若原始节点不存在，快照节点 is_deleted=1。评审记录/执行记录不受影响，最终状态保留。


#### 5.3.5 计划列表页（功能测试 - 测试计划）

**路由**：`/workspace/projects/plans`

左侧菜单选中“测试计划”时展示。

**页面布局**：

```
┌──────────────────────────────────────────────────┐
│  测试计划                          [+ 创建计划]   │
├──────────────────────────────────────────────────┤
│  [状态: 全部 ▼]                                  │
│  名称 │ 负责人 │ 起止时间 │ 状态 │ 操作          │
│  功能  │ 赵六   │08-01~08-10│进行中│ [进入]       │
│  回归  │ 张三   │07-01~07-15│已完成│ [查看]       │
└──────────────────────────────────────────────────┘
```

**交互说明**：

| 操作   | 触发方式     | 反馈                           |
| ---- | -------- | ---------------------------- |
| 创建计划 | 点击[创建计划] | 弹出创建表单：名称、负责人、起止时间、执行环境、关联用例 |
| 进入执行 | 点击[进入]   | 跳转至计划详情页                     |
| 查看详情 | 点击[查看]   | 跳转至计划详情页（已完成/已关闭）            |


#### 5.3.6 计划详情页

**路由**：`/workspace/projects/plans/:planId`

**页面布局**：

```
┌──────────────────────────────────────────────────┐
│  ← 返回    功能测试计划                           │
│  负责人: 赵六  时间: 08-01~08-10  状态: 进行中    │
│  [同步最新用例] (负责人)       [关闭计划] (负责人) │
├──────────┬───────────────────────────────────────┤
│ 快照模块树│   快照脑图                              │
│          │   节点按执行结果显示颜色：               │
│          │   🟢通过 🟡未执行 🔴失败 ⚪阻塞        │
│          │   点击关联用例节点 → 执行面板           │
└──────────┴───────────────────────────────────────┘
```

详情页复用脑图组件（mode='plan'），快照树数据以嵌套根节点对象形式返回，工具栏切换为执行操作按钮，节点显示执行状态图标。

**交互说明**：

| 操作     | 触发方式                 | 反馈                 |
| ------ | -------------------- | ------------------ |
| 标记执行结果 | 点击关联用例节点 → 选择结果 + 备注 | 提交执行记录，节点颜色更新      |
| 查看执行历史 | 点击节点查看详情             | 显示执行记录列表           |
| 关闭计划   | 负责人点击[关闭计划]          | 检查未执行用例 → 确认后关闭    |
| 同步用例   | 负责人点击[同步]            | 确认 → 更新快照属性，保留执行记录 |
