### 3.3 测试用例管理接口

#### 3.3.1 获取模块树

- **路径**：`GET /api/project/modules`
- **响应**：直接返回树形数组，每个节点包含 id、name、type、children。

#### 3.3.2 创建模块节点

- **路径**：`POST /api/project/modules`
- **请求体**：`{ "parentId": null, "type": "directory", "name": "新目录" }`
- **校验**：同父节点下名称唯一。
- **文档类型特殊处理**：当 `type=document` 时，事务中创建文档节点并自动创建默认根节点（title 与文档 name 一致，type='normal'）。
- **响应**：创建后的模块节点信息，状态码 201。

#### 3.3.3 更新/删除模块节点

- **路径**：`PUT/DELETE /api/project/modules/:id`
- 更新：可修改 name；也用于拖拽移动——请求体中 `targetIndex` 非空时视为移动操作，`parentId` 为目标父目录（空表示根层级），`targetIndex` 为目标层级下的位置下标。
  - 校验：目标父必须存在、属于同项目且为目录类型；禁止移到自身或其子孙目录下（循环引用）；目标层级下名称唯一。
  - 处理：按 targetIndex 插入后重写目标层级的 sort_order（自 0 连续编号）。
  - 前端：模块树 el-tree 开启 draggable，文档节点仅允许平级排序或放入目录内部；提交失败时整树重载回滚。
- 删除：目录需为空；文档级联删除所有节点及布局。

#### 3.3.4 获取文档全量节点

- **路径**：`GET /api/project/documents/:docId/nodes`

- **说明**：返回文档的完整脑图结构。node 为文档的根节点对象（嵌套树形结构），layout 为布局信息。根节点是创建文档时自动生成的默认节点，其 children 包含用户在脑图中创建的所有子节点。

- **响应**：
  
  ```json
  {
  "node": {
    "id": 1,
    "parentId": null,
    "type": "normal",
    "title": "登录用例集",
    "priority": null,
    "sortOrder": 0,
    "version": 1,
    "children": [
      {
        "id": 2,
        "parentId": 1,
        "type": "case",
        "title": "邮箱登录",
        "priority": "P1",
        "sortOrder": 0,
        "version": 1,
        "children": [
          {
            "id": 3,
            "parentId": 2,
            "type": "precondition",
            "title": "用户已注册且处于登录页",
            "priority": null,
            "sortOrder": 0,
            "version": 1,
            "children": []
          },
          {
            "id": 4,
            "parentId": 2,
            "type": "step",
            "title": "输入邮箱和密码",
            "priority": null,
            "sortOrder": 1,
            "version": 1,
            "children": []
          },
          {
            "id": 5,
            "parentId": 2,
            "type": "expected",
            "title": "成功跳转到首页",
            "priority": null,
            "sortOrder": 2,
            "version": 1,
            "children": []
          }
        ]
      }
    ]
  },
  "layout": { "...": "..." }
  }
  ```

- **字段说明**：node 为嵌套的根节点对象，每个节点包含 id、parentId、type、title、priority、sortOrder、version 和 children 数组。根节点的 parentId 为 null，叶子节点的 children 为空数组。

#### 3.3.5 获取用例详情

- **路径**：`GET /api/project/cases/:caseId`
- **响应**：包含 type、priority、title 等完整属性。


### 4.1 文档创建与默认根节点

创建 type=document 的模块节点时，事务中插入 test_case_module 记录，并在 test_case_node 表中创建默认根节点（title 与文档名称相同，type='normal'，sort_order=0，parent_id 为 NULL）。此根节点作为文档脑图的唯一顶层节点，用户可在其下添加子节点并标记为不同用例类型。获取文档节点树时，该根节点作为顶层节点返回，其 children 包含所有用户创建的节点。


### 4.2 脑图实时协作

通过 WebSocket 连接 `/ws/documents/:docId`，客户端加入文档房间。操作消息包含 op（add_node、move_node、update_attrs、delete_node、update_layout）及 payload。服务端校验权限后更新 test_case_node 和 test_case_document_layout，广播给同房间其他用户。冲突处理使用节点 version 字段的乐观锁机制。脑图数据以嵌套树形结构在前端组件中渲染，保存时递归遍历节点树并更新数据库。


#### 5.3.2 用例管理页（功能测试 - 测试用例）

**路由**：`/workspace/projects/cases`

左侧菜单选中“测试用例”时展示。页面进一步分为左右结构：左侧模块树 + 右侧脑图编辑器。前端调用 `GET /api/project/documents/:docId/nodes` 获取嵌套的根节点对象和布局信息，根节点的 children 递归渲染为脑图节点树。

**页面布局**：

```
┌──────────┬───────────────────────────────────────┐
│ 模块树   │   📄 登录用例集                        │
│          │                                       │
│ 📁功能   │  ┌──────────────────────────────┐     │
│  📁登录  │  │        脑图编辑区              │     │
│   📄用例集│  │                              │     │
│  📁支付  │  │    ┌───┐                      │     │
│   📄流程 │  │    │根节点│                    │     │
│ [+新建]  │  │    └─┬─┘                      │     │
│          │  │  ┌───┴───┐                    │     │
│          │  │  │子节点1 │                    │     │
│          │  │  └───────┘                    │     │
│          │  └──────────────────────────────┘     │
│          │  悬浮工具栏：[📋用例][📘前置][📗步骤]  │
└──────────┴───────────────────────────────────────┘
```

**模块树交互说明**：

| 操作    | 触发方式            | 反馈                                                     |
| ----- | --------------- | ------------------------------------------------------ |
| 展开/折叠 | 点击目录左侧箭头        | 展开/收起子节点，箭头旋转动画                                        |
| 选中文档  | 点击文档节点          | 调用 `GET /api/project/documents/:docId/nodes`，右侧加载脑图编辑器 |
| 新建目录  | 右键空白处或点击[+新建]   | 输入框出现在目标位置，输入名称回车确认                                    |
| 新建文档  | 右键目录或点击[+新建]    | 同上；创建后自动创建默认根节点（根节点作为文档脑图的唯一顶层节点）                      |
| 重命名   | 右键→“重命名”或双击     | 节点变为输入框，回车确认，Esc取消                                     |
| 移动    | 拖拽节点到目标位置       | 高亮放置位置，松手完成移动                                          |
| 删除    | 右键→“删除”或按Delete | 二次确认弹窗；文档级联删除所有节点                                      |

**脑图编辑器交互说明**：

| 操作     | 触发方式            | 反馈                |
| ------ | --------------- | ----------------- |
| 添加子节点  | Tab键或工具栏按钮      | 新节点出现在下方，标题自动聚焦   |
| 添加兄弟节点 | Enter键或工具栏按钮    | 新节点出现在同层级         |
| 编辑文本   | 双击节点            | 文本变为可编辑输入框        |
| 标记类型   | 工具栏按钮或右键菜单      | 节点样式更新，联动优先级      |
| 标记优先级  | 工具栏P0-P3按钮或右键菜单 | 自动标记为用例，节点优先级色标更新 |
| 删除节点   | Delete键或右键菜单    | 确认弹窗后删除           |
| 移动节点   | 拖拽              | 高亮目标位置，松手完成       |
| 缩放画布   | 滚轮或工具栏按钮        | 画布缩放              |
| 抓手模式   | 工具栏按钮或H键        | 切换画布拖拽模式          |
| 撤销/重做  | Ctrl+Z / Ctrl+Y | 画布状态还原/重做         |

**脑图组件支持三种模式**：编辑模式（edit）用于用例编辑；评审模式（review）用于快照评审；计划模式（plan）用于快照执行跟踪。详细交互参见《脑图组件实现设计文档》。
