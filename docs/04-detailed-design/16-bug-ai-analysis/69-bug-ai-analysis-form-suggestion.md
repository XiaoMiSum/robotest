## 1. 缺陷表单智能建议

- **路径**：`POST /api/project/ai/bugs/suggest`（同步，`bug_form_suggestion`）
- **请求体**：`{ "title": "点登录没反应", "reproSteps": "……可空" }`
- **响应**：

```json
{
  "optimizedTitle": "登录页点击「登录」按钮无响应，无任何错误提示",
  "severity": "serious",
  "priority": "high",
  "reason": "阻断核心登录流程，但存在绕行方式未知"
}
```

- **请求校验**：`title` 必填且 ≤ 300（对齐 bug 表列宽）；`reproSteps` 可空，超长部分由服务端按 2 截断，不报错；
- **响应校验**：`optimizedTitle` ≤ 300；`severity` ∈ fatal/serious/general/minor、`priority` ∈ high/medium/low（`@InEnum` 映射平台既有枚举，不引入新枚举值）；
- **交互约束**：结果仅回填表单待用户确认（一键替换标题 / 采纳等级），不产生任何自动提交。


## 2. 表单建议 Prompt 与交互

- 上下文仅取表单当前标题 + 重现步骤（截断 4000 token），不送入项目其他缺陷数据（数据出域最小化）；
- 前端标题输入框内嵌「AI 建议」按钮触发（标题为空禁用），按钮态 loading，**并发**发起建议（1）与查重（3.2）两个请求；结果合并展示于标题下方 AI 结果面板：建议区（优化标题一键替换/忽略、等级与优先级点击采纳回填下拉框）+ 疑似重复缺陷列表区；各区域独立 loading，任一失败仅轻提示，不影响表单操作。
