### 3.2 项目工作台接口

#### 3.2.1 获取项目工作台数据

- **路径**：`GET /api/project/dashboard`

- **说明**：返回当前项目的概览统计数据。

- **响应**：
  
  ```json
  {
  "caseCount": 256,
  "activeReviewCount": 3,
  "activePlanCount": 2,
  "openBugCount": 12,
  "recentReviews": [
    { "id": 1, "title": "登录模块评审", "status": "completed", "createdAt": "2026-07-01T10:00:00Z" }
  ],
  "recentPlans": [
    { "id": 1, "name": "功能测试计划", "status": "in_progress", "createdAt": "2026-07-05T09:00:00Z" }
  ]
  }
  ```


#### 5.3.1 项目工作台

**路由**：`/workspace/projects/dashboard`

进入项目后的默认页面，展示统计卡片和最近活动。

**页面布局**：

```
┌──────────────────────────────────────────────────┐
│  项目工作台                                      │
├──────────────────────────────────────────────────┤
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌────────┐ │
│  │ 用例总数 │ │ 进行中  │ │ 进行中  │ │ 未关闭  │ │
│  │   256   │ │ 评审数  │ │ 计划数  │ │ 缺陷数  │ │
│  │         │ │    3    │ │    2    │ │   12   │ │
│  └─────────┘ └─────────┘ └─────────┘ └────────┘ │
│                                                  │
│  ┌────────────────────┐ ┌──────────────────────┐ │
│  │  最近评审           │ │  最近计划             │ │
│  │  · 登录模块评审     │ │  · 功能测试计划       │ │
│  │    通过 2026-07-01  │ │    进行中 2026-07-05  │ │
│  └────────────────────┘ └──────────────────────┘ │
└──────────────────────────────────────────────────┘
```

**交互说明**：

| 操作     | 触发方式  | 反馈                                          |
| ------ | ----- | ------------------------------------------- |
| 页面加载   | 进入项目时 | 调用 `GET /api/project/dashboard`，填充统计数据和最近活动 |
| 点击统计卡片 | 点击卡片  | 跳转至对应功能页面                                   |
| 点击最近评审 | 点击列表项 | 跳转至对应评审详情                                   |
| 点击最近计划 | 点击列表项 | 跳转至对应计划详情                                   |
