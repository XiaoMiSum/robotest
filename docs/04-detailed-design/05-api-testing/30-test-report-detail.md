# 软件测试平台——详情与生成

**文档版本**：V1.0
**日期**：2026-09-23
**状态**：起草中

---

## 1. 报告生成

- 场景报告（`source = 'scene'`）：场景执行完成后由执行引擎生成，`report_type = 'scene'`，`result` 存场景数据集：

1. **步骤级结果收集**：从 Ryze 结果树收集每个步骤的请求/响应快照（Real* 序列化）、验证器结果、提取器结果、耗时。
2. **结果汇总计算**：总步骤数、通过数、失败数、跳过数、总耗时。
3. **报告写入**：`report_type='scene'`、`external_id` = 场景 ID、`name` = 场景名 + 执行时间戳，`result` 填充场景数据集，同时更新 `api_execution_record.report_id`。
4. **Ryze 快照保存**：平台内执行时保存序列化后的完整 Ryze 结果树至 `api_report.ryze_snapshot`。

- 套件报告（`source = 'schedule'`）：测试计划任务（含立即执行）执行多个场景后聚合生成，`report_type = 'suite'`，`result` 存套件数据集：

1. **场景结果收集**：遍历本次执行各场景的最终结果（各场景执行记录已生成）；无结果的场景写入占位场景数据集（`sceneId = null`、`status = failed`、步骤为空）。
2. **套件汇总计算**：场景数、通过/失败场景数、全部场景步骤总数与通过/失败/跳过数、总耗时。
3. **报告写入**：`report_type='suite'`、`external_id` = 任务 ID、`name` = 任务名 + 执行时间戳，`result` 的 `scenes[]` 填充各场景数据集；将该套件报告 ID 回写至本套件内各场景执行记录的 `report_id`（共享）。
4. **Ryze 快照保存**：平台内执行时聚合生成套件树序列化至 `ryze_snapshot`。

**报告状态判定**（与 `docs/04-detailed-design/05-api-testing/05-api-testing-infra-report.md` 1.6 同口径）：

- 场景报告（落库于场景数据集 `status`，套件数据集内嵌场景同口径）：
  - `success`：无失败步骤且无引擎异常。
  - `partial`：存在失败步骤或执行被取消，但无引擎异常。
  - `failed`：存在引擎异常（步骤配置解析失败、引擎结果为 `error`、结果树与步骤数不匹配等）。
  - 判定顺序：引擎异常 → `failed`；否则全部步骤通过 → `success`；其余（失败步骤 / 执行被取消）→ `partial`。
- 套件报告：仅 `success` / `failed` 两态，套件层面不产生 `partial`：
  - `success`：全部场景 `status = success`。
  - `failed`：存在结果状态非 `success` 的场景（含 `partial`、`failed` 的场景与无结果的占位场景）。

> `partial` 只出现在场景报告与套件数据集的场景级状态中；报告列表当前只含套件报告，故列表与套件详情仅有「通过 / 失败」两态。

**验证器解析失败规则**：验证器表达式解析失败按验证失败处理，该验证器 `status = failed` 并在 `message` 字段记录解析错误信息；该步骤随之计为失败步骤，报告状态按上述口径归为 `partial`（仅引擎异常计 `failed`）。


## 2. 场景执行记录弹窗查看报告

场景编辑器「执行历史」中带 `report_id` 的记录行提供 [报告] 按钮，点击在弹窗（`web/src/pages/project/api-testing/scene/ReportDetailDialog.vue`，标题「报告详情」）内调用报告详情接口 `GET /api/project/reports/:id` 直接展示报告明细，不离开场景编辑页：

- 场景页 [运行] 产生的报告（`source = 'scene'`，`report_type = 'scene'`）不进报告列表，只能通过该执行记录弹窗查看。
- 弹窗内容与详情页共用同一套结果展示组件（`ReportResultView.vue`）：Hero 概览、统计卡、场景卡（处理器 Tab + 步骤卡，展开查看请求/响应快照、验证器明细、提取器结果）。
- 定时任务的场景执行记录（共享套件报告）：弹窗以当前场景 ID 聚焦，从套件数据集 `result.scenes[]` 定位该场景展示步骤明细，顶部显示聚焦横幅并提供「查看完整套件报告」；完整套件视图下弹窗工具栏提供「返回当前场景明细」（见 4）。
- 状态分支：加载中显示遮罩；加载失败以顶部错误消息提示，内容区展示「暂无报告内容」空态；弹窗底部 [关闭] 关闭弹窗。

## 3. 报告查看页

- **入口与定位**：详情页不是独立路由，而是接口测试页「测试报告」菜单（权限 `api-report:view`）下的子状态——报告列表点击报告名称链接或行内 [查看] 后，`ApiTestingPage.vue` 渲染 `web/src/pages/project/api-testing/report/ReportDetailPage.vue`；Hero 右侧 [关闭] 返回列表。
- **报告列表**（`ReportsPage.vue`，本页内嵌）：分页（每页 20 条）、筛选（状态 / 执行方式 / 场景 / 时间范围）、搜索（回车或清空触发的关键字）。
  - 列表列：选择框、报告名称（链接）、类型（套件 / 场景报告）、状态、通过率、耗时、创建时间、操作（查看 / 删除）。
  - 状态列：`success` 通过（绿）、`failed` 失败（红）、`partial` 部分通过（黄）。
  - 批量操作：勾选后出现「已选 N 项 + 批量删除」，二次确认后调用批量删除接口。
  - 筛选参数中场景下拉传入的 `sceneId` 不被后端接收；列表只返回定时任务聚合的套件报告（见 `docs/04-detailed-design/05-api-testing/05-api-testing-infra-report.md` 1.1），场景页 [运行] 直接产生的报告通过场景执行记录弹窗查看（见 2）。
  - 空态：「暂无测试报告，定时任务执行后生成；场景页运行报告可在场景执行历史中查看」。
- **报告详情**（统一由 `ReportResultView.vue` 渲染，接收报告详情与可选 `focusSceneId`、抛出 `view-suite` 事件；详情页 / 免登录分享页 / 场景执行记录弹窗三者复用同一套展示）：
  - **顶部概览（Hero）**：渐变淡绿卡片——报告名称 + 状态章（执行成功 / 执行失败 / 部分通过）+ 来源章（套件数据集 `source = 'schedule'` 显示「定时任务」，否则「平台内执行」）；动作位挂 [分享]、[关闭]（仅详情页，分享页与执行记录弹窗无动作位）；元信息行：环境、触发时间（套件）/ 执行时间（场景）、总耗时、Task ID（套件）/ 场景 ID（场景，等宽字体）。
  - **执行概览（5 项统计卡）**：场景报告与套件定位单场景为步骤口径（总步骤 / 通过 / 失败 / 通过率 / 总耗时）；套件报告整体为场景口径（场景总数 / 通过场景 / 失败场景 / 通过率 / 总耗时）。
  - **聚焦横幅**：执行记录弹窗传入 `focusSceneId` 时只渲染对应场景，顶部 info 提示「当前展示场景「××」的执行明细」并附 [查看完整套件报告]；完整套件视图下由弹窗提供 [返回当前场景明细]。详情页与分享页不传 `focusSceneId`。
  - **处理器 Tab**（环境级 / 场景级复用 `ReportProcessorsTabs.vue`）：仅渲染非空的前置 / 后置页签（数量角标 + 状态圆点），页签面板内为执行顺序提示链（任务级：任务前置 › 场景前置 › 步骤 › 场景后置 › 任务后置；场景级：场景前置 › 步骤 › 场景后置，当前项高亮）与处理器小卡（默认折叠，含名称、方法徽标、状态徽标、URL 行、请求头表、Query / 请求体 / 响应体格式化 code、提取器表、验证器表）。环境级处理器区仅在套件整体视图且存在处理器时渲染。
  - **场景卡**：头部整体可点击展开 / 收起，含场景名、场景 ID、执行时间、四项迷你指标（步骤 / 通过 / 失败 / 耗时）、状态徽标（`partial` 显示「部分通过」、灰色样式）；失败场景头部带红色左边框。场景报告与聚焦场景默认展开，套件场景卡默认收起；展开体为「场景级处理器页签（存在处理器时）+ 步骤卡列表」。
  - **步骤卡**（`ReportStepCard.vue`）：工具栏「测试步骤（N）」+ [全部展开 / 收起]（有步骤才显示）；无步骤时空态「该场景无步骤明细」。头部含序号、步骤名、方法徽标（GET / POST / PUT / DELETE，缺省显示 `HTTP`）、状态徽标、验证器数（仅存在验证器时显示，任一失败标红）、耗时。展开体依次为：请求块（方法 + URL、请求头表、Query 参数、请求体）、响应块（状态码徽标、`HTTP/1.1 · Content-Type`、格式化响应体、响应头表）、验证器表（字段 / 规则 / 期望值 / 实际值 / 结果）、提取器表（引用名 / 字段 / 提取值 / 默认值 / 结果，`message` 有值显示「提取失败」）、`errorMessage` 错误提示条。失败 / 错误步骤默认展开。
  - **场景输出**：
    - 场景报告：Hero + 步骤口径统计卡 + 单场景卡（默认展开：场景处理器 Tab + 步骤区）。
    - 套件报告：Hero + 场景口径统计卡 + 环境处理器卡（任务前置 / 后置）+ 场景卡列表（自上而下平铺，含聚焦与「查看完整套件 / 返回当前场景」定位）。
  - **页脚**：报告生成时间、来源、环境。
  - 组件职责：`ReportResultView.vue` 编排数据（数据逻辑在 `useReportResultView.ts`），`ReportProcessorsTabs.vue`（`useReportProcessors.ts`）/ `ReportStepCard.vue`（`useReportStepCard.ts`）纯展示，状态文案与格式化辅助函数在 `useReportDisplay.ts`；颜色语义引用视觉设计 CSS 变量。
- **加载与错误态**：详情页整体加载遮罩；加载失败以顶部错误消息提示（`ElMessage`），内容区留空；`result` 为空时展示「暂无报告内容」空态。
- **接口与权限**：详情 `GET /api/project/reports/:id`、生成分享 `POST /api/project/reports/:id/share`，权限码均为 `api-report:view`；前端不按权限码隐藏 [分享] 等按钮，越权调用由后端拒绝（HTTP 403）。
- **分享操作**：[分享] 按钮位于 Hero 右上角（始终可用）。打开弹窗时若报告存在**未过期分享**（详情接口 `share` 非空）→ 直接展示现有记录（分享链接、有效期至、分享人）+ [复制]；复制内容为带描述文本（报告名称 / 链接 / 有效期 / 分享人，见 `docs/04-detailed-design/05-api-testing/31-test-report-share.md` 1.3）。无未过期分享 → 弹窗两步式（选有效期，缺省 7 天 → 生成链接），生成后展示并支持复制；[重新生成] 显式覆盖旧分享。


## 4. 执行记录弹窗查看报告

场景执行记录中的 [报告] 按钮打开 `ReportDetailDialog.vue`（复用 3 的 `ReportResultView.vue`：Hero + 统计卡 + 场景卡 / 环境处理器，弹窗内调用报告详情接口，见 2）：

- 场景报告：展示单场景的步骤口径统计卡与步骤明细。
- 套件执行记录：默认按当前场景 `sceneId` 从套件数据集定位该场景展示（聚焦横幅 + 步骤口径统计卡），[查看完整套件报告] 切换为完整套件视图（场景口径统计卡 + 环境处理器卡 + 场景卡列表），完整套件视图下工具栏提供 [返回当前场景明细]。
- 报告详情渲染的通用结构与状态分支约定见 `docs/04-detailed-design/05-api-testing/05-api-testing-infra-report.md` 2。
