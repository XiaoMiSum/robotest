## 1. 报告列表筛选参数

`GET /api/project/reports` 在《API 测试基础设施详细设计说明书》3.4.1 基础上补充以下筛选参数：

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| executionMode | string | 否 | 执行方式筛选：platform |
| reportType | string | 否 | 报告粒度筛选：scene / suite |
| keyword | string | 否 | 搜索关键字：模糊匹配报告名称（场景报告的场景名 / 套件报告的任务名） |

**列表范围**：场景页 [运行] 直接产生的报告（`source = 'scene'`、`report_type = 'scene'`）不进列表；定时任务（含调度页"立即执行"，`source = 'schedule'`，聚合为套件报告）正常展示。列表查询按 `source` 过滤（见《API 测试基础设施详细设计说明书》3.4.1）。

列表响应在 3.4.1 基础上补充字段：

| 字段 | 说明 |
| ---- | ---- |
| name | 报告名称（场景报告：场景名 + 执行时间戳；套件报告：任务名 + 执行时间戳） |
| reportType | 报告粒度：scene / suite |
| sceneName | 场景报告时场景名称快照；套件报告为 null |


## 2. 批量删除报告

- **路径**：`POST /api/project/reports/batch-delete`
- **请求体**：

```json
{
  "ids": ["018f...", "019a..."]
}
```

- **响应**：`{ "success": true }`
- **权限**：项目维护者。


## 3. 刷新报告状态

- **路径**：`POST /api/project/reports/:id/refresh`
- **说明**：报告状态为 `pending_sync` 时调用，重新拉取执行结果并更新报告状态与汇总；成功后状态更新为 `success` / `failed` / `partial`。
- **响应**：更新后的报告状态与汇总。
- **权限**：执行者本人或项目维护者。

---


## 4. 报告清理

复用《API 测试基础设施详细设计说明书》4 定义的数据清理策略：
- 报告与执行记录保留期限默认 90 天（系统配置项）。
- 清理后执行记录保留元数据，报告详情置为「执行结果被清理」。
- `api_report.ryze_snapshot` 随报告一起清理。
